# Lua 安装与环境配置

---

## 各操作系统安装指南

### Linux

#### Arch Linux
```bash
sudo pacman -S lua
```

#### Ubuntu / Debian
```bash
sudo apt update
sudo apt install lua5.4 liblua5.4-dev
# 如果需要 LuaJIT
sudo apt install luajit libluajit-5.1-dev
```

#### Fedora
```bash
sudo dnf install lua lua-devel
```

#### 验证安装
```bash
lua -v
# 输出: Lua 5.4.x Copyright (C) 1994-2024 Lua.org, PUC-Rio
```

---

### macOS

#### 方法一：Homebrew（推荐）
```bash
brew install lua
```

#### 方法二：编译安装
```bash
curl -R -O https://www.lua.org/ftp/lua-5.4.7.tar.gz
tar zxf lua-5.4.7.tar.gz
cd lua-5.4.7
make macosx test
sudo make install
```

---

### Windows

#### 方法一：官方二进制（推荐新手）
1. 访问 [LuaBinaries](https://luabinaries.sourceforge.net/download.html)
2. 下载 `lua-5.4.x_Win64_bin.zip`
3. 解压到 `C:\Lua`
4. 将 `C:\Lua` 添加到系统环境变量 `PATH`

#### 方法二：Chocolatey
```powershell
choco install lua
```

#### 方法三：Scoop
```powershell
scoop install lua
```

#### 方法四：MSYS2
```bash
pacman -S mingw-w64-x86_64-lua
```

## VS Code 配置（推荐初学者）

### 1. 安装 VS Code
从 [code.visualstudio.com](https://code.visualstudio.com) 下载安装。

### 2. 安装 Lua 扩展

在扩展市场搜索并安装：

| 扩展名 | 用途 |
|--------|------|
| `sumneko.lua` | Lua 语言服务器（代码补全、类型检查、跳转定义） |
| `actboy168.lua-debug` | Lua 调试器 |
| `yinfei.luahelper` | 代码格式化、语法检查（备选） |

### 3. 推荐设置（settings.json）

```json
{
 "Lua.runtime.version": "Lua 5.4",
 "Lua.workspace.library": [
 "${3rd}/love2d/library"
 ],
 "Lua.diagnostics.globals": ["love"],
 "Lua.completion.enable": true,
 "Lua.hover.enable": true,
 "[lua]": {
 "editor.tabSize": 2,
 "editor.insertSpaces": true
 }
}
```

### 4. 运行 Lua 代码

- 安装 **Code Runner** 扩展
- 按 `Ctrl+Alt+N` 运行当前文件
- 或使用终端：`lua filename.lua`

## Neovim 配置（推荐高级用户）

### 前提
- Neovim 0.8+
- LazyVim、NvChad 等框架用户可直接进行配置

### 配置 LSP

在 `~/.config/nvim/lua/plugins/lsp.lua` 中添加：

```lua
return {
 "neovim/nvim-lspconfig",
 opts = {
 servers = {
 lua_ls = {
 settings = {
 Lua = {
 runtime = { version = "Lua 5.4" },
 diagnostics = { globals = { "vim" } },
 workspace = { checkThirdParty = false },
 telemetry = { enable = false },
 },
 },
 },
 },
 },
}
```

### 运行快捷键

```lua
-- 在 init.lua 或 plugins 中添加
vim.keymap.set("n", "<F5>", function()
 vim.cmd("!lua %")
end, { desc = "运行当前 Lua 文件" })
```

## 第一个 Lua 程序

### Hello World

创建文件 `hello.lua`：

```lua
print("Hello, Lua!")
```

### 运行

```bash
lua hello.lua
```

### 交互式解释器

```bash
lua
> print("Hello from REPL!")
> a = 10
> b = 20
> print(a + b)
> -- 按 Ctrl+D 退出
```

## Lua 命令行参数

```bash
lua [选项] [脚本 [参数]]

# 常用选项
lua -e "print('一行脚本')" # 执行一行 Lua 代码
lua -i hello.lua # 运行脚本后进入交互模式
lua -v # 查看版本
lua -l module # 加载模块
```

### 脚本内获取命令行参数

```lua
-- test.lua
for i, arg in ipairs(arg) do
 print(i, arg)
end
```

```bash
lua test.lua hello world
-- 1 hello
-- 2 world
```

## 安装包管理器 Luarocks

Luarocks 是 Lua 的包管理器，类似于 Python 的 pip。

### 安装

**Ubuntu/Debian:**
```bash
sudo apt install luarocks
```

**Arch Linux:**
```bash
sudo pacman -S luarocks
```

**macOS:**
```bash
brew install luarocks
```

**Windows (MSYS2):**
```bash
pacman -S mingw-w64-x86_64-luarocks
```

### 基本使用

```bash
luarocks install luasocket # 安装包
luarocks list # 查看已安装的包
luarocks search json # 搜索包
luarocks remove luasocket # 卸载包
```

### 在代码中使用

```lua
local socket = require("socket")
-- 使用 luasocket 库的功能
```

## 环境检查清单

运行以下命令确认环境就绪：

```bash
lua -v # Lua 解释器
luarocks --version # 包管理器
```

创建一个测试文件验证一切正常：

```lua
-- test_env.lua
print("===== 环境测试 =====")
print("Lua 版本: " .. _VERSION)
print("当前目录: " .. os.execute("pwd")) -- Linux/macOS
-- print("当前目录: " .. os.execute("cd")) -- Windows
print("环境配置完成！")
```

```bash
lua test_env.lua
```

如果看到版本号和 "环境配置完成"，恭喜你，Lua 开发环境已准备就绪！
