# SFML

"Simple and Fast Multimedia Library" — 面向对象的 C++ 多媒体库。与 SDL2 功能类似但设计上更"C++ 风格"：模块化类设计、RAII 资源管理、内置的 2D 图形渲染（精灵、形状、文字）。比 SDL2 更好入门。

## 核心组件

| 组件 | 说明 |
|------|------|
| sf::RenderWindow | 窗口和渲染目标 |
| sf::Sprite / Texture | 精灵和纹理 |
| sf::Shape / Text | 矢量图形和文字渲染 |
| sf::Sound / Music | 音效和音乐播放 |
| sf::TcpSocket / UdpSocket | 网络通信模块 |
| sf::Clock / Time | 时间管理和帧率控制 |
| sf::Shader | GLSL 着色器支持 |

## 何时使用

- 2D 游戏快速开发
- 图形学学习项目
- 需要简洁 C++ 接口的多媒体应用
- 新手友好的游戏开发

## 关键特性

C++ 类设计、2D 渲染、音频播放、网络模块、RAII 管理
