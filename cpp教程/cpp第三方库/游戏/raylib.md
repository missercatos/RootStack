# raylib

极简主义的游戏开发库，目标是"让所有人都能轻松享受编程"。零依赖配置，函数式 API 风格，非常适合教学和快速原型。内置 3D 模型加载和着色器支持。整个库理念是"no fancy interfaces, just enjoy coding"。

## 核心组件

| 组件 | 说明 |
|------|------|
| InitWindow / CloseWindow | 窗口生命周期管理 |
| Draw* 系列函数 | 2D/3D 绘制 API |
| LoadModel / DrawModel | 3D 模型加载和渲染 |
| LoadShader | 自定义着色器 |
| raylib math (raymath) | 内置向量/矩阵数学库 |
| PlaySound / LoadMusic | 音频播放 |
| rGui / rGuiLayout | 内置即时模式 GUI 扩展 |

## 何时使用

- 游戏编程入门教学
- Game Jam 和快速原型
- 独立游戏开发
- 想要"无压力"写游戏的场景

## 关键特性

零配置、极简 API、2D/3D 渲染、着色器、数学库、教学友好
