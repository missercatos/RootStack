# OpenCV

"Open Source Computer Vision Library" — 计算机视觉领域的事实标准。包含数千个图像处理、特征检测、目标识别、相机标定等算法。提供 C++、Python、Java 等多语言接口。内含基础的线性代数模块（Mat 类）。

## 核心组件

| 组件 | 说明 |
|------|------|
| cv::Mat | 多维矩阵/图像的核心数据结构 |
| cv::imread / imwrite | 图像读写 |
| cv::GaussianBlur / Canny | 滤波和边缘检测 |
| cv::ORB / SIFT | 特征检测和描述 |
| cv::CascadeClassifier | Haar/目标检测 |
| cv::dnn | 深度学习模型推理 |
| cv::VideoCapture / VideoWriter | 视频流处理 |
| cv::viz / cv::aruco | 3D 可视化和 AR 标记 |

## 何时使用

- 图像处理、视频分析
- 目标检测、人脸识别
- AR/VR 应用
- 传统计算机视觉任务首选

## 关键特性

全面的 CV 算法、GPU 加速、多语言绑定、深度学习接口(DNN 模块)
