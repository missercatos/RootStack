# CGAL

"Computational Geometry Algorithms Library" — 计算几何领域的权威库。提供 2D/3D 几何算法：凸包、三角剖分、网格处理、布尔运算、最邻近搜索等。使用精确算术内核，保证几何计算的正确性。

## 核心组件

| 组件 | 说明 |
|------|------|
| CGAL::Exact_predicates_inexact_constructions_kernel | 常用几何内核 |
| convex_hull_2 / convex_hull_3 | 凸包计算 |
| Delaunay_triangulation_2 / 3 | 德劳内三角剖分 |
| Polygon_mesh_processing | 网格布尔运算和修复 |
| AABB_tree | 包围盒加速结构 |
| Surface_mesh | 半边数据结构网格表示 |
| Polyhedron_3 | 多面体几何体 |

## 何时使用

- CAD 软件开发
- 3D 打印切片和网格处理
- GIS 系统
- 机械设计和几何处理研究
- 需要精确几何布尔运算的场景

## 关键特性

精确几何计算、丰富的几何算法、2D/3D 全覆盖、精确算术
