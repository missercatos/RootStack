# 基础教程第十章: 函数基础  (Functions)
---

##  章节概述

函数是 C++ 程序的基本组织单元，通过将代码分解为独立的功能模块，提高代码的可读性、
可维护性和复用性。本章将讲解函数的声明与定义、参数传递方式（值传递与引用传递）、
返回值、void 函数、函数重载、默认参数、递归函数入门、函数原型与头文件的关系，
以及内联函数的概念与使用。

---
###  第一节: 基础语法与概念
---

#### 1.1 函数的声明与定义

函数由返回类型、函数名、参数列表和函数体组成。

```cpp
#include <iostream>

int add(int a, int b) {
    return a + b;
}

void greet(std::string name) {
    std::cout << "Hello, " << name << "!" << std::endl;
}

int main() {
    int result = add(3, 5);
    std::cout << "3 + 5 = " << result << std::endl;
    greet("World");
    return 0;
}
```

#### 1.2 函数声明（原型）与定义分离

函数可以先声明后定义，声明告诉编译器函数的接口信息。

```cpp
#include <iostream>

int multiply(int a, int b);

int main() {
    std::cout << multiply(4, 7) << std::endl;
    return 0;
}

int multiply(int a, int b) {
    return a * b;
}
```

#### 1.3 参数传递——值传递

值传递时函数接收参数的副本，修改形参不影响实参。

```cpp
#include <iostream>

void increment(int x) {
    x++;
    std::cout << "函数内 x = " << x << std::endl;
}

int main() {
    int a = 10;
    increment(a);
    std::cout << "函数外 a = " << a << std::endl;
    return 0;
}
```

输出：
```
函数内 x = 11
函数外 a = 10
```

#### 1.4 参数传递——引用传递

引用传递时形参是实参的别名，修改形参直接影响实参。

```cpp
#include <iostream>

void increment(int& x) {
    x++;
    std::cout << "函数内 x = " << x << std::endl;
}

void swap(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int a = 10;
    increment(a);
    std::cout << "函数外 a = " << a << std::endl;

    int x = 5, y = 8;
    swap(x, y);
    std::cout << "x = " << x << ", y = " << y << std::endl;
    return 0;
}
```

#### 1.5 返回值

函数通过 return 语句将结果返回给调用者。

```cpp
#include <iostream>
#include <cmath>

double distance(double x1, double y1, double x2, double y2) {
    return std::sqrt((x2 - x1) * (x2 - x1) + (y2 - y1) * (y2 - y1));
}

int max3(int a, int b, int c) {
    int m = a;
    if (b > m) m = b;
    if (c > m) m = c;
    return m;
}

int main() {
    std::cout << "距离: " << distance(0, 0, 3, 4) << std::endl;
    std::cout << "最大值: " << max3(7, 3, 9) << std::endl;
    return 0;
}
```

#### 1.6 void 函数

不需要返回值的函数使用 void 返回类型。

```cpp
#include <iostream>

void printLine(int n, char ch = '-') {
    for (int i = 0; i < n; i++) {
        std::cout << ch;
    }
    std::cout << std::endl;
}

int main() {
    printLine(20);
    printLine(20, '=');
    return 0;
}
```

#### 2.1 函数重载

C++ 允许定义同名但参数列表不同的函数，编译器根据调用时的参数类型和数量选择匹配版本。

```cpp
#include <iostream>

int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}

int add(int a, int b, int c) {
    return a + b + c;
}

int main() {
    std::cout << add(3, 5) << std::endl;
    std::cout << add(1.5, 2.3) << std::endl;
    std::cout << add(1, 2, 3) << std::endl;
    return 0;
}
```

注意：仅返回类型不同不构成重载。

#### 2.2 默认参数

函数参数可以指定默认值，调用时可省略有默认值的参数。

```cpp
#include <iostream>

void printMessage(std::string msg, int times = 1, std::string end = "\n") {
    for (int i = 0; i < times; i++) {
        std::cout << msg << end;
    }
}

int power(int base, int exp = 2) {
    int result = 1;
    for (int i = 0; i < exp; i++) {
        result *= base;
    }
    return result;
}

int main() {
    printMessage("Hello");
    printMessage("Hi", 3);
    printMessage("OK", 2, " ");
    std::cout << std::endl;

    std::cout << power(5) << std::endl;
    std::cout << power(2, 10) << std::endl;
    return 0;
}
```

规则：默认参数必须从右向左连续设置。

#### 2.3 递归函数入门

递归是函数调用自身的编程技巧，每个递归函数必须有基准条件（终止条件）。

```cpp
#include <iostream>

int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

int fibonacci(int n) {
    if (n <= 1) return n;
    return fibonacci(n - 1) + fibonacci(n - 2);
}

int main() {
    std::cout << "5! = " << factorial(5) << std::endl;

    std::cout << "斐波那契数列前10项: ";
    for (int i = 0; i < 10; i++) {
        std::cout << fibonacci(i) << " ";
    }
    std::cout << std::endl;
    return 0;
}
```

#### 2.4 函数原型与头文件

大型项目中，函数声明放在头文件(.h)中，定义放在源文件(.cpp)中。

```cpp
// math_utils.h
#ifndef MATH_UTILS_H
#define MATH_UTILS_H

int add(int a, int b);
int subtract(int a, int b);
double divide(double a, double b);

#endif
```

```cpp
// math_utils.cpp
#include "math_utils.h"

int add(int a, int b) { return a + b; }
int subtract(int a, int b) { return a - b; }
double divide(double a, double b) { return a / b; }
```

```cpp
// main.cpp
#include <iostream>
#include "math_utils.h"

int main() {
    std::cout << add(3, 4) << std::endl;
    std::cout << divide(10.0, 3.0) << std::endl;
    return 0;
}
```

#### 2.5 内联函数（inline）

内联函数建议编译器将函数体在调用处展开，避免函数调用开销，适合短小函数。

```cpp
#include <iostream>

inline int square(int x) {
    return x * x;
}

inline int max(int a, int b) {
    return (a > b) ? a : b;
}

int main() {
    std::cout << square(5) << std::endl;
    std::cout << max(10, 20) << std::endl;
    return 0;
}
```

#### 3.1 案例一：简易计算器

```cpp
#include <iostream>

double calculate(double a, double b, char op) {
    switch (op) {
        case '+': return a + b;
        case '-': return a - b;
        case '*': return a * b;
        case '/':
            if (b == 0) {
                std::cout << "错误: 除数不能为0" << std::endl;
                return 0;
            }
            return a / b;
        default:
            std::cout << "错误: 未知运算符" << std::endl;
            return 0;
    }
}

int main() {
    double a, b;
    char op;

    std::cout << "输入表达式 (如 3 + 5): ";
    std::cin >> a >> op >> b;

    std::cout << a << " " << op << " " << b << " = " << calculate(a, b, op) << std::endl;
    return 0;
}
```

#### 3.2 案例二：汉诺塔（递归经典）

```cpp
#include <iostream>

void hanoi(int n, char from, char to, char aux) {
    if (n == 1) {
        std::cout << "移动盘 1 从 " << from << " 到 " << to << std::endl;
        return;
    }
    hanoi(n - 1, from, aux, to);
    std::cout << "移动盘 " << n << " 从 " << from << " 到 " << to << std::endl;
    hanoi(n - 1, aux, to, from);
}

int main() {
    int n;
    std::cout << "输入盘子数量: ";
    std::cin >> n;
    hanoi(n, 'A', 'C', 'B');
    return 0;
}
```

#### 3.3 案例三：函数重载实现通用打印

```cpp
#include <iostream>
#include <string>

void print(int value) {
    std::cout << "[int] " << value << std::endl;
}

void print(double value) {
    std::cout << "[double] " << value << std::endl;
}

void print(const std::string& value) {
    std::cout << "[string] " << value << std::endl;
}

void print(const int arr[], int size) {
    std::cout << "[array] ";
    for (int i = 0; i < size; i++) {
        std::cout << arr[i];
        if (i < size - 1) std::cout << ", ";
    }
    std::cout << std::endl;
}

int main() {
    print(42);
    print(3.14);
    print(std::string("Hello"));

    int nums[] = {1, 2, 3, 4, 5};
    print(nums, 5);
    return 0;
}
```

> > **解析**: 头文件保护宏通过预处理器条件判断确保头文件内容在同一编译单元中只被包含一次，避免重定义错误。

> [!question] 判断题 10
> 函数的形参和实参可以同名。（ ）
> - [ ]  正确
> - [ ]  错误
>
> > [!success]- 点击查看答案
> > 答案: 正确
> > **解析**: 形参和实参在不同的作用域中，名称相同不会冲突。函数调用时会创建形参变量，与实参是独立的（值传递时）。

### 选择题

> [!question] 选择题 1
> 以下函数调用哪个会导致编译错误？
> ```cpp
> void f(int a, int b = 10, int c = 20);
> ```
> - [ ] A. `f(1);`
> - [ ] B. `f(1, 2);`
> - [ ] C. `f(1, 2, 3);`
> - [ ] D. `f();`
>
> > [!success]- 点击查看答案
> > 正确答案: D
> > **解析**: 参数 a 没有默认值，必须提供。`f()` 没有为 a 提供实参，会导致编译错误。

> [!question] 选择题 2
> 以下代码输出什么？
> ```cpp
> int f(int n) {
>     if (n == 0) return 0;
>     return n + f(n - 1);
> }
> std::cout << f(4);
> ```
> - [ ] A. 4
> - [ ] B. 10
> - [ ] C. 6
> - [ ] D. 24
>
> > [!success]- 点击查看答案
> > 正确答案: B
> > **解析**: f(4) = 4 + f(3) = 4 + 3 + f(2) = 4 + 3 + 2 + f(1) = 4 + 3 + 2 + 1 + f(0) = 4+3+2+1+0 = 10。

> [!question] 选择题 3
> 以下关于引用传递的说法，哪个是正确的？
> - [ ] A. 引用传递会创建参数的副本
> - [ ] B. 引用传递可以接收字面量（如 f(5)）
> - [ ] C. const 引用可以接收字面量
> - [ ] D. 引用传递和值传递效果完全相同
>
> > [!success]- 点击查看答案
> > 正确答案: C
> > **解析**: 非 const 引用不能绑定到字面量或临时值，但 const 引用可以。例如 `void f(const int& x)` 可以调用 `f(5)`。

> [!question] 选择题 4
> 哪种情况下应该优先使用引用传递而非值传递？
> - [ ] A. 传递 int 类型
> - [ ] B. 传递 char 类型
> - [ ] C. 传递大型结构体或类对象
> - [ ] D. 传递 bool 类型
>
> > [!success]- 点击查看答案
> > 正确答案: C
> > **解析**: 大型对象值传递会产生昂贵的拷贝开销，使用 const 引用可以避免拷贝。基本类型（int、char、bool）值传递即可，引用反而可能更慢。

> [!question] 选择题 5
> 以下代码有什么问题？
> ```cpp
> int add(int a, int b) { return a + b; }
> double add(int a, int b) { return a + b; }
> ```
> - [ ] A. 函数名相同
> - [ ] B. 仅返回类型不同不构成重载，编译错误
> - [ ] C. 没有问题
> - [ ] D. 运行时错误
>
> > [!success]- 点击查看答案
> > 正确答案: B
> > **解析**: 两个函数参数列表完全相同（都是 int, int），仅返回类型不同，不构成重载，编译器无法区分。

> [!question] 选择题 6
> `#ifndef MATH_H` 中 `#ifndef` 的含义是？
> - [ ] A. if not defined
> - [ ] B. if not default
> - [ ] C. if no file
> - [ ] D. if not declared
>
> > [!success]- 点击查看答案
> > 正确答案: A
> > **解析**: #ifndef 是 "if not defined" 的缩写，检查宏是否未被定义，是头文件保护的标准写法。

> [!question] 选择题 7
> 以下哪种函数适合标记为 inline？
> - [ ] A. 包含 100 行代码的函数
> - [ ] B. 递归函数
> - [ ] C. 只有一行 return 语句的简单函数
> - [ ] D. 包含文件操作的函数
>
> > [!success]- 点击查看答案
> > 正确答案: C
> > **解析**: 内联适合函数体短小、频繁调用的函数。大型函数内联会增加代码膨胀，递归函数无法完全内联。

> [!question] 选择题 8
> 以下代码的输出是？
> ```cpp
> void modify(int& a, int b) {
>     a = 100;
>     b = 200;
> }
> int main() {
>     int x = 1, y = 2;
>     modify(x, y);
>     std::cout << x << " " << y;
> }
> ```
> - [ ] A. 100 200
> - [ ] B. 1 2
> - [ ] C. 100 2
> - [ ] D. 1 200
>
> > [!success]- 点击查看答案
> > 正确答案: C
> > **解析**: a 是引用传递，修改 a 影响 x（变为 100）。b 是值传递，修改 b 不影响 y（仍为 2）。

> [!question] 选择题 9
> 递归计算 fibonacci(5) 时，fibonacci(2) 被调用了几次？
> - [ ] A. 1 次
> - [ ] B. 2 次
> - [ ] C. 3 次
> - [ ] D. 5 次
>
> > [!success]- 点击查看答案
> > 正确答案: C
> > **解析**: 朴素递归计算斐波那契数列存在大量重复计算。fibonacci(5) 的调用树中 fibonacci(2) 被调用 3 次，这就是递归效率低的原因。

> [!question] 选择题 10
> 以下默认参数设置哪个是合法的？
> - [ ] A. `void f(int a = 1, int b, int c = 3);`
> - [ ] B. `void f(int a, int b = 2, int c = 3);`
> - [ ] C. `void f(int a = 1, int b = 2, int c);`
> - [ ] D. `void f(int a, int b = 2, int c);`
>
> > [!success]- 点击查看答案
> > 正确答案: B
> > **解析**: 默认参数必须从右向左连续设置。B 中 b 和 c 有默认值且在最右边，合法。A、C、D 中间断了（有默认值的参数右边存在无默认值的参数）。
