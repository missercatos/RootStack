
本教程的python部分是基于C体系考虑的，所以一些python原生的内容在这里考虑较少
比如说python的基础语法，循环，分支，变量，输入输出，标准库之类的。

如果说需要阅读细致的关于python的教程内容，网上资源极多且丰富，各家纷纭，百家争鸣，视频课，知识库，开源仓库，课本教材，AI学习，各种各样的方法特别多。这得益于python简单的语法和丰富的框架，使得python的社区成为有史以来规模最大的计算机语言社区，目前最为活跃且资源最为丰富，即使是非计算机领域的其他职业者也在学习python

因此，我们的教程就不必要赘述那些基本的python教程了
这里给出一些链接，是本教程编著者推荐的一些视频课链接，知识库，学习网站

#### 权威文档和仓库

[python官方文档](https://docs.python.org/zh-cn/3/) -这是最权威的网站，也是最推荐一看的网站，虽然上手很难，但是一些具体的模糊点这里应该可以找到最标准的答案

[python官方源代码](https://github.com/python/cpython) -最权威的仓库之一

#### 视频教学

[黑马程序员AI+python教学](https://www.bilibili.com/video/BV1sHU9BmEne/) -比较热门和对新手相对友好的视频课，很适合没接触过编程的新手小白去学习，可以跟着视频学习，且在视频下方也形成了小型社区，更利于学习交流

[黑马程序员python零基础教学](https://www.bilibili.com/video/BV1qW4y1a7fU/) 比较经典的python视频课，从小白入门的数据库开发，程序设计，科学计算的入门

[sentdex](https://www.youtube.com/user/sentdex) 专注于实战型 Python 编程教学，特别是在机器学习和数据科学领域 

[traversy mdeia](https://www.youtube.com/c/TraversyMedia) Web 开发基础方面的优质内容，项目驱动的教学风格

[3小时快速入门python](https://www.bilibili.com/video/BV1944y1x7SW/) -动画演示，视频节奏较快，适合快速了解python

[深度学习框架入门教程](https://www.bilibili.com/video/BV1hE411t7RN/) 相对于上面的系列课程来说，这个课程对新手很友好，主要深挖python的深度学习框架，不是基础教程

[鱼C工作室《零基础入门学习python》](https://www.bilibili.com/video/BV1c4411e77t/?trackid=web_related_0.router-related-2479604-s7xkd.1788577804510.814) -非常经典的python教学课程

[爬虫教程](https://www.bilibili.com/video/BV1uN4y1W7Du/) -面向网络抓取方面的python教学

#### 教学网站和学习类仓库

[菜鸟教程-python3](https://www.runoob.com/python3/python3-tutorial.html) -比较推荐的python学习页面，涵盖的内容很广，从最基础的环境配置到后期的一些框架都有涉及


[菜鸟教程-python2](https://www.runoob.com/python/python-tutorial.html) -同样是菜鸟教程，这里讲的是比较经典的python版本，为什么专门列出来，是因为有一些比较经典的脚本工具是由python2编写的，因为python3相比于python2有较大的改变，所以个别工具无法用python3运行和用python3的逻辑修改

[菜鸟教程主页面](https://www.runoob.com/) -值得一提的是菜鸟教程的主页，映入眼帘的就是python/科学计算的各种框架教学和人工智能的各种教学，虽然在具体项目上菜鸟教程很少涉及，且一些语言的关键讲解有冲突，但是对于初学者来说，这里是极好的增加知识面的地方，且是一个很好的学习python的地方

[小白学python](https://learn-py.org/) -比较有意思的python学习网站，基于python 3.10+编写，零基础学习应该很有意思[文档版](https://walter201230.github.io/Python/) 可以查看具体文档


[REALpython](https://realpython.com/) -高质量的python教程参考库，以长文和代码示例为主

[《pyhon-100天从新手到大师》](https://github.com/jackfrued/Python-100-Days) -非常系统的学习路线

[《30天 Python 编程挑战》](https://github.com/Asabeneh/30-Days-Of-Python) -非常创新的教程，30天，每天给出不同的题目和代码，在挑战中学会python的方方面面

[《Python 语法与核心概念的交互式游乐场和速查表》](https://github.com/trekhleb/learn-python) -非常经典的项目

#### 实战类项目仓库

[Personal Python Projects](https://github.com/kishanrajput23/Personal-Python-Projects) -从初级到中级的 Python 项目合集

#### 工具类的仓库

[生态权威工具合集](https://github.com/vinta/awesome-python) -涵盖了python社区的大量第三方库，工具列表
