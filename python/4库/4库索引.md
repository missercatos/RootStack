
# Python 库大全 -- 4库索引

> C 语言标准库很小，只有几十个头文件；Python 的哲学恰恰相反——"batteries included"（电池已装好），标准库涵盖了从正则到 XML、从邮件到 HTTP Server 的大量模块，开箱即用。
> 标准库底层分析见 [[../2精通/03_字节码与dis：Python也是"编译"的|字节码深度剖析]]。第三方库生态则通过 pip 获取，是 Python 真正的战斗力来源。

> **本教程的定位**：Python 是 C 工程师的"第二把刀"。本库索引强调 `python -c "..."` 一行流用法——能一行解决的，绝不写脚本。
