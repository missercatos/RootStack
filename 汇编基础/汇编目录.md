# 汇编基础教程

汇编是唯一能真正"直接操作硬件"的编程语言。C 语言被称为"可移植汇编"，但有一些操作 C 根本做不到——**特权指令（in/out、cli/sti、rdmsr/wrmsr）只能由汇编发出、裸机第一行代码只能是汇编、中断入口只能是汇编**。本教程立足 RootStack 体系的底层视角，为你揭开从键盘、串口、显存到 CPU 控制寄存器的全部硬件操控秘密。

> 本教程假设你已有 C 或 C++ 基础，了解 [[../c语言教程/1入门/03_变量与数据类型|C/C++ 变量与类型]] 和基本的 [[../计算机原理/计算机原理_索引|计算机组成原理]] 概念。

## x86-64 汇编快速参考

### 通用寄存器

| 64位 | 32位 | 16位 | 8位 | 常见用途 |
|:-----|:-----|:-----|:---|:---------|
| `rax` | `eax` | `ax` | `al` | 返回值 |
| `rbx` | `ebx` | `bx` | `bl` | 被调用者保存 |
| `rcx` | `ecx` | `cx` | `cl` | 第4参数(Linux)/第1参数(Win) |
| `rdx` | `edx` | `dx` | `dl` | 第3参数(Linux)/第2参数(Win) |
| `rsi` | `esi` | `si` | `sil` | 第2参数(Linux) |
| `rdi` | `edi` | `di` | `dil` | 第1参数(Linux)→C++ this指针 |
| `rbp` | `ebp` | `bp` | `bpl` | 栈帧基址 |
| `rsp` | `esp` | `sp` | `spl` | 栈顶指针 |
| `r8`~`r15` | `r8d`~ | `r8w`~ | `r8b`~ | 通用/第5-6参数(Linux) |

### NASM ↔ AT&T 语法对照

| 操作 | NASM (Intel) | AT&T (GCC 风格) |
|------|-------------|-----------------|
| 传送 | `mov rax, rbx` | `movq %rbx, %rax` |
| 取内存 | `mov rax, [rdi+8]` | `movq 8(%rdi), %rax` |
| 存内存 | `mov [rdi], rax` | `movq %rax, (%rdi)` |
| 立即数 | `mov eax, 42` | `movl $42, %eax` |
| 加法 | `add rax, 10` | `addq $10, %rax` |
| 比较 | `cmp rax, rbx` | `cmpq %rbx, %rax` |
| 函数调用 | `call func` | `call func` |
| 返回 | `ret` | `ret` |

> 本教程主力使用 NASM（Intel 语法），关键位置给出 AT&T 对照以衔接 [[../c语言教程/2深化/05_位运算与硬件操作|C 教程的内联汇编章节]]。
