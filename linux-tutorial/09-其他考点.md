## 9.1 环境变量

```bash
# 查看
env
printenv
echo "$PATH"
echo "$HOME"

# 临时设置（仅当前 Shell）
export PATH="$HOME/bin:$PATH"
export EDITOR=vim

# 永久设置 — Shell 配置文件
# ~/.bashrc         交互式非登录 Shell（每次打开终端）
# ~/.profile        登录 Shell
# ~/.bash_profile   登录 Shell

# 示例
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
echo 'export EDITOR=nvim' >> ~/.bashrc

# 系统级
# /etc/profile         全局登录 Shell
# /etc/bash.bashrc     全局交互 Shell
# /etc/environment     简单 KEY=VALUE（所有进程）

# 常用变量
echo "$USER"        # 当前用户
echo "$SHELL"       # 当前 Shell
echo "$LANG"        # 语言环境
echo "$PWD"         # 当前目录
echo "$OLDPWD"      # 上一个目录
echo "$RANDOM"      # 随机数(0-32767)
echo "$UID"         # 用户 UID
```

### PATH 优先级

```bash
# PATH 顺序决定命令查找优先级
# /usr/local/bin:/usr/bin:/bin
# 如果两个位置都有同名程序，先找到先执行
```

## 9.2 硬链接与软链接

### 软链接（符号链接，symbolic link）

```bash
ln -s /usr/bin/python3 /usr/local/bin/python    # 创建
ln -sf /usr/bin/python3.12 /usr/local/bin/python  # 强制覆盖
ls -l /usr/local/bin/python                      # 查看 → 箭头显示目标
readlink /usr/local/bin/python                   # 读取目标
```

```bash
# 特点
# - 可以跨文件系统
# - 可以链接目录
# - 如果原文件删除，软链接失效（断链）
# - 有自己的 inode，内容是目标路径字符串
```

### 硬链接（hard link）

```bash
ln /etc/hosts /tmp/hosts_backup    # 创建
ls -li /etc/hosts /tmp/hosts_backup   # 查看 → inode 号相同
```

```bash
# 特点
# - 同一文件多个目录项（不同名字，相同 inode）
# - 不能跨文件系统
# - 不能链接目录（root 也不行）
# - 原文件删除后，硬链接仍然有效（因为数据还在）
# - ls -l 第二列的数字就是硬链接计数
```

### 对比

| | 软链接 | 硬链接 |
|------|--------|--------|
| 跨设备 | ✓ | ✗ |
| 链接目录 | ✓ | ✗ |
| inode | 不同 | 相同 |
| 原文件删除 | 断链 | 仍然有效 |
| 命令 | `ln -s` | `ln` |

## 9.3 inode 概念

```bash
# inode 存储文件的元数据（文件类型、权限、大小、时间戳、数据块指针）
# inode 不存储文件名和文件内容

# 查看
ls -li                              # 第一列即 inode 号
stat /etc/passwd                    # 查看完整元数据
df -i                               # 查看 inode 使用情况

# 现象：磁盘有空间但报 disk full → inode 耗尽
# 原因：大量小文件（如邮件队列、日志碎片）
```

## 9.4 locale 与字符集

```bash
locale                              # 查看当前设置
locale -a                           # 列出可用

# 设置
echo 'LANG=en_US.UTF-8' | sudo tee /etc/locale.conf
# 或
sudo localectl set-locale LANG=en_US.UTF-8

# 生成 locale（Arch）
echo 'en_US.UTF-8 UTF-8' | sudo tee -a /etc/locale.gen
echo 'zh_CN.UTF-8 UTF-8' | sudo tee -a /etc/locale.gen
sudo locale-gen
```

## 9.5 帮助系统

```bash
# man — 手册页（最重要）
man ls
man 5 crontab               # 第 5 节（配置文件格式）
man -k "disk usage"         # 关键字搜索手册

# man 章节
# 1  用户命令（ls, bash）
# 5  配置文件格式（crontab, fstab）
# 7  杂项/约定（regex, man-pages）
# 8  系统管理（systemctl, mount）

# --help
ls --help

# info（GNU 风格，更详细）
info coreutils

# tldr（简化版示例）
sudo pacman -S tldr
tldr tar
```

## 9.6 常见服务器搭建速览

### Nginx

```bash
sudo pacman -S nginx
sudo systemctl enable --now nginx

# 站点配置 /etc/nginx/nginx.conf
# 独立站点 /etc/nginx/sites-available/
```

### MariaDB (MySQL)

```bash
sudo pacman -S mariadb
sudo mariadb-install-db --user=mysql --basedir=/usr --datadir=/var/lib/mysql
sudo systemctl enable --now mariadb
sudo mysql_secure_installation
```

### Samba（Windows 文件共享）

```bash
sudo pacman -S samba
sudo systemctl enable --now smb nmb

# /etc/samba/smb.conf
[shared]
    path = /srv/samba/shared
    browsable = yes
    writable = yes
    guest ok = no
```

## 9.8 杂项常见考题

1. 软链接断开（红色）意味着什么？ → 目标文件被删除或移动
2. `df -h` 和 `df -i` 区别？ → 前者查磁盘空间，后者查 inode 数量
3. `stat` 命令做什么？ → 显示文件完整元数据（inode、权限、时间）
4. PATH 中 `.` 有什么风险？ → 执行当前目录程序可能被恶意替换
5. `man 5 crontab` 和 `man crontab` 区别？ → 前者是配置文件的文档（第5节），后者是命令文档（第1节）

> [!example] 📝 自测题目

> [!question]- 选择题 1：硬链接和软链接的核心区别是？
> - A. 硬链接可以跨文件系统，软链接不可以
> - B. 硬链接共享 inode，软链接有独立 inode
> - C. 软链接不能链接文件
> - D. 硬链接可以链接目录
>
> > [!success]- 点击查看答案
> > **B**
> > 硬链接与原文件共享同一个 inode，软链接有自己的 inode，内容是目标路径

> [!question]- 选择题 2：磁盘空间充足但无法创建新文件，最可能的原因是？
> - A. 权限不足
> - B. 文件系统损坏
> - C. inode 耗尽
> - D. 磁盘只读
>
> > [!success]- 点击查看答案
> > **C**
> > 每个文件需要一个 inode，大量小文件可能耗尽 inode，用 `df -i` 检查

> [!question]- 判断题 3：删除原文件后，指向它的硬链接仍然可以正常访问数据
> - A. ✓ 正确
> - B. ✗ 错误
>
> > [!success]- 点击查看答案
> > **A. ✓ 正确**
> > 硬链接共享 inode 和数据块，只要还有硬链接指向数据，数据就不会被删除

> [!question]- 选择题 4：`~/.bashrc` 在什么时候被读取？
> - A. 系统启动时
> - B. 每次打开交互式非登录 Shell 时
> - C. 仅在 SSH 登录时
> - D. 仅执行脚本时
>
> > [!success]- 点击查看答案
> > **B**
> > `.bashrc` 在每次打开新的交互式非登录 Shell（如打开新终端窗口）时被读取

> [!question]- 选择题 5：`man` 手册第 5 节的内容是？
> - A. 用户命令
> - B. 系统调用
> - C. 配置文件格式
> - D. 系统管理命令
>
> > [!success]- 点击查看答案
> > **C**
> > 第1节=用户命令，第5节=配置文件格式，第7节=杂项，第8节=系统管理

> [!question]- 判断题 6：硬链接可以跨不同的文件系统创建
> - A. ✓ 正确
> - B. ✗ 错误
>
> > [!success]- 点击查看答案
> > **B. ✗ 错误**
> > 硬链接共享 inode，inode 号只在同一文件系统内唯一，因此不能跨文件系统

> [!question]- 选择题 7：`Ctrl+Z` 在终端中的作用是？
> - A. 终止当前进程
> - B. 挂起（暂停）当前前台进程
> - C. 退出 Shell
> - D. 清屏
>
> > [!success]- 点击查看答案
> > **B**
> > Ctrl+Z 发送 SIGTSTP 信号，暂停前台进程并放入后台作业列表

> [!question]- 选择题 8：环境变量 `PATH` 中目录的搜索顺序是？
> - A. 按字母顺序
> - B. 从左到右
> - C. 从右到左
> - D. 随机
>
> > [!success]- 点击查看答案
> > **B**
> > Shell 按 PATH 中目录从左到右的顺序查找命令，先找到的先执行

> [!question]- 判断题 9：`ln -s` 创建的软链接可以指向目录
> - A. ✓ 正确
> - B. ✗ 错误
>
> > [!success]- 点击查看答案
> > **A. ✓ 正确**
> > 软链接可以指向文件或目录，硬链接则不能链接目录

> [!question]- 选择题 10：`stat` 命令显示的信息不包括？
> - A. 文件大小
> - B. inode 号
> - C. 文件内容
> - D. 修改时间
>
> > [!success]- 点击查看答案
> > **C**
> > `stat` 显示文件的元数据（大小、inode、权限、时间戳等），不显示文件内容
