## 8.1 防火墙

### iptables（传统）

```bash
# 查看规则
sudo iptables -L -v -n               # 详细列表
sudo iptables -L -v -n --line-numbers

# 添加规则
sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT     # 允许 SSH
sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT     # 允许 HTTP
sudo iptables -A INPUT -p tcp --dport 443 -j ACCEPT    # 允许 HTTPS
sudo iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT  # 允许已有连接

# 默认策略
sudo iptables -P INPUT DROP           # 默认拒绝入站
sudo iptables -P OUTPUT ACCEPT        # 默认允许出站
sudo iptables -P FORWARD DROP         # 默认禁止转发

# 删除规则
sudo iptables -D INPUT 3              # 按行号删除
sudo iptables -F                      # 清空链

# 保存（因为是内存中的，重启失效）
sudo iptables-save > /etc/iptables/iptables.rules
```

### nftables（新一代，Arch 默认）

```bash
# 概念：table → chain → rule

# 临时查看
sudo nft list ruleset

# 常见预设配置
cat << 'EOF' | sudo tee /etc/nftables.conf
#!/usr/sbin/nft -f

flush ruleset

table inet filter {
    chain input {
        type filter hook input priority 0; policy drop;

        # 允许回环
        iif "lo" accept

        # 允许已有/相关连接
        ct state established,related accept

        # 允许 SSH
        tcp dport 22 accept

        # 允许 ICMP(ping)
        ip protocol icmp accept
        icmpv6 type { echo-request, nd-router-advert, nd-neighbor-solicit } accept
    }

    chain forward {
        type filter hook forward priority 0; policy drop;
    }

    chain output {
        type filter hook output priority 0; policy accept;
    }
}
EOF

sudo systemctl enable --now nftables
```

### 简单防火墙工具

```bash
# ufw（简化 iptables）
sudo pacman -S ufw
sudo ufw enable
sudo ufw allow 22/tcp
sudo ufw allow 80,443/tcp
sudo ufw status verbose
```

## 8.2 SSH 安全配置

### 服务端 `/etc/ssh/sshd_config`

```bash
# 修改端口
Port 2222

# 禁止 root 登录
PermitRootLogin no

# 仅允许密钥登录（禁止密码）
PubkeyAuthentication yes
PasswordAuthentication no

# 限制用户
AllowUsers alice bob

# 其他安全选项
MaxAuthTries 3
ClientAliveInterval 300
ClientAliveCountMax 2

# 重载
sudo systemctl reload sshd
```

### 密钥认证

```bash
# 生成密钥对
ssh-keygen -t ed25519 -C "alice@arch"
# 输出：~/.ssh/id_ed25519 (私钥) + ~/.ssh/id_ed25519.pub (公钥)

# 复制公钥到服务器
ssh-copy-id alice@192.168.1.100

# 或手动复制
cat ~/.ssh/id_ed25519.pub >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
chmod 700 ~/.ssh

# ~/.ssh/config 客户端配置
Host myserver
    HostName 192.168.1.100
    Port 2222
    User alice
    IdentityFile ~/.ssh/id_ed25519
```

### fail2ban

```bash
sudo pacman -S fail2ban
sudo systemctl enable --now fail2ban

# /etc/fail2ban/jail.local
[sshd]
enabled = true
port = 22
maxretry = 5
bantime = 3600
```

## 8.3 备份策略

### rsync — 增量备份（最常用）

```bash
# 基本语法
rsync -av /source/ /destination/          # 本地 → 本地
rsync -av /source/ user@server:/dest/     # 本地 → 远程
rsync -av user@server:/source/ /dest/     # 远程 → 本地

# 常用参数
rsync -avP /home/alice /backup/           # P=显示进度 + 断点续传
rsync -av --delete /src/ /dst/            # 删除目标多余文件（镜像）
rsync -av --exclude='node_modules' --exclude='.cache' /src/ /dst/
rsync -avz /src/ server:/dst/             # z=压缩传输

# 完整备份脚本
#!/bin/bash
BACKUP_DIR="/backup/home-$(date +%Y%m%d)"
rsync -av --delete \
    --exclude='.cache' \
    --exclude='node_modules' \
    /home/alice/ "$BACKUP_DIR/"
# 保留最近 7 个备份
ls -dt /backup/home-* | tail -n +8 | xargs rm -rf
```

### tar — 归档压缩

```bash
# 创建
tar -czf backup.tar.gz /home/alice        # gzip(.gz)
tar -cjf backup.tar.bz2 /home/alice       # bzip2(.bz2，小)
tar -cJf backup.tar.xz /home/alice        # xz(.xz，最小)

# 解压
tar -xzf backup.tar.gz
tar -xjf backup.tar.bz2
tar -xJf backup.tar.xz

# 查看内容不解压
tar -tzf backup.tar.gz

# 加密备份
tar -cz /home/alice | gpg -c -o backup.tar.gz.gpg
# 解密
gpg -d backup.tar.gz.gpg | tar -xz
```

### dd — 磁盘镜像

```bash
# 整盘备份
sudo dd if=/dev/sda of=/backup/disk.img bs=4M status=progress

# 恢复
sudo dd if=/backup/disk.img of=/dev/sda bs=4M status=progress

# 压缩镜像
sudo dd if=/dev/sda bs=4M status=progress | gzip > disk.img.gz
```

## 8.4 常见考题

1. iptables 和 nftables 区别？ → nftables 是现代化替代，语法更简洁，性能更好
2. SSH 如何禁用密码登录？ → `PasswordAuthentication no`
3. rsync 和 scp 区别？ → rsync 增量传输、支持断点续传、更灵活
4. `chmod 600 ~/.ssh/authorized_keys` 为什么？ → 防止其他人读取密钥
5. 3-2-1 备份原则？ → 3份副本、2种介质、1份异地

> [!question]- 选择题 1：iptables 中 `-P INPUT DROP` 的作用是？
> - A. 删除所有 INPUT 规则
> - B. 设置 INPUT 链的默认策略为丢弃
> - C. 阻止所有输出流量
> - D. 暂停防火墙
>
> > [!success]- 点击查看答案
> > **B**
> > `-P` 设置链的默认策略（Policy），`DROP` 表示不匹配任何规则的包将被丢弃

> [!question]- 选择题 2：SSH 禁止 root 直接登录应在 sshd_config 中设置？
> - A. `DenyRoot yes`
> - B. `PermitRootLogin no`
> - C. `RootLogin disabled`
> - D. `AllowRoot false`
>
> > [!success]- 点击查看答案
> > **B**
> > `PermitRootLogin no` 禁止 root 用户通过 SSH 直接登录

> [!question]- 判断题 3：`rsync --delete` 会删除目标目录中源目录没有的文件
> - A. ✓ 正确
> - B. ✗ 错误
>
> > [!success]- 点击查看答案
> > **A. ✓ 正确**
> > `--delete` 使目标成为源的精确镜像，目标中多余的文件会被删除

> [!question]- 选择题 4：生成 SSH 密钥对推荐使用的算法是？
> - A. RSA 1024
> - B. DSA
> - C. ed25519
> - D. MD5
>

> [!question]- 选择题 5：`tar -cJf backup.tar.xz /data` 中 `-J` 指定的压缩格式是？

> > [!success]- 点击查看答案

> [!question]- 选择题 8：nftables 中规则的层级结构是？
> - A. rule → chain → table
> - B. table → chain → rule

> > [!success]- 点击查看答案

> > nftables 结构为 table（表）包含 chain（链），chain 包含 rule（规则）
