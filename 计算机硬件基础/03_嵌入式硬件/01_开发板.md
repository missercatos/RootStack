## 选购建议

| 用途 | 推荐 | 原因 |
|------|------|------|
| 入门学习 | Arduino Uno R4 | 生态好，教程多 |
| 工业控制 | STM32F4/H7 | 可靠性高，外设丰富 |
| 物联网 | ESP32 | 自带 WiFi/BT，便宜 |
| 边缘计算/AI | Raspberry Pi 5 | Linux 生态，算力强 |
| 机器人 | STM32 + ESP32 | 实时控制+通信 |
| 快速原型 | Arduino + shields | 模块化，快速搭建 |
