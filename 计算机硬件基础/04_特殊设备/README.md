# 特殊设备

> 特殊设备指不属于常规计算机范畴但广泛应用于工程、科研、教育、安防、农业、航拍等领域的专用硬件。

---

## 目录

| 设备 | 用途 | 典型应用 |
|------|------|---------|
| 3D 打印机 | 增材制造 | 快速原型、模型制作 |
| 激光切割/雕刻机 | 减材制造 | 亚克力/木材切割 |
| 示波器 | 信号观测 | 电路调试、嵌入式开发 |
| 逻辑分析仪 | 数字信号分析 | SPI/I2C/UART 协议调试 |
| 万用表 | 电路测量 | 电压/电流/电阻 |
| 可编程电源 | 精确供电 | 嵌入式开发、电池模拟 |
| 机械臂 | 自动化操作 | 工业自动化、教学 |
| CNC 雕刻机 | 减材制造 | 金属/木材加工 |
| 摄像头/相机 | 图像采集 | 安防、航拍、直播 |
| 无人机 | 飞行平台 | 航拍、农业、物流 |
| NAS | 网络存储 | 家庭/企业数据管理 |
| 路由器/交换机 | 网络互联 | 家庭/企业网络 |
| 工控机 | 工业控制 | 工厂自动化 |
