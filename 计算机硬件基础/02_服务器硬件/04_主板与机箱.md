# 服务器主板与机箱

---

## 服务器主板

### 与台式机主板的区别

| 维度 | 服务器主板 | 台式机主板 |
|------|:----------:|:----------:|
| CPU 插座 | 支持多路（2-4 路）| 仅 1 路 |
| 内存插槽 | 8-32 个 | 2-4 个 |
| PCIe 插槽 | 多达 7-13 个 x16 | 2-3 个 |
| 网口 | 2-4 个万兆网口 | 1 个千兆 |
| 远程管理 | IPMI/BMC | 无 |
| 尺寸 | E-ATX / proprietary | ATX / M-ATX |

### 服务器主板品牌

| 品牌 | 说明 |
|------|------|
| 超微（Supermicro） | 服务器主板标杆，型号最多 |
| 华硕（ASUS） | RS 系列服务器 |
| 戴尔（Dell） | PowerEdge 系列 |
| 惠普（HPE） | ProLiant 系列 |
| 联想（Lenovo） | ThinkSystem 系列 |

## 远程管理

服务器主板标配 BMC（Baseboard Management Controller）芯片，支持 IPMI 协议：

- **远程开关机**：无需到机房物理操作
- **远程控制台**：通过网页访问 KVM（键盘+视频+鼠标）
- **硬件监控**：温度、风扇转速、电源状态实时监控
- **远程安装系统**：通过虚拟 ISO 挂载安装镜像

| BMC 品牌 | 说明 |
|---------|------|
| IPMI 2.0 | 通用标准 |
| Dell iDRAC | Dell 专用，功能丰富 |
| HPE iLO | HPE 专用 |
| 超微 BMC | 超微主板标配 |
