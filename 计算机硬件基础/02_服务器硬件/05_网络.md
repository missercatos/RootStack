# 服务器网络设备

> 服务器网络是数据进出的通道。内网带宽决定服务器间通信速度，外网带宽决定用户访问速度。

---

## 网卡

### 按速度分类

| 速率 | 接口 | 典型带宽 | 适用 |
|------|:----:|:--------:|------|
| 1GbE | RJ45 | 125 MB/s | 入门/管理网 |
| 2.5GbE | RJ45 | 312 MB/s | 新一代桌面 |
| 10GbE | SFP+/RJ45 | 1.25 GB/s | 服务器标配 |
| 25GbE | SFP28 | 3.125 GB/s | 数据中心主流 |
| 40GbE | QSFP+ | 5 GB/s | 高性能计算 |
| 100GbE | QSFP28 | 12.5 GB/s | 核心交换 |
| 200GbE | QSFP56 | 25 GB/s | 超算/AI 集群 |
