# 服务器内存

> 服务器内存的核心要求是"可靠"——ECC 纠错能自动修复单比特错误，防止数据损坏导致系统崩溃。

---

## 核心参数

| 参数 | 说明 |
|------|------|
| ECC | Error Correcting Code，自动纠正单比特错误 |
| RDIMM | 带寄存器的 DIMM，支持更大容量 |
| LRDIMM | 加载减少 DIMM，支持最大容量（单条 128GB+）|
| 频率 | DDR4-3200 / DDR5-4800+ |
| 容量 | 16GB / 32GB / 64GB / 128GB / 256GB |
| Rank | 单面/双面，影响兼容性 |

---

## ECC vs 非 ECC

| 维度 | ECC | 非 ECC |
|------|:---:|:------:|
| 纠错 | 自动修复单比特错误 | 无 |
| 价格 | 贵 20-30% | 便宜 |
| 适用 | 服务器/工作站 | 台式机/游戏 |
| 兼容性 | 需要服务器主板支持 | 台式机主板 |

---

## DDR4 vs DDR5 服务器内存

| 维度 | DDR4 | DDR5 |
|------|------|------|
| 频率 | 3200 MHz | 4800-5600+ MHz |
| 电压 | 1.2V | 1.1V |
| 单条容量 | 最大 64GB | 最大 256GB |
| 带宽 | 25.6 GB/s | 38.4-44.8+ GB/s |
| 价格 | 便宜 | 贵 30-50% |

## 内存配置建议

| 用途 | 容量建议 | 配置示例 |
|------|:--------:|---------|
| Web 服务器 | 32-64GB | 2x16GB RDIMM |
| 数据库 | 128-256GB | 4x32GB 或 4x64GB |
| 虚拟化 | 256-512GB | 8x32GB 或 4x128GB |
| 大数据分析 | 512GB-1TB | 8x64GB 或 8x128GB |
| AI 训练 | 256-1024GB | 取决于模型大小 |

**注意**：内存通道数影响带宽。双路服务器有 16 个内存通道（每路 8 通道），应至少填充 8 条内存以充分利用带宽。
