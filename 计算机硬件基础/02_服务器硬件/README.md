# 服务器硬件

> 服务器与台式机的核心区别：7x24 不间断运行、ECC 纠错内存、多路 CPU、RAID 存储、远程管理。服务器硬件的每一个选型都围绕"稳定性"和"可扩展性"展开。

---

## 服务器的分类

| 类型 | 外形 | 适用场景 | 特点 |
|------|------|---------|------|
| 塔式服务器 | 类似台式机 | 小型办公室/入门 | 便宜、噪音低 |
| 机架式服务器 | 扁平，装入机柜 | 数据中心/企业 | 标准化、密度高 |
| 刀片服务器 | 极高密度 | 大型数据中心 | 共享电源/散热 |
| GPU 服务器 | 高性能 | 深度学习/HPC | 多块 GPU |

---

## 服务器由哪些部分组成

| 部件 | 与台式机的区别 | 重要性 |
|------|---------------|:------:|
| CPU | 支持多路（2-8 颗）、ECC 指令集 | 核心 |
| 内存 | ECC 纠错、支持更大容量（TB 级） | 核心 |
| 存储 | RAID 阵列、企业级 SSD | 核心 |
| 主板 | 服务器专用、支持多路 CPU 和大量 PCIe | 核心 |
| 电源 | 冗余电源（1+1 热备） | 高 |
| 网络 | 万兆/25G/100G 网卡 | 高 |
| 散热 | 机柜内强制风冷 | 中 |
