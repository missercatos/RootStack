# CPU（中央处理器）

> CPU 是计算机的核心计算部件。选购 CPU 是装机的第一步——它决定了整机的性能上限和预算分配。

---

## 如何判断 CPU 的性能

### 核心参数

| 参数 | 含义 | 越大越好 |
|------|------|:--------:|
| 核心数（Cores） | 同时处理的任务数 | 是 |
| 线程数（Threads） | 通过超线程虚拟出的逻辑核心数 | 是 |
| 主频（GHz） | 每秒时钟周期数 | 是 |
| 睿频（Turbo Boost） | 自动超频到的最高频率 | 是 |
| 缓存（Cache） | L1/L2/L3 三级缓存容量 | 是 |
| TDP（热设计功耗） | 散热设计参考功耗 | 不是越大越好 |
| 制程（nm） | 晶体管大小，越小越省电 | 是 |

### Intel vs AMD 对比（2024-2026）

| 维度 | Intel | AMD |
|------|-------|-----|
| 主流产品线 | Core i3/i5/i7/i9（12-14代） | Ryzen 3/5/7/9（5000/7000/9000系列） |
| 服务器产品线 | Xeon（Scalable 系列） | EPYC（7003/9004系列） |
| 插槽 | LGA 1700（12-14代）| AM5（Ryzen 7000+）|
| 内存支持 | DDR4/DDR5 | DDR5（仅 AM5）|
| 核显 | UHD 730/770 | Radeon（部分型号有）|
| 功耗 | 中等 | 中等 |
| 价格 | 中等 | 同性能略便宜 |

### 老 CPU 升级价值判断

| 条件 | 是否值得升级 | 说明 |
|------|:----------:|------|
| 现有 CPU < 4 核 | 值得 | 4 核是办公最低线 |
| 现有 CPU 是 DDR3 平台 | 不值得换 CPU | DDR3 平台已到瓶颈，直接换新平台 |
| 现有 CPU 是 DDR4 平台 | 可以换 | 同平台升级（如 i5-8400 → i7-9700） |
| 现有 CPU < 6 代 Intel | 不值得换 CPU | 主板老化，换新平台更划算 |
| 现有 CPU 是 Ryzen 1000/2000 | 可以换 | AM4 通用，直接换 Ryzen 5 5600 |
