# 内存（RAM）

> 内存是 CPU 的工作台——正在运行的程序和数据都临时存放在内存中。内存的容量和速度直接影响多任务和大文件处理的流畅度。

---

## 核心参数

| 参数 | 含义 | 影响 |
|------|------|------|
| 代数 | DDR4 vs DDR5 | DDR5 更快更省电，但价格更高 |
| 容量 | 8GB / 16GB / 32GB / 64GB | 越大多任务越流畅 |
| 频率 | MHz（如 3200 / 5600） | 越高带宽越大 |
| 时序 | CL 值（如 CL16 / CL36） | 越小延迟越低 |
| 电压 | 1.1V（DDR5）vs 1.35V（DDR4） | DDR5 更省电 |
| 通道 | 单通道 vs 双通道 | 双通道带宽翻倍 |

## DDR4 vs DDR5

| 维度 | DDR4 | DDR5 |
|------|------|------|
| 频率 | 2133-4800 MHz | 4800-8000+ MHz |
| 电压 | 1.2V | 1.1V |
| 时序 | CL14-CL22 | CL30-CL40 |
| 带宽 | 25-38 GB/s | 38-64+ GB/s |
| 价格 | 便宜 | 贵 30-50% |
| 平台支持 | Intel 12代前, AMD AM4 | Intel 13代+, AMD AM5 |
| 建议 | 预算紧张/旧平台 | 新装机首选 |

| 虚拟机/开发 | 32-64GB | 多个 Docker 容器 |
| 3D 渲染 | 64GB+ | 大场景渲染 |

### 双通道规则

- 2 条内存 = 双通道（带宽翻倍）
- 4 条内存 = 双通道（不是四通道，消费级平台只支持双通道）
- 优先买 2 条组成双通道，不要买单条

## XMP/EXPO 内存超频

内存标称频率（如 6000 MHz）需要在 BIOS 中开启 XMP（Intel）或 EXPO（AMD）才能生效。不开启则运行在默认频率（DDR5-4800 / DDR4-2133）。

操作步骤：开机按 DEL → 进入 BIOS → 找到 XMP/EXPO 选项 → 选择 Profile 1 → 保存重启。
