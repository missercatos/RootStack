# 显卡（GPU）

> 显卡负责图形渲染和并行计算。游戏、3D 建模、视频剪辑、深度学习都离不开显卡。办公用户可使用 CPU 核显，无需独立显卡。

---

## 核心参数

| 参数 | 含义 |
|------|------|
| GPU 芯片 | 决定性能档次（如 RTX 4070 Ti） |
| 显存容量 | 8GB / 12GB / 16GB / 24GB，影响高分辨率和大模型 |
| 显存类型 | GDDR6 / GDDR6X / HBM3，影响带宽 |
| CUDA 核心数 | NVIDIA 的并行计算单元，越多越快 |
| TDP | 功耗，决定电源功率需求 |
| 接口 | PCIe x16 + 视频输出（HDMI/DP） |
