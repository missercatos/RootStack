# 外设

> 外设包括显示器、键盘、鼠标、音箱等。它们是人机交互的窗口，直接影响使用体验。

---

## 显示器

### 核心参数

| 参数 | 含义 | 选购建议 |
|------|------|---------|
| 尺寸 | 对角线长度（英寸） | 24-27 英寸最主流 |
| 分辨率 | 像素数（1080p/2K/4K） | 27 英寸以上选 2K+ |
| 刷新率 | 每秒画面数（60/144/165Hz） | 游戏选 144Hz+ |
| 面板类型 | IPS/VA/TN/OLED | IPS 通用，OLED 高端 |
| 响应时间 | 像素切换速度（ms） | 游戏选 1ms（GTG） |
| 色域 | sRGB/DCI-P3 覆盖 | 设计选高色域 |
| HDR | 高动态范围 | HDR400 起步 |

| 红米 G27Q | 27 | 2K | 165Hz | IPS | 800 | 性价比游戏 |
| 戴尔 S2722QC | 27 | 4K | 60Hz | IPS | 1500 | 办公设计 |

## 鼠标

### 核心参数

| 参数 | 说明 |
|------|------|
| 传感器 | 光学/激光，DPI 灵敏度 |
| 插拔轮询率 | 125/500/1000Hz，越高越跟手 |
| 重量 | 轻量化趋势（60-80g） |
| 连接 | 有线/2.4G 无线/蓝牙 |
| 微动 | 寿命（8000 万次-1 亿次） |
