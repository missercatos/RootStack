# 主板

> 主板是所有硬件的连接平台。选主板的核心原则：先选 CPU，再选对应插槽的主板，最后看芯片组决定功能。

---

## 主板的核心参数

| 参数 | 说明 |
|------|------|
| 插槽（Socket） | CPU 安装接口，必须与 CPU 匹配 |
| 芯片组 | 决定功能：超频、PCIe 通道数、USB 口数量 |
| 板型（Form Factor） | ATX / M-ATX / ITX，决定尺寸和扩展性 |
| 内存插槽数 | 通常 2-4 个，决定最大内存容量 |
| M.2 插槽数 | NVMe SSD 的数量 |
| PCIe 插槽数 | 显卡/扩展卡的插槽数量和规格 |
| 后置 USB 口 | USB 3.2/Type-C 数量 |
| 网卡 | 2.5G 有线/WiFi 6/7 |

## 选购要点

1. **先选 CPU，再选主板**：Intel 14 代选 B760/Z790，AMD Ryzen 7000 选 B650/X670
2. **不超频选 B 系列**：B760/B650 性价比最高，功能够用
3. **超频选 Z/X 系列**：Z790/X670E 支持超频和更多 PCIe 通道
4. **M.2 数量看需求**：1 块 NVMe 够用选 2 槽主板，需要多块选 3-4 槽
5. **WiFi 按需选**：有线网络稳定选无 WiFi 版，需要无线选 WiFi 版（省一个 USB 网卡）
