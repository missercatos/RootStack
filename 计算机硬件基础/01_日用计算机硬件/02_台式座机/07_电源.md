# 电源（PSU）

> 电源是整机稳定运行的基础。电源功率不足或质量差会导致蓝屏、死机甚至烧毁硬件。选购电源的原则：功率留余量，选有品牌认证的。

---

## 核心参数

| 参数 | 含义 |
|------|------|
| 额定功率 | 电源能持续输出的最大功率（W） |
| 80 Plus 认证 | 转换效率（越高越省电、发热越低） |
| 模组化 | 全模组/半模组/非模组（影响理线难度） |
| 供电接口 | 24pin 主板、8pin CPU、PCIe 显卡供电 |
| 保护机制 | 过压/过流/过温/短路保护 |

## 功率计算

整机满载功耗 = CPU TDP + GPU TDP + 其他部件（约 50-100W）+ 余量（100W）

| 配置 | 推荐电源功率 |
|------|:----------:|
| 办公（核显）| 300-400W |
| 游戏（RTX 4060）| 450-550W |
| 游戏（RTX 4070）| 550-650W |
| 游戏（RTX 4080）| 650-750W |
| 游戏（RTX 4090）| 850-1000W |
| 工作站（双卡）| 1000W+ |

## 选购要点

1. **功率留 20-30% 余量**：满载功耗不要超过电源额定功率的 80%
2. **选 80 Plus Gold 及以上**：Bronze 够用但 Gold 更省电更安静
3. **全模组优先**：理线方便，机箱风道好
4. **选大品牌**：海韵、振华、酷冷至尊、海盗船、鑫谷——杂牌电源可能烧硬件
5. **注意显卡供电接口**：RTX 4090 用 12VHPWR 接口，需确认电源支持
