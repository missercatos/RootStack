## 组装前准备

### 工具

| 工具 | 用途 |
|------|------|
| 十字螺丝刀（PH1/PH0） | 拧固定螺丝 |
| 扎带 | 理线 |
| 导热硅脂（可选） | CPU 散热器安装（部分散热器预涂） |
| U 盘（8GB+） | 制作系统安装盘 |
| 防静电手环（可选） | 防止静电损坏元件 |

### 兼容性检查清单

组装前必须确认以下兼容性：

| 检查项 | 说明 |
|--------|------|
| CPU 插槽 vs 主板 | Intel LGA 1700 vs AMD AM5——不匹配装不上 |
| 内存代数 vs 主板 | DDR4 主板只能用 DDR4，DDR5 主板只能用 DDR5 |
| 主板尺寸 vs 机箱 | ATX 主板只能装 ATX 机箱，M-ATX 可装 ATX 机箱 |
| 显卡长度 vs 机箱 | 查看机箱最大显卡限长 |
| 散热器高度 vs 机箱 | 塔式散热器查机箱 CPU 散热器限高 |
| 电源功率 vs 整机功耗 | 整机满载功耗应低于电源额定功率的 80% |
| 电源尺寸 vs 机箱 | ATX 电源 vs SFX 电源（小机箱用 SFX） |

## 组装步骤详解

### 步骤 1：安装 CPU

1. 打开主板 CPU 插槽的扣具拉杆
2. 将 CPU 的防呆缺口对准插槽的凸起（Intel LGA 1700 有两个缺口，AMD AM5 有一个缺口）
3. 轻轻放入，不要用力按压——靠重力自然落入
4. 扣上扣具，压下拉杆

**注意**：Intel CPU 底部有触点，AMD CPU 底部有针脚。两者都极其脆弱，掉落或弯曲会导致报废。

### 步骤 2：安装内存

1. 打开内存插槽两端的卡扣
2. 对准内存条底部的缺口与插槽凸起（DDR4 和 DDR5 缺口位置不同，不能混插）
3. 垂直按下，两端卡扣自动扣合
4. 双通道安装：若主板有 4 个插槽，优先插第 2 和第 4 槽（从 CPU 近端数起）

### 步骤 3：安装 M.2 SSD

1. 找到主板上的 M.2 槽位（通常在 CPU 和显卡之间）
2. 以 30 度角斜插入 M.2 接口
3. 按下 SSD，用螺丝固定尾部

### 步骤 4：安装 CPU 散热器

1. 若散热器预涂硅脂，直接安装；否则在 CPU 顶盖中心挤一粒米粒大小的硅脂
2. 将散热器对准主板上的安装孔位
3. 按对角线顺序拧紧螺丝（避免压力不均）
4. 将风扇供电线接到主板 `CPU_FAN` 接口

### 步骤 5：主板装入机箱

1. 先将 I/O 挡板从机箱内部按入后部开口
2. 将主板的 I/O 接口对准挡板开口
3. 用螺丝固定主板（至少 6 颗螺丝）

### 步骤 6：安装电源

1. 将电源放入机箱电源仓（通常在底部后方）
2. 从机箱外部拧螺丝固定
3. 将 24pin 主板供电和 8pin CPU 供电穿过机箱背线孔

### 步骤 7：安装显卡

1. 拆除机箱后部对应的 PCIe 挡片（2-3 片）
2. 将显卡插入主板 PCIe x16 插槽
3. 拧螺丝固定显卡挡板
4. 接上显卡供电线（6pin/8pin/12VHPWR）

### 步骤 8：接线

| 线材 | 连接位置 | 说明 |
|------|---------|------|
| 前面板跳线 | 主板 JFP1 | POWER SW, RESET SW, HDD LED, POWER LED（参考主板说明书） |
| 前置 USB | 主板 USB 3.0/Type-C 接口 | 19pin 蓝色接头 |
| 前置音频 | 主板 HD_AUDIO 接口 | 通常在左下角 |
| SATA 数据线 | 主板 SATA 口 + 硬盘 | 传统硬盘需要 |
| 风扇线 | 主板 SYS_FAN 接口 | 机箱风扇 |

### 步骤 9：理线

用扎带将线材固定在机箱背部，避免线材阻挡风道。

### 步骤 10：开机测试

1. 接上显示器、键鼠、电源线
2. 按下开机键，观察是否正常点亮
3. 进入 BIOS（开机时按 DEL/F2），检查 CPU/内存/硬盘是否识别
4. 设置 XMP/EXPO 内存超频（可选）
5. 安装操作系统
