# 机箱

> 机箱是所有硬件的"房子"。机箱的选择影响散热、噪音、扩展性和外观。

---

## 核心参数

| 参数 | 说明 |
|------|------|
| 板型支持 | ATX / M-ATX / ITX（大板型机箱兼容小主板） |
| 显卡限长 | 机箱能容纳的最大显卡长度 |
| CPU 散热器限高 | 机箱能容纳的最大风冷散热器高度 |
| 冷排位置 | 前置/顶置/后置水冷冷排安装位 |
| 风扇位 | 可安装的风扇数量 |
| 硬盘位 | 2.5 寸和 3.5 寸硬盘安装位 |
| 前置接口 | USB/Type-C/音频口 |
| 侧透 | 钢化玻璃侧板（展示内部） |

---

## 机箱类型

| 类型 | 适用 | 特点 |
|------|------|------|
| Mini-ITX | 迷你主机 | 仅支持 ITX 主板，空间紧凑 |
| M-ATX 中塔 | 主流游戏 | 支持 M-ATX/ITX，性价比高 |
| ATX 中塔 | 标准游戏/工作站 | 支持 ATX，扩展性好 |
| ATX 全塔 | 高端/双卡 | 空间大，支持 E-ATX 主板 |
| 开放式测试架 | 超频/评测 | 无侧板，散热好但积灰 |

## 选购要点

1. **板型匹配**：ATX 主板必须用 ATX 机箱，M-ATX 可用 M-ATX 或 ATX 机箱
2. **显卡限长**：购买前查显卡尺寸和机箱限长，留 10mm 余量
3. **风道优先**：前进后出、下进上出是最佳风道
4. **静音需求**：选带隔音棉的机箱（如追风者 G500A）
5. **外观**：侧透看个人喜好，注意钢化玻璃有自爆风险
