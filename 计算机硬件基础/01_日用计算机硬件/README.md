# 日用计算机硬件

> 日用计算机指个人使用的台式机和笔记本电脑。与服务器不同，日用计算机追求性价比、静音、便携（笔记本）等体验指标，而非7x24稳定性。

---

## 日用计算机由哪些部分组成

### 台式机（组装机/品牌整机）

一台台式机由以下部件组成（按安装顺序排列）：

| 部件 | 必需 | 作用 | 预算占比 |
|------|:----:|------|:--------:|
| CPU | 是 | 计算核心，决定程序运行速度 | 20-30% |
| 主板 | 是 | 连接所有硬件的平台 | 10-15% |
| 内存 | 是 | 临时数据存储，多任务的关键 | 10-15% |
| 硬盘 | 是 | 永久存储系统和数据 | 10-15% |
| 电源 | 是 | 供电，决定整机稳定性 | 5-10% |
| 机箱 | 是 | 容纳所有硬件，提供散热风道 | 5-8% |
| 散热器 | 是 | CPU 散热，保证性能不降频 | 3-5% |
| 显卡 | 视需求 | 游戏/渲染/深度学习必需，办公可无 | 0-30% |
| 显示器 | 是 | 输出图像 | 10-20% |
| 键鼠 | 是 | 输入设备 | 2-5% |

### 笔记本电脑

笔记本电脑将上述所有部件集成在一个便携机身中，无法自行更换 CPU/显卡（少数高端型号可换），主要选购维度是品牌和型号。

---

## 台式机 vs 笔记本：如何选择

| 维度 | 台式机 | 笔记本 |
|------|--------|--------|
| 性能 | 同价位性能更强 | 同价位性能弱于台式机 |
| 升级性 | 所有部件可更换 | 通常只可加内存/换硬盘 |
| 散热 | 风道好，性能释放充分 | 散热受限，高负载降频 |
| 便携性 | 不可移动 | 随身携带 |
| 噪音 | 可选静音方案 | 风扇噪音不可避免 |
| 维修 | 单个部件更换，成本低 | 维修成本高，部分部件焊死 |
| 使用场景 | 家用/办公/游戏/工作站 | 移动办公/学生/出差 |

## 台式机组装流程概述

详见 [[02_台式座机/README|台式座机组装指南]]。

简要步骤：

1. 安装 CPU 到主板（对准防呆口，按下扣具）
2. 安装内存（对准缺口，按下卡扣）
3. 安装 M.2 SSD（插入 M.2 槽，拧螺丝固定）
4. 安装 CPU 散热器（涂硅脂，扣上散热器，接风扇线）
5. 将主板装入机箱（先装 I/O 挡板，再固定主板）
6. 安装电源（固定螺丝，接主板 24pin + CPU 8pin）
7. 安装显卡（插入 PCIe x16 插槽，接供电线）
8. 接线（前面板跳线、SATA、风扇、USB）
9. 理线（扎带整理线材，保证风道）
10. 开机测试（先装系统，再进 BIOS 检查硬件识别）
