# 如何根据需求选择硬件

> 本章不是推荐清单，而是选择方法论。面对任何硬件需求，通过以下步骤可以找到正确的答案。

---

## 第一步：明确你要做什么

先回答三个问题：

| 问题 | 为什么重要 |
|------|-----------|
| 要运行什么软件？ | 软件决定硬件（深度学习需要 NVIDIA GPU，iOS 开发需要 Mac） |
| 要处理多大的数据？ | 数据量决定内存和存储容量 |
| 要用多久？ | 3 年以上选更好的配置，1 年过渡选够用即可 |

### 软件-硬件对应关系

| 软件类型 | 必需硬件 | 说明 |
|---------|---------|------|
| Office/WPS | 任意 CPU + 4GB RAM | 10 年前的电脑都够 |
| Chrome（20+ 标签）| 8GB+ RAM | 浏览器是内存杀手 |
| VS Code / IntelliJ | 16GB+ RAM，SSD | Java 项目吃内存 |
| Photoshop | 16GB+ RAM，独立显卡 | GPU 加速滤镜 |
| Premiere / DaVinci | 32GB+ RAM，强 GPU | GPU 加速渲染 |
| AutoCAD / SolidWorks | 独立显卡（专业卡优先）| OpenGL 加速 |
| 游戏（3A 大作）| 独立显卡，16GB+ RAM | 显卡决定帧数 |
| 深度学习训练 | NVIDIA GPU（CUDA）| 显存决定模型大小 |
| 深度学习推理 | NVIDIA GPU 或 NPU | 边缘设备用 NPU |
| 编译大型项目 | 多核 CPU，32GB+ RAM | 并行编译 |
| 虚拟机 | 多核 CPU，大内存 | 每个 VM 需要独立资源 |
| 数据库（MySQL/PostgreSQL）| 大内存，SSD | 缓存越大查询越快 |
| Web 服务器 | 多核 CPU，ECC 内存 | 稳定性优先 |
| 视频监控 | 大容量 HDD，低功耗 CPU | 持续写入 |
| 嵌入式控制 | MCU（STM32/ESP32）| 实时性，低功耗 |

## 第三步：选择具体部件

### CPU 选择路径

```
你要做什么？
├─ 办公/上网 → 4核足够（i3-12100 / Ryzen 5 5600G）
├─ 编程/多任务 → 6-8核（i5-13400F / Ryzen 5 7600）
├─ 游戏 → 看显卡预算，CPU 不是瓶颈
│   ├─ 显卡预算 2000 → i5-13400F / Ryzen 5 7600
│   └─ 显卡预算 5000+ → i7-14700KF / Ryzen 7 7800X3D
├─ 视频剪辑 → 多核优先（i7-14700KF / Ryzen 9 7900X）
├─ 深度学习训练 → CPU 不重要，钱花在 GPU 上
├─ 服务器 → 看核心数（EPYC 核心数最多）
└─ 嵌入式 → 按功耗选（低功耗选 ESP32/L 系列，高性能选 H7）
```

### 显卡选择路径

```
你需要独立显卡吗？
├─ 办公/上网 → 不需要，用核显
├─ 编程/轻度使用 → 不需要
├─ 游戏
│   ├─ 1080p 中画质 → RTX 4060 / RX 7600
│   ├─ 1440p 高画质 → RTX 4070 / RX 7800 XT
│   ├─ 4K 高画质 → RTX 4080 Super / RX 7900 XTX
│   └─ 4K 极致 → RTX 4090
├─ 视频剪辑
│   ├─ 1080p → RTX 4060（NVENC 编码）
│   └─ 4K → RTX 4070+ 
├─ 3D 建模/渲染 → RTX 4070 Ti+（显存越大越好）
├─ 深度学习训练
│   ├─ 入门 → RTX 4060 Ti 16GB（16GB 显存）
│   ├─ 中端 → RTX 4090（24GB 显存）
│   └─ 专业 → A100 80GB / H100
└─ 不玩游戏不做 AI → 不需要独立显卡
```

### 内存选择路径

```
需要多大内存？
├─ 办公/上网 → 8GB 够用，16GB 更舒适
├─ 编程
│   ├─ Web 前端 → 16GB
│   ├─ Java/后端 → 16-32GB
│   └─ 大型项目（Android 源码编译）→ 32-64GB
├─ 游戏 → 16GB（DDR5-5600 或 DDR4-3200）
├─ 视频剪辑
│   ├─ 1080p → 32GB
│   ├─ 4K → 64GB
│   └─ 8K → 128GB
├─ 虚拟机/Docker → 32-64GB（每个 VM 预留 2-4GB）
├─ 服务器 → 看应用（数据库 128GB+，虚拟化 256GB+）
└─ 嵌入式 → MCU 级别（KB 级）到 RPi 级别（GB 级）
```

### 存储选择路径

```
需要多大存储？
├─ 500GB → 1 块 NVMe SSD（办公/轻度使用）
├─ 1TB → 1 块 NVMe SSD（游戏/编程）
├─ 2TB → 1TB SSD + 1TB HDD（视频素材）
├─ 4TB+ → 1TB SSD + 4TB HDD（大量数据）
└─ 10TB+ → NAS（群晖/威联通）
```

### SSD 选择路径

```
选什么 SSD？
├─ 只装系统 → 256GB SATA SSD（够用最便宜）
├─ 系统+常用软件 → 500GB NVMe SSD（PCIe 3.0 入门）
├─ 游戏/编程 → 1TB NVMe SSD（PCIe 4.0 主流）
├─ 视频素材盘 → 2TB NVMe SSD（PCIe 4.0 高速）
└─ 专业工作 → 2TB+ PCIe 5.0 SSD（极速）
```

## 第四步：验证兼容性

### 快速兼容性检查

| 检查项 | 方法 |
|--------|------|
| CPU 插槽 vs 主板 | 查 CPU 规格页的 "Socket" 字段 |
| 内存代数 vs 主板 | 查主板规格页的 "Memory Type" 字段 |
| 内存频率 vs 主板支持 | 查主板 QVL（内存兼容列表） |
| 显卡长度 vs 机箱限长 | 查机箱规格页的 "Max GPU Length" |
| 散热器限高 vs 机箱限高 | 查机箱规格页的 "Max CPU Cooler Height" |
| 电源功率 vs 整机功耗 | 用 online PSU calculator 计算 |
| SSD 接口 vs 主板 | M.2 NVMe 需要主板有 M.2 槽且支持 NVMe 协议 |

### 常见搭配组合

| CPU | 主板 | 内存 | 说明 |
|-----|------|------|------|
| i3-12100 / i5-12400 | B660M | DDR4-3200 | 入门/办公 |
| i5-13400F / i5-13600KF | B760M | DDR4-3200 或 DDR5-5600 | 主流游戏 |
| i7-14700KF | Z790M | DDR5-6000 | 高性能 |
| Ryzen 5 7600 | B650M | DDR5-5600 | AMD 性价比 |
| Ryzen 7 7800X3D | B650M | DDR5-6000 | AMD 游戏神U |
| Ryzen 9 7950X | X670E | DDR5-6000 | AMD 旗舰 |
| Xeon Silver 4410Y | 服务器主板 | DDR5-4800 ECC | 服务器入门 |
| EPYC 9354 | 服务器主板 | DDR5-4800 ECC | 服务器主流 |

## 第五步：老旧硬件的利用

### 老电脑能做什么

| 配置 | 推荐用途 |
|------|---------|
| 10 年前（Core 2 Duo, 2GB）| 路由器/OpenWrt、轻量 NAS、打印服务器 |
| 8 年前（i3-4130, 4GB）| 办公机（WPS/浏览器）、下载机 |
| 5 年前（i5-8400, 8GB）| 轻度游戏、编程学习、家庭服务器 |
| 3 年前（i5-12400, 16GB）| 中度游戏、视频剪辑（1080p）|

### 老硬件升级优先级

| 升级项 | 效果 | 成本 |
|--------|:----:|:----:|
| HDD → SSD | 最大（开机从 1 分钟变 10 秒）| 200 元 |
| 4GB → 16GB | 大（多任务不卡）| 150 元 |
| 加独立显卡 | 大（游戏帧数翻倍）| 500-2000 元 |
| 换 CPU | 中（需换主板）| 不推荐单独换 |

### 老 CPU 参考（还能用的）

| CPU | 年份 | 核心/线程 | 频率 | 推荐用途 |
|-----|:----:|:--------:|:----:|---------|
| Core 2 Duo E8400 | 2008 | 2/2 | 3.0GHz | 路由器/NAS |
| i5-2400 | 2011 | 4/4 | 3.1GHz | 办公 |
| i5-3470 | 2012 | 4/4 | 3.2GHz | 办公 |
| i5-4590 | 2014 | 4/4 | 3.3GHz | 轻度使用 |
| i5-6500 | 2015 | 4/4 | 3.2GHz | 够用的办公机 |
| i5-8400 | 2018 | 6/6 | 2.8GHz | 够用的编程机 |
| i5-10400 | 2020 | 6/12 | 2.9GHz | 主流办公/轻度游戏 |
| Ryzen 5 2600 | 2018 | 6/12 | 3.4GHz | 编程/轻度游戏 |
| Ryzen 5 3600 | 2019 | 6/12 | 3.6GHz | 主流编程/游戏 |

### 老内存参考

| 内存 | 时代 | 主板兼容 | 建议 |
|------|------|---------|------|
| DDR2-667/800 | 2004-2009 | DDR2 主板 | 太老，直接换电脑 |
| DDR3-1333/1600 | 2009-2015 | DDR3 主板 | 可升级到 16GB |
| DDR4-2133/2400 | 2015-2018 | DDR4 主板 | 可升级到 32GB |
| DDR4-3200 | 2019-2023 | DDR4 主板 | 主流，够用 |
| DDR5-4800+ | 2023+ | DDR5 主板 | 新平台标配 |

## 第六步：特殊场景决策树

### 我要做 NAS

```
预算多少？
├─ 1000 元 → 买二手群晖 DS218j（2 盘位）
├─ 2000 元 → 买绿联 DXP2800（2 盘位）
├─ 3000 元 → 买群晖 DS224+（2 盘位）或威联通 TS-264
├─ 5000 元 → 买群晖 DS423+（4 盘位）
└─ 8000 元 → 买群晖 DS923+（4 盘位）

需要几块硬盘？
├─ 1-2TB → 1 块 2TB 红盘（400 元）
├─ 4-8TB → 2 块 4TB 红盘（1000 元）
├─ 10TB+ → 2 块 8TB 红盘（2000 元）
└─ 企业级 → 4+ 块希捷银河（5000 元+）
```

### 我要买无人机

```
用途是什么？
├─ 旅行航拍 → DJI Mini 4 Pro（249g 免注册）
├─ 专业摄影 → DJI Air 3 或 Mavic 3 Pro
├─ 竞速/特技 → DJI Avata 2 或自组 FPV
├─ 农业喷洒 → DJI T25 或 T60
├─ 巡检/测绘 → DJI Matrice 系列
└─ 入门玩玩 → DJI Mini 2 SE（1500 元）

预算多少？
├─ 2000 元以下 → DJI Mini 2 SE / DJI Neo
├─ 3000-5000 元 → DJI Mini 4 Pro / DJI Air 3
├─ 5000-10000 元 → DJI Air 3 / Mavic 3 Classic
├─ 10000-20000 元 → DJI Mavic 3 Pro / Inspire 3
└─ 30000+ → DJI Inspire 3 / 行业无人机
```

### 我要做嵌入式/IoT

```
需要联网吗？
├─ 不需要 → STM32 系列
├─ 需要 WiFi → ESP32 系列
├─ 需要蓝牙 → nRF52840 / ESP32
├─ 需要 4G/5G → SIM800L / SIM7600 + MCU
└─ 需要以太网 → W5500 + MCU / RPi

需要跑 Linux 吗？
├─ 不需要（裸机/RTOS）→ STM32 / ESP32
├─ 需要 → Raspberry Pi / Orange Pi
└─ 需要 AI → Jetson Orin Nano / RPi + Coral
```

### 我要做深度学习

```
什么阶段？
├─ 学习入门 → RTX 4060 Ti 16GB（16GB 显存够入门）
├─ 日常训练 → RTX 4090（24GB 显存）
├─ 大模型微调 → RTX 4090 x2 或 A6000（48GB）
├─ 生产环境 → A100 80GB / H100
└─ 预算有限 → 云 GPU（AutoDL / Lambda Labs）
```

### 我要建家庭影院

```
房间大小？
├─ 卧室（<20平）→ 投影仪（极米 RS Pro 3）
├─ 客厅（20-40平）→ 大尺寸电视（65-85 寸）
└─ 影音室（40平+）→ 激光电视 + 专业音响

音质要求？
├─ 够用 → 电视自带音响 + 回音壁
├─ 较好 → 5.1 声道套装
└─ 发烧 → 7.1.4 全景声 + AV 功放
```
