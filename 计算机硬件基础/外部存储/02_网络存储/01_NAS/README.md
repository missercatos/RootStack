# 01 NAS 网络附加存储

> **NAS（Network Attached Storage）** 是一台"专门管文件的服务器"：插上几块硬盘，接入局域网，你的电脑/手机/电视就能像访问文件夹一样读写里面的数据。它是**家庭与企业最实用的共享/备份方案**。

## 一、NAS 提供什么

| 能力 | 说明 |
|------|------|
| 文件共享 | SMB/NFS，多设备访问同一份数据 |
| 集中备份 | 电脑/手机自动备份、快照 |
| 媒体服务 | 影音库、相册、DLNA |
| 下载/同步 | BT/网盘同步/云盘挂载 |
| 私有云 | 替代部分公有云盘 |
| 虚拟化/容器 | Docker、轻量虚拟机 |

## 其他问题（Q&A）

**Q1：NAS 和移动硬盘有何不同？**
A：移动硬盘是"一个人用、插上才用"；NAS 是"一直在线、多人共享"。NAS 能 7×24、能远程访问、能多副本。

**Q2：NAS 和云盘有何不同？**
A：NAS 数据在**自己手里**（隐私/成本可控），云盘**异地容灾**但依赖服务商。理想是 **NAS + 云备份** 组合。

**Q3：小白适合自建 NAS 吗？**
A：想省心选**成品 NAS**；想折腾/省钱选**自建**（见第 3 篇）。
