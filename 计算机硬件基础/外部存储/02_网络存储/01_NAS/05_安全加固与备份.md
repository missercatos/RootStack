# 安全加固与备份

> NAS 常年在网、存着全公司/全家的数据，是**高风险资产**。本篇给安全加固与备份清单，防止泄露、勒索与丢失。

---

## 一、账号与访问

| 措施 | 说明 |
|------|------|
| 强密码 + 两步验证 | 防暴破/撞库 |
| 最小权限 | 按用户/群组分配，别全盘可写 |
| 关闭默认账号 | 如 admin/guest |
| 禁用不必要服务 | Telnet、FTP、UPnP 等 |
| 限制访问来源 | 内网/白名单/VPN |

---

## 二、网络暴露

- **不要把 SMB/管理面板直接映射到公网**。
- 远程访问优先 **VPN 回连**（WireGuard/Tailscale/ZeroTier）。
- 必须公网暴露时：HTTPS + 强鉴权 + 2FA + 限流 + 反代。

---

## 三、系统与数据

| 措施 | 说明 |
|------|------|
| 及时更新 | 修补漏洞 |
| 快照 | 防误删（但同盘，非万全） |
| **不可变/离线备份** | 防勒索 |
| 加密 | 敏感数据加密/加密卷 |
| 审计日志 | 发现异常访问 |

---

## 四、备份清单

```text
□ 3-2-1: 本地 + 异地(云/离线) 至少两份
□ 定期快照
□ 关键目录自动同步到云
□ 定期恢复演练
□ 备份账号无删除权限 / 不可变
```

---

## 其他问题（Q&A）

**Q1：NAS 被勒索了怎么办？**
A：断开网络，用**离线/不可变备份**恢复；别付赎金。

**Q2：快照能防勒索吗？**
A：能缓解（可回滚），但快照若可被写/删就不保险——需**不可变**。

**Q3：怎么防 NAS 被公网扫描？**
A：不暴露端口 + VPN + 强鉴权 + 关闭 UPnP 自动映射。

**Q4：NAS 自己坏了数据怎么办？**
A：RAID 防盘坏 + 异地备份防整机坏；两者都要。

**Q5：家庭 NAS 有必要这么严吗？**
A：只要联网就有风险；至少做到强密码/2FA/不裸暴露。
