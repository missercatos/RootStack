# 应用与影音服务

> NAS 装好共享只是开始。本篇讲怎么把它用起来：影音库、下载、相册、网盘同步、Docker 等常见玩法。

---

## 一、常见应用

| 应用 | 说明 |
|------|------|
| **影音库** | Jellyfin/Emby/Plex，媒体刮削与串流 |
| **下载** | qBittorrent/Transmission + Aria2 |
| **相册** | Immich/PhotoPrism 自建相册 |
| **笔记/文档** | Nextcloud、Obsidian 同步 |
| **网盘同步** | rclone/Syncthing 与云盘/NAS 互备 |
| **Docker** | 跑各类自托管服务 |
| **备份目标** | 电脑 Time Machine / 系统镜像目标 |

---

## 二、影音服务要点

- 需要**硬件转码**时关注 CPU 核显（Intel Quick Sync 强）。
- 媒体库**命名规范**（电影/剧集）方便刮削。
- 局域网千兆/2.5G 才能流畅播放高码率原盘。
- 外网看片用 VPN（见 [[03_系统软件与远程访问]]）。

---

## 三、Docker 自托管

- 用 Docker/Compose 部署，隔离、易升级。
- 常见组合：反向代理(Nginx Proxy Manager) + 各服务。
- **别把管理面板暴露公网**（见安全加固）。

---

## 四、同步与备份

| 工具 | 用途 |
|------|------|
| Syncthing | 点对点多端同步（无中心） |
| rclone | 与云/对象存储同步 |
| rsync | 定时增量备份 |
| restic/borg | 加密去重备份 |

> NAS 既做"共享"，也做"备份目标/中转"，但**本身也要被备份**（异地）。

---

## 其他问题（Q&A）

**Q1：NAS 转码卡顿怎么办？**
A：用带核显的 Intel CPU 开硬件转码，或降低码率/用 Direct Play。

**Q2：影音库刮削不到海报？**
A：检查文件命名、网络（TMDB 访问）、刮削器设置。

**Q3：Docker 和虚拟机怎么选？**
A：轻量服务用 Docker；需要独立内核/系统的用虚拟机。

**Q4：NAS 能跑下载不停机吗？**
A：能，但注意硬盘 7×24 寿命与散热；用 NAS 盘。
