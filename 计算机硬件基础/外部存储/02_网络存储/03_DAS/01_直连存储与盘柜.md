# 直连存储与盘柜

> DAS 的"简单"是优点也是局限：**没有网络、没有共享、没有冗余（除非自己做）**。企业里它常作为服务器本地盘或扩展柜，配合 RAID/ZFS 使用。

---

## 一、关键部件

| 部件 | 作用 |
|------|------|
| **HBA / RAID 卡** | 连接并提供 RAID |
| **Expander（扩展芯片）** | 一个口带多块盘 |
| **背板（Backplane）** | 盘位与信号连接 |
| **扩展柜（JBOD）** | 增加盘位 |

---

## 二、接口

| 接口 | 特点 |
|------|------|
| SATA | 便宜、单盘 6Gbps |
| SAS | 企业级、双端口、高可靠 |
| U.2 / NVMe | 高性能 |
| 外接 SAS | 连扩展柜 |

---

## 三、DAS 的使用要点

- 冗余靠**主机 RAID/ZFS**，不是 DAS 本身。
- 电源/线缆/背板是常见故障点。
- 扩展柜与主机的连接带宽会**被多盘共享**。

---

## 其他问题（Q&A）

**Q1：DAS、NAS 能混合吗？**
A：能。主机挂 DAS 提供容量，再跑 NAS 软件对外共享，是常见家庭/小型方案。

**Q2：扩展柜热插拔安全吗？**
A：若用支持热插拔的 SAS + 有冗余（如 ZFS 镜像/RAID），可安全更换。

**Q3：DAS 为什么延迟最低？**
A：没有网络转发，走直连总线（SAS/PCIe），路径最短。
