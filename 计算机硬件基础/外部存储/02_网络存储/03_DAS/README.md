# 03 DAS 直连存储

> **DAS（Direct Attached Storage）** = 直接挂在一台主机上的存储：内置硬盘、RAID 卡、外接盘柜都算。它最简单、最快，但**只能被那台主机使用**。

## 一、DAS 的形态

| 形态 | 说明 |
|------|------|
| 主机内置盘 | 最原始的 DAS |
| RAID 卡 + 多盘 | 服务器常见 |
| 外接盘柜（JBOD/扩展柜） | SAS/背板扩展，容量大 |
| 直连 NVMe | 最快 |

---

## 二、与 NAS / SAN 的区别

| | DAS | NAS | SAN |
|--|:---:|:---:|:---:|
| 连接 | 直连主机 | 网络(文件) | 网络(块) |
| 共享 | 不可 | 多客户端 | 通常单主机 |
| 延迟 | 最低 | 中 | 低 |
| 成本 | 低 | 中 | 高 |
| 场景 | 单机扩容 | 共享 | 企业块存储 |

## 其他问题（Q&A）

**Q1：DAS 和"移动硬盘"什么关系？**
A：移动硬盘本质也是 DAS（直连一台主机），只是便携。

**Q2：DAS 能做共享吗？**
A：原生的 DAS 不能；但可以**在主机上装 NAS 软件**把 DAS 变成"共享的存储"。

**Q3：扩展柜（JBOD）安全吗？**
A：本身无冗余；靠主机 RAID 卡或 ZFS 提供冗余。连扩展柜的线/背板故障会导致整柜掉。
