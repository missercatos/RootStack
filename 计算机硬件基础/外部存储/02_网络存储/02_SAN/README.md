# 02 SAN 存储区域网络

> **SAN（Storage Area Network）** 是把存储设备组成一个**专用高速网络**，向服务器提供**块级**存储（服务器把它看成一块本地磁盘）。它面向**企业级**场景：数据库、虚拟化、关键业务。

## 一、SAN 的核心概念

| 概念 | 含义 |
|------|------|
| **块级存储** | 服务器看到的是"裸磁盘"，自己建文件系统 |
| **LUN** | 逻辑单元号，SAN 暴露给主机的"一块盘" |
| **HBA** | 主机总线适配器（光纤/以太网卡） |
| **Fabric** | SAN 交换网络 |
| **多路径** | 多条链路冗余/负载均衡 |

---

## 二、两种主流协议

| 协议 | 底层 | 特点 |
|------|------|------|
| **FC（光纤通道）** | 专用光纤网络 | 高性能、低延迟、贵 |
| **iSCSI** | 以太网 | 便宜、通用、易部署 |
| FCoE | 融合以太网 | 折中 |

---

## 三、SAN vs NAS

| | SAN | NAS |
|--|:---:|:---:|
| 级别 | 块 | 文件 |
| 主机看到 | 一块磁盘 | 文件夹 |
| 协议 | iSCSI/FC | SMB/NFS |
| 场景 | 数据库/虚拟化 | 文件共享 |
| 复杂度 | 高 | 低 |

## 其他问题（Q&A）

**Q1：个人/小团队需要 SAN 吗？**
A：一般不需要。**NAS 足够**；除非要跑数据库/虚拟化且追求块级性能。

**Q2：iSCSI 能家用吗？**
A：能，很多 NAS 支持 iSCSI，可把一部分空间当"网络硬盘"给主机用。

**Q3：SAN 会做 RAID 吗？**
A：会，底层存储阵列通常本身有 RAID/冗余，再通过多路径提高可用性。
