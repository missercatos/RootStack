# 02 网络存储

> **网络存储**指通过网络协议访问的存储设备/系统，用于让**多台设备共享**数据、集中备份、7×24 在线。它把"存储"从"插在主机上的盘"变成"网络里的服务"。本目录按**架构类型**分：NAS、SAN、DAS、分布式与集群。

## 一、四种架构的本质区别

```mermaid
flowchart LR
    subgraph 文件级
      NAS[NAS: 直接给你一个网络文件夹]
    end
    subgraph 块级
      SAN[SAN: 给你一块'网络硬盘']
      DAS[DAS: 直连服务器的硬盘柜]
    end
    subgraph 分布式
      DS[分布式: 多节点拼成一个大海]
    end
```

| 架构 | 你怎么用 | 优点 | 缺点 |
|------|---------|------|------|
| **NAS** | 直接访问共享文件夹 | 简单、便宜、跨平台 | 性能受网络/CPU 限制 |
| **SAN** | 挂载成一块本地磁盘 | 高性能、块级 | 贵、复杂 |
| **DAS** | 服务器直连磁盘柜 | 简单、快 | 只能一台主机用 |
| **分布式** | 多机组成一个大池 | 弹性扩展、高可用 | 复杂、需多节点 |

---

## 二、关键协议

| 协议 | 层级 | 用途 |
|------|------|------|
| **SMB/CIFS** | 文件 | Windows/NAS 共享 |
| **NFS** | 文件 | Linux/Unix 共享 |
| **AFP** | 文件 | 苹果（渐淘汰） |
| **iSCSI** | 块 | 以太网上的"硬盘" |
| **FC / FCoE** | 块 | 光纤通道，高性能 |
| **S3** | 对象 | 云/对象存储 API |

---

## 三、怎么选

| 需求 | 推荐 |
|------|------|
| 家里/小团队共享文件 | **NAS** |
| 数据库/虚拟化要高性能块存储 | **SAN** |
| 单台服务器扩盘 | **DAS** |
| 大规模/高可用/弹性 | **分布式存储** |
