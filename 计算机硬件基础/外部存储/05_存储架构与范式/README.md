## 一、三种存储范式（一句话版）

| 范式 | 你操作的是 | 代表 |
|------|-----------|------|
| **块存储** | 裸扇区/块设备 | 硬盘、SAN、云盘 |
| **文件存储** | 文件与目录 | NAS、SMB/NFS |
| **对象存储** | 对象 + 元数据 | S3/OSS/COS |

> 详见 [[01_三种存储范式]]。

## 二、存储层级（快而贵 → 慢而廉）

```
寄存器 → CPU缓存 → 内存 → 持久内存 → SSD → HDD → 磁带 → 云/离线
 快    ←────────────────────────────────────────→   慢
 贵    ←────────────────────────────────────────→   廉
```

> 详见 [[02_存储层级与性能指标]]。

## 其他问题（Q&A）

**Q1：块/文件/对象能互相转换吗？**
A：能（如对象存储可用 `s3fs` 挂载成文件；文件可做成 iSCSI 块）。但各有最佳场景。

**Q2：为什么要有这么多层？**
A：速度与成本的权衡——用少量昂贵介质做缓存，用大量廉价介质做容量。

**Q3：软件定义存储(SDS)一定好吗？**
A：灵活、便宜，但依赖硬件可靠性与运维能力；关键业务要评估。
