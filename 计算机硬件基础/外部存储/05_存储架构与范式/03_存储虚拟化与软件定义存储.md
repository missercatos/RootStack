# 存储虚拟化与软件定义存储

> **存储虚拟化**把多块物理存储抽象成"一个池"，再按需切分、分层、快照、复制。**软件定义存储（SDS）** 则是把存储能力从专用硬件搬到通用服务器上的软件里。它们是云、超融合、分布式存储的基石。

---

## 一、存储虚拟化做什么

| 能力 | 说明 |
|------|------|
| **池化** | 多盘/多设备合成一个存储池 |
| **切分/供给** | 按需划分 LUN/卷/文件系统 |
| **精简置备** | 先声明大容量，实际按用分配 |
| **分层（Tiering）** | 热数据放 SSD、冷数据放 HDD |
| **快照/克隆** | 时间点副本、快速复制 |
| **复制/迁移** | 跨设备/跨站点同步与迁移 |

---

## 二、三种实现层面

| 层面 | 位置 | 例子 |
|------|------|------|
| 主机层 | 服务器 OS | LVM、ZFS、mdadm |
| 存储层 | 阵列控制器 | 硬件 RAID、企业阵列 |
| 网络层 | 交换/网关 | 存储网关、虚拟化网关 |

---

## 三、软件定义存储（SDS）

| 特点 | 说明 |
|------|------|
| 硬件通用 | 用普通 x86 + 硬盘 |
| 软件定义 | 功能由软件实现 |
| 弹性扩展 | 加节点即加容量/性能 |
| 代表 | Ceph、vSAN、ZFS、MinIO、GlusterFS |

> 与"分布式存储"高度重叠（见 [[计算机硬件基础/外部存储/02_网络存储/04_分布式与集群存储/README|分布式存储]]）。

---

## 四、超融合（HCI）

把**计算 + 存储 + 网络**虚拟化后跑在同一批节点上，存储由各节点本地盘组成（如 vSAN）。特点是**横向扩展、易管理**。

---

## 其他问题（Q&A）

**Q1：SDS 一定比硬件阵列便宜吗？**
A：通常便宜、灵活，但**可靠性与运维**取决于设计，关键业务要评估。

**Q2：LVM 算存储虚拟化吗？**
A：算——主机层的逻辑卷管理，能池化、快照、动态扩缩。

**Q3：精简置备有什么风险？**
A：空间"超卖"，实际写满会**写失败**——需要监控与预留。

**Q4：超融合适合什么场景？**
A：虚拟化/私有云，节点可横向扩展、运维统一；不适合极高性能单点。
