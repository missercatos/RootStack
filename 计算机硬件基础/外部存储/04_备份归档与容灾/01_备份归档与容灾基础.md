# 备份、归档与容灾基础

> 设计任何存储方案前，先问自己：**最坏会丢什么？能接受丢多少、停多久？** 答案决定了你要做备份、归档还是容灾。

---

## 一、为什么"存储"不等于"安全"

数据丢失的常见原因，**大多不是盘坏**，而是：

| 原因 | 占比感受 |
|------|---------|
| 人为误删/误操作 | 高 |
| 病毒/勒索加密 | 高 |
| 软件/逻辑错误 | 中 |
| 硬件故障 | 中 |
| 火灾/水淹/被盗 | 低但致命 |

> RAID/副本防的是"硬件故障"这一类，**防不住前两类**。所以必须有**备份**。

---

## 二、备份的分类

| 维度 | 类型 |
|------|------|
| 范围 | 全量 / 增量 / 差异 |
| 方式 | 文件级 / 块级 / 镜像 / 快照 |
| 位置 | 本地 / 异地 / 离线 / 云 |
| 目标 | 系统 / 数据 / 配置 / 密钥 |

### 全量 / 增量 / 差异
```
全量: A B C D E            (每周一份完整)
增量: +e1 +e2 +e3 +e4      (只备变化, 依赖链)
差异: +e1 +e1e2 +e1e2e3    (备自上次全量以来)
```

---

## 三、容灾的分级

| 级别 | 说明 | 成本 |
|------|------|:----:|
| 数据级 | 只保数据（备份） | 低 |
| 应用级 | 能快速重建服务 | 中 |
| 业务级 | 双活/热备，自动切换 | 高 |

**Site 类型**：冷备（备而不用）、温备（定期同步）、热备（实时同步）。

---

## 四、不可变与勒索防护

勒索病毒会**加密它能写到的所有位置**。防护关键：

| 手段 | 说明 |
|------|------|
| **离线备份** | 备份完拔离/断网 |
| **不可变存储（Immutable）** | 对象锁/WORM，写入后不可改删 |
| **快照** | 存储级时间点副本 |
| **最小权限** | 备份账号不能删除旧备份 |
| **多重备份** | 至少一份离线/异地 |

## 其他问题（Q&A）

**Q1：RAID1 镜像是不是备份？**
A：不是。镜像同步所有改动（包括删除和加密）。

**Q2：云备份会被勒索加密吗？**
A：如果云盘被挂载为可写，就可能。用**不可变/离线**才安全。

**Q3：多久备一次？**
A：看 RPO。关键数据每日甚至实时；冷数据每周/每月。

**Q4：归档要加密吗？**
A：长期留存的数据建议加密，尤其涉隐私/合规。
