# 06 去中心化与边缘存储

> 除了"集中式"（数据中心/NAS/云），还有两类值得了解的存储形态：**去中心化存储**（数据分散在众多节点、由加密与激励保证）与**边缘存储**（把数据放在离用户/设备更近的地方）。

## 一、集中式 vs 去中心化

| | 集中式 | 去中心化 |
|--|:------:|:--------:|
| 数据在哪 | 单一/少数数据中心 | 众多节点 |
| 信任 | 信任服务商 | 密码学 + 共识 |
| 容错 | 服务商内部冗余 | 网络级冗余 |
| 性能 | 高、可控 | 参差 |
| 合规 | 明确 | 复杂 |

> 去中心化不是替代，而是**一种补充**：适合抗审查、抗单点、众筹存储的场景。

---

## 二、边缘存储是什么

把数据/缓存**下沉到离用户近的位置**（基站、边缘机房、CDN 节点），减少延迟与回源流量。典型就是 **CDN**。

---

## 其他问题（Q&A）

**Q1：去中心化存储能替代云吗？**
A：目前不能完全替代；它延迟/可用性/合规仍有挑战，适合特定场景。

**Q2：IPFS 是"永久存储"吗？**
A：不是。IPFS 是内容寻址与分发；要"被保存"需有人 **pin** 或配合激励层。

**Q3：CDN 会存我的数据吗？**
A：CDN 主要缓存**可公开分发**的内容，不适合敏感/私密数据。
