# 07 设备内与嵌入式存储

> 手机、路由器、开发板、SSD、U 盘里都藏着"看不见的存储"：**eMMC、UFS、SPI NAND、NOR Flash、EEPROM、OTP** 等。它们不是外接设备，而是设备的"内置存储"，决定了设备能不能刷机、怎么恢复、寿命多长。

## 一、为什么单独讲

- 刷路由器/开发板/手机时，你要面对的是 **eMMC/NAND** 而不是 U 盘。
- 设备变砖、掉固件、坏块，都和这类存储有关。
- 理解它们，能帮你**刷机、救砖、判断寿命**。

---

## 二、常见类型（详见分章）

| 类型 | 典型设备 |
|------|---------|
| eMMC | 老手机、电视盒、开发板 |
| UFS | 现代手机、旗舰设备 |
| SPI NAND / NOR | 路由器、固件、BIOS |
| EEPROM | 参数、MAC 地址 |
| OTP/fuse | 一次性写入（密钥/序列号） |

## 其他问题（Q&A）

**Q1：eMMC 和 UFS 谁快？**
A：UFS 快得多（全双工、命令队列），eMMC 是半双工。

**Q2：路由器刷机刷坏了能救吗？**
A：看是否有 **Bootloader**（如 U-Boot）与串口/救援模式；NOR/NAND 有坏块会麻烦。

**Q3：手机"存储空间"和"运行内存"是一回事吗？**
A：不是。存储 = eMMC/UFS（掉电不丢）；内存 = RAM（掉电即失）。
