# 03 云备份与归档

> **备份**是为"出事能救回来"；**归档**是为"长期低成本留存"。云备份利用**异地**特性满足"3-2-1"原则；云归档（冷存储）用极低成本保存几乎不访问的数据。

## 一、备份 / 同步 / 归档，别混淆

| | 备份 | 同步 | 归档 |
|--|:----:|:----:|:----:|
| 目的 | 出事可恢复 | 多端一致 | 长期留存 |
| 历史版本 | 有 | 无 | 有（只读） |
| 误删保护 | 有 | **无** | 有 |
| 典型 | restic/云备份 | OneDrive | 冷归档 |

> **同步 ≠ 备份**。同步盘删了就是删了；备份能回滚到昨天。

---

## 二、3-2-1 原则（再次强调）

- **3** 份数据 · **2** 种介质 · **1** 份异地。
- 云是理想的"异地那一份"。
- 高级版 **3-2-1-1-0**：+1 份离线/不可变，0 错误（定期校验）。

---

## 三、云备份 vs 云归档

| | 云备份 | 云归档（冷存储） |
|--|:------:|:---------------:|
| 访问频率 | 会恢复 | 几乎不访问 |
| 成本 | 中 | **低** |
| 取回 | 快 | **慢、可能收费** |
| 例 | 对象存储标准层 | Glacier/归档存储/深度归档 |

## 其他问题（Q&A）

**Q1：备份到云就万无一失了吗？**
A：不。要**定期恢复演练**——没验证过的备份等于没有。

**Q2：勒索病毒会加密云备份吗？**
A：若云盘被挂载为可写，就可能。用**离线/不可变（对象锁）**备份才安全。

**Q3：冷归档取回为什么慢？**
A：为省成本，数据存在低成本介质上，取回需**解冻**（分钟到小时），可能按 GB 收费。

**Q4：敏感数据能上云吗？**
A：先**客户端加密**（密钥自己掌握），或按合规要求不上公网云。

**Q5：云备份贵不贵？**
A：取决于**容量 + 流量 + 取回**。归档层存储费很低，但**取回流量费**要留意。
