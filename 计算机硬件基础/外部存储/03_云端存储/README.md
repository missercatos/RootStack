# 03 云端存储

> **云端存储**是把数据放在**服务商的数据中心**，通过互联网访问。它提供**异地容灾、弹性扩展、按量付费**，是移动存储与家庭 NAS 之外的第三种外部存储。本目录按**服务形态**分：网盘/同步盘、对象存储、云备份与归档。

## 一、云存储的本质

```
你的设备 ──互联网──> 服务商数据中心(海量服务器+分布式存储) ──> 你的数据
```

- 底层通常是**分布式存储**（见 [[计算机硬件基础/外部存储/02_网络存储/04_分布式与集群存储/README]]）。
- 你买的不是"一块盘"，而是**容量 + 可用性 + 传输 + 服务**。

---

## 二、四种常见形态

| 形态 | 你看到 | 适合 |
|------|--------|------|
| **网盘** | 网页/App 里的文件列表 | 存文件、分享 |
| **同步盘** | 本地一个文件夹自动同步 | 多设备协同 |
| **对象存储** | API/控制台里的 bucket | 开发、网站、海量文件 |
| **云备份/归档** | 备份任务/归档库 | 容灾、长期留存 |

---

## 三、与 NAS / 移动存储对比

| | 移动存储 | NAS | 云 |
|--|:--------:|:---:|:--:|
| 数据在哪 | 你手里 | 你家里 | 服务商 |
| 容量 | 有限 | 中 | 近乎无限 |
| 异地容灾 | 无 | 弱 | **强** |
| 隐私可控 | 最好 | 好 | 一般 |
| 依赖 | 无 | 家庭网络/电 | 互联网 |
| 成本 | 一次性 | 一次性 | 订阅/按量 |

> **最佳实践：NAS + 云** —— 本地快、云上异地容灾，互补。

---

## 四、选择与注意

- **不要把所有数据只放云**：依赖服务商与网络，可能限速/停服/被封。
- **敏感数据先加密**再上传（见各篇）。
- **注意合规**：涉密/敏感数据按单位规定，勿随意上公网云。
- **成本模型**：网盘多是订阅；对象存储按量计费（存储+流量+请求），**流量费常是坑**。
