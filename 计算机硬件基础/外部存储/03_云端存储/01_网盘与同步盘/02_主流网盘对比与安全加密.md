# 主流网盘对比与安全加密

> 网盘选型常纠结"用哪家"。本篇按**用途分类**给选择思路，并重点讲**加密**——把敏感数据交给云前的最后一道防线。

---

## 一、按用途分类选择

| 用途 | 侧重 | 建议类型 |
|------|------|---------|
| 存照片/资料 | 容量、价格 | 大容量网盘 |
| 多设备协同办公 | 同步能力、生态 | 同步盘（Office/系统集成） |
| 国内高速传大文件 | 速度、分享 | 国内网盘/对象存储 |
| 跨平台开发 | API/CLI | 对象存储 |
| 隐私敏感 | 端到端加密 | 自建 Nextcloud / 加密后再上传 |

> 没有"最好"，只有"最适合"。可同时用**一个同步盘 + 一个网盘 + 对象存储**组合。

---

## 二、加密方案（重要）

| 方案 | 说明 |
|------|------|
| **Cryptomator** | 为网盘设计的透明加密，跨平台 |
| **VeraCrypt 容器** | 整个加密卷上传 |
| **7-Zip 加密压缩** | 简单应急，文件级 |
| **rclone crypt** | 与对象存储结合的加密层 |
| 端到端加密网盘 | 少见，需确认真的 E2EE |

> 原则：**在本地加密后再上传**，密钥自己保管。这样即使云被攻破/扫描，内容也不泄露。

---

## 三、账号与分享安全

| 措施 | 说明 |
|------|------|
| 强密码 + 两步验证 | 防账号被盗 |
| 分享链接设密码/有效期 | 防外泄 |
| 最小分享 | 只分享必要文件 |
| 定期检查登录设备 | 发现异常 |

---

## 四、成本与限速

- 网盘多为**订阅 + 限速**；对象存储按量（流量费是坑）。
- 大文件长期存放，**归档层**更省。
- 用前算清"上传/下载/取回"的总成本。

---

## 其他问题（Q&A）

**Q1：网盘里的文件服务商能看到吗？**
A：默认能看到（除非 E2EE）。敏感文件先加密。

**Q2：加密后还能在线预览/编辑吗？**
A：不能（云看到的是密文）。需要预览的文件别加密，或放非敏感区。

**Q3：换网盘怎么迁移？**
A：用 `rclone` 直接云到云搬，或先下载再上传。

**Q4：免费网盘可靠吗？**
A：别把**唯一副本**放免费网盘（可能清理/停服）。

**Q5：企业数据能用个人网盘吗？**
A：通常不行。用企业批准的存储与合规通道。
