# 01 网盘与同步盘

> **网盘**（面向文件）与**同步盘**（面向文件夹）是普通人最常用的云存储。二者常被混为一谈，但机制不同：一个"上传下载"，一个"自动同步"。

## 一、网盘 vs 同步盘

| | 网盘 | 同步盘 |
|--|:----:|:------:|
| 操作 | 手动上传/下载 | 本地文件夹**自动同步** |
| 冲突 | 少 | 多设备可能冲突 |
| 用途 | 存文件/分享 | 多设备协同工作 |
| 例子 | 百度网盘、夸克 | OneDrive、iCloud、坚果云、Dropbox |

> 同步盘**删本地会删云端**（双向），别把它当备份（见 [[计算机硬件基础/外部存储/03_云端存储/03_云备份与归档/README]]）。

## 三、限速与成本

- 很多网盘对**非会员限速**、限容量、限分享。
- 同步盘按容量订阅。
- 大文件长期归档，**对象存储/云归档**可能更便宜或有专门优惠（见 [[计算机硬件基础/外部存储/03_云端存储/02_对象存储/README]]、[[计算机硬件基础/外部存储/03_云端存储/03_云备份与归档/README]]）。

---

## 四、安全与隐私

- 云盘内容**服务商可见**（除非端到端加密，罕见）。
- 敏感文件**先用加密工具打包/加密卷**再上传。
- 开启**两步验证**；警惕分享链接泄露。
- 合规要求高的数据**不要上公网云**。

## 其他问题（Q&A）

**Q1：同步盘能当备份吗？**
A：**不能**。同步是双向的，误删会同步删除。备份要**保留历史、可回滚**。

**Q2：网盘下载很慢怎么办？**
A：多为**非会员限速**。可换服务、或用对象存储/自建（NAS）。

**Q3：网盘会永久保存吗？**
A：不保证。可能因违规、长期未登录、服务停运而清理。**不要只存一份**。

**Q4：怎么保护网盘里的隐私？**
A：上传前用 **7-Zip 加密 / VeraCrypt 容器 / Cryptomator** 加密，密钥自己保管。

**Q5：网盘和 NAS 怎么配合？**
A：NAS 做本地主力，**自动把关键目录备份/同步到云**，实现异地容灾。
