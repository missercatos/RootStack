# 网盘与同步盘原理选型

> 选网盘别只看"容量大不大、免不免费"，要看**速度、同步能力、隐私、生态、稳定性**。理解"网盘是上传下载、同步盘是双向镜像"，就能避开"同步当备份"的大坑。

---

## 一、同步盘的工作机制

```
本地文件夹 ←──双向同步──> 云端 ←──双向同步──> 其他设备
```

- 核心是**变更检测 + 增量传输 + 冲突处理**。
- **增量同步**（只传改动块）比整体上传省流量、快。
- 多设备同时改同一文件 → **冲突副本**（如 "文档(冲突副本).docx"）。

---

## 二、选型维度

| 维度 | 关注点 |
|------|--------|
| 速度 | 是否限速、是否有国内节点 |
| 同步 | 是否支持选择性同步、局域网加速 |
| 隐私 | 是否端到端加密、是否扫描内容 |
| 生态 | 与系统/办公软件集成程度 |
| 分享 | 链接/权限/过期控制 |
| 稳定性 | 是否长期运营、有免费额度 |

---

## 三、进阶：与 NAS/对象存储组合

| 需求 | 组合方案 |
|------|---------|
| 本地快 + 异地容灾 | NAS + 云同步/备份 |
| 大文件、长期存放 | 对象存储 + 归档 |
| 多设备协同 | 同步盘 + LAN 加速 |
| 隐私优先 | 自建 Nextcloud + 加密 |

## 其他问题（Q&A）

**Q1：同步盘占用本地空间怎么办？**
A：用**选择性同步/按需下载**（文件保留在云端，用时才下载）。

**Q2：同步冲突是怎么产生的？**
A：两台设备离线改同一文件后同时上传。避免多设备同时编辑同一文件。

**Q3：怎么让云同步更快？**
A：选支持**增量同步 + 国内节点/局域网加速**的服务；避开限速时段。

**Q4：公司文件能用个人网盘吗？**
A：**通常不行**（合规/保密）。用企业获批的网盘/云。

**Q5：Nextcloud 自建是啥？**
A：把"网盘"装在自己的服务器/NAS 上，数据自己掌控，可端到端加密（见 [[计算机硬件基础/外部存储/02_网络存储/01_NAS/03_系统软件与远程访问]]）。
