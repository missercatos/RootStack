# 06 手机与便携设备存储

> 手机、平板、播放器、随身听本身就是**大容量移动存储**，还能通过 **OTG** 当"主机"读写 U 盘/硬盘。本篇讲手机与便携设备在"移动存储"里的角色。

## 一、手机作为存储的角色

| 方向 | 说明 |
|------|------|
| 手机 **←** 电脑 | 通过 USB/MTP 传文件 |
| 手机 **→** 外设 | 通过 OTG 读 U 盘/键鼠/网卡 |
| 手机 **↔** 云 | 相册/文件自动同步 |
| 手机 **→** 存储卡 | microSD 扩展（部分机型） |

> 手机是"最随身"的移动存储，但**容量有限、接口封闭**，重要数据仍需多备份。

---

## 二、连接协议

| 协议 | 特点 |
|------|------|
| **MTP** | 媒体传输，安卓默认，兼容好但慢、易卡 |
| **PTP** | 仅照片 |
| **USB 大容量(UMS)** | 直接暴露为磁盘（少见于手机） |
| 无线 | 隔空投送/互传/局域网共享 |

## 其他问题（Q&A）

**Q1：手机插 U 盘没反应？**
A：①手机需支持 **OTG**；②线/转接头要支持数据传输；③U 盘文件系统（FAT/exFAT）要兼容。

**Q2：电脑传文件到手机很慢/总断开？**
A：MTP 本身慢；换**数据线（原装）**、换 USB 口、或用无线传输 App。

**Q3：手机照片怎么安全备份？**
A：自动同步到云 + 定期用 OTG 把 U 盘/硬盘接手机导出，做到**多副本**。

**Q4：安卓能直接把 U 盘格式化成给手机用吗？**
A：能，部分机型支持在存储设置里格式化 SD 卡；注意格式化为设备要求的格式。
