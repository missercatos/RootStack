# 刻录实践与工具

> 刻录光盘看似老派，但做**系统安装盘/归档盘**时仍有价值。本篇讲工具、命令、校验与稳定刻录的要点。

---

## 一、工具

| 工具 | 平台 | 用途 |
|------|------|------|
| ImgBurn | Windows | 刻 ISO、校验 |
| Brasero / K3b | Linux | 图形化刻录 |
| `xorriso` / `growisofs` | Linux 命令行 | 刻录/校验 |
| `cdrdao` | Linux | 音轨/DAO |
| `cdrskin` | Linux | 后端 |

---

## 二、Linux 命令行示例

```bash
# 刻录 ISO（蓝光/DVD）
growisofs -dvd-compat -Z /dev/sr0=image.iso
# 或
xorriso -as cdrecord -v dev=/dev/sr0 -eject image.iso

# 看光盘信息 / 引导
xorriso -indev /dev/sr0 -report_el_torito plain
```

## 三、稳定刻录要点

| 要点 | 说明 |
|------|------|
| **降速刻录** | 如 4x/8x，比标称更快更稳 |
| 好盘 | 归档级/M-DISC |
| 供电稳定 | 外置光驱尤其注意 |
| 关闭占用 | 刻录时别跑重负载 |
| 刻后校验 | `cmp` 或读回哈希 |

---

## 四、刻录失败排查思路

```text
盘 → 换一张已知好盘试试
光驱 → 是否老化/脏污
速度 → 降低速度重刻
软件 → 换工具/换 ISO
数据 → 先校验源 ISO 哈希
```

## 其他问题（Q&A）

**Q1：刻录时提示"缓冲区下溢"？**
A：供电/速度/盘问题。降速、换盘、别同时跑重任务。

**Q2：能多次续刻（多区段）吗？**
A：BD/DVD 支持多区段追加，但兼容性差；一次性刻满最省心。

**Q3：刻好的盘过段时间读不出？**
A：染料老化/划伤。尽快拷出并翻录到新盘。

**Q4：外置光驱推荐吗？**
A：偶尔用可以；长期刻录建议内置/供电充足的外置。
