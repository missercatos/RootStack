# 类型、刻录与归档

> 光盘看似"过时"，但在**冷数据归档**里仍有硬价值：不怕电磁、不怕掉电、单位成本低。关键是**选对盘、刻对方式、定期校验**。

---

## 一、盘片结构（为什么怕光怕热）

```
标签层 → 保护层 → 反射层 → 记录层(染料/相变) → 基底
```

- **CD/DVD-R**：有机染料，激光烧出"坑"，长期受光热会衰减。
- **BD-R**：无机记录层，更耐久。
- **M-DISC**：特殊无机层，宣称超长寿命。

---

## 二、刻录文件系统

| 格式 | 说明 |
|------|------|
| ISO9660 | 光盘标准 |
| Joliet | Windows 长文件名 |
| Rock Ridge | Unix 权限 |
| UDF | 大文件/可续写（DVD/BD 常用） |
| El Torito | **可引导光盘**的引导目录 |

---

## 三、校验与抽检

- 刻完**立刻校验**：`cmp` 比对或哈希。
- 归档后**每隔几年抽检**：能读、哈希一致。
- 发现读错误 → 立即迁移到新介质。

---

## 四、Linux 常用命令

```bash
# 刻录 ISO 到光驱
xorriso -as cdrecord -v dev=/dev/sr0 overwrite=off image.iso
# 或
growisofs -Z /dev/sr0=image.iso
# 查看光盘内容/引导
xorriso -indev /dev/sr0 -report_el_torito plain
```

## 其他问题（Q&A）

**Q1：为什么刻录失败/写坏盘？**
A：盘质量差、刻录速度过高、供电/缓存不足。**降速刻录**（如 4x）更稳。

**Q2：可擦写盘（RW/RE）能反复刻吗？**
A：能，但次数有限（几十~上千次），且比一次性盘寿命短。

**Q3：光盘能当系统盘启动吗？**
A：能，Windows/Linux 安装光盘都靠 **El Torito** 引导，见 [[计算机硬件基础/外部存储/01_移动存储/01_U盘/03_制作系统启动盘与PE]]。

**Q4：怎么让光盘保存更久？**
A：避光、干燥、低温、竖直存放；用**归档级/M-DISC**；定期校验并翻刻。

**Q5：光驱读不出盘，是盘还是光驱的问题？**
A：换一张已知好盘测试区分；光驱激光头老化也会读不出。
