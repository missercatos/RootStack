# 02 移动硬盘

> **移动硬盘**是把硬盘（机械 HDD 或固态 SSD）装进带外壳的盒子里、通过 USB/雷电连接的便携大容量存储。容量大、单位成本低，是**备份和冷数据**的主力。

## 一、两大类

| | 移动机械硬盘 | 移动固态硬盘(移动 SSD) |
|--|:-----------:|:---------------------:|
| 介质 | 磁盘盘片 | NAND 闪存 |
| 容量 | 1T–20T+ | 250G–8T |
| 速度 | 100–250 MB/s | 500–2000 MB/s |
| 抗震 | **差**（怕摔） | 好 |
| 噪音/发热 | 有/低 | 无/中 |
| 单位成本 | 低 | 高 |
| 适用 | 备份、冷数据、大容量归档 | 剪辑、随身系统、高频传输 |

> **结论**：**容量便宜选机械，速度便携选固态。**

---

## 二、选型速查

| 需求 | 推荐 |
|------|------|
| 家庭备份/照片库 | 2.5 寸移动机械 2–4T |
| 大容量冷归档 | 3.5 寸 + 外接电源，8T+ |
| 视频剪辑/大文件 | 移动 SSD（NVMe，USB 3.2 Gen2） |
| 随身系统 WTG | 移动 SSD（4K 性能高） |
| 三平台通用 | exFAT 分区 |

---

## 三、使用注意

1. **机械盘怕摔、怕带电移动**：运行时别搬动。
2. **写完安全弹出**：防缓存未落盘。
3. **别做唯一副本**：移动盘也会坏。
4. **供电**：3.5 寸需外接电源；前置 USB 口/Hub 可能供电不足。
5. **重要数据加密**：丢了也不怕被读。

## 其他问题（Q&A）

**Q1：移动硬盘插上"咔咔"响不识别？**
A：机械盘磁头/电机故障的最典型征兆。**立即停用**，别再通电尝试；重要数据找专业恢复。

**Q2：移动硬盘和 U 盘怎么选？**
A：要容量/备份 → 移动硬盘；要小巧便携/做启动盘 → U 盘。

**Q3：为什么我的移动硬盘速度远低于标称？**
A：①接到 USB 2.0 口；②机械盘本身只有 100–200MB/s；③线材/桥接瓶颈；④SMR 盘写入掉速。

**Q4：移动 SSD 会像 U 盘那样掉速吗？**
A：大文件持续写入也可能因 SLC 缓存用尽而掉速，但通常仍远快于 U 盘。
