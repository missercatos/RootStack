# 使用保养与数据安全

> 移动硬盘"能用"和"用得久、不丢数据"是两回事。本篇讲使用习惯、保养与数据安全，把故障挡在发生之前。

---

## 一、使用习惯

| 习惯 | 原因 |
|------|------|
| 运行时别移动机械盘 | 磁头碰撞盘片 |
| **安全弹出 / sync** | 防缓存未落盘 |
| 别边充电边高负载 | 供电/发热 |
| 避开前置口/Hub | 供电不足掉盘 |
| 竖直/平放稳定，防摔 | 机械盘怕摔 |

---

## 二、保养

| 项 | 建议 |
|----|------|
| 防潮防高温 | 电子/机械寿命 |
| 防磁防振 | 尤其机械盘 |
| 定期通电 | 防长期静置问题 |
| 清理散热 | 移动 SSD 高速读写发热 |
| 外壳保护 | 防磕碰 |

---

## 三、数据安全

| 措施 | 说明 |
|------|------|
| **加密** | VeraCrypt/BitLocker/LUKS |
| **多副本** | 3-2-1，别做唯一 |
| **定期校验** | 哈希/读回，防静默损坏 |
| **备份演练** | 确认能恢复 |
| 防丢失 | 加密 + 标记联系方式 |

---

## 四、故障预防清单

```text
□ 重要数据不止一份
□ 盘已加密(若含敏感)
□ 每次安全弹出
□ 定期 SMART/健康检查
□ 机械盘无异常声响
□ 备份可正常恢复
```

---

## 其他问题（Q&A）

**Q1：移动硬盘可以长期插着不拔吗？**
A：可以，但注意散热与休眠；做 NAS 请用内置盘位。

**Q2：硬盘有异响还能用吗？**
A：立即停用并备份；异响多为物理故障前兆。

**Q3：SSD 移动盘要不要定期通电？**
A：长期不通电可能电荷流失，建议定期通电刷新。

**Q4：怎么防止移动盘丢失导致泄露？**
A：全盘加密；密码/密钥另存；必要时用"自毁"类方案。

**Q5：移动硬盘寿命到了有什么征兆？**
A：掉速、异响、识别困难、SMART 告警、坏道增多。
