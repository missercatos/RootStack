# 原理与选型

> 移动硬盘 = **盘体（HDD/SSD）+ 桥接芯片 + 外壳**。理解桥接与供电，就能解释大多数"速度不对、认不出、掉盘"的问题。

---

## 一、结构

```
主机 USB → [USB-SATA / USB-NVMe 桥接芯片] → [HDD 盘体 / SSD]
```

- **桥接芯片**：把 USB 协议转成硬盘的 SATA/NVMe 协议。桥接质量影响性能与稳定性。
- **外壳**：散热、防震（机械盘尤其需要）。
- **供电**：2.5 寸通常总线供电；**3.5 寸必须外接电源**。

---

## 二、机械（HDD）vs 固态（SSD）

| | HDD | SSD |
|--|:---:|:---:|
| 随机性能 | 差 | 极好 |
| 速度上限 | ~200 MB/s | 500–2000+ MB/s |
| 抗震 | 差 | 好 |
| 寿命 | 机械磨损(数年) | 写入寿命(TBW) |
| 数据可恢复性 | 相对可恢复 | 损坏难恢复 |

> 机械盘**摔一下就可能报废**；固态盘**主控一挂数据也难救**。都别做唯一副本。

---

## 三、接口与速度

| 接口 | 实际上限 | 说明 |
|------|:--------:|------|
| USB 2.0 | ~30 MB/s | 别用 |
| USB 3.0 | ~400 MB/s | 够机械盘跑满 |
| USB 3.2 Gen2 | ~900 MB/s | 移动 SSD |
| 雷电 3/4、USB4 | 2–3 GB/s | 高端移动 SSD |

- **SMR vs CMR（机械盘）**：SMR 盘连续写入会掉速，做仓库盘注意。
- **缓存**：机械盘也有缓存；写满后掉速。

---

## 四、选型要素

| 要素 | 建议 |
|------|------|
| 容量 | 备份 = 数据量 × 2 以上；按需 |
| 类型 | 备份/归档→机械；速度/随身系统→SSD |
| 接口 | 至少 USB 3.0；SSD 用 3.2 Gen2 以上 |
| 供电 | 3.5 寸配原装电源；2.5 寸注意口/线 |
| 主控/桥接 | 大厂成品更省心；DIY 盒注意桥接芯片 |
| 是否加密 | 敏感数据选带硬件加密或自建加密卷 |

## 其他问题（Q&A）

**Q1：移动硬盘一定要格式化吗？**
A：新盘通常已格式化为 NTFS/exFAT，可直接用；跨平台建议转 exFAT。见 [[02_分区文件系统与加密]]。

**Q2：移动硬盘能分区吗？**
A：能，和内置盘一样（见 [[计算机硬件基础/外部存储/01_移动存储/01_U盘/02_分区文件系统与格式化]]）。但**跨平台大容量**通常一个 exFAT 分区最省事。

**Q3：为什么桥接的 SSD 达不到内置速度？**
A：USB 带宽 + 桥接芯片 + 协议开销。想接近内置速度用雷电/USB4。

**Q4：移动硬盘能长期通电吗（做 NAS 盘）？**
A：可以但**不推荐**：USB 桥接与休眠机制不适合 7×24；要做 NAS 请用内置盘位（见 [[计算机硬件基础/外部存储/02_网络存储/01_NAS/README]]）。

**Q5：怎么判断是不是 SMR 盘？**
A：查型号资料；或观察**连续写入掉速**是否明显。做冷备/归档影响不大。
