# 分区、文件系统与加密

> 移动硬盘出厂大多已格式化，但"能读"≠"适合你"。本篇讲清楚该用什么分区表、什么文件系统、怎么加密。

---

## 一、出厂常见格式

| 出厂格式 | 说明 | 问题 |
|----------|------|------|
| NTFS | Windows 友好 | macOS 默认只读 |
| exFAT | 跨平台 | 部分老设备不认 |
| HFS+/APFS | 苹果 | 非苹果生态不友好 |

> 想三平台通用，**转成 exFAT**。

---

## 二、分区表选择

| 场景 | 推荐 |
|------|------|
| 现代机器、容量 >2T | **GPT** |
| 老设备、兼容性 / 虚标坏盘 | **MBR** |

> 大容量盘（>2TiB）**必须 GPT**，否则用不满容量。

---

## 三、分区方案

| 方案 | 说明 |
|------|------|
| **单分区 exFAT** | 最简单、跨平台最省心（推荐） |
| 多分区（各平台专用） | 如 NTFS + HFS+ 各一份，复杂、易浪费 |
| 加密卷 + 普通区 | 敏感数据放加密卷，普通数据放明文区 |

---

## 四、加密方案

| 方案 | 平台 | 特点 |
|------|------|------|
| **VeraCrypt** | 跨平台 | 整盘/分区/容器加密，兼容最好 |
| BitLocker To Go | Windows | 系统集成 |
| LUKS | Linux | 原生、功能强 |
| 硬件加密盘 | 跨平台 | 无需软件，认准正规品牌 |

> **加密 = 防泄露 + 便于销毁（丢密钥即废）。** 但**密钥必须另行备份**，否则自己也会打不开。

---

## 五、格式化注意

- 转格式前**先备份**（转换有风险）。
- 用 exFAT 时注意簇大小（大文件多可大簇）。
- 机械盘可做**慢速格式化**顺带扫坏道。
- 3.5 寸盘注意供电稳定，格式化时别断。

---

## 其他问题（Q&A）

**Q1：移动硬盘在 mac 上只读？**
A：NTFS 默认只读。改 exFAT 或装写入插件。

**Q2：整个盘加密后，换电脑能打开吗？**
A：装对应软件 + 记得密码即可（VeraCrypt/LUKS 跨平台；BitLocker 跨平台较弱）。

**Q3：分区表损坏，数据会不会全没？**
A：不一定。先**备份/镜像整盘**，再用 `testdisk` 尝试恢复分区表；别急着格式化。

**Q4：能不能一个盘同时给 Windows 和 mac 用？**
A：可以，用 exFAT；或分区做 NTFS + HFS+（但两边互读不完美）。

**Q5：格式化会影响寿命吗？**
A：快速格式化几乎无影响；**完整格式化会全盘读写一遍**，对机械盘是负担、对 SSD 消耗一次全盘写入。
