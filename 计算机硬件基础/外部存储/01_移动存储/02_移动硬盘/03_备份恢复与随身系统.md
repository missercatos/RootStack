# 备份、恢复与随身系统

> 移动硬盘最常见的使命是**备份**，最怕的是**坏盘丢数据**。本篇讲备份原则、数据恢复思路，以及把系统装进移动硬盘（WTG）。

---

## 一、备份原则：3-2-1

| 原则 | 含义 |
|------|------|
| **3** 份数据 | 至少 3 个副本 |
| **2** 种介质 | 例如 SSD + 云 / 机械盘 + 光盘 |
| **1** 份异地 | 防火防盗防丢失 |

> 移动硬盘是其中"1 份"，**绝不能是唯一副本**。

### 常见备份类型
| 类型 | 说明 |
|------|------|
| 全量 | 每次完整备份，占空间 |
| 增量 | 只备变化，快但依赖链 |
| 差异 | 备自上次全量以来的变化 |
| 镜像/克隆 | 可引导的整体克隆（如 Clonezilla） |

## 二、备份工具

| 工具 | 平台 | 特点 |
|------|------|------|
| `rsync` | Linux/mac | 增量、可靠、脚本化 |
| Borg / restic | 跨平台 | 去重、加密、快照 |
| Duplicati | 跨平台 | 图形化、支持云 |
| 文件历史/时间机器 | Win/mac | 系统自带 |
| Clonezilla | 跨平台 | 整盘/分区镜像 |

## 三、数据恢复思路（顺序很重要）

```text
1. 立即停止对该盘写入！
2. 先整盘镜像(ddrescue)到好盘，后续都在镜像上操作
3. 用 testdisk 恢复分区表 / photorec 恢复文件
4. 机械盘有异响 → 断电，找专业机构
```

- **机械盘异响（咔咔/咯噔）**：磁头/电机故障，别反复通电。
- **SSD 掉盘/不识别**：主控或掉电损坏，自行恢复极难。
- **误删/误格式化**：越早停止写入越好。

---

## 四、Windows To Go / 随身系统

- 把完整系统装进**移动 SSD**，插哪用哪。
- 要求：USB 3.0+、UEFI、良好的 4K 性能。
- 注意事项见 [[计算机硬件基础/外部存储/01_移动存储/01_U盘/04_盘内微型系统与持久化]]。
- 机械移动硬盘做 WTG **体验很差**，不推荐。

---

## 五、日常保养

| 注意 | 原因 |
|------|------|
| 运行时别移动机械盘 | 磁头碰撞盘片 |
| 安全弹出 | 落盘 |
| 防潮防高温 | 电子元件寿命 |
| 定期校验备份 | 备份也会静默损坏 |
| 做异地副本 | 防丢失/灾害 |

## 其他问题（Q&A）

**Q1：移动硬盘做备份，怎么知道备份没坏？**
A：定期**校验**（哈希）、尝试**恢复演练**；别只在备份日成功、恢复日才发现坏了。

**Q2：机械盘摔了一下不认了，能修吗？**
A：轻微可能只是接口/板子问题；若异响多为磁头损伤，需开盘（专业无尘环境）。**别自己拆**。

**Q3：SSD 移动盘突然变小/只读？**
A：主控进入保护或颗粒耗尽。尽快把数据拷出，别再写。

**Q4：备份和同步有什么区别？**
A：**同步**是双向镜像（删了会跟着删），**备份**是保留历史、可回滚。别把同步当备份。

**Q5：能不能用移动硬盘直接跑系统长期用？**
A：移动 SSD 可以（WTG），但注意散热、供电与拔插风险；机械盘不行。
