# 07 软盘与其他历史介质

> 在 U 盘之前，人们用**软盘、ZIP、MO、MiniDisc** 等移动介质。它们今天基本退场，但仍可能出现在**老设备、老数据、复古玩家**的场景里。

## 二、为什么"老盘读不出来"

- **磁介质老化/掉磁**：软盘、ZIP、磁带都会。
- **机械磨损**：驱动器难找、易坏。
- **专有格式/加密**：系统与软件早已消失。

## 其他问题（Q&A）

**Q1：还能读 3.5 寸软盘吗？**
A：需要**软驱 + 老主板 FDD 接口**或 USB 软驱；数据可能已损坏，尽量**镜像**抢救。

**Q2：怎么抢救老介质里的数据？**
A：①先**做整盘/整带镜像**（能读一遍算一遍）；②再用工具解析镜像；③别反复读一张已脆弱的盘。

**Q3：老硬盘（IDE/SCSI）数据怎么取？**
A：用 **IDE/SATA 转接器**或老机器/虚拟化环境；优先**克隆**再分析。

**Q4：这些介质还值得用吗？**
A：收藏/复古可以；**存重要数据不建议**（容量小、可靠性差、设备难找）。
