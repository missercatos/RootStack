# 老电脑与复古计算

> 历史介质离不开**老电脑**：很多软盘/ZIP/老硬盘只有在旧硬件或虚拟化里才能读。本篇讲怎么用老机器/模拟器抢救与体验。

---

## 一、为什么需要老电脑

| 需求 | 原因 |
|------|------|
| 读取软盘/老接口 | 现代主板没有 FDD/IDE/SCSI |
| 运行老系统/老软件 | 兼容性 |
| 复古游戏/体验 | 原汁原味 |

---

## 二、三条路线

| 路线 | 说明 |
|------|------|
| **老硬件实机** | 最原汁原味，但难找、难维护 |
| **虚拟化** | 用 VMware/VirtualBox/QEMU 装老系统 |
| **模拟器** | DOSBox、PCem、86Box（模拟老硬件） |

> 读**物理介质**通常仍需转接器或老机器；软件/数据可在虚拟机里跑。

---

## 三、常见转接与工具

| 目的 | 工具 |
|------|------|
| IDE/老硬盘 → USB | IDE-SATA/USB 转接器 |
| 软盘 → USB | USB 软驱 |
| SCSI → USB | SCSI 转接卡（少见、贵） |
| 老系统 | QEMU / 86Box / DOSBox |
| 数据抢救 | ddrescue + testdisk/photorec |

---

## 四、注意

- 老介质脆弱，**先镜像再折腾**。
- 老电源/电容老化，注意安全。
- 保存老机器干燥、防尘。

---

## 其他问题（Q&A）

**Q1：现在的电脑能读 IDE 硬盘吗？**
A：用 **IDE-USB/SATA 转接器**，或插到老主板上。

**Q2：86Box 和 DOSBox 区别？**
A：86Box **模拟整机硬件**（含 BIOS/显卡），更像真机；DOSBox 侧重 DOS 兼容。

**Q3：怎么把软盘镜像写回软盘？**
A：用 `dd` 把 `.img` 写回软驱设备（需软驱 + 合适主板）。

**Q4：老硬盘数据还值得救吗？**
A：看价值。优先**镜像**，再分析；物理坏道用 ddrescue。
