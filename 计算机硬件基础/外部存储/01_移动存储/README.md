## 一、移动存储的共同原理

无论哪种移动存储，内部都可抽象为：

```
主机接口(USB/SATA/读卡器) → 控制器/桥接芯片 → 存储介质(闪存/磁盘/光盘) + 缓存
```

- **接口**：USB 最通用；存储卡经读卡器；光盘经光驱。
- **控制器**：闪存类做地址翻译（FTL）与纠错；磁盘类用桥接芯片。
- **介质**：NAND 闪存、磁盘盘片、光盘染料/相变、磁带磁粉。
- **缓存**：写入先进缓存，**"保存成功"≠已落盘**。

## 三、如何选择

| 需求 | 推荐 |
|------|------|
| 拷文件、做系统启动盘 | U 盘（64–128G 足够） |
| 大量备份/冷数据 | 移动硬盘（机械，便宜大容量） |
| 频繁大文件/剪辑 | 移动 SSD |
| 相机/无人机/手机 | SD/TF 卡（看速度等级） |
| 长期离线归档 | 蓝光光盘 / LTO 磁带 |
| 多系统随身启动 | U 盘 + Ventoy / 移动 SSD |

---

## 四、使用移动存储的铁律

1. **先验真假与健康**（虚标盘/坏盘是最大坑）。
2. **写完务必安全弹出 / `sync`**，防止缓存未落盘。
3. **重要数据至少两份**，移动盘只做其中一份。
4. **跨平台选 exFAT**（无 4G 单文件限制）。
5. **启动盘遵循"盘要真、方式匹配固件、写完必校验"**。
6. **来历不明的设备有安全风险**（BadUSB）。
