# 03 SD 卡与存储卡

> **存储卡**是以 SD/microSD/CFexpress 为代表的闪存卡，广泛用于相机、手机、无人机、行车记录仪、开发板。它与 U 盘同属闪存，但**接口、速度等级和用途**不同。

## 一、常见类型

| 类型 | 尺寸 | 典型用途 |
|------|------|---------|
| SD / microSD(TF) | 大卡/小卡 | 相机、手机、无人机 |
| CFexpress Type A/B | 中 | 高端相机 |
| CFast / CF | 中/大 | 老式单反、工业 |
| NM 卡 | 小 | 华为设备 |

---

## 二、为什么相机/无人机要用"快卡"

- 4K/8K 视频、连拍需要**持续写入**，卡不够快会掉帧/卡死。
- 卡的速度等级（U3/V30/V60/V90）就是保证**最低持续写速**。
- 详见 [[01_类型速度与真假卡]]。

## 其他问题（Q&A）

**Q1：手机能读 SD/TF 卡吗？**
A：多数安卓机支持 microSD；没有卡槽可用 OTG 读卡器。

**Q2：行车记录仪/监控必须用专用卡吗？**
A：建议用**高耐久（High Endurance）**卡，普通卡写满很快坏。

**Q3：卡里照片误删了能恢复吗？**
A：能，**停止再拍/再写**，用 PhotoRec 等恢复。见 [[01_类型速度与真假卡]]。
