# 文件存储与日常使用

> 抛开"启动盘"这种重活，U 盘最日常的用途就是**存文件、搬数据**。本篇讲清楚：选什么文件系统、怎么跨平台、怎么加密、怎么提速、怎么组织。

---

## 一、文件系统怎么选

| 场景 | 推荐 | 理由 |
|------|------|------|
| Windows/macOS/Linux 三平台混用 | **exFAT** | 都能读写、无 4G 限制 |
| 只在 Windows 用 | NTFS | 权限、日志、大文件 |
| 老设备（电视/车机/相机） | FAT32 | 兼容性最好 |
| 只在 Linux 用 | ext4 | 原生、稳定 |

> 详见 [[02_分区文件系统与格式化]]。

---

## 二、跨平台注意

| 问题 | 说明 |
|------|------|
| macOS 默认不写 NTFS | 需第三方驱动；跨平台建议 exFAT |
| Linux 挂载 FAT/exFAT | 需 `exfatprogs`/`exfat-fuse` |
| 文件名限制 | FAT/exFAT 不允许 `\ / : * ? " < > |` 等字符 |
| 权限/符号链接 | FAT/exFAT 不支持，Linux 间传文件建议 tar 打包 |

---

## 三、给 U 盘加密

| 方案 | 平台 | 特点 |
|------|------|------|
| **VeraCrypt** | 跨平台 | 创建加密卷，兼容性最好 |
| **BitLocker To Go** | Windows | 系统自带，Windows 生态方便 |
| **LUKS** | Linux | 原生、强大 |
| 7-Zip 加密压缩包 | 跨平台 | 简单应急；文件级 |

> 加密能同时解决两个问题：**防泄露** + **安全销毁**（丢掉密钥 ≈ 数据销毁）。

---

## 四、提速与稳定性

| 手段 | 说明 |
|------|------|
| 用 USB 3.0+ 接口和后置口 | 避免前置口/Hub 瓶颈与供电不足 |
| 选 UASP 协议 | 比 BOT 快、延迟低 |
| 大文件用大簇 | 减少元数据开销 |
| 写完 `sync` / 安全弹出 | 防缓存未落盘 |
| 避免满盘 | 留一点空间有利性能与寿命 |

---

## 五、便携软件与常见用途

- **便携软件（Portable Apps）**：程序和数据都放 U 盘，插上即用。
- **刷机/固件**：把 `.bin`/`.img` 放 U 盘给路由器、开发板、电视盒子刷机。
- **OTG**：通过 OTG 线把 U 盘接到手机/平板，用于扩展或传文件。
- **系统救援**：配合 PE/Live，把重要文件拷出来。
- **密钥/证书**：GPG 密钥、SSH 私钥、源代码签名。

> 注意 U 盘是**易失/易损**介质，**不要作为唯一副本**。

## 六、文件组织建议

```
U盘根目录/
├── 01_工作/         (按用途)
├── 02_备份/         (定期备份, 带日期)
├── 03_软件/         (安装包)
├── 04_镜像/         (系统 ISO)
└── README.txt       (盘用途/联系人, 丢了也许能还)
```

- 重要文件**带日期 + 多副本**（U 盘 + 移动硬盘 + 云）。
- 用 exFAT 时注意字符限制。

## 其他问题（Q&A）

**Q1：拷大文件到 U 盘失败，提示文件过大？**
A：FAT32 单文件上限 4G。改 **exFAT** 或 NTFS。

**Q2：U 盘在 mac 上只能读不能写（NTFS）？**
A：macOS 默认不写 NTFS。改用 **exFAT**，或装 NTFS 写入插件。

**Q3：怎么防止偶尔拔出损坏数据？**
A：①写完 `sync` 或"安全弹出"；②重要文件用校验（`sha256sum`）；③别在传输中拔盘。

**Q4：U 盘能加密吗？丢了怎么办？**
A：能（VeraCrypt/BitLocker/LUKS）。丢了**只要密码/密钥不泄露，数据无法读取**；但密钥也丢了就无解——所以要有**密钥备份**。

**Q5：U 盘和云盘，哪个更适合备份？**
A：两者互补。**3-2-1 原则**：至少 3 份、2 种介质、1 份异地。U 盘/移动盘做本地，"云"做异地。

**Q6：手机用什么读 U 盘？**
A：支持 OTG 的安卓机接 OTG 线即可；或用带 Type-C 的 U 盘。

**Q7：怎么避免把机密拷到 U 盘外泄？**
A：用加密卷、只读介质、禁用公用机的 USB 存储策略；敏感数据尽量走加密通道。
