# 盘内微型系统与持久化

> 把"能被启动的系统"升级成"**随身可用的系统**"：U 盘不只是安装盘，还能直接运行一个完整系统。本篇讲 Live、持久化、Windows To Go 与便携系统的原理与取舍。

---

## 一、三种"盘内系统"

| 类型 | 含义 | 改动是否保存 | 例子 |
|------|------|:-----------:|------|
| **Live 系统** | 启动后从镜像读取运行，内存中操作 | ❌ 重启即还原 | Ubuntu Live、Debian Live |
| **持久化 Live** | Live + 一块"保存区"，改动写入 U 盘 | ✅ | Ubuntu/Linux Mint persistence |
| **完整随身系统** | 系统真正装在 U 盘上 | ✅ | Windows To Go、便携 Linux |

---

## 二、Live 系统的原理

```
固件 → 引导器 → 内核 + initramfs → 挂载 squashfs(只读) → 叠加可写层(内存)
```

- 根文件系统是**只读压缩镜像（squashfs）**，改动放**内存（tmpfs）**。
- 好处：不伤盘、干净、每次都是全新系统。
- 坏处：改动不保存、耗内存、性能有限。

---

## 三、持久化（Persistence）

在盘上划出一块**持久分区/文件**作为可写层：

| 实现 | 说明 |
|------|------|
| `casper-rw` 分区 | Ubuntu 系的持久分区 |
| `persistence` 文件 | 持久化文件（大小可设） |
| overlay 机制 | 把只读层 + 可写层叠加 |
| Ventoy Persistence | Ventoy 为支持的 ISO 提供持久化 |

> 注意：持久化**通常只对特定发行版有效**，且**跨内核大版本升级可能失效**。

---

## 四、Windows To Go（WTG）

把**完整 Windows** 装进 U 盘/移动 SSD，插哪台电脑都能启动自己的系统。

| 要点 | 说明 |
|------|------|
| 介质要求 | **移动 SSD** 最佳；普通 U 盘 4K 太差，体验糟、易卡 |
| 官方支持 | Win10 企业版自带 WTG；Win10/11 其他版本可用第三方工具 |
| 端口 | UEFI + USB 3.0；有的用雷电/Type-C |
| 注意 | 首次在新机器启动会装驱动、可能跑 OOBE；**换机时注意授权/激活** |
| 风险 | U 盘拔除/损坏 = 系统损坏；注意备份 |

---

## 五、便携 Linux / Ventoy 多启动

- **便携发行版**：Puppy、Porteus、Slax 等，体积小、可保存。
- **Ventoy**：把多个 ISO 放一个盘，启动时菜单选择；部分 ISO 支持持久化。
- **Ventoy VDisk 启动**：还能引导 VHD/VHDX（部分场景替代 WTG）。

---

## 六、在 U 盘跑系统的性能与寿命注意

| 问题 | 原因 | 建议 |
|------|------|------|
| 卡顿 | U 盘 4K 随机性能极差 | 用**移动 SSD**做 WTG，U 盘只做 Live |
| 发热大 | 持续读写 | 注意散热，别长时间高负载 |
| 寿命短 | 频繁写入 | 关闭不必要的日志/交换，或改用 SSD |
| 拔了会坏 | 系统盘被强拔 | 正常关机/弹出 |

## 其他问题（Q&A）

**Q1：Live 系统能保存文件吗？**
A：默认不能（改动在内存）。要么手动存到另一个分区，要么用**持久化**。

**Q2：持久化怎么做？**
A：Ubuntu 系可用 `mkusb`/Rufus 的 persistence；Ventoy 对部分 ISO 支持在 `ventoy` 配置里开启。

**Q3：普通 U 盘能装 Windows To Go 吗？**
A：能启动，但**体验极差**（4K 太慢），而且很快损坏。强烈建议用**移动 SSD**。

**Q4：WTG 换电脑会怎样？**
A：第一次在新硬件上启动会装驱动、跑初始化；激活可能受硬件变更影响。数据在盘上，随盘走。

**Q5：Live 系统能装到硬盘吗？**
A：可以，很多 Live 镜像自带安装器；也可以手动分区拷贝。

**Q6：为什么持久化有时突然失效？**
A：内核/发行版大版本升级后，持久层格式或配置不兼容；或 U 盘出错。重要数据另存备份。

**Q7：一个 U 盘能既当 Live 又当安装盘吗？**
A：能，Ventoy 多启动即可；或用 YUMI。
