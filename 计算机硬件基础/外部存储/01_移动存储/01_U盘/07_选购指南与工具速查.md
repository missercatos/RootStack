# 选购指南与工具速查

> 本篇是 U 盘的"实用手册"：怎么挑、怎么验、常用命令与工具一览，遇到问题快速定位。

---

## 一、选购指南

| 维度 | 建议 |
|------|------|
| 容量 | 装系统 ≥16G；拷文件/多系统 64–256G |
| 接口 | USB 3.0/3.1/3.2（Type-A 或 Type-C） |
| 速度 | 顺序读 ≥100MB/s；4K 随机普遍差 |
| 主控/颗粒 | 大厂正品（三星/闪迪/铠侠/雷克沙/金士顿…） |
| 用途 | 启动盘/随身系统 → 双接口/固态 U 盘 |
| 外壳 | 金属、带盖、散热好 |

> ⚠️ 警惕"超低价大容量"：多为**虚标/黑片**（见 [[计算机硬件基础/外部存储/01_移动存储/01_U盘/01_U盘原理与硬件#其他问题]]）。

## 二、到手先"验盘"

```bash
lsblk -o NAME,SIZE,RM,FSTYPE,LABEL,MODEL     # 看设备
# 全盘写读校验(需 root)
sudo f3probe /dev/sdX            # 快速测真实容量/真假
sudo f3write /mnt && sudo f3read /mnt   # 挂载后全盘写读
# 或 Windows 的 h2testw
```

---

## 三、常用命令速查

```bash
# 分区 + 格式化(FAT32)
printf 'label: dos\n2048,,c,*\n' | sudo sfdisk /dev/sdX
sudo mkfs.vfat -F32 -n MYUSB /dev/sdX1
# exFAT / NTFS
sudo mkfs.exfat -n MYUSB /dev/sdX1
sudo mkfs.ntfs -f -L MYUSB /dev/sdX1
# 挂载/卸载
sudo mount /dev/sdX1 /mnt/u
sudo umount /mnt/u
# 烧录 ISO(dd)
sudo dd if=x.iso of=/dev/sdX bs=4M conv=fsync status=progress
# 校验
sudo cmp -n $(stat -c%s x.iso) x.iso /dev/sdX
```

## 其他问题（Q&A）

**Q1：买双接口(Type-A+Type-C)U 盘值吗？**
A：常手机/电脑互传就值；否则普通口足够。

**Q2：固态 U 盘(SSD U盘)值得买吗？**
A：要高速/随身系统值得，但贵；普通拷文件普通 U 盘即可。

**Q3：怎么快速判断买到假盘？**
A：到手立刻 `h2testw`/`f3` 全盘写读，超真实容量处会出错。

**Q4：U 盘需要定期"刷新"吗？**
A：长期不通电可能电荷流失，重要数据定期重写/换盘。

**Q5：一个 U 盘能分区成"启动区 + 数据区"吗？**
A：能（如 Ventoy 或手动多分区），但老设备可能只认第一个分区。
