# 01 U 盘

> **U 盘（USB Flash Drive）** 是最普及的移动存储：小、便宜、即插即用。它既是最简单的"文件抽屉"，也是最常见的"系统安装盘"载体。本目录按方向分章，从硬件原理讲到系统启动盘制作。

## 二、选购速查

| 指标 | 建议 | 说明 |
|------|------|------|
| 容量 | 32–128G | 装系统 16G 起；多系统/存文件 128G+ |
| 接口 | USB 3.0 及以上 | 2.0 只有 ~30MB/s |
| 速度 | 顺序读 ≥100MB/s | 4K 随机普遍差，别当硬盘 |
| 主控/颗粒 | 认准大厂 | 杂牌常见虚标/黑片 |
| 外壳 | 金属/带盖 | 散热、防尘 |

> ⚠️ 网上超便宜的"2T U 盘"基本都是**虚标盘**，见 [[01_U盘原理与硬件#其他问题]]。

## 三、U 盘的三个"神话"与现实

| 神话 | 现实 |
|------|------|
| "容量越大越好" | 杂牌大容量 = 高风险虚标 |
| "可以当硬盘长期用" | 4K 随机差、寿命短 |
| "文件拖进去就安全" | 缓存未落盘就拔会损坏；重要数据别只放一份 |
