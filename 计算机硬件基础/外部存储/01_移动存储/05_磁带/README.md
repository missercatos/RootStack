# 05 磁带

> **磁带（Magnetic Tape）** 看似"上古"，却是**企业级大容量冷归档**的主力：**单位容量最便宜、离线保存最久、顺序吞吐极高**。LTO（Linear Tape-Open）是主流标准。

## 一、为什么企业还在用磁带

| 优点 | 说明 |
|------|------|
| 单位成本极低 | 每 TB 成本远低于硬盘 |
| 容量大 | LTO 单盘可达 12–30 TB（压缩后） |
| 离线安全 | 平时不在线，抗勒索/断电 |
| 寿命长 | 正确保存可达 10–30 年 |
| 顺序吞吐高 | 适合大批量归档/恢复 |

| 缺点 | 说明 |
|------|------|
| **随机访问慢** | 只能顺序（"线性"）查找 |
| 需要驱动器 | 磁带机昂贵 |
| 管理复杂 | 需归档软件、条件苛刻 |

## 三、适用场景

- 企业**冷数据归档**、合规留存（视频监控、医疗影像）。
- **防勒索**：离线磁带无法被在线加密。
- 不适合：频繁随机读写、个人日常备份（成本/复杂度太高）。

## 其他问题（Q&A）

**Q1：个人用户值得用磁带吗？**
A：一般**不值得**——磁带机贵、随机访问差。个人归档优选**移动硬盘 + 光盘/云**。

**Q2：磁带保存要注意什么？**
A：恒温恒湿、避磁、竖直存放、**定期走带**并校验；环境差会掉磁粉。

**Q3：磁带和硬盘谁更可靠？**
A：**离线长期**磁带更稳；**在线随机访问**硬盘更强。企业常**磁带 + 磁盘分层**。

**Q4：为什么叫"线性"磁带？**
A：数据按磁道顺序写入/读出，找数据需**快进/倒带**，所以随机访问慢。
