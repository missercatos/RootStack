# 磁带库与 LTFS 实战

> 企业磁带归档离不开两个关键词：**磁带库（自动换盘）** 与 **LTFS（把磁带当文件系统）**。本篇讲它们怎么用、怎么选。

---

## 一、磁带库（Library / Changer）

- 机械臂自动在驱动器与槽位间取放磁带。
- 可从几盘到上千盘，配合归档软件做**分级存储**。
- 常见厂商：IBM、Quantum、HPE、Oracle（StorageTek）。

| 类型 | 盘数 |
|------|------|
| 自动加载机（Autoloader） | 数盘~数十盘 |
| 磁带库 | 数十~上千盘 |

---

## 二、LTFS（Linear Tape File System）

- 把磁带格式化成一个**类似 UDF 的文件系统**，可直接挂载读写。
- 优点：跨平台交换、无需专用归档软件。
- 缺点：随机访问仍慢；更适合**大批量顺序读写**。

```bash
# Linux 下用 ltfs（需安装 ltfs 工具，且挂载单盘）
mkltfs -d /dev/st0
ltfs /mnt/tape -o dev=/dev/st0
cp bigfile /mnt/tape/
umount /mnt/tape
```

---

## 三、选型与运维

| 要点 | 说明 |
|------|------|
| 驱动器代数 | 向下兼容读前两代 |
| 介质寿命 | 定期走带、抽检、翻录 |
| 环境 | 恒温恒湿、避磁 |
| 索引 | 记录每盘的**内容清单** |
| 3-2-1 | 磁带是"离线异地"的重要一环 |

---

## 其他问题（Q&A）

**Q1：LTFS 可以像硬盘一样随便改文件吗？**
A：可以但有代价（顺序介质，改写慢）。批量顺序写更合适。

**Q2：磁带需要 RAID 吗？**
A：不需要；靠**多份磁带 + 库内冗余 + 校验**。

**Q3：个人能用 LTFS 吗？**
A：需要 LTO 驱动器（贵）。个人归档更推荐硬盘 + 光盘/云。

**Q4：磁带会不会过时？**
A：企业冷归档仍是主力，新代际容量持续增长。
