
# C 语言库大全 -- 容器类库

> C 语言没有 STL，但可以通过手动实现或使用第三方库来获得容器功能。
> 每个容器的详细手动实现见 [[../../../c语言教程/3数据结构/|C语言数据结构教程]]。

---

## 手动实现的容器

| 容器 | 文件 | 核心 API |
|------|------|---------|
| 动态数组 | [[动态数组]] | init, push_back, pop_back, get, resize, free |
| 单向链表 | [[链表/单向链表]] | push_front, pop_front, insert_after, remove_after, reverse |
| 双向链表 | [[链表/双向链表]] | push_back, push_front, pop_back, pop_front, remove, insert_before |
| 栈 | [[栈]] | push, pop, top, empty（数组 + 链表两种实现） |
| 循环队列 | [[队列/循环队列]] | enqueue, dequeue, front, is_full, is_empty |
| 链式队列 | [[队列/链式队列]] | enqueue, dequeue, front, is_empty |
| 哈希表（链地址法） | [[哈希表/链地址法]] | put, get, remove, rehash |
| 哈希表（开放地址法） | [[哈希表/开放地址法]] | put, get, remove, rehash（线性/二次/双重探测） |
| 二叉搜索树 | [[树/二叉搜索树]] | insert, search, delete, inorder, min |
| AVL 树 | [[树/AVL树]] | insert, delete, search（自平衡，严格 O(log n)） |
| 堆 | [[树/堆]] | push, pop, top, heapify（优先队列） |
| 图（邻接表） | [[图/邻接表]] | add_edge, bfs, dfs（适合稀疏图） |
| 图（邻接矩阵） | [[图/邻接矩阵]] | add_edge, bfs, dfs（适合稠密图） |

## 第三方 C 容器库

| 库 | 特点 | 链接 |
|----|------|------|
| **uthash** | 纯头文件哈希表，支持增删查 | https://github.com/troydhanson/uthash |
| **klib** | 纯头文件通用库：khash(哈希), kvec(动态数组), kbtree(B树) | https://github.com/attractivechaos/klib |
| **GLib** | GTK 的基础库，提供 GList, GHashTable, GArray 等 | https://docs.gtk.org/glib/ |
| **stb** | 纯头文件库集合，含 stb_ds（动态数组+哈希表） | https://github.com/nothings/stb |
| **libcork** | C 语言工具集，含 darray, hash-map 等 | |
| **ConcurrencyKit** | 高并发无锁数据结构 | https://github.com/concurrencykit/ck |
