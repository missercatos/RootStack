
# C 语言教程 —— 学会 C 语言，构建自我 C 语言体系

## 写在教程之前

本教程的目标是从零开始(手把手教会搭建环境)到精通 C 语言, 构建自己的 C 语言知识体系。
真正的工程师经验来自项目堆砌和自我踩坑, 而不是靠教程学习。师傅领进门, 修行靠个人。

本教程的核心理念:

1. **面向底层** -- C 语言是距离硬件最近的高级语言。本教程大量涉及汇编层面、内存布局、指针本质、系统调用等底层话题。每个关键概念都会从"CPU 看到了什么"的角度进行剖析。
2. **向上延伸** -- C 语言是 C++ 的基石。理解 C 的指针、内存管理、结构体后, 再学 C++ 的 this 指针、虚表、智能指针会豁然开朗。教程在合适位置提供指向 [[../cpp教程/cpp目录|CPP教程]] 的链接。
3. **视野开阔** -- 本教程第四部分"内核"将读者引入操作系统内核的世界, 理解 C 语言在系统工程中的核心地位。同时, 数据结构部分与根 [[../数据结构/DSA学习路线|DSA学习路线]] 配合, 从底层内存布局理解每种数据结构的本质。
4. **系统化思考** -- 希望读者带着辩论态度阅读。题目和概念交错排布, 题目的目的就是启发思考。如果发现题目不会, 回去重新想想。
5. **善用工具** -- 不反对也不鼓吹 AI。自我思考是第一要务, AI 辅助。推荐读者旁边开着 AI, 遇到不懂的问题先自己对 AI 解释看法让其纠正。
