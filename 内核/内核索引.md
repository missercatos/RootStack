
# 内核思想

> "内核"不只是操作系统。任何一个复杂系统的核心调度引擎、资源管理器、状态机都是"内核"。
> 本模块从四种内核视角出发，覆盖从硬件到应用的完整"核心思维"链。

## 四种内核

```
内核/
├── 内核索引.md            ← 你在这里
├── C与Rust的内核新时代.md  ← C 与 Rust 的系统编程新时代
├── 系统内核/             操作系统内核: Linux, Windows, macOS (Darwin/XNU)
├── 语言运行时内核/       编程语言运行时: CRT, CPython, V8/JavaScriptCore, JVM/JIT
├── 工具内核/             软件工具的核心引擎: 数据库内核, 浏览器内核, 消息队列内核
└── 游戏引擎内核/         游戏的"操作系统": 渲染/物理/音频/脚本核心环
```

## 为什么学内核

1. **性能优化的终极手段** -- 理解内核调度才能理解程序的真实性能瓶颈
2. **调试能力的上限** -- 用户态程序的问题经常根在 kernel 层
3. **架构设计的范本** -- 操作系统内核是软件工程的最高杰作之一
4. **面试竞争力** -- 区分普通开发者与系统级工程师
