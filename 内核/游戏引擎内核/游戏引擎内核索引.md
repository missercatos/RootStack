
# 游戏引擎内核

> 游戏引擎是"游戏的实时操作系统"——每帧 16ms(60fps)内完成输入、物理、AI、渲染。

## 为什么学游戏引擎内核

游戏引擎的约束条件与操作系统内核类似: 严格的实时要求 (不能掉帧), 资源管理 (GPU 显存, 音频缓冲区), 并发调度 (渲染线程 vs 逻辑线程)。Eigen 数学库、Lua 虚拟机、物理求解器——这些组件共同构成了"游戏的 OS"。同时, ECS 架构的数据驱动思维对通用软件架构也有深刻启示。

## 核心循环

```
FUNCTION game_loop():
    WHILE running:
        delta_time ← clock.update()
        process_input()
        update_physics(delta_time)
        update_ai(delta_time)
        render_frame()
        present_frame()
        IF delta_time < target_frame_time:
            SLEEP(target_frame_time - delta_time)
```

## 阅读路径

```
游戏循环 → ECS架构 → 渲染管线 → 物理引擎 → 音频引擎 → 脚本引擎
```

- 先理解帧循环——这是游戏引擎的心脏
- ECS 是数据架构基础, 渲染/物理 System 都跑在 ECS 上
- 然后看渲染和物理——计算量最大的两个子系统
- 最后看音频和脚本——技术支持层面
