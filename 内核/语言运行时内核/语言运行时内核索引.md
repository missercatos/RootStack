
# 语言运行时内核

> 编程语言的"操作系统"——内存管理、垃圾回收、JIT 编译、对象模型。

## 核心概念

每种编程语言都有一个运行时环境, 它负责:
1. **内存管理** -- 分配/回收, 垃圾回收策略
2. **类型系统** -- 运行时类型信息, 虚表, 方法分派
3. **执行模型** -- 解释器, JIT 编译器, AOT 编译器
4. **并发模型** -- 线程模型, 事件循环, 协程
5. **异常处理** -- 栈展开, 异常表, setjmp/longjmp

## 阅读路径

```
CRT → CPython → 垃圾回收算法 → JVM → V8 → JIT编译原理
```

- 先理解最简单的 CRT, 建立无运行时的基线
- 然后看引用计数 GC (CPython), 理解最简单的自动内存管理
- 再系统学习所有 GC 算法
- 最后理解 JIT 编译——从解释到优化编译的阶梯
