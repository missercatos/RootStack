# 学生管理系统：命令行工具

## 我们要做什么

在本教程中，你将构建一个**命令行学生管理系统**。你可以通过终端命令来添加学生、列出所有学生、搜索、删除、修改成绩。所有数据会保存到 JSON 文件中，下次打开程序时自动加载。

```bash

┌────┬──────┬─────┬───────┐
│ ID │ 姓名 │ 年龄 │ 成绩  │
```

## 第 2 步：添加依赖并理解概念

打开 `Cargo.toml`，添加以下内容：

```toml
[package]
name = "student_manager"
version = "0.1.0"
edition = "2021"

[dependencies]
serde = { version = "1.0", features = ["derive"] }
serde_json = "1.0"
clap = { version = "4.5", features = ["derive"] }
```

**依赖解释：**

| Crate | 版本 | 作用 |
|-------|------|------|
| `serde` | 1.0 | **序列化/反序列化框架**。序列化就是把 Rust 结构体变成 JSON 字符串或字节；反序列化就是把 JSON 字符串变回 Rust 结构体。这不是一个具体的格式库，而是框架——具体的格式由 `serde_json` 等提供。`features = ["derive"]` 让我们能用 `#[derive(Serialize, Deserialize)]` 自动生成序列化代码。 |
| `serde_json` | 1.0 | 配合 `serde`，提供 JSON 格式的具体实现。能把结构体转成 JSON 字符串，也能把 JSON 字符串解析为结构体。 |
| `clap` | 4.5 | **命令行参数解析库**。解析用户在 `cargo run -- add --name "张三"` 中提供的参数。`features = ["derive"]` 让我们能通过 `#[derive(Parser)]` 声明式地定义参数。 |

### 什么是 CLI？

**CLI（Command Line Interface）** 就是命令行界面。你通过打字和程序交互，而不是用鼠标点击按钮。CLI 程序的特点是：
- 快速：不需要等待 GUI 启动
- 可脚本化：可以写在 bash 脚本里批量处理
- 可组合：通过管道（`|`）把多个 CLI 程序串联

### 什么是序列化？

**序列化（Serialization）** 是把内存中的数据结构转换为可存储或传输的格式（如 JSON、二进制）。**反序列化（Deserialization）** 是反向操作。在我们的项目中：
- 添加学生 → 把 `Student` 结构体序列化为 JSON → 写入文件
- 启动程序 → 从文件读取 JSON → 反序列化为 `Vec<Student>`

### 什么是 JSON？

**JSON（JavaScript Object Notation）** 是一种人类可读的轻量级数据格式。例如：
```json
{
  "students": [
    {"id": 1, "name": "张三", "age": 20, "grade": 85.5},
    {"id": 2, "name": "李四", "age": 22, "grade": 92.0}
  ]
}
```

## 第 3 步：定义 Student 结构体和 CLI 参数

这是整个程序的数据基础。创建 `src/main.rs`：

```rust
use clap::{Parser, Subcommand};
use serde::{Deserialize, Serialize};

/// 学生信息
#[derive(Debug, Clone, Serialize, Deserialize)]
struct Student {
    id: u64,
    name: String,
    age: u8,
    grade: f64,
}

/// 学生管理系统 — 一个简单的命令行工具
#[derive(Parser)]
#[command(name = "student_manager")]
#[command(version = "0.1.0")]
#[command(about = "管理学生信息的命令行工具", long_about = None)]
struct Cli {
    #[command(subcommand)]
    command: Commands,
}

#[derive(Subcommand)]
enum Commands {
    /// 添加一名新学生
    Add {
        /// 学生姓名
        #[arg(short, long)]
        name: String,
        /// 学生年龄
        #[arg(short, long)]
        age: u8,
        /// 学生成绩（0-100）
        #[arg(short, long)]
        grade: f64,
    },
    /// 列出所有学生
    List,
    /// 搜索学生（按姓名或 ID）
    Search {
        /// 按姓名搜索（支持部分匹配）
        #[arg(short, long)]
        name: Option<String>,
        /// 按 ID 搜索
        #[arg(short, long)]
        id: Option<u64>,
    },
    /// 删除学生
    Delete {
        /// 要删除的学生 ID
        #[arg(short, long)]
        id: u64,
    },
    /// 修改学生成绩
    Update {
        /// 要修改的学生 ID
        #[arg(short, long)]
        id: u64,
        /// 新成绩（0-100）
        #[arg(short, long)]
        grade: f64,
    },
}

fn main() {
    let cli = Cli::parse();
    println!("{:?}", cli.command);
}
```

**逐行解释：**

1. `#[derive(Debug, Clone, Serialize, Deserialize)]` — 自动实现四个 trait：`Debug`（调试打印）、`Clone`（复制）、`Serialize`（序列化为 JSON）、`Deserialize`（从 JSON 解析）。
2. `struct Student` — 表示一个学生，有 id、name、age、grade 四个字段。
3. `#[derive(Parser)]` — 告诉 clap 自动生成命令行解析代码。
4. `#[command(name = "student_manager")]` — 设置程序名称。
5. `#[derive(Subcommand)]` — 定义子命令枚举。每个变体对应一个命令（如 `add`、`list`）。
6. `#[arg(short, long)]` — 表示这个参数既可以用短格式（`-n`）也可以用长格式（`--name`）。

## 第 4 步：实现"添加学生"

现在我们把参数解析和实际逻辑连接起来。替换 `main.rs`：

```rust
use clap::{Parser, Subcommand};
use serde::{Deserialize, Serialize};
use std::fs;

/// 学生信息
#[derive(Debug, Clone, Serialize, Deserialize)]
struct Student {
    id: u64,
    name: String,
    age: u8,
    grade: f64,
}

/// 学生管理系统
#[derive(Parser)]
#[command(name = "student_manager")]
#[command(version = "0.1.0")]
#[command(about = "管理学生信息的命令行工具", long_about = None)]
struct Cli {
    #[command(subcommand)]
    command: Commands,
}

#[derive(Subcommand)]
enum Commands {
    /// 添加一名新学生
    Add {
        #[arg(short, long)]
        name: String,
        #[arg(short, long)]
        age: u8,
        #[arg(short, long)]
        grade: f64,
    },
    /// 列出所有学生
    List,
    /// 搜索学生
    Search {
        #[arg(short, long)]
        name: Option<String>,
        #[arg(short, long)]
        id: Option<u64>,
    },
    /// 删除学生
    Delete {
        #[arg(short, long)]
        id: u64,
    },
    /// 修改学生成绩
    Update {
        #[arg(short, long)]
        id: u64,
        #[arg(short, long)]
        grade: f64,
    },
}

const DATA_FILE: &str = "students.json";

fn main() {
    let cli = Cli::parse();

    // 加载已有数据
    let mut students: Vec<Student> = load_students();

    match cli.command {
        Commands::Add { name, age, grade } => {
            // 生成新 ID：找到最大 ID + 1
            let max_id = students.iter().map(|s| s.id).max().unwrap_or(0);
            let new_student = Student {
                id: max_id + 1,
                name,
                age,
                grade,
            };
            println!("✓ 已添加学生：{} (ID: {})", new_student.name, new_student.id);
            students.push(new_student);
            save_students(&students);
        }
        Commands::List => {
            println!("TODO: 列出所有学生");
        }
        Commands::Search { name, id } => {
            println!("TODO: 搜索学生");
        }
        Commands::Delete { id } => {
            println!("TODO: 删除学生 {}", id);
        }
        Commands::Update { id, grade } => {
            println!("TODO: 修改学生 {} 的成绩为 {}", id, grade);
        }
    }
}

fn load_students() -> Vec<Student> {
    match fs::read_to_string(DATA_FILE) {
        Ok(contents) => {
            serde_json::from_str(&contents).unwrap_or_else(|e| {
                eprintln!("⚠ 读取数据文件失败，将使用空列表：{}", e);
                Vec::new()
            })
        }
        Err(_) => {
            // 文件不存在，返回空列表
            Vec::new()
        }
    }
}

fn save_students(students: &Vec<Student>) {
    let json = serde_json::to_string_pretty(students).expect("序列化失败");
    fs::write(DATA_FILE, json).expect("写入文件失败");
}
```

**新内容解释：**

- `const DATA_FILE: &str = "students.json";` — 定义常量，数据文件路径。
- `load_students()` — 从文件读取 JSON，反序列化为 `Vec<Student>`。如果文件不存在，返回空列表。
  - `fs::read_to_string` — 读取整个文件内容为字符串。
  - `serde_json::from_str` — 把 JSON 字符串解析为 `Vec<Student>`。
- `save_students()` — 把 `Vec<Student>` 序列化为格式化的 JSON 字符串，写入文件。
  - `serde_json::to_string_pretty` — 序列化为美观的 JSON（带缩进和换行）。
  - `fs::write` — 把字符串写入文件。
- `max_id + 1` — 自动生成不重复的 ID。

**运行：**

```bash
cargo run -- add --name "张三" --age 20 --grade 85
cargo run -- add --name "李四" --age 22 --grade 92
```

**你应该看到：**
```
✓ 已添加学生：张三 (ID: 1)
✓ 已添加学生：李四 (ID: 2)
```

## 第 6 步：实现"搜索学生"

搜索支持按姓名（部分匹配）和按 ID（精确匹配）：

```rust
use clap::{Parser, Subcommand};
use serde::{Deserialize, Serialize};
use std::fs;

#[derive(Debug, Clone, Serialize, Deserialize)]
struct Student {
    id: u64,
    name: String,
    age: u8,
    grade: f64,
}

#[derive(Parser)]
#[command(name = "student_manager")]
#[command(version = "0.1.0")]
#[command(about = "管理学生信息的命令行工具", long_about = None)]
struct Cli {
    #[command(subcommand)]
    command: Commands,
}

#[derive(Subcommand)]
enum Commands {
    Add {
        #[arg(short, long)]
        name: String,
        #[arg(short, long)]
        age: u8,
        #[arg(short, long)]
        grade: f64,
    },
    List,
    Search {
        #[arg(short, long)]
        name: Option<String>,
        #[arg(short, long)]
        id: Option<u64>,
    },
    Delete {
        #[arg(short, long)]
        id: u64,
    },
    Update {
        #[arg(short, long)]
        id: u64,
        #[arg(short, long)]
        grade: f64,
    },
}

const DATA_FILE: &str = "students.json";

fn main() {
    let cli = Cli::parse();
    let mut students: Vec<Student> = load_students();

    match cli.command {
        Commands::Add { name, age, grade } => {
            let max_id = students.iter().map(|s| s.id).max().unwrap_or(0);
            let new_student = Student {
                id: max_id + 1,
                name,
                age,
                grade,
            };
            println!("✓ 已添加学生：{} (ID: {})", new_student.name, new_student.id);
            students.push(new_student);
            save_students(&students);
        }
        Commands::List => {
            if students.is_empty() {
                println!("暂无学生记录。");
                return;
            }
            print_student_table(&students);
        }
        Commands::Search { name, id } => {
            // 按 ID 搜索（精确匹配）
            if let Some(search_id) = id {
                let results: Vec<&Student> = students
                    .iter()
                    .filter(|s| s.id == search_id)
                    .collect();
                if results.is_empty() {
                    println!("未找到 ID 为 {} 的学生。", search_id);
                } else {
                    println!("找到 1 名学生：");
                    print_student_table(&results);
                }
            }
            // 按姓名搜索（部分匹配，不区分大小写）
            else if let Some(search_name) = name {
                let search_lower = search_name.to_lowercase();
                let results: Vec<&Student> = students
                    .iter()
                    .filter(|s| s.name.to_lowercase().contains(&search_lower))
                    .collect();
                if results.is_empty() {
                    println!("未找到姓名包含 \"{}\" 的学生。", search_name);
                } else {
                    println!("找到 {} 名学生：", results.len());
                    print_student_table(&results);
                }
            } else {
                println!("请指定搜索条件：--name 或 --id");
            }
        }
        Commands::Delete { id } => {
            println!("TODO: 删除学生 {}", id);
        }
        Commands::Update { id, grade } => {
            println!("TODO: 修改学生 {} 的成绩为 {}", id, grade);
        }
    }
}

fn load_students() -> Vec<Student> {
    match fs::read_to_string(DATA_FILE) {
        Ok(contents) => {
            serde_json::from_str(&contents).unwrap_or_else(|e| {
                eprintln!("⚠ 读取数据文件失败，将使用空列表：{}", e);
                Vec::new()
            })
        }
        Err(_) => Vec::new(),
    }
}

fn save_students(students: &Vec<Student>) {
    let json = serde_json::to_string_pretty(students).expect("序列化失败");
    fs::write(DATA_FILE, json).expect("写入文件失败");
}

fn print_student_table(students: &[&Student]) {
    if students.is_empty() {
        return;
    }
    println!("┌──────┬────────────────────┬──────┬────────┐");
    println!("│ {:<4} │ {:<18} │ {:<4} │ {:<6} │", "ID", "姓名", "年龄", "成绩");
    println!("├──────┼────────────────────┼──────┼────────┤");
    for student in students {
        println!(
            "│ {:<4} │ {:<18} │ {:<4} │ {:<6.1} │",
            student.id, student.name, student.age, student.grade
        );
    }
    println!("└──────┴────────────────────┴──────┴────────┘");
}
```

**新内容解释：**

- `if let Some(search_id) = id` — 模式匹配：如果 `id` 是 `Some(值)`，则取出值并执行。
- `.iter().filter(|s| ...).collect()` — 迭代器链：遍历所有学生，保留满足条件的，收集成 `Vec`。
- `to_lowercase()` — 转小写，实现不区分大小写的搜索。

## 第 9 步：JSON 文件持久化

实际上，持久化代码已经在前面步骤中集成了！让我们回顾一下关键点：

1. **程序启动时**调用 `load_students()` → 读取 `students.json` → `serde_json::from_str` 反序列化
2. **每次修改后**调用 `save_students()` → `serde_json::to_string_pretty` 序列化 → `fs::write` 写入文件

这已经是完整的持久化方案了。让我解释一下为什么我们不使用"退出时保存"：

- ❌ **退出时保存**：如果程序崩溃，所有修改丢失
- ✓ **每次修改后保存**：数据实时安全

如果你有大量数据，可以改用"退出时保存"来提高性能。但对于学生管理系统这种小数据量的场景，实时保存是最安全的选择。

```rust
                let results: Vec<&Student> = students
                    .iter()
                    .filter(|s| s.id == search_id)
                    .collect();
                if results.is_empty() {
                    println!("未找到 ID 为 {} 的学生。", search_id);
                } else {
                    println!("找到 1 名学生：");
                    print_student_table(&results);
                }
            } else if let Some(search_name) = name {
                if search_name.trim().is_empty() {
                    println!("{}", "请提供非空的搜索关键词。".yellow());
                    return;
                }
                let search_lower = search_name.to_lowercase();
                let results: Vec<&Student> = students
                    .iter()
                    .filter(|s| s.name.to_lowercase().contains(&search_lower))
                    .collect();
                if results.is_empty() {
                    println!("未找到姓名包含 \"{}\" 的学生。", search_name);
                } else {
                    println!("找到 {} 名学生：", results.len());
                    print_student_table(&results);
                }
            } else {
                println!("{}", "请指定搜索条件：--name 或 --id".yellow());
            }
        }
        Commands::Delete { id } => {
            let len_before = students.len();
            students.retain(|s| s.id != id);
            if students.len() < len_before {
                println!(
                    "{} 已删除 ID 为 {} 的学生。",
                    "✓".green().bold(),
                    id.to_string().yellow()
                );
                save_students(&students);
            } else {
                println!(
                    "{} 未找到 ID 为 {} 的学生。",
                    "✗".red().bold(),
                    id
                );
            }
        }
        Commands::Update { id, grade } => {
            if grade < 0.0 || grade > 100.0 {
                eprintln!("{} {}", "✗".red().bold(), "错误：成绩必须在 0-100 之间！".red());
                return;
            }
            if let Some(student) = students.iter_mut().find(|s| s.id == id) {
                let old_grade = student.grade;
                student.grade = grade;
                println!(
                    "{} 已更新学生 {} 的成绩：{} → {}",
                    "✓".green().bold(),
                    student.name.bright_blue(),
                    old_grade.to_string().yellow(),
                    grade.to_string().green()
                );
                save_students(&students);
            } else {
                println!(
                    "{} 未找到 ID 为 {} 的学生。",
                    "✗".red().bold(),
                    id
                );
            }
        }
    }
}

fn load_students() -> Vec<Student> {
    match fs::read_to_string(DATA_FILE) {
        Ok(contents) => {
            serde_json::from_str(&contents).unwrap_or_else(|e| {
                eprintln!("{} {}", "⚠".yellow(), format!("警告：数据文件格式错误，将使用空列表。详情：{}", e).yellow());
                Vec::new()
            })
        }
        Err(ref e) if e.kind() == std::io::ErrorKind::NotFound => {
            Vec::new()
        }
        Err(e) => {
            eprintln!("{} {}", "⚠".yellow(), format!("警告：无法读取数据文件：{}", e).yellow());
            Vec::new()
        }
    }
}

fn save_students(students: &Vec<Student>) {
    let json = match serde_json::to_string_pretty(students) {
        Ok(j) => j,
        Err(e) => {
            eprintln!("{} {}", "✗".red().bold(), format!("错误：序列化失败：{}", e).red());
            return;
        }
    };
    if let Err(e) = fs::write(DATA_FILE, json) {
        eprintln!("{} {}", "✗".red().bold(), format!("错误：无法写入数据文件：{}", e).red());
    }
}

fn print_student_table(students: &[&Student]) {
    if students.is_empty() {
        return;
    }
    let header_color = |s: &str| s.cyan().bold().to_string();
    println!("┌──────┬────────────────────┬──────┬────────┐");
    println!("│ {} │ {} │ {} │ {} │",
        format!("{:<4}", header_color("ID")),
        format!("{:<18}", header_color("姓名")),
        format!("{:<4}", header_color("年龄")),
        format!("{:<6}", header_color("成绩")),
    );
    println!("├──────┼────────────────────┼──────┼────────┤");
    for student in students {
        let grade_color = if student.grade >= 90.0 {
            student.grade.to_string().green()
        } else if student.grade >= 70.0 {
            student.grade.to_string().yellow()
        } else {
            student.grade.to_string().red()
        };
        println!(
            "│ {:<4} │ {:<18} │ {:<4} │ {:<6.1} │",
            student.id,
            student.name.bright_blue(),
            student.age,
            grade_color
        );
    }
    println!("└──────┴────────────────────┴──────┴────────┘");
    println!("{} 共 {} 名学生", "ℹ".cyan(), students.len().to_string().bold());
}
```

**新内容解释：**

- `use colored::*;` — 引入 colorized 扩展 trait，给 `&str` 和 `String` 添加了 `.red()`、`.green()`、`.yellow()`、`.bold()` 等方法。
- `.red()` — 设置文字为红色。
- `.green().bold()` — 设置文字为绿色并加粗。
- `.bright_blue()` — 设置文字为亮蓝色。
- 成绩颜色：90 分以上绿色，70-89 黄色，70 以下红色。
- `header_color` 闭包 — 将表头文字设为青色和加粗。

**运行：**

```bash
cargo run -- list
```

**你应该看到：** 彩色的表格！成功信息是绿色的，错误是红色的，表头是青色的，成绩根据分数有不同的颜色。

### 选择题（每题 10 分，共 40 分）

**1. `serde` crate 的作用是什么？**

A. 处理命令行参数
B. 提供终端彩色输出
C. 提供序列化和反序列化框架
D. 提供 HTTP 客户端

<details>
<summary>答案</summary>

**C. 提供序列化和反序列化框架**

`serde` 是 Rust 中最常用的序列化/反序列化框架。它本身不处理具体格式，而是提供 trait 和宏，由其他 crate（如 `serde_json`）实现具体格式。
</details>

**2. 以下哪个代码正确地把 `Vec<Student>` 写入 JSON 文件？**

A. `std::fs::write("data.json", students);`
B. `let json = serde_json::to_string_pretty(&students)?; std::fs::write("data.json", json)?;`
C. `serde_json::write_file("data.json", &students);`
D. `students.serialize_to_file("data.json");`

<details>
<summary>答案</summary>

**B.**

`serde_json::to_string_pretty` 将数据结构序列化为格式化的 JSON 字符串，然后 `std::fs::write` 将字符串写入文件。选项 A 缺少序列化步骤，C 和 D 是虚构的方法。
</details>

**3. `clap` 的 `#[derive(Parser)]` 宏做了什么？**

A. 将结构体解析为 JSON
B. 自动生成命令行参数解析代码
C. 将结构体转换为 HTML
D. 自动生成数据库查询代码

<details>
<summary>答案</summary>

**B. 自动生成命令行参数解析代码**

`clap` 的 derive 模式通过 `#[derive(Parser)]` 和 `#[arg(short, long)]` 等属性自动生成解析命令行参数的代码，无需手动解析 `std::env::args()`。
</details>

**4. `Vec::retain(|x| condition)` 方法的作用是什么？**

A. 返回满足条件的元素的引用
B. 保留满足条件的元素，移除不满足的元素
C. 复制满足条件的元素到新 Vec
D. 不改变原 Vec，返回满足条件的数量

<details>
<summary>答案</summary>

**B. 保留满足条件的元素，移除不满足的元素**

`retain` 是一个就地过滤方法：保留闭包返回 `true` 的元素，移除返回 `false` 的元素。这是修改原 Vec，而不是创建新的。
</details>

<details>
<summary>答案</summary>

**`short` 表示短参数名（如 `-n`），`long` 表示长参数名（如 `--name`）**

clap 会根据字段名自动生成短名（取字段名首字母）和长名（取字段名本身，下划线变连字符）。
</details>
