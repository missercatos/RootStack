# 实践总结与进阶指南

## 原理

5个项目覆盖了 Rust 的主要应用领域和关键生态：

| 项目 | 核心 crate | 领域 | 关键技术 |
|------|-----------|------|----------|
| 计算器 | eframe/egui | GUI | 立即模式, 事件循环 |
| 学生管理 | clap/serde | CLI | 子命令, 序列化 |
| 工具管理 | ratatui | TUI | 保留模式, 键盘事件 |
| 音乐播放 | rodio/reqwest | 媒体 | 音频解码, 流式 I/O |
| 贪吃蛇 | macroquad | 游戏 | 游戏循环, 碰撞检测 |

技术栈全貌：Cargo 工程 → clap CLI → serde 数据 → reqwest 网络 → egui/ratatui 界面 → rodio 音频 → tokio 异步。

进阶方向：异步后端（tokio/axum Web 服务）、嵌入式（no_std + embassy）、内核开发（Linux kernel modules）、密码学（ring/rustls）、数据库（sqlx/diesel）。
