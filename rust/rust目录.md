# Rust 教程

Rust 是一门系统级编程语言，在**零开销抽象**的前提下通过**所有权系统**在编译期消除内存错误，无需垃圾回收即可保证内存安全。RootStack 的 Rust 教程承接 C/C++ 知识体系，强调底层原理与工程实践。

## 新形势下的 Rust 优势

在 2024-2025 年的技术格局下，Rust 已从实验性语言发展为关键基础设施语言：

- **系统安全重写潮**: 美国政府（NSA/CISA）和欧盟均发布报告，建议将关键基础设施从 C/C++ 迁移至内存安全语言。Rust 是唯一满足"零成本 + 内存安全 + 无 GC"三项条件的生产语言
- **Linux 内核官方接纳**: Linux 6.1 起正式支持 Rust 内核模块，Android 已将 Rust 作为新系统代码的首选语言
- **AI/ML 基础设施**: HuggingFace 的 tokenizers、Polars、DataFusion 等核心组件均用 Rust 编写，因其可直接编译为 Python 原生扩展（PyO3），性能远超纯 Python
- **WebAssembly 生态**: Rust 是 WASM 的第一语言——wasm-bindgen、wasm-pack 等工具链最成熟，是前端性能敏感场景的首选

Rust 不是 C++ 的替代品，而是**C++ 的互补演进方向**——两者共享零开销哲学，但 Rust 将运行时错误前置到编译期。

> 本教程假设读者已有 C 或 C++ 基础。若为纯初学者，建议先完成 [[../c语言教程/c目录|C 语言教程]] 的前 5 章再回到这里。

## C ↔ Rust 对照学习

| 概念 | C | C++ | Rust |
|------|---|-----|------|
| 堆分配 | `malloc/free` | `new/delete` | `Box::new` / RAII 自动释放 |
| 泛型 | `_Generic` 宏 | 模板 | 泛型 + trait bound |
| 多态 | 函数指针 | 虚函数 (vtable) | trait object (`dyn Trait`) |
| 错误处理 | 返回码 / `errno` | 异常 | `Result<T, E>` / `?` |
| 模块化 | `#include` | `#include` + namespace | `mod` / `use` (真正的模块系统) |
| 并发 | pthread | `std::thread` | `Send + Sync` trait（编译期检查） |
| 字符串 | `char*` | `std::string` | `&str` / `String` |
