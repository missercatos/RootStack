### Auto-Deref  Deref Trait

Rust  **auto-deref**  `&T`  `&T``&&T``&Box<T>` 

```rust
let s = String::from("hello");

// String  Deref<Target = str>
//  &String  &str

fn print_str(s: &str) {
    println!("{}", s);
}

print_str(&s);        //  &String → &strDeref coercion
print_str(&&s);       //  &&String → &str deref
print_str(&**&s);     //  
```

**Deref coercion **

```text
&String → &str           String: Deref<Target = str>
&Vec<T> → &[T]          Vec<T>: Deref<Target = [T]>
&Box<T> → &T            Box<T>: Deref<Target = T>
&mut T → &T              &mut T  &T


&Box<String> → &String → &str
Box: Deref → String, String: Deref → str
```

```rust
//  Deref
let s = String::from("hello");

// String  len() 
//  str  len() 
//  Deref  str::len()

s.len()  //  (*s).len()  //  <String as Deref>::deref(&s).len()
```

**Deref trait **

```rust
// 
pub trait Deref {
    type Target: ?Sized;
    fn deref(&self) -> &Self::Target;
}

// String 
impl Deref for String {
    type Target = str;
    fn deref(&self) -> &str {
        //  str 
    }
}
```

### String vs &str 

|  |  |  |  |  |
|------|--------|------|------|---------|
| `String` |  |  | 24B | (24B) + () |
| `&str` |  |  | 16B | (16B) → / |
| `&String` |  |  | 8B | (8B) → (24B) →  |

```rust
// String: 
let mut s = String::from("hello");
s.push_str(" world");  //  

// &str: 
let s: &str = "hello";
// s.push_str(" world");  //   push_str 

// &String:  String Deref  &str
let owned = String::from("hello");
let r: &String = &owned;
// r  &String &str 
print_str(r);  //  Deref coercion: &String → &str
```
