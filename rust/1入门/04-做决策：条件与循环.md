# 做决策：条件与循环

## 原理

`if` 在 Rust 中是表达式（expression），每个分支必须有相同类型。编译期确认所有分支类型一致，生成单一返回值的 LLVM `Phi` 节点。

`for .. in` 基于 `IntoIterator` trait 进行迭代。编译器对范围 `0..5` 进行循环展开（loop unrolling）优化，消除边界检查。`loop` 在 LLVM 中生成无条件分支（`br label`），`while` 在每次迭代前执行条件分支。

`break` 可携带返回值：`break value;`，这使得 `loop` 成为常规表达式的替代方案。`continue` 生成无条件跳回循环头的分支。

## 深入理解：Rust 控制流的表达式语义

### if/else 作为表达式（不是语句）

在 C/C++ 中，`if` 是语句（statement），不返回值。在 Rust 中，`if` 是表达式（expression），有返回值：

```rust
// Rust: if 是表达式
let x = 5;
let description = if x > 0 { "positive" } else { "non-positive" };
// description 的类型是 &str，由两个分支的类型决定

// C 等价代码（需要变量赋值）：
// const char* description;
// if (x > 0) { description = "positive"; }
// else { description = "non-positive"; }
```

**为什么 `if` 必须是表达式？** 因为 Rust 的设计哲学是「一切皆表达式」。这消除了临时变量和重复代码：

```rust
// ❌ C 风格（冗余）
let result;
if condition {
    result = expensive_calculation_a();
} else {
    result = expensive_calculation_b();
}

// ✅ Rust 风格（简洁）
let result = if condition {
    expensive_calculation_a()
} else {
    expensive_calculation_b()
};
```

**编译器如何实现 `if` 表达式：** LLVM 的 SSA 形式中，`if` 表达式生成 `Phi`（φ）节点：

```text
// Rust: let y = if x > 0 { 1 } else { 0 };

// LLVM IR（简化）：
// entry:
//   %cmp = icmp sgt i32 %x, 0
//   br i1 %cmp, label %then, label %else
//
// then:
//   br label %merge
//
// else:
//   br label %merge
//
// merge:
//   %y = phi i32 [1, %then], [0, %else]  ← Phi 节点选择值
```

**分支类型必须一致：**

```rust
// ❌ 编译错误：分支类型不一致
// let value = if true { 5 } else { "hello" };
//                       ^^ i32   ^^^^^^^ &str

// ✅ 统一类型
let value = if true { 5 } else { 0 };       // 两个分支都是 i32
let value = if true { 5 } else { 0.0 };     // ❌ i32 vs f64
let value = if true { 5.0 } else { 0.0 };   // ✅ 都是 f64
```

### 循环标签（Loop Labels）与 break 带值

嵌套循环时，默认 `break` 只退出最内层循环。**循环标签**（loop label）允许指定退出哪一层：

```rust
// 无标签：break 只退出最内层
let mut count = 0;
loop {
    let mut inner = 0;
    loop {
        inner += 1;
        count += 1;
        if inner >= 5 { break; }  // 只退出内层 loop
    }
    if count >= 20 { break; }
}

// 有标签：break 指定退出外层
'outer: loop {
    let mut inner = 0;
    loop {
        inner += 1;
        if inner >= 5 { break 'outer; }  // 退出外层 loop
    }
}
```

**标签的命名约定：** 以 `'` 开头，后跟标识符（如 `'outer`、`'inner`、`'search`）。这是 Rust 生命周期标注的语法前缀。

**`break` 可以携带返回值：**

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2;  // break 携带值，loop 整体返回 20
    }
};
// result == 20
```

**`continue` 也可以跳转到标签：**

```rust
'outer: for i in 0..5 {
    'inner: for j in 0..5 {
        if j == 3 { continue 'outer; }  // 跳到外层循环的下一次迭代
        println!("{} {}", i, j);
    }
}
```

### while let 模式匹配

`while let` 结合了循环和模式匹配，常用于处理迭代器和枚举：

```rust
// 从 Vec 中逐个 pop
let mut stack = vec![1, 2, 3];
while let Some(top) = stack.pop() {
    println!("{}", top);  // 3, 2, 1
}
// 当 pop() 返回 None 时循环结束

// 读取输入直到空行
let mut lines = vec!["hello", "world", ""];
while let Some(line) = lines.pop() {
    if line.is_empty() { break; }
    println!("{}", line);
}
```

**`while let` 的等价展开：**

```rust
// while let Some(x) = iter.next() { ... }

// 等价于：
loop {
    match iter.next() {
        Some(x) => { ... }
        None => break,
    }
}
```

### for 循环与 Range

```rust
// 半开区间：0..5 → [0, 1, 2, 3, 4]
for i in 0..5 {
    print!("{} ", i);  // 0 1 2 3 4
}

// 闭区间：0..=5 → [0, 1, 2, 3, 4, 5]
for i in 0..=5 {
    print!("{} ", i);  // 0 1 2 3 4 5
}

// 逆序
for i in (0..5).rev() {
    print!("{} ", i);  // 4 3 2 1 0
}

// 带索引
for (index, value) in arr.iter().enumerate() {
    println!("[{}] = {}", index, value);
}

// 步长（需要自定义迭代器）
for i in (0..20).step_by(3) {
    print!("{} ", i);  // 0 3 6 9 12 15 18
}
```

**`for` 的底层机制——`IntoIterator` trait：**

```rust
// for 循环会调用 into_iter() 获取迭代器
// for item in collection { ... }

// 等价于：
let mut iter = collection.into_iter();
loop {
    match iter.next() {
        Some(item) => { ... }
        None => break,
    }
}

// 三种迭代方式：
for v in vec { }       // into_iter() → 消耗 Vec，v 是 T
for v in &vec { }      // iter() → 借用，v 是 &T
for v in &mut vec { }  // iter_mut() → 可变借用，v 是 &mut T
```

### 与 C/C++ 的对比

```rust
// Rust: match 是表达式，穷尽性检查
let x = 1;
let description = match x {
    1 => "one",
    2 => "two",
    _ => "other",  // _ 是通配符，必须覆盖所有情况
};
```

```c
// C: switch 有 fallthrough 风险
int x = 1;
const char* description;
switch (x) {
    case 1:
        description = "one";
        break;        // 忘记 break 会 fall through
    case 2:
        description = "two";
        break;
    default:
        description = "other";
        break;
}
// C 的 switch 不是表达式，必须赋值给变量
```

**Rust 的 `match` vs C 的 `switch`：**

| 特性 | Rust `match` | C `switch` |
|------|-------------|------------|
| 类型 | 表达式（有返回值） | 语句（无返回值） |
| 穷尽性 | 编译期检查必须覆盖所有情况 | 不检查 |
| Fallthrough | 不存在（每个分支独立） | 存在（需要 break） |
| 模式匹配 | 支持复杂模式 | 仅整数常量 |
| 类型安全 | 类型必须一致 | 隐式整数转换 |

### loop 作为表达式

`loop` 是 Rust 中唯一可以返回值的无限循环：

```rust
// loop 返回值
let mut counter = 0;
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2;  // 返回 20
    }
};
// result == 20

// 与 C 的对比：C 的 do-while 不能返回值
// int result;
// do { counter++; } while (counter < 10);
// result = counter;  // 必须在循环外赋值
```

## 语法

### if/else

```rust
let score = 85;
let grade = if score >= 90 { "A" }
 else if score >= 75 { "B" }
 else if score >= 60 { "C" }
 else { "F" };
// grade 是 &str 类型，各分支统一
```

比较运算符：`==` `!=` `>` `<` `>=` `<=`

逻辑运算符：

| 符号 | 含义 | 示例 |
|------|------|------|
| `&&` | 且 | `a > 0 && b > 0` |
| `\|\|` | 或 | `x == 1 \|\| x == 2` |
| `!` | 非 | `!done` |

> `if` 条件必须是 `bool` 类型。`if 1 {}` 是编译错误（区别于 C）。

### 循环

```rust
// loop — 无限循环
let mut count = 0;
let result = loop {
 count += 1;
 if count >= 10 { break count * 2; }
};

// while — 带条件
let mut n = 5;
while n > 0 {
 n -= 1;
}

// for — 迭代遍历
for i in 0..5 { } // 0,1,2,3,4
for i in 0..=5 { } // 0,1,2,3,4,5
for (i, v) in arr.iter().enumerate() { }
for v in arr { } // 消耗所有权
for v in &arr { } // 借用
for v in (1..5).rev() { // 逆序
```

### break / continue

```rust
for i in 1..=10 {
 if i == 5 { break; } // 立即退出循环
 if i % 2 == 0 { continue; } // 跳过本次迭代
}
```

| 关键字 | 行为 |
|--------|------|
| `break` | 退出循环（可带值） |
| `continue` | 跳过本次剩余代码，继续下一次 |

## 常见陷阱

### 1. `if` 条件不是 `bool` 类型
```rust
let x = 1;
// if x { }  // ❌ 编译错误：expected `bool`, found `i32`
if x != 0 { }  // ✅ 正确
```

### 2. 分支类型不一致
```rust
// let result = if true { 5 } else { "hello" };
// ❌ 编译错误：expected `i32`, found `&str`
```

### 3. `for` 循环默认消耗所有权
```rust
let v = vec![1, 2, 3];
for item in v { }     // v 被消耗，不能再用
// for item in v { }  // ❌ 编译错误：value used after move
for item in &v { }    // ✅ 借用，v 仍可用
```
