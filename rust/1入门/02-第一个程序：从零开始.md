# 第一个程序：从零开始

## 原理

Rust 程序入口是 `fn main()`，编译器在链接时寻找该符号作为 CRT（C Runtime）调用起点。`let` 声明的变量默认不可变（immutable by default），编译器将变量名映射到栈上或寄存器中的确定位置，拒绝二次赋值。这与 C 的 `const int` 语义类似，但默认生效。

`println!` 宏在编译期展开为对 `std::io::_print` 的调用，格式化字符串在编译期通过 `format_args!` 做类型检查，避免了 C `printf` 的运行时不匹配问题。

数字运算对于整数默认溢出时在 debug 模式 panic，release 模式则进行二进制补码回绕（two's complement wrapping）。

## 深入理解：Rust 程序的执行机制

### `fn` 语法详解

`fn` 是 Rust 的函数关键字。Rust 函数的完整语法包括可见性修饰、泛型参数、生命周期标注、参数列表和返回类型：

```rust
// 最简形式
fn greet() {
    println!("hello");
}

// 带参数和返回值
fn add(a: i32, b: i32) -> i32 {
    a + b  // 注意：没有分号，这是表达式，作为返回值
}

// 带泛型和生命周期
<'a, T: std::fmt::Display> fn print_ref(r: &'a T) {
    println!("{}", r);
}

// pub 表示公开可见性（库 crate 对外暴露）
pub fn public_api() -> i32 {
    42
}
```

**Rust 函数参数必须标注类型**，不像 C 有默认的 `int` 推断。这是显式优于隐式的设计哲学：

```rust
// ✅ 正确：显式类型
fn square(x: i32) -> i32 {
    x * x
}

// ❌ 编译错误：缺少类型标注
// fn square(x) -> i32 { x * x }
//            ^^ expected one of `:`, `@`, or `|`
```

### `println!` 宏的工作原理

`println!` 是一个 **声明宏（declarative macro）**，使用 `macro_rules!` 定义。它在编译期展开，不是运行时函数调用：

```rust
// 你写的代码：
println!("我叫{}，今年{}岁。", name, age);

// 编译期展开为类似（简化）：
{
    // format_args! 在编译期分析格式字符串，验证参数类型
    let _args = format_args!("我叫{}，今年{}岁。", name, age);
    std::io::_print(_args);
}
```

**为什么宏而非函数？** 因为 Rust 的 `println!` 需要：
1. 编译期检查格式字符串的语法（`{}`、`{:.2}`、`{:?}` 等）
2. 编译期验证参数数量和类型是否匹配
3. 避免 C `printf` 的运行时格式不匹配风险

```rust
// C 的危险：
// printf("%s %d", name);  // 参数不匹配！运行时未定义行为

// Rust 的安全：
println!("{}", name);      // ✅ 编译通过
// println!("{}", name, age);  // ❌ 编译错误：too few arguments
```

### 分号（`;`）与表达式（Expression）

这是 Rust 最独特的特性之一：**几乎一切都是表达式**。

```rust
// Rust 中，块 `{}` 的最后一个表达式就是块的值
let x = {
    let a = 5;
    let b = 10;
    a + b  // ← 没有分号！这是表达式，值为 15
};
// x == 15

// 如果加了分号，就变成语句（statement），块的值变成 ()
let y = {
    let a = 5;
    let b = 10;
    a + b;  // ← 有分号！这是语句，返回 ()
};
// y == ()
```

```text
表达式（Expression）          语句（Statement）
─────────────────          ──────────────────
有返回值                     无返回值（返回 ()）
可以放在赋值右侧             不能放在赋值右侧
可以嵌套                     可以嵌套

5 + 3           → 8         let x = 5;    → ()
if a { 1 } else { 0 } → 1  println!("hi"); → ()
{ a + b }       → 15        x = 5;        → ()
```

**分号的本质：加了分号 = 丢弃返回值。** 这就是为什么函数的隐式返回必须不加分号：

```rust
fn double(x: i32) -> i32 {
    x * 2   // ✅ 表达式，值为 x*2，作为函数返回值
}

fn double_broken(x: i32) -> i32 {
    x * 2;  // ❌ 编译错误：expected `i32`, found `()`
            //    分号使其变成语句，返回 ()
}
```

### main 函数的返回类型

`main` 函数默认返回 `()`（unit type），但也可以返回 `Result`：

```rust
// 默认形式
fn main() {
    println!("Hello!");
}

// 返回 Result，方便在 main 中使用 ? 运算符
fn main() -> Result<(), Box<dyn std::error::Error>> {
    let content = std::fs::read_to_string("config.toml")?;
    println!("{}", content);
    Ok(())
}

// 返回 !
// fn main() -> ! {
//     loop { }  // 永不返回，用于守护进程
// }
```

`!` 类型叫做 **never type**（永不类型），表示函数永远不会返回。`loop {}`、`panic!()`、`std::process::exit()` 的类型都是 `!`。

### 隐式返回 vs 显式返回

```rust
// 隐式返回（推荐，更符合 Rust 惯例）
fn add(a: i32, b: i32) -> i32 {
    a + b
}

// 显式返回（也可以，但不推荐）
fn add_explicit(a: i32, b: i32) -> i32 {
    return a + b;
}

// 早期返回（提前退出，必须用 return）
fn find_first_negative(arr: &[i32]) -> Option<i32> {
    for &val in arr {
        if val < 0 {
            return Some(val);  // 提前返回
        }
    }
    None  // 隐式返回
}
```

## 语法

### 基本结构

```rust
fn main() {
 let name = "小明";
 let age: i32 = 18; // 显式类型标注
 println!("我叫{}，今年{}岁。", name, age);
}
```

### 变量与不可变性

```rust
let x = 5;
// x = 6; // 编译错误：cannot assign twice to immutable variable

let mut y = 5;
y = 6; // 合法
```

### 变量遮蔽 (Shadowing)

```rust
let x = 5;
let x = x + 1; // 新 x 遮蔽旧 x，类型可以不同
let x = "hello"; // 允许
```

**Shadowing 与 `mut` 的本质区别：**

| | Shadowing | `mut` |
|--|-----------|-------|
| 语义 | 创建新变量，旧变量被遮蔽 | 同一变量，值可变 |
| 类型 | 可以改变 | 必须相同 |
| 生命周期 | 新变量从声明处开始 | 原变量全程有效 |
| 编译器视角 | 两个不同的变量 | 一个变量，值可变 |

```rust
let spaces = "   ";          // &str 类型
let spaces = spaces.len();   // usize 类型，合法（类型变了）
// mut 版本：
// let mut spaces = "   ";
// spaces = spaces.len();     // ❌ 编译错误：类型不匹配
```

### 基本类型

| 类型 | 含义 | 例子 |
|------|------|------|
| `i32` | 32位有符号整数（默认） | `42` |
| `f64` | 64位浮点数（默认） | `3.14` |
| `bool` | 布尔值 | `true`, `false` |
| `char` | Unicode 字符（4字节） | `'好'` |
| `&str` | 字符串切片引用 | `"hello"` |

### 运算

```rust
let a = 10;
let b = 3;
println!("{}+{}={}", a, b, a + b); // 10+3=13
println!("{}/{}={}", a, b, a / b); // 10/3=3（整数截断）
println!("{}/{}={}", 10.0/3.0, f64); // 3.333...
```

### 占位符

```rust
println!("{0} + {1} = {2}", x, y, x + y); // 按索引
println!("{name} {age}", name="小明", age=18); // 按命名
println!("{:#?}", some_struct); // 美化调试输出
```

### 注释

```rust
// 单行注释
/* 多行注释 */
/// 文档注释（用于 rustdoc）
//! 模块级文档注释
```

### 常见错误

| 错误 | 原因 |
|------|------|
| 忘记分号 | 每条语句必须以 `;` 结尾 |
| 单引号字符串 | `'你好'` 是 char，字符串用 `"你好"` |
| 类型不匹配 | `let x: i32 = "hello"` 编译失败 |
| 返回类型不一致 | 函数所有分支必须返回相同类型 |

## 常见陷阱

### 1. `println!` 的格式字符串必须是字面量
```rust
let fmt = "{}";
// println!(fmt, 42);  // ❌ 编译错误：格式字符串必须是字面量
println!("{}", 42);     // ✅ 正确
```

### 2. 整数除法截断
```rust
let result = 7 / 2;   // result == 3，不是 3.5
let result = 7.0 / 2.0; // result == 3.5（浮点除法）
```

### 3. 函数返回类型不匹配
```rust
// ❌ 编译错误
// fn example(x: bool) -> i32 {
//     if x { 1 } else { "hello" }  // 类型不一致
// }

// ✅ 正确
fn example(x: bool) -> i32 {
    if x { 1 } else { 0 }
}
```
