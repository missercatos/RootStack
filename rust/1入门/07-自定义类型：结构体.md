# 自定义类型：结构体

## 原理

`struct` 在编译后对应连续内存布局（C 兼容的 repr）。Rust 默认不保证字段顺序（可重排以优化对齐填充），但 `#[repr(C)]` 可锁定为 C 兼容布局。

栈上结构体内存：`struct { x: i32, y: f64 }` 对齐后为 16 字节（4B x + 4B padding + 8B y）。`#[derive(Debug)]` 通过过程宏自动生成 `fmt::Debug` trait 实现，不增加运行时开销。

`impl` 块的 `&self` 参数在编译后对应一个隐式指针参数（等价于 C 的 `this` 指针）。关联函数（无 `&self`）是普通的命名空间函数，调用方式 `Type::func()`。

元组结构体 `struct Point(i32, i32)` 和普通同名结构体是不同的类型，不能互换。单元结构体 `struct Unit;` 实例大小为 0 字节（零大小类型 ZST），编译器优化后不留内存痕迹。

## 深入理解：结构体的内存与行为

### Struct 内存布局与对齐

Rust 结构体的内存布局遵循 **对齐（alignment）** 规则——每个字段的起始地址必须是其大小的整数倍：

```rust
struct A {
    x: i32,   // 4 字节，对齐到 4
    y: f64,   // 8 字节，对齐到 8
    z: u8,    // 1 字节，对齐到 1
}
```

```text
默认布局（Rust 可能重排字段以减少填充）：

编译器可能重排为 z, x, y 或 x, z, y 等顺序
以最小化填充字节

假设重排为 z, x, y：
偏移  内容
0     z (u8)         1 字节
1     [padding]      3 字节  ← 对齐到 4
4     x (i32)        4 字节
8     y (f64)        8 字节
────────────────────────
总计 16 字节

如果按声明顺序 x, y, z：
偏移  内容
0     x (i32)        4 字节
4     [padding]      4 字节  ← 对齐到 8
8     y (f64)        8 字节
16    z (u8)         1 字节
17    [padding]      7 字节  ← 总大小对齐到 8
────────────────────────
总计 24 字节（多了 8 字节填充）
```

**`#[repr(C)]` 强制 C 布局（按声明顺序，不重排）：**

```rust
#[repr(C)]
struct Point {
    x: i32,  // 偏移 0
    y: f64,  // 偏移 8（对齐到 8，中间有 4 字节填充）
    z: u8,   // 偏移 16
}
// 总大小：16 + 1 + 7(padding) = 24 字节
```

**`#[repr(packed)]` 消除填充（可能降低性能）：**

```rust
#[repr(packed)]
struct Packed {
    x: i32,
    y: f64,
    z: u8,
}
// 总大小：4 + 8 + 1 = 13 字节（无填充）
// 但未对齐的访问可能导致性能问题或 CPU 异常
```

### Method Syntax（方法语法）

Rust 的方法通过 `impl` 块定义，`self` 参数是隐式的：

```rust
struct Circle {
    radius: f64,
}

impl Circle {
    // 方法：第一个参数是 &self（不可变借用）
    fn area(&self) -> f64 {
        std::f64::consts::PI * self.radius * self.radius
    }

    // 方法：第一个参数是 &mut self（可变借用）
    fn grow(&mut self, factor: f64) {
        self.radius *= factor;
    }

    // 方法：第一个参数是 self（获取所有权）
    fn into_area(self) -> f64 {
        // self 被消耗，Circle 被 drop
        std::f64::consts::PI * self.radius * self.radius
    }

    // 关联函数（无 self）：类似其他语言的静态方法
    fn new(radius: f64) -> Self {
        Circle { radius }
    }

    // 关联常量
    const PI: f64 = 3.14159265358979;
}
```

**`self` 的三种形式及其底层机制：**

```text
fn area(&self) -> f64          fn grow(&mut self, f)    fn into_area(self)
─────────────────────         ─────────────────────    ──────────────────
&self = &Circle               &mut self = &mut Circle  self = Circle
底层：*const Circle            底层：*mut Circle         底层：Circle（值传递）

调用时：
circle.area()                 circle.grow(2.0)         circle.into_area()
↓                             ↓                        ↓
Circle::area(&circle)         Circle::grow(&mut c, 2)  Circle::into_area(c)
```

**方法调用的编译转换：**

```rust
let c = Circle { radius: 5.0 };
let a = c.area();

// 编译器将其转换为：
let a = Circle::area(&c);  // 显式传递 &self

// 对于 &mut 方法：
let mut c = Circle { radius: 5.0 };
c.grow(2.0);
// 编译为：
Circle::grow(&mut c, 2.0);
```

### Associated Functions vs Methods

```text
关联函数（Associated Functions）    方法（Methods）
─────────────────────────        ──────────────────
没有 self 参数                    有 self 参数
通过 Type::func() 调用            通过 instance.method() 调用
类似其他语言的 static 方法         类似其他语言的实例方法
通常用于构造器（new、from）        用于操作实例数据
```

```rust
impl Circle {
    // 关联函数：构造器
    fn new(radius: f64) -> Self { Circle { radius } }

    // 关联函数：工厂方法
    fn unit() -> Self { Circle { radius: 1.0 } }
}

// 调用方式
let c1 = Circle::new(5.0);  // Type::func()
let c2 = Circle::unit();
let a = c1.area();           // instance.method()
```

### 三种结构体形式

```rust
// 1. 普通结构体：具名字段
struct User {
    name: String,
    age: u32,
    email: String,
}

// 2. 元组结构体：匿名字段
struct Color(u8, u8, u8);
struct Point(f64, f64);

// 3. 单元结构体：无字段
struct Marker;
```

**内存布局对比：**

```text
User（3 个 String + u32）：
┌──────────────────────────────┐
│ name: String (24B)           │ → 堆
│ age: u32 (4B) + pad (4B)    │
│ email: String (24B)          │ → 堆
└──────────────────────────────┘
总计：56B（可能更多填充）

Color(u8, u8, u8)：
┌─────────┐
│ .0: u8  │  1B
│ .1: u8  │  1B
│ .2: u8  │  1B
│ [pad]   │  1B（对齐到 4）
└─────────┘
总计：4B

Point(f64, f64)：
┌──────────────┐
│ .0: f64      │  8B
│ .1: f64      │  8B
└──────────────┘
总计：16B

Marker：
┌────┐
│    │  0 字节（ZST）
└────┘
```

### Struct Update Syntax（结构体更新语法）

```rust
let p1 = Person {
    name: String::from("Alice"),
    age: 25,
};

let p2 = Person {
    name: String::from("Bob"),
    ..p1  // age 从 p1 复制（Copy），name 使用新值
};
// p1.name 已被 move 到... 等等，这里 name 是新的
// p1.age 被 Copy（u32 是 Copy 类型）
// p1 整体仍然有效，因为 name 没有被 move
```

```text
struct Update Syntax 的内存操作：

p1:
┌──────────────────┐
│ name: String     │ ──→ "Alice" (堆)
│ age: 25          │
└──────────────────┘

p2 = Person { name: String::from("Bob"), ..p1 }:
┌──────────────────┐
│ name: String     │ ──→ "Bob" (新分配的堆数据)
│ age: 25          │  ← 从 p1 复制 (u32 是 Copy)
└──────────────────┘

p1 仍然有效：
┌──────────────────┐
│ name: String     │ ──→ "Alice" (仍然有效)
│ age: 25          │  ← 被复制了，但 p1 仍然有值
└──────────────────┘
```

**更新语法的所有权规则：**

```rust
// Copy 字段：复制值，原结构体仍然有效
let p1 = Person { name: String::from("Alice"), age: 25 };
let p2 = Person { name: String::from("Bob"), ..p1 };
// ✅ p1.name 没有被移动，p1 仍然完整

// 如果使用了 p1 的非 Copy 字段：
struct Wrapper { data: Vec<i32>, id: u32 }
let w1 = Wrapper { data: vec![1, 2, 3], id: 1 };
let w2 = Wrapper { data: vec![4, 5], ..w1 };
// w1.data 没有被移动（w2 用了新的 data）
// w1.id 被 Copy
// ✅ w1 仍然有效

let w3 = Wrapper { id: 2, ..w1 };
// w1.data 会被 move 到 w3
// ❌ w1 不再完整，w1.data 不能再用
// ✅ 但 w1.id 可以继续使用（它是 Copy 的）
```

### Derive Traits（派生特征）

`#[derive(...)]` 自动为结构体实现常用 trait：

```rust
#[derive(Debug, Clone, PartialEq)]
struct Point {
    x: f64,
    y: f64,
}

// #[derive(Debug)] 自动生成：
// impl fmt::Debug for Point {
//     fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
//         f.debug_struct("Point")
//          .field("x", &self.x)
//          .field("y", &self.y)
//          .finish()
//     }
// }

// #[derive(Clone)] 自动生成：
// impl Clone for Point {
//     fn clone(&self) -> Self {
//         Point { x: self.x.clone(), y: self.y.clone() }
//     }
// }

// #[derive(PartialEq)] 自动生成：
// impl PartialEq for Point {
//     fn eq(&self, other: &Self) -> bool {
//         self.x == other.x && self.y == other.y
//     }
// }
```

**常用 derive trait：**

| Trait | 作用 | 自动生成 |
|-------|------|---------|
| `Debug` | 调试输出 `{:?}` | `fmt::Debug` |
| `Clone` | 显式深拷贝 `.clone()` | `clone()` |
| `Copy` | 隐式按位复制 | 需要 Clone |
| `PartialEq` | 相等比较 `==` | `eq()` |
| `Eq` | 完全相等（标记 trait） | — |
| `PartialOrd` | 部分排序 `<` `>` | `partial_cmp()` |
| `Ord` | 完全排序 | `cmp()` |
| `Hash` | 哈希计算 | `hash()` |
| `Default` | 默认值 | `default()` |

**不能 derive 的情况：**

```rust
// ❌ 不能为包含非 Copy 字段的结构体 derive Copy
// #[derive(Copy, Clone)]
// struct User {
//     name: String,  // String 不是 Copy
// }

// ✅ 但可以 derive Clone（深拷贝）
#[derive(Clone)]
struct User {
    name: String,
    age: u32,
}
```

### C/C++ 中的结构体对比

```c
// C 结构体
struct Point {
    double x;
    double y;
};

// C 结构体可以这样初始化（C99 复合字面量）
struct Point p = { .x = 1.0, .y = 2.0 };

// C 结构体赋值是浅拷贝
struct Point p1 = { 1.0, 2.0 };
struct Point p2 = p1;  // 浅拷贝，两个独立副本
```

```rust
// Rust 结构体
struct Point {
    x: f64,
    y: f64,
}

// Rust 结构体初始化
let p = Point { x: 1.0, y: 2.0 };

// Rust 赋值：如果所有字段都是 Copy，则自动 Copy
// Point 的两个 f64 都是 Copy → Point 可以 Copy
let p1 = Point { x: 1.0, y: 2.0 };
let p2 = p1;  // Copy，p1 仍然有效
```

| 特性 | C 结构体 | Rust 结构体 |
|------|---------|------------|
| 字段顺序 | 固定（声明顺序） | 可重排（除非 `repr(C)`） |
| 填充 | 手动管理 | 编译器自动优化 |
| 方法 | 不支持（用函数） | `impl` 块 |
| 泛型 | 不支持（用 `void*`） | 支持 |
| 继承 | 不支持 | 不支持（用 trait） |
| 内存布局 | 可预测（`repr(C)`） | 可预测（`repr(C)`） |

## 语法

### 定义与实例化

```rust
#[derive(Debug)]
struct Person {
 name: String,
 age: u32,
}

let mut p = Person {
 name: String::from("小明"),
 age: 18,
};
p.age = 19; // 需要 mut
```

### 字段初始化简写

```rust
let name = String::from("小明");
let age = 18;
let p = Person { name, age }; // 变量名==字段名时可省略
```

### 结构体更新语法

```rust
let p2 = Person {
 name: String::from("小红"),
 ..p1 // 其余字段从 p1 移动（Copy 字段复制）
};
// 非 Copy 字段被移动后 p1 不可再用
```

### 方法（impl 块）

```rust
impl Person {
 // 实例方法：&self / &mut self / self
 fn greet(&self) {
 println!("我叫{}", self.name);
 }

 fn birthday(&mut self) {
 self.age += 1;
 }

 // 关联函数（构造器模式）
 fn new(name: String, age: u32) -> Self {
 Person { name, age }
 }
}

let p = Person::new(String::from("小红"), 17);
p.greet();
```

### 结构体三种形式

| 形式 | 语法 | 访问 |
|------|------|------|
| 普通 | `struct P { x: i32 }` | `p.x` |
| 元组 | `struct P(i32, f64)` | `p.0`, `p.1` |
| 单元 | `struct P;` | 无字段 |

### Debug 打印

```rust
#[derive(Debug)]
struct P { x: i32 }
let p = P { x: 5 };
println!("{:?}", p); // P { x: 5 }
println!("{:#?}", p); // 美化输出
```

## 常见陷阱

### 1. 忘记 `#[derive(Debug)]` 导致无法打印
```rust
// struct Foo { x: i32 }
// println!("{:?}", Foo { x: 1 });  // ❌ 编译错误：Foo doesn't implement Debug

#[derive(Debug)]
struct Foo { x: i32 }
println!("{:?}", Foo { x: 1 });  // ✅ Foo { x: 1 }
```

### 2. 结构体更新语法中的所有权问题
```rust
let p1 = Person { name: String::from("Alice"), age: 25 };
let p2 = Person { name: String::from("Bob"), ..p1 };
// p1.name 没有被 move（p2 用了新的 name）
// 但 p1.age 被 Copy 了
// ✅ p1 仍然完整

// 危险情况：
let p3 = Person { age: 30, ..p1 };
// p1.name 会被 move 到 p3
// ❌ p1.name 不再可用
```

### 3. 元组结构体不能与普通结构体互换
```rust
struct Point(f64, f64);
struct Point2 { x: f64, y: f64 }

let p1 = Point(1.0, 2.0);
// let p2: Point2 = p1;  // ❌ 编译错误：不同类型
```

### 4. ZST（零大小类型）的使用场景
```rust
struct Marker;  // 0 字节

// ZST 常用于：
// 1. 类型状态标记（typestate pattern）
// 2. 泛型参数的零开销抽象
// 3. 作为迭代器的 Item 类型（when no data）

let m = Marker;
println!("{}", std::mem::size_of_val(&m));  // 0
```
