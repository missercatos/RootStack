### Method Syntax

Rust  `impl` `self` 

```rust
struct Circle {
    radius: f64,
}

impl Circle {
    //  &self
    fn area(&self) -> f64 {
        std::f64::consts::PI * self.radius * self.radius
    }

    //  &mut self
    fn grow(&mut self, factor: f64) {
        self.radius *= factor;
    }

    //  self
    fn into_area(self) -> f64 {
        // self Circle  drop
        std::f64::consts::PI * self.radius * self.radius
    }

    //  self
    fn new(radius: f64) -> Self {
        Circle { radius }
    }

    // 
    const PI: f64 = 3.14159265358979;
}
```

** derive trait**

| Trait |  |  |
|-------|------|---------|
| `Debug` |  `{:?}` | `fmt::Debug` |
| `Clone` |  `.clone()` | `clone()` |
| `Copy` |  |  Clone |
| `PartialEq` |  `==` | `eq()` |
| `Eq` |  trait | — |
| `PartialOrd` |  `<` `>` | `partial_cmp()` |
| `Ord` |  | `cmp()` |
| `Hash` |  | `hash()` |
| `Default` |  | `default()` |
