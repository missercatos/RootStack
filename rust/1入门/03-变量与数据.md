### Shadowing

```rust
let x = 5;        // x1: i32,  5
let x = x + 1;    // x2: i32,  6x1 shadowed
let x = "hello";  // x3: &str,  "hello"x2 
```

```text



 x1 (i32 = 5)        ← 
 x2 (i32 = 6)        ← x1 
 x3 (&str = "hello") ← x2 

NLL x1  x2  drop
```
