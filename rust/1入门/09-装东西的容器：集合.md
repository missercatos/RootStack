### Vec\<T\> 

`Vec<T>` ptr, len, cap 24  2x push  len==cap  realloc  2*cap `ptr::copy_nonoverlapping`  C  `realloc`

```text
Vec<i32>  64 :

 (24 ):

 ptr:   *mut i32  →          8 
 len:   usize     →        8 
 cap:   usize     →          8 


 (cap=4, len=2):

 10        20        ()    ()   

```

#### 

```rust
let mut v: Vec<i32> = Vec::with_capacity(4);
//  4 * 4 = 16 
// ptr → [ ?, ?, ?, ? ]
// len=0, cap=4

v.push(10);
v.push(20);
// ptr → [ 10, 20, ?, ? ]
// len=2, cap=4

v.push(30);
v.push(40);
// ptr → [ 10, 20, 30, 40 ]
// len=4, cap=4  ← 

v.push(50); // len==cap!
// 1. : 8 * 4 = 32 
// 2. : ptr::copy_nonoverlapping(old_ptr, new_ptr, 4)
// 3. : dealloc(old_ptr, old_layout)
// 4.  Vec: ptr=new_ptr, cap=8
// ptr → [ 10, 20, 30, 40, 50, ?, ?, ? ]
// len=5, cap=8
```

####  2x  1x

amortized analysis

```text
 A:  push  realloc (1x  len+1)
   1 : 1 
   2 : 2 
   3 : 3 
  ...
   n : n 
  : 1+2+3+...+n = n(n+1)/2
  : O(n) 

 B: 2x 
   1  push: 1  ( 0→1)
   2  push: 1  ( 1→2)
   3  push: 2  ( 2→4 )
   4  push: 1 
   5-8 :  1 
   9  push: 4  ( 8→16 )
  : 1+1+2+1+1+1+1+1+4+... ≈ 2n
  : O(1) 
```

2x  O(1)  push 1.5x  C++ `vector` 2x  realloc

```rust
use std::collections::HashMap;

fn two_sum(nums: &[i32], target: i32) -> Option<(usize, usize)> {
    let mut map: HashMap<i32, usize> = HashMap::with_capacity(nums.len());
    for (i, &num) in nums.iter().enumerate() {
        if let Some(&j) = map.get(&(target - num)) {
            return Some((j, i));
        }
        map.insert(num, i);
    }
    None
}
```
