# 装东西的容器：集合

## 原理

### Vec\<T\> 内部布局

`Vec<T>` 在栈上保存三元组（ptr, len, cap，共 24 字节），堆上存实际数据。扩容策略为 2x 增长（push 时若 len==cap 则 realloc 到 2*cap）。重新分配时通过 `ptr::copy_nonoverlapping` 迁移旧数据，类似 C 的 `realloc`。

```text
Vec<i32> 在 64 位平台的内存布局:

栈上 (24 字节):
┌─────────────────────────────────────┐
│ ptr:   *mut i32  →  指向堆数据      │  8 字节
│ len:   usize     →  当前元素数量    │  8 字节
│ cap:   usize     →  分配的容量      │  8 字节
└─────────────────────────────────────┘

堆上 (cap=4, len=2):
┌──────────┬──────────┬──────────┬──────────┐
│ 10       │ 20       │ (未用)   │ (未用)   │
└──────────┴──────────┴──────────┴──────────┘
```

#### 扩容过程详解

```rust
let mut v: Vec<i32> = Vec::with_capacity(4);
// 堆上分配 4 * 4 = 16 字节
// ptr → [ ?, ?, ?, ? ]
// len=0, cap=4

v.push(10);
v.push(20);
// ptr → [ 10, 20, ?, ? ]
// len=2, cap=4

v.push(30);
v.push(40);
// ptr → [ 10, 20, 30, 40 ]
// len=4, cap=4  ← 已满

v.push(50); // len==cap，触发扩容!
// 1. 分配新堆: 8 * 4 = 32 字节
// 2. 复制旧数据: ptr::copy_nonoverlapping(old_ptr, new_ptr, 4)
// 3. 释放旧堆: dealloc(old_ptr, old_layout)
// 4. 更新 Vec: ptr=new_ptr, cap=8
// ptr → [ 10, 20, 30, 40, 50, ?, ?, ? ]
// len=5, cap=8
```

#### 为什么是 2x 而不是 1x？

从均摊分析（amortized analysis）角度：

```text
策略 A: 每次 push 都 realloc (1x 扩容，即 len+1)
  第 1 次: 1 次复制
  第 2 次: 2 次复制
  第 3 次: 3 次复制
  ...
  第 n 次: n 次复制
  总复制次数: 1+2+3+...+n = n(n+1)/2
  均摊每次: O(n) ❌

策略 B: 2x 扩容
  第 1 次 push: 1 次复制 (从 0→1)
  第 2 次 push: 1 次复制 (从 1→2)
  第 3 次 push: 2 次复制 (从 2→4 扩容)
  第 4 次 push: 1 次复制
  第 5-8 次: 各 1 次复制
  第 9 次 push: 4 次复制 (从 8→16 扩容)
  总复制次数: 1+1+2+1+1+1+1+1+4+... ≈ 2n
  均摊每次: O(1) ✓
```

2x 扩容保证了均摊 O(1) 的 push 复杂度。1.5x 是另一种常见策略（如 C++ `vector`），但 2x 在实际中更常用（减少 realloc 次数，代价是略多内存浪费）。

### String

`String` 实质是 `Vec<u8>`，保证了内容为有效 UTF-8 字节序列。`len()` 返回字节数，非字符数（一个中文字符占 3 字节）。`s[i]` 不可用于索引，因为 UTF-8 非定长编码，单字节索引可能切到字符中间 → 编译期拒绝。

```text
String "你好" 的内存布局:

栈上: Vec<u8> = (ptr, len=6, cap=6)
堆上: [E4 BD A0] [E5 A5 BD]
       ↑ "你" (3字节)  ↑ "好" (3字节)

如果允许 s[0]，会返回 0xE4，这是无效字符
```

### HashMap\<K,V\>

`HashMap<K,V>` 使用 Swiss table（hashbrown crate）实现，提供 O(1) 平均查找。Hash 碰撞通过开放式寻址（open addressing）+ SIMD 探测解决。无序性意味着遍历顺序随插入和 resize 改变。

```text
HashMap 内部结构 (Swiss Table 简化):

┌─────────────────────────────────────────┐
│ RandomState (随机种子)                   │
├─────────────────────────────────────────┤
│ Ctrl bytes (控制位): 每 slot 1 字节      │
│   0x00 = empty, 0x80 = deleted,         │
│   hash低7位 = occupied                   │
├─────────────────────────────────────────┤
│ Slots: [ (key, value), ... ]             │
│   与 ctrl bytes 一一对应                  │
└─────────────────────────────────────────┘

查找过程:
1. 计算 hash(key) → 使用 SipHash（抗 DoS）
2. 用 hash 高位选择 group (16个连续ctrl bytes)
3. SIMD 并行比较 16 个 ctrl bytes
4. 找到匹配后访问对应 slot
```

RandomState 使用随机化的哈希种子，防止 HashDoS 攻击（攻击者精心构造 key 使所有 hash 冲突，导致 O(n) 退化）。

三者使用堆存储，所以非 Copy。遍历时 `for x in vec` 消耗所有权，`for x in &vec` 仅借用。

## 语法

### Vec

```rust
let mut v: Vec<i32> = Vec::new();
v.push(1);
v.push(2);

let v2 = vec![1, 2, 3, 4, 5]; // vec! 宏，编译时推断类型
let v3: Vec<i32> = Vec::with_capacity(100); // 预分配，避免扩容

v[2]; // 索引访问（越界 panic）
v.get(2); // 返回 Option<&i32>，越界返回 None

for n in &v { } // 不可变遍历
for n in &mut v { *n += 1; } // 可变遍历
for (i, n) in v.iter().enumerate() { } // 带索引遍历

v.pop(); // 移除末尾，返回 Option<T>
v.insert(0, 9); // 指定位置插入（O(n)）
v.remove(0); // 指定位置移除（O(n)）
v.len();
v.is_empty();

// 保留满足条件的元素
v.retain(|&x| x > 0);

// 批量操作
v.extend([10, 20, 30]);
v.splice(1..3, [99]); // 在位置1~3插入99，删除原1~2
```

| 方法 | 效果 | 复杂度 |
|------|------|--------|
| `push` | 末尾插入 | O(1) 均摊 |
| `pop` | 末尾删除 | O(1) |
| `insert` | 指定位置插入 | O(n) |
| `remove` | 指定位置删除 | O(n) |
| `retain` | 按条件过滤 | O(n) |
| `extend` | 批量追加 | O(k) |

### String

```rust
let mut s = String::from("你好");
s.push_str("世界");
s.push('!'); // push 单个 char
let s = s + "结尾"; // s 被移动（左操作数被消费）

let a = String::from("A");
let b = String::from("B");
let c = format!("{} {}", a, b); // 不移动所有权，推荐

s.len(); // UTF-8 字节数（中文*3）
&s[0..6]; // 切片（注意 UTF-8 边界）

// s[0]; // 错误：String 不支持直接整数索引
s.chars().nth(0); // 按 char 遍历（O(n)）

// 字符串拼接的性能陷阱
let mut result = String::new();
for word in words {
    result.push_str(word);  // 每次可能 realloc
}
// 更高效:
let result: String = words.join("");  // 预计算大小
```

### HashMap

```rust
use std::collections::HashMap;

let mut map = HashMap::new();
map.insert("a", 1);
map.insert("b", 2);

let val = map.get("a"); // Option<&V>
let val = map["a"]; // 不存在时 panic

for (k, v) in &map { } // 无序

// Entry API: 避免重复哈希查找
// get + insert 分别计算两次 hash
// entry 只计算一次
map.entry("c").or_insert(3); // 返回 &mut V

// 统计词频（经典用法）
let count = map.entry(word).or_insert(0);
*count += 1;

// 带条件的插入
map.entry("d").or_insert_with(|| expensive_computation());

// 已存在则更新
map.insert("a", 100); // 直接覆盖
```

### HashSet

```rust
use std::collections::HashSet;

let mut set = HashSet::new();
set.insert(1);
set.insert(2);
set.insert(2); // 重复插入被忽略

set.contains(&1); // true
set.remove(&1);

// 集合运算
let a: HashSet<i32> = [1, 2, 3].into();
let b: HashSet<i32> = [2, 3, 4].into();

let union: HashSet<_> = a.union(&b).cloned().collect(); // {1,2,3,4}
let intersection: HashSet<_> = a.intersection(&b).cloned().collect(); // {2,3}
let diff: HashSet<_> = a.difference(&b).cloned().collect(); // {1}
let sym_diff: HashSet<_> = a.symmetric_difference(&b).cloned().collect(); // {1,4}
```

### BTreeMap / BTreeSet

```rust
use std::collections::BTreeMap;

let mut tree = BTreeMap::new();
tree.insert(3, "c");
tree.insert(1, "a");
tree.insert(2, "b");

// 有序遍历
for (k, v) in &tree { } // 1, 2, 3

// 范围查询 (HashMap 不支持!)
tree.range(1..=2); // 1 → "a", 2 → "b"
tree.keys(); // 有序键
tree.values(); // 有序值
```

### 集合选择指南

| 场景 | 推荐 | 原因 |
|------|------|------|
| 按键快速查找 | HashMap | O(1) 平均 |
| 需要有序遍历 | BTreeMap | O(log n) 查找，有序 |
| 范围查询 | BTreeMap | `range()` 原生支持 |
| 去重 | HashSet | O(1) 插入/查找 |
| 小集合 (<~100) | BTreeMap | 缓存友好，常数小 |
| 需要稳定迭代器 | BTreeMap | 迭代顺序稳定 |

### 集合对比

| | Vec\<T\> | String | HashMap\<K,V\> |
|--|--------|--------|--------------|
| 存储 | 同类型序列 | UTF-8 文本 | 键→值映射 |
| 访问 | 索引 O(1) | 按字节切片 | 键查找 O(1) 平均 |
| 顺序 | 插入顺序 | 插入顺序 | 无序 |
| 堆/栈 | 堆 | 堆 | 堆 |

### 迭代模式

```rust
// map: 变换每个元素
let doubled: Vec<i32> = vec![1, 2, 3].iter().map(|x| x * 2).collect();

// filter: 过滤
let evens: Vec<&i32> = vec![1, 2, 3, 4].iter().filter(|&&x| x % 2 == 0).collect();

// fold: 累积
let sum: i32 = vec![1, 2, 3].iter().fold(0, |acc, x| acc + x);

// chain: 连接两个迭代器
let combined: Vec<i32> = vec![1, 2].iter().chain(vec![3, 4].iter()).cloned().collect();

// zip: 配对
let pairs: Vec<(_, _)> = vec![1, 2, 3].iter().zip(vec!["a", "b", "c"]).collect();

// flat_map: 展开嵌套
let words: Vec<char> = vec!["hello world", "foo bar"]
    .iter()
    .flat_map(|s| s.chars())
    .collect();

// peekable: 查看下一个元素
let mut iter = vec![1, 2, 3].iter().peekable();
if iter.peek() == Some(&&1) {
    println!("以 1 开头");
}
```

## 内存预分配与性能

```rust
// ❌ 差: 多次扩容
let mut v = Vec::new();
for i in 0..10000 {
    v.push(i); // 可能扩容 ~14 次
}

// ✅ 好: 预分配
let mut v = Vec::with_capacity(10000);
for i in 0..10000 {
    v.push(i); // 零次扩容
}

// HashMap 同理
let mut map = HashMap::with_capacity(100);
```

力扣: 力扣哈希映射题 — HashMap 映射

```rust
use std::collections::HashMap;

fn two_sum(nums: &[i32], target: i32) -> Option<(usize, usize)> {
    let mut map: HashMap<i32, usize> = HashMap::with_capacity(nums.len());
    for (i, &num) in nums.iter().enumerate() {
        if let Some(&j) = map.get(&(target - num)) {
            return Some((j, i));
        }
        map.insert(num, i);
    }
    None
}
```
