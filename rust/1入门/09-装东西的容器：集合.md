# 装东西的容器：集合

## 学习目标

学完本章后，你将能够：
- 使用 `Vec` 存储动态数组
- 使用 `String` 进行文本操作
- 使用 `HashMap` 存储键值对
- 根据需求选择合适的集合类型
- 遍历和处理集合中的数据

---

## 一、为什么需要集合？

之前我们学的变量一次只能存一个值：

```rust
let x = 5;          // 一个数字
let s = "hello";    // 一段文字
```

但现实生活中，我们经常需要存**一堆东西**：

- 班级里所有学生的名字
- 购物车里的所有商品
- 单词表中每个单词对应的翻译

集合（Collections）就是用来存"一堆东西"的数据类型。

## 二、Vec：可以变长的数组

### 2.1 最简单的 Vec

```rust
fn main() {
    let mut v: Vec<i32> = Vec::new();
    v.push(1);
    v.push(2);
    v.push(3);

    println!("{:?}", v);
}
```

输出：

```
[1, 2, 3]
```

`Vec` 和数组不同：
- 数组大小固定，Vec 可以增长
- 数组用 `[1, 2, 3]` 字面量，Vec 用 `Vec::new()` 或 `vec![]`

### 2.2 用 vec! 宏快速创建

```rust
fn main() {
    let v = vec![1, 2, 3, 4, 5];
    println!("{:?}", v);
    println!("长度：{}", v.len());
}
```

`vec![...]` 是最常用的创建 Vec 的方式，就像 `println!` 一样是宏。

### 2.3 访问元素

```rust
fn main() {
    let v = vec![10, 20, 30, 40, 50];

    // 下标访问（越界会 panic）
    println!("第三个元素：{}", v[2]);

    // get 方法（越界返回 None）
    match v.get(10) {
        Some(value) => println!("值：{}", value),
        None => println!("索引 10 不存在！"),
    }
}
```

| 访问方式 | 越界行为 | 返回类型 |
|----------|---------|----------|
| `v[index]` | **panic**（程序崩溃） | 元素类型 `T` |
| `v.get(index)` | 返回 None | `Option<&T>` |

**建议**：如果你不确定索引是否有效，用 `get`。确定索引有效时用下标。

### 2.4 遍历 Vec

```rust
fn main() {
    let v = vec![10, 20, 30, 40, 50];

    // 只读遍历
    println!("所有元素：");
    for num in &v {
        println!("  {}", num);
    }

    // 带索引的遍历
    for (i, num) in v.iter().enumerate() {
        println!("v[{}] = {}", i, num);
    }
}
```

### 2.5 修改 Vec 中的元素

```rust
fn main() {
    let mut v = vec![10, 20, 30];

    // 通过可变引用遍历并修改
    for num in &mut v {
        *num += 5;  // * 解引用，修改原值
    }

    println!("{:?}", v);  // [15, 25, 35]
}
```

### 2.6 Vec 的常用操作

```rust
fn main() {
    let mut v = vec![1, 2, 3];

    v.push(4);       // 在末尾添加
    v.pop();         // 移除最后一个，返回 Option<T>

    v.insert(1, 99); // 在索引1处插入
    v.remove(0);     // 移除索引0的元素

    println!("{:?}", v);     // [99, 2, 3]
    println!("长度：{}", v.len());    // 3
    println!("是否为空：{}", v.is_empty());  // false
}
```

| 操作 | 方法 | 说明 |
|------|------|------|
| 末尾添加 | `push(value)` | 加到最后 |
| 末尾弹出 | `pop()` | 返回 Option，拿掉最后一个 |
| 插入 | `insert(index, value)` | 在指定位置插入 |
| 删除 | `remove(index)` | 删掉并返回 |
| 长度 | `len()` | 有多少元素 |
| 判空 | `is_empty()` | 是否为空 |
| 清空 | `clear()` | 全部删掉 |

## 三、String：会变长的字符串

之前我们经常用 `"Hello"` 这样的字符串字面量，但它是不可变的。`String` 是**可变的、拥有所有权的字符串**。

### 3.1 创建 String

```rust
fn main() {
    let s1 = String::new();          // 空字符串
    let s2 = String::from("你好");    // 从字面量创建
    let s3 = "你好".to_string();     // 另一种方式

    println!("s2: {}, s3: {}", s2, s3);
}
```

### 3.2 修改 String

```rust
fn main() {
    let mut s = String::from("你好");

    s.push_str("世界");    // 追加字符串
    s.push('！');         // 追加单个字符

    println!("{}", s);    // 你好世界！
}
```

### 3.3 拼接 String

```rust
fn main() {
    let s1 = String::from("Hello");
    let s2 = String::from("World");

    // 方式1：+ 运算符（会把 s1 的所有权移走）
    let s3 = s1 + " " + &s2;
    // println!("{}", s1);  // s1 已被移走

    // 方式2：format! 宏（不移动所有权）
    let s4 = String::from("Rust");
    let s5 = String::from("很棒");
    let s6 = format!("{} {}", s4, s5);
    println!("{}", s6);        // Rust 很棒
    println!("s4 还能用：{}", s4);  // format! 不移动所有权
}
```

| 拼接方式 | 是否转移所有权 | 推荐度 |
|----------|-------------|--------|
| `+` | 第一个 String 会移走 | 适合简单拼接 |
| `format!` | 不转移 | 推荐，更灵活 |

### 3.4 取子串和长度

```rust
fn main() {
    let s = String::from("你好世界！");

    println!("长度（字节）：{}", s.len());    // UTF-8 字节数
    println!("是否为空：{}", s.is_empty());

    // 取子串（注意 UTF-8 边界问题）
    let hello = &s[0..6];  // "你好" 在 UTF-8 中占 6 个字节
    println!("{}", hello); // 你好
}
```

## 四、HashMap：键值对字典

HashMap 就像一本电话簿：你通过名字找电话号码。名字是"键"，号码是"值"。

### 4.1 创建和插入

```rust
use std::collections::HashMap;

fn main() {
    let mut phone_book = HashMap::new();

    phone_book.insert("小明", "13800138000");
    phone_book.insert("小红", "13900139000");
    phone_book.insert("小刚", "13700137000");
}
```

`use std::collections::HashMap;` 是"导入"声明，因为 HashMap 不像 Vec 和 String 那样在"预导入"中。

### 4.2 查找

```rust
fn main() {
    let mut phone_book = HashMap::new();
    phone_book.insert("小明", "13800138000");

    // 用 get 查找
    match phone_book.get("小明") {
        Some(number) => println!("小明的电话：{}", number),
        None => println!("没找到小明"),
    }

    // 用 [] 查找（不存在会 panic）
    println!("{}", phone_book["小明"]);
}
```

### 4.3 遍历

```rust
fn main() {
    let mut scores = HashMap::new();
    scores.insert("小明", 90);
    scores.insert("小红", 85);
    scores.insert("小刚", 78);

    for (name, score) in &scores {
        println!("{}：{}分", name, score);
    }
}
```

注意：HashMap 的遍历顺序**不固定**。

### 4.4 更新和插入规则

```rust
fn main() {
    let mut map = HashMap::new();

    // 直接覆盖
    map.insert("a", 1);
    map.insert("a", 100);  // 覆盖为 100

    // 只在没有键的时候插入
    map.entry("a").or_insert(999);      // a 已有，不插入
    map.entry("b").or_insert(200);      // b 没有，插入 200

    println!("a: {}, b: {}", map["a"], map["b"]);  // a: 100, b: 200
}
```

`entry().or_insert()` 是"字典里有没有这个词？没有就补上"的意思。

### 4.5 根据旧值更新

```rust
fn main() {
    let text = "你好世界你好";
    let mut word_count = HashMap::new();

    for word in text.chars() {
        let count = word_count.entry(word).or_insert(0);
        *count += 1;
    }

    println!("{:?}", word_count);
    // {'你': 2, '好': 2, '世': 1, '界': 1}
}
```

这是"统计词频"的经典写法！

## 五、三大集合对比

| 特性 | Vec<T> | String | HashMap<K, V> |
|------|--------|--------|---------------|
| 存储内容 | 同类型的多个值 | 文字 | 键 → 值 映射 |
| 访问方式 | 索引 v[0] | 切片 &s[..] | 键 map["key"] |
| 是否有序 | 有序 | 有序 | 无序 |
| 是否可变长 | 是 | 是 | 是 |
| 典型用途 | 列表、队列 | 文字处理 | 字典、缓存、统计 |
| 比喻 | 铅笔盒 | 便签纸 | 电话簿 |

## 六、综合示例：学生成绩管理

```rust
use std::collections::HashMap;

fn main() {
    // 用 Vec 存学生名字列表
    let names = vec![
        String::from("小明"),
        String::from("小红"),
        String::from("小刚"),
    ];

    // 用 HashMap 存成绩
    let mut scores = HashMap::new();
    scores.insert(String::from("小明"), 90);
    scores.insert(String::from("小红"), 85);
    scores.insert(String::from("小刚"), 78);

    // 遍历并打印
    let mut total = 0;
    for name in &names {
        if let Some(score) = scores.get(name) {
            println!("{}：{}分", name, score);
            total += score;
        }
    }

    println!("平均分：{:.1}", total as f64 / names.len() as f64);
}
```

## 本章小结

这一章你学习了三种最常用的集合：

- **`Vec<T>`**：动态数组，像"可以变长的列表"。`vec![]` 创建，`push` 添加，`get` 安全访问
- **`String`**：可变的文本。`push_str` 追加，`format!` 安全拼接
- **`HashMap<K,V>`**：键值对，像电话簿。`insert` 存入，`get` 查找，`entry().or_insert()` 按需插入

这三个集合能覆盖你大部分的日常编程需求。下一章，我们学习如何处理"错误"。

### 四、编程大题（15分）

**题目：** 编写一个"单词计数器"程序：
1. 定义一个字符串 `text`，包含一段英文或中文句子
2. 用 HashMap 统计每个单词出现的次数（中文按单个汉字统计，英文按空格分词）
3. 用 Vec 存储单词和次数的配对（按任意顺序）
4. 遍历打印每个单词和它的次数
5. 找出出现次数最多的单词并打印

<details><summary>点击查看答案</summary>

```rust
use std::collections::HashMap;

fn main() {
    let text = "你好世界你好Rust学习RustRust";

    let mut word_count: HashMap<&str, u32> = HashMap::new();

    // 中文字符按单个字统计，英文单词按空格分词
    // 简化版：按字符统计
    for ch in text.chars() {
        // 因为 HashMap 的 key 是 &str，这里我们用简单的办法
        // 实际应用中可能需要更复杂的分词逻辑
    }

    // 改进版本：全部按字符串中的单词（按空格分）
    let text_en = "hello world hello rust world rust rust";
    let mut word_count = HashMap::new();

    for word in text_en.split_whitespace() {
        let count = word_count.entry(word).or_insert(0);
        *count += 1;
    }

    // 打印所有统计
    println!("单词统计：");
    let mut pairs: Vec<(&&str, &u32)> = word_count.iter().collect();
    for (word, count) in &pairs {
        println!("  {}: {} 次", word, count);
    }

    // 找出最多
    let max_word = word_count.iter()
        .max_by_key(|&(_, count)| count)
        .unwrap();

    println!("出现最多：\"{}\"，共 {} 次", max_word.0, max_word.1);
```
