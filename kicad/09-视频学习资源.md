## 9.4 学习路线建议

### 初学者路线（1-2 周）
```
1. 安装 KiCad（01-安装与界面.md）
2. 熟悉界面和基本操作
3. 学习常用快捷键（02-快捷键与自定义.md）
4. 观看 Michael_AU #010-#015（界面和工具介绍）
5. 尝试绘制简单原理图
6. 尝试简单 PCB 布局
```

### 进阶路线（2-4 周）
```
1. 自定义快捷键和主题（02/03）
2. 学习符号和封装编辑（05）
3. 观看 Michael_AU #016-#029
4. 学习 PCB 布线技巧（06）
5. 学习 3D 查看和输出（07）
6. 安装常用插件（08）
```

### 高级路线（1-2 月）
```
1. 学习层次化设计
2. 学习差分对布线
3. 学习铜皮和电源设计
4. 观看 Phil's Lab 完整教程
5. 实际项目练习
6. 学习制造输出和 DFM
```

### 推荐学习顺序
```
安装 → 界面 → 快捷键 → 原理图 → 封装/符号 → PCB → 输出 → 插件 → 自定义
```
