# KiCad 从零到实战

> KiCad 软件使用教程，从安装配置到社区插件，纯软件操作，不涉及电路设计理论。

| 章节 | 文件 | 内容 |

| 03 | [主题与美化](03-主题与美化.md) | 颜色主题、暗色模式、自定义配色、网格设置 |
| 04 | [原理图编辑器](04-原理图编辑器.md) | Eeschema 操作、元件添加、连线、ERC、层次化设计 |
| 05 | [封装与符号编辑器](05-封装与符号编辑器.md) | 符号创建、封装创建、库管理、外部资源 |
| 06 | [PCB 编辑器](06-PCB编辑器.md) | 层管理、布局、布线、铜皮、DRC、自动布线 |

| 10 | [常见问题与技巧](10-常见问题与技巧.md) | FAQ、效率技巧、版本管理、性能优化 |
