# 社区插件

## 8.1 Plugin and Content Manager（PCM）

### 打开方式

```
方式 1：项目管理器 → 点击顶部 "Plugin and Content Manager" 图标
方式 2：菜单 → 工具 → Plugin and Content Manager
```

PCM 是 KiCad 官方的插件管理器，从 KiCad 7.0 开始内置。所有插件、主题、图标包和脚本都可以通过 PCM 统一管理。

### 浏览与安装

```
1. 打开 PCM
2. 浏览分类：
   - 通用插件
   - 颜色主题
   - 图标包
   - 库
   - 脚本
3. 选择插件 → 点击 "Install"
4. 重启 KiCad 生效
```

PCM 左侧栏显示可用插件列表，右侧显示插件描述、版本和作者信息。点击 Install 后插件不会立即生效，需要关闭并重新打开 KiCad。

### 添加第三方仓库

```
1. PCM → 管理仓库
2. 点击 "添加仓库"
3. 输入仓库 URL
4. 确认添加
```

第三方仓库的插件未经 KiCad 官方审核，使用前请确认来源可靠。添加后第三方插件会出现在 PCM 的单独分类中。

### 官方仓库

```
https://gitlab.com/kicad/addons/repository
```

### 第三方仓库

```
https://omegarogue.omegavoid.codes/Unofficial-KiCad-Plugins/repository.json
```

### 检查插件更新

```
1. 打开 PCM
2. 点击 "检查更新"
3. 选择需要更新的插件
4. 点击 "更新"
5. 重启 KiCad
```

### 卸载插件

```
1. 打开 PCM
2. 切换到 "已安装" 标签
3. 找到目标插件
4. 点击 "卸载"
5. 重启 KiCad
```

## 8.2 制造相关插件

### Kicad JLCPCB Tools

```
GitHub: https://github.com/Bouni/kicad-jlcpcb-tools
功能: 生成 JLCPCB 所需的制造文件（Gerber、BOM、CPL）
特点:
- 一键生成所有制造文件
- 支持 JLCPCB 元件库
- 自动生成 BOM 和贴片文件
安装: KiCad PCM → 搜索 "JLCPCB" → Install
```

该插件在 PCB 编辑器中添加一个专用面板，可以为每个元件设置 JLCPCB 位置号。设置完成后点击一键导出即可生成完整的制造文件包。

### KiKit

```
GitHub: https://github.com/yaqwsx/KiKit
功能: 拼板工具
特点:
- 自动拼板
- 添加工艺边
- 添加定位孔
- 生成 V-Cut / 镂空线
- 导出制造数据
安装: pip install kikit
使用: kikit panelize PCB input.kicad_pcb output.kicad_pcb
```

KiKit 既可以通过命令行使用，也可以通过 KiCad PCM 安装后在 PCB 编辑器中使用。命令行方式适合批量处理和 CI/CD 集成。

### KiBot

```
GitHub: https://github.com/INTI-CMNB/KiBot
功能: KiCad 自动化工具
特点:
- 自动化构建流程
- 批量生成输出
- CI/CD 集成
- 支持 YAML 配置
安装: pip install kibot
使用: kibot -c config.yaml -b board.kicad_pcb
```

KiBot 是 KiCad 的自动化后端，可以通过 YAML 配置文件定义完整的构建流程。适合在 GitLab CI 或 GitHub Actions 中自动执行原理图检查、BOM 生成、Gerber 导出等操作。

### kicad-gerberzipper

```
GitHub: https://github.com/g200kg/kicad-gerberzipper
功能: 一键生成 Gerber 并压缩
特点:
- 自动选择所需层
- 自动压缩为 zip
- 支持自定义输出
安装: KiCad PCM → 搜索 "GerberZipper" → Install
```

该插件会自动识别当前 PCB 使用的层，只导出制造所需的文件，避免导出多余层造成混淆。

### gerber_to_order

```
GitHub: https://github.com/asukiaaa/gerber_to_order
功能: 生成制造订单文件
支持: JLCPCB, PCBWay, Elecrow, FusionPCB
安装: KiCad PCM → 搜索 "gerber_to_order" → Install
```

该插件可以同时为多家制造商生成订单所需的文件格式，方便比价和选择。

## 8.3 BOM 插件

### InteractiveHtmlBom

```
GitHub: https://github.com/openscopeproject/InteractiveHtmlBom
功能: 生成交互式 BOM 网页
特点:
- 可视化显示元件位置
- 支持搜索和过滤
- 可以关联原理图和 PCB
- 适合团队协作
安装: KiCad PCM → 搜索 "InteractiveHtmlBom" → Install
```

生成的 HTML 文件包含 PCB 的可视化视图，点击 BOM 中的元件会在 PCB 图上高亮对应位置。非常适合调试和组装时参考。

### KiBoM

```
GitHub: https://github.com/SchrodingersGat/KiBoM
功能: 可配置的 BOM 生成工具
特点:
- 支持分组
- 支持排序
- 支持多种输出格式
- 可配置模板
安装: pip install kibom
使用: kibom -c config.ini schematic.kicad_sch
```

KiBoM 通过 INI 配置文件控制 BOM 的生成方式，可以指定分组规则、排序方式和输出字段。配置文件模板可以保存复用。

### KiABOM

```
GitHub: https://github.com/Mage-Control-Systems-Ltd/KiABOM
功能: 简单的 BOM 生成工具
特点:
- 在线元件数据
- 支持价格查询
- 支持库存检查
安装: KiCad PCM → 搜索 "KiABOM" → Install
```

KiABOM 可以在线查询元件价格和库存，帮助在设计阶段评估成本。

## 8.4 设计辅助插件

### FreeRouting

```
GitHub: https://github.com/freerouting/freerouting
功能: 开源自动布线器
使用:
1. 在 KiCad 中导出 DSN 文件
2. 用 FreeRouting 打开
3. 运行自动布线
4. 导出 SES 文件
5. 在 KiCad 中导入 SES 文件
```

FreeRouting 是独立的自动布线器，可以处理 KiCad 无法完成的复杂布线。工作流程需要在 KiCad 和 FreeRouting 之间手动交换文件。

### KiCadStepUp

```
GitHub: https://github.com/easyw/kicadStepUpMod
功能: FreeCAD 联动工具
特点:
- KiCad 与 FreeCAD 互操作
- 3D 模型导入/导出
- 机械协作设计
- 3D 打印支持
安装: FreeCAD → 宏 → 安装
```

StepUp 是 KiCad 和 FreeCAD 之间的桥梁，可以将 PCB 导入 FreeCAD 进行机械设计验证，也可以将 FreeCAD 中创建的 3D 模型导出为 KiCad 封装。

### KiCad-Diff

```
GitHub: https://github.com/Gasman2014/KiCad-Diff
功能: PCB 版本对比
特点:
- 图像对比不同版本
- 高亮显示变更
- 支持 Git 集成
安装: pip install kicad-diff
```

KiCad-Diff 可以对比两个版本的 PCB 布局差异，用不同颜色高亮显示新增、删除和移动的走线及元件。

### kicanvas

```
GitHub: https://github.com/theacodes/kicanvas
功能: 浏览器查看器
特点:
- 在浏览器中查看原理图和 PCB
- 不需要安装 KiCad
- 支持分享和协作
访问: https://kicanvas.org
```

kicanvas 是基于 Web 的 KiCad 文件查看器，可以将原理图和 PCB 文件上传到网页供团队成员查看，无需本地安装 KiCad。

### kicad-happy

```
GitHub: https://github.com/aklofas/kicad-happy
功能: AI 辅助设计审查
特点:
- 原理图分析
- PCB 布局审查
- 元件选型建议
- BOM 管理
- 制造准备
```

kicad-happy 集成了 AI 能力，可以对设计进行自动审查并给出改进建议。

## 8.5 美化与创意插件

### KiBuzzard

```
GitHub: https://github.com/mattvenn/kicad-buzzard
功能: 创建标签和 Logo
特点:
- 支持多种字体
- 支持反转背景
- 支持自定义样式
安装: KiCad PCM → 搜索 "KiBuzzard" → Install
```

KiBuzzard 可以在丝印层创建文字标签和简单图形。支持自定义字体、大小和旋转角度，适合添加版本号、日期或 Logo。

### PcbDraw

```
GitHub: https://github.com/yaqwsx/PcbDraw
功能: PCB 2D 渲染图
特点:
- 生成漂亮的 PCB 渲染图
- 支持自定义颜色
- 支持背景
- 适合文档和展示
安装: pip install pcbdraw
使用: pcbdraw render board.kicad_pcb output.png
```

PcbDraw 可以生成高质量的 PCB 渲染图，支持自定义焊盘颜色、阻焊颜色和丝印颜色。生成的图片适合用于文档、演示或 README。

### Img2Silk

```
GitHub: https://github.com/NBalciunas/kicad-img2silk
功能: 图片转丝印
特点:
- 将图片转换为丝印层
- 支持多种算法
- 支持彩色和黑白
安装: KiCad PCM → 搜索 "Img2Silk" → Install
```

Img2Silk 可以将普通图片转换为丝印层图形，适合在 PCB 上添加装饰性图案。

### svg2mod

```
GitHub: https://github.com/openscopeproject/svg2mod
功能: SVG 转封装
特点:
- 将 SVG 图片转换为 KiCad 封装
- 支持自定义形状
- 适合创建艺术性封装
安装: pip install svg2mod
```

svg2mod 可以将 SVG 矢量图形转换为 KiCad 封装，适合创建非标准形状的焊盘或装饰性封装。

## 8.6 转换工具

### Altium2Kicad

```
GitHub: https://github.com/thesourcerer8/altium2kicad
功能: Altium 转 KiCad
支持:
- 原理图转换
- PCB 转换
- 库转换
使用: java -jar Altium2Kicad.jar
```

Altium2Kicad 是一个 Java 程序，可以将 Altium Designer 的文件转换为 KiCad 格式。转换后建议人工检查，部分复杂元素可能需要手动调整。

### Eagle to KiCad

```
GitHub: https://github.com/lachlanA/eagle-to-kicad
功能: Eagle 转 KiCad
支持:
- 原理图转换
- 库转换
使用: ULP 脚本在 Eagle 中运行
```

该工具通过 Eagle 的 ULP 脚本机制运行，将原理图和库导出为 KiCad 可以导入的格式。

### typeCAD

```
GitHub: https://github.com/typecad/typecad
功能: 用 TypeScript 创建硬件设计
特点:
- 程序化创建电路
- 版本控制
- 可复用
安装: npm install typecad
```

typeCAD 允许使用 TypeScript 代码描述电路，适合习惯编程工作流的硬件工程师。

### SKiDL

```
GitHub: https://github.com/devbisme/skidl
功能: 用 Python 创建电路
特点:
- Python 语法描述电路
- 可以生成网表
- 可以与 KiCad 集成
安装: pip install skidl
```

SKiDL 用 Python 代码描述电路连接关系，可以自动生成网表并导入 KiCad。适合需要程序化生成电路的场景。
