# 3D 查看与输出

## 7.1 3D 查看器

### 打开方式
```
方式 1：快捷键 Alt+3
方式 2：菜单 → 视图 → 3D 查看器
方式 3：工具栏点击 "3D Viewer" 图标
```

### 导航操作
```
左键拖动 → 旋转视角
中键拖动 → 平移视角
滚轮 → 缩放
Ctrl+左键拖动 → 垂直旋转
Shift+左键拖动 → 水平旋转
Home → 适配视图
```

### 显示选项
```
视图 → 显示选项：
- 显示丝印层
- 显示铜层
- 显示焊盘
- 显示走线
- 显示过孔
- 显示 3D 模型
- 显示板框
- 渲染模式：实心 / 线框 / 透明
```

### 3D 模型管理
```
如果某些元件没有 3D 模型显示：
1. 双击元件 → 封装属性
2. 检查 "3D Model" 字段
3. 添加 3D 模型路径（.step / .wrl 文件）
4. 或从封装库中关联 3D 模型
```

### 3D 导出
```
文件 → 导出 → VRML（虚拟现实建模语言）
文件 → 导出 → STEP（用于机械 CAD）
文件 → 导出 → PNG（截图）
```

## 7.2 Gerber 输出

### 打开 Plot 对话框
```
文件 → 绘图
或工具栏点击 "Plot" 图标
```

### Plot 对话框设置
```
┌─────────────────────────────────────┐
│ 绘图                                │
├─────────────────────────────────────┤
│ 输出目录: ./gerber/                 │
│                                     │
│ 层选择:                             │
│ ☑ F.Cu        (顶层铜)             │
│ ☑ B.Cu        (底层铜)             │
│ ☑ F.SilkS     (顶层丝印)           │
│ ☑ B.SilkS     (底层丝印)           │
│ ☑ F.Mask      (顶层阻焊)           │
│ ☑ B.Mask      (底层阻焊)           │
│ ☑ F.Paste     (顶层助焊)           │
│ ☑ B.Paste     (底层助焊)           │

│ ☐ B.Fab       (底层制造)           │
```

### 生成钻孔文件
```
点击 "生成钻孔文件" 按钮：
- 格式：Excellon
- 单位：mm
- 零点：绝对 / 参考
- 公制 / 英制
```

### Gerber 文件列表
```
生成的文件：
├── my_project-F_Cu.gbr          (顶层铜)
├── my_project-B_Cu.gbr          (底层铜)
├── my_project-F_SilkS.gbr       (顶层丝印)
├── my_project-B_SilkS.gbr       (底层丝印)
├── my_project-F_Mask.gbr        (顶层阻焊)
├── my_project-B_Mask.gbr        (底层阻焊)
├── my_project-Edge_Cuts.gbr     (板框)
├── my_project-F_Paste.gbr       (顶层助焊)
├── my_project-B_Paste.gbr       (底层助焊)
├── my_project.drl               (钻孔文件)
└── my_project.gbrjob            (Gerber 作业文件)
```

## 7.3 Gerber 查看器

### 打开方式
```
方式 1：项目管理器 → 点击 "Gerber Viewer"
方式 2：工具 → Gerber 查看器
```

### 加载 Gerber 文件
```
文件 → 打开 Gerber Job 文件 → 选择 .gbrjob 文件
或
文件 → 打开 Gerber 文件 → 选择 .gbr 文件
```

### 查看操作
```
右侧面板可以：
- 切换各层显示/隐藏
- 修改层颜色
- 检查焊盘对齐
- 检查钻孔位置
- 检查板框尺寸
```

### 发送前检查
```
发送给制造商前检查：
1. 各层是否完整
2. 焊盘对齐是否正确
3. 钻孔位置是否准确
4. 板框尺寸是否正确
5. 丝印是否在阻焊范围内
6. 走线间距是否满足制造规则
```

## 7.4 BOM 输出

### 原理图编辑器导出
```
工具 → 生成 BOM 文件
选择输出格式：
- CSV
- XML
- JSON
```

### PCB 编辑器导出
```
文件 → 导出 → BOM
```

### InteractiveHtmlBom 插件
```
GitHub: https://github.com/openscopeproject/InteractiveHtmlBom
功能：生成交互式 BOM 网页
特点：
- 可视化显示元件位置
- 支持搜索和过滤
- 可以关联原理图和 PCB
- 适合团队协作
安装：KiCad PCM → 搜索 "InteractiveHtmlBom" → Install
```

### BOM 文件格式
```csv
Reference,Value,Footprint,Quantity,Manufacturer,MPN
R1,10k,R0402,1,Yageo,RC0402FR-0710KL
R2,10k,R0402,1,Yageo,RC0402FR-0710KL
C1,100nF,C0402,1,Samsung,CL05B104KO5NNNC
U1,STM32F103C8T6,LQFP-48,1,STMicroelectronics,STM32F103C8T6
```

## 7.5 Pick and Place 文件

### 导出 CPL 文件
```
文件 → 导出 → Pick and Place
选择输出格式：
- CSV
- XML
```

### CPL 文件内容
```
Ref,Val,Package,PosX,PosY,Rot,Side

C1,100nF,C0402,10.50,7.00,90,front
U1,STM32F103C8T6,LQFP-48,15.00,10.00,0,front
```

## 7.6 其他输出

### 原理图 PDF
```
文件 → 打印 → 选择 PDF 打印机
或 文件 → 导出 → PDF
```

### 网表
```
文件 → 导出 → 网表
格式：Netlist
```

### 装配图
```
文件 → 绘图 → 选择 F.CrtYd / B.CrtYd 层
```

### 制造规范
```
在 Edge.Cuts 层添加：
- 板框尺寸标注
- 安装孔位置
- 关键元件位置
```

## 7.7 发送到制造商

### JLCPCB
```
1. 压缩 gerber 文件夹为 .zip
2. 上传到 https://jlcpcb.com
3. 选择层数、板厚、颜色等参数
4. 如需贴片，上传 BOM 和 CPL 文件
5. 下单
```

### PCBWay
```
1. 压缩 gerber 文件夹为 .zip
2. 上传到 https://www.pcbway.com
3. 选择参数
4. 下单
```

### 嘉立创
```
1. 压缩 gerber 文件夹为 .zip
2. 上传到 https://www.jlc.com
3. 选择参数
4. 下单
```
