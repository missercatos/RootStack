# 原理图编辑器

## 4.1 界面布局

### 工具栏
```
顶部工具栏（从左到右）：
保存 | 撤销 | 重做 | 放大 | 缩小 | 适配 | 1:1 | 刷新
| 添加符号 | 添加电源 | 添加导线 | 添加标签 | 添加文本
| ERC | 导入到 PCB | 属性编辑器
```

### 右侧工具栏
```
A - 添加符号
W - 连线
Q - 快速连线
L - 添加标签
P - 添加电源端口
N - 添加网络类标签
I - 添加图片
T - 添加文本
B - 添加矩形框
X - 添加无连接标记
```

### 画布操作
```
缩放：鼠标滚轮
平移：按住鼠标中键拖动
选择：左键点击
取消选择：按 Esc
全选：Ctrl+A
框选：按住左键拖动
```

## 4.2 添加元件符号

### 方法 1：快捷键 A
```
1. 按 A 打开符号选择器
2. 在搜索框输入元件名称（如 "resistor"）
3. 从库中选择元件
4. 点击 OK
5. 在画布上点击放置
```

### 方法 2：工具栏按钮
```
点击工具栏的 "添加符号" 图标
```

### 方法 3：库浏览器
```
左侧面板 → Symbol Browser
→ 展开库 → 双击符号
```

### 符号选择器界面
```
┌─────────────────────────────────────────┐
│ 搜索框                                  │
├──────────────────┬──────────────────────┤
│ 库列表           │ 符号预览             │
│ ┌──────────────┐ │ ┌──────────────────┐ │
│ │ Device       │ │ │    电阻符号      │ │
│ │ Connector    │ │ │    ─/\/\/─       │ │
```

### 放置后操作
```
放置符号后：
- 按 M 可以移动
- 按 R 可以旋转
- 按 F 可以翻转
- 按 Esc 取消放置
```

## 4.3 电气连线

### 连线（Wire）
```
1. 按 W 进入连线模式
2. 点击起点（元件引脚端点）
3. 点击终点或转角点
4. 双击或按 Esc 结束连线
```

### 连线规则
- 起点和终点必须在引脚端点上
- 连线会自动吸附到引脚端点
- 连线交叉不等于电气连接
- 需要节点（Junction）表示交叉连接

### 快速连线（Quick Connect）
```
1. 按 Q 进入快速连线模式
2. 点击起点
3. KiCad 自动找到最近的连接点
4. 点击确认
```

### 总线（Bus）
```
1. 按 B 进入总线模式
2. 点击起点
3. 点击终点
4. 双击结束

总线用于表示多位信号的集合
如 DATA[0..7] 表示 8 位数据总线
```

### 节点（Junction）
```
自动添加：两条连线交叉时自动添加
手动添加：放置 → 节点
```

## 4.4 标签与网络

### 网络标签（Label）
```
1. 按 L 添加标签
2. 输入网络名称（如 "VCC"、"GND"、"DATA0"）
3. 点击放置到连线上
```
- 相同标签名的网络自动电气连接
- 跨图纸连接必须使用标签

### 电源端口（Power Port）
```
1. 按 P 添加电源端口
2. 选择电源类型（VCC、GND、+3.3V 等）
3. 放置到连线上
```

### 网络类标签（Net Class）
```
1. 按 N 添加网络类标签
2. 输入网络类名称（如 "Power"、"Signal"、"DiffPair"）
3. 放置到连线上
```
- 网络类用于设置不同的设计规则（线宽、间距等）

### 全局标签（Global Label）
```
工具 → 放置全局标签
- 跨图纸的电气连接
- 所有图纸中同名全局标签相连
```

### 无连接标记（No Connect）
```
按 X 添加无连接标记
- 标记未使用的引脚
- 防止 ERC 报告未连接引脚错误
```

## 4.5 元件操作

### 移动与旋转
| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 移动 | M | 拖动选中对象 |
| 旋转 | R | 逆时针旋转 90 度 |
| 翻转 | F | 水平翻转 |
| 拖动连线 | 右键拖动 | 移动连线端点 |
| 复制 | Ctrl+C | 复制选中对象 |
| 粘贴 | Ctrl+V | 粘贴对象 |
| 删除 | Delete | 删除选中对象 |

### 编辑属性
```
1. 双击元件
2. 或选中元件后按 E
3. 打开属性对话框
```

### 查找与替换
```
Ctrl+F：查找元件
Ctrl+H：查找与替换
- 可替换元件值、封装、网络名等
```

## 4.6 批量操作

### 标注元件（Annotate）
```
工具 → 填充标注元件编号
或点击工具栏的 "Annotate" 按钮

选项：
- 从 1 开始
- 按位置标注（从左到右、从上到下）
- 按原理图标注
```

### 电气规则检查（ERC）
```
工具 → 电气规则检查
或点击工具栏的 "ERC" 按钮

检查内容：
- 未连接的引脚
- 多个驱动源
- 缺少电源连接
- 引脚类型冲突
```

### ERC 错误类型
| 错误 | 说明 | 严重程度 |
|------|------|---------|
| Pin not connected | 引脚未连接 | Error |
| Multiple net names | 多个网络名 | Warning |
| Power pin not driven | 电源引脚无驱动 | Error |
| Pin type conflict | 引脚类型冲突 | Error |
| Duplicate reference | 重复编号 | Error |

### ERC 排除标记
```
右键点击 ERC 错误 → 排除此违规
用于忽略已知的、不影响设计的警告
```

### 符号字段编辑器
```
工具 → 符号字段编辑器
- 批量编辑元件属性
- 可导出为 CSV 格式
- 支持批量修改封装、值等
```

## 4.7 层次化设计

### 创建子图纸
```
1. 在原理图中放置 "Sheet" 元件
2. 双击 Sheet 设置文件名和图纸大小
3. 双击进入子图纸编辑
```

### 图纸连接
```
子图纸的输入/输出引脚通过 "Sheet Pin" 连接到父图纸
父图纸的 Sheet 上会显示对应的 Sheet Pin
```

### 根图纸与子图纸关系
```
根图纸（Root）
├── 子图纸 1（子电路 1）
├── 子图纸 2（子电路 2）
└── 子图纸 3（子电路 3）
```

### 图纸引脚类型
```
输入引脚：信号从子图纸输入
输出引脚：信号从子图纸输出
双向引脚：信号双向传输
三态引脚：高阻态支持
```

### 图纸导航
```
左侧面板 → Sheets
双击子图纸名称可快速切换
右键子图纸 → 返回父图纸
```

## 4.8 导出与输出

### 导出到 PCB
```
工具 → 更新 PCB 带有原理图的更改
或点击工具栏的 "Import PCB" 按钮
```

### 导出 PDF
```
文件 → 打印 → 选择 PDF 打印机
或文件 → 导出 → PDF
```

### 导出网表
```
文件 → 导出 → 网表
```

### 导出 BOM
```
工具 → 生成 BOM 文件
```

### BOM 模板
```
KiCad 内置 BOM 生成器
- 支持自定义模板
- 可导出 CSV、XML 等格式
- 可配置输出字段
```

### 网络表格式
```
KiCad 网络表包含：
- 元件列表及属性
- 网络连接关系
- 引脚连接详情
- 封装信息
```
