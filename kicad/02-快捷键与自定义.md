## 2.3 快捷键自定义方法

### 菜单路径
```
Preferences → Preferences → Hotkeys
```

### 操作步骤
```
1. 打开 Preferences → Preferences → Hotkeys
2. 在搜索框中输入要查找的命令名称
3. 找到命令后，双击右侧的快捷键列
4. 按下新的键组合
5. 如果与其他命令冲突，会弹出确认对话框
6. 点击 OK 保存
```

### 自定义规则
- 同一编辑器内不能有两个命令共用同一个快捷键
- 不同编辑器可以有相同的快捷键（如原理图和 PCB 都可以用 W）
- 可以使用 Ctrl、Alt、Shift 的任意组合
- 支持多键组合（先按 Ctrl+K，再按某个键）

### 修改示例
```
# 将"添加符号"从 A 改为 S
1. 搜索 "Add Symbol"
2. 双击快捷键列
3. 按下 S
4. 确认覆盖
```

## 2.4 配置文件

### hotkeys 文件位置

| 系统 | 路径 |
|------|------|
| Linux | ~/.config/kicad/版本号/user.hotkeys |
| Windows | %APPDATA%\kicad\版本号\user.hotkeys |
| macOS | ~/Library/Preferences/kicad/版本号/user.hotkeys |

### 导入/导出
```
Preferences → Preferences → Hotkeys → Import Hotkeys
Preferences → Preferences → Hotkeys → Export Hotkeys
```

### 手动编辑
```bash
# user.hotkeys 文件格式（JSON）
{
  "schematic": {
    "addSymbol": "A",
    "addWire": "W",
    "addLabel": "L"
  },
  "pcbnew": {
    "track": "X",
    "via": "V",
    "fill zones": "B"
  }
}
```

### 迁移配置
```bash
# 从旧版本迁移快捷键到新版本
# 1. 找到旧版本的 user.hotkeys
ls ~/.config/kicad/7.0/user.hotkeys

# 2. 复制到新版本目录
cp ~/.config/kicad/7.0/user.hotkeys ~/.config/kicad/9.0/user.hotkeys

# 3. 或在 KiCad 中导入
Preferences → Preferences → Hotkeys → Import Hotkeys → 选择文件
```

## 2.5 各编辑器独立快捷键

KiCad 的每个编辑器有独立的快捷键配置：

| 编辑器 | 快捷键配置 |
|--------|-----------|
| 原理图编辑器 | Preferences → Schematic Editor → Hotkeys |
| PCB 编辑器 | Preferences → PCB Editor → Hotkeys |
| 符号编辑器 | Preferences → Symbol Editor → Hotkeys |
| 封装编辑器 | Preferences → Footprint Editor → Hotkeys |

- 原理图和 PCB 可以有不同的快捷键
- 符号编辑器继承原理图的快捷键
- 封装编辑器继承 PCB 的快捷键

## 2.7 快捷键记忆技巧

### 原理图记忆口诀
```
A - Add 添加符号
W - Wire 连线
L - Label 标签
P - Power 电源
T - Text 文本
E - Edit 编辑
M - Move 移动
R - Rotate 旋转
C - Copy 复制
X - 打叉 无连接
```

### PCB 记忆口诀
```
X - 走线（像交叉线）
V - 过孔（Via 首字母）
B - 铜皮（Border/Boundary 边界）
E - 边缘（Edge.Cuts）
M - 测量（Measure 首字母）
D - 画图（Draw 首字母）
```

## 2.8 常见问题

### 问题 1：快捷键不响应
```
# 可能原因
1. 焦点不在编辑器画布上
2. 快捷键与其他软件冲突
3. 快捷键被自定义覆盖

# 解决方法
1. 点击画布空白区域
2. 检查系统全局快捷键设置
3. Preferences → Hotkeys → Reset to Defaults
```

### 问题 2：想恢复默认快捷键
```
Preferences → Preferences → Hotkeys → Reset to Defaults
```

### 问题 3：如何查看当前所有快捷键
```
Preferences → Preferences → Hotkeys
# 可以看到所有命令及其对应快捷键
# 使用搜索框筛选特定命令
```

### 问题 4：如何为同一个命令设置多个快捷键
```
KiCad 不支持直接设置多个快捷键
# 变通方法：
1. 通过修改配置文件添加备用快捷键
2. 或使用外部按键映射工具
```

## 2.9 效率提升建议

### 新手阶段
1. 先记住最常用的 10 个快捷键
2. 边用边查，逐步扩展
3. 不要一次性记忆所有快捷键

### 进阶阶段
1. 自定义最顺手的快捷键
2. 根据项目类型调整配置
3. 导出配置文件备份

### 专家阶段
1. 创建不同项目的快捷键配置
2. 编写脚本自动化重复操作
3. 分享配置给团队成员

## 2.10 小结

掌握快捷键是提高 KiCad 使用效率的关键。建议从最常用的快捷键开始记忆，逐步扩展到更多命令。定期备份和导出快捷键配置，可以在更换电脑或升级版本时快速恢复工作环境。每个编辑器的快捷键是独立的，需要分别记忆和自定义。
