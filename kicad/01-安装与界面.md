# KiCad 安装与界面

## 1.1 下载与安装

### 官网

访问 KiCad 官方网站获取最新安装包：

https://kicad.org/download/

### Windows

```
1. 下载 .exe 安装包（稳定版）
2. 双击安装，勾选组件：
   - KiCad（主程序）
   - symbols（符号库）
   - footprints（封装库）
   - 3D models（3D 模型）
3. 安装完成后桌面出现 KiCad 快捷方式
```

### macOS

```bash
# 方法 1：下载 .dmg 安装包
# 方法 2：Homebrew
brew install --cask kicad
```

### Linux

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install kicad

# Arch Linux
sudo pacman -S kicad

# Flatpak（跨发行版）
flatpak install flathub org.kicad.KiCad

# Snap
sudo snap install kicad
```

### 版本说明

- 稳定版：推荐生产使用（当前最新：KiCad 9.x）
- Nightly：每日构建，包含最新功能但可能不稳定
- 查看版本：Help -> About KiCad

## 1.2 项目文件结构

创建新项目后，KiCad 会生成以下文件：

```
my_project/
+-- my_project.kicad_pro    # 项目配置文件（JSON 格式）
+-- my_project.kicad_sch    # 原理图文件
+-- my_project.kicad_pcb    # PCB 布局文件
+-- sym-lib-table           # 符号库表（项目级）
+-- fp-lib-table            # 封装库表（项目级）
+-- my_project-cache.lib    # 符号缓存（旧版本兼容）
```

### 关键文件说明

| 文件          | 用途                       | 可否手动编辑 |
| ------------- | -------------------------- | ------------ |
| .kicad_pro    | 项目设置（层、设计规则、网络类） | 可以（JSON） |
| .kicad_sch    | 原理图                     | 不推荐（用编辑器） |
| .kicad_pcb    | PCB 布局                   | 不推荐（用编辑器） |
| sym-lib-table | 项目级符号库路径           | 可以         |
| fp-lib-table  | 项目级封装库路径           | 可以         |

### 全局配置文件位置

| 系统    | 路径                                 |
| ------- | ------------------------------------ |
| Linux   | ~/.config/kicad/版本号/              |
| Windows | %APPDATA%\kicad\版本号\              |
| macOS   | ~/Library/Preferences/kicad/版本号/  |

## 1.6 基本设置

### 单位切换

```
Preferences -> Preferences -> Common -> Grid and Canvas
-> Units: Millimeters / Inches / Mils
```

- 快捷键：Ctrl+U 切换单位
- 推荐使用 mm（毫米）

### 网格设置

```
Preferences -> Preferences -> Common -> Grid and Canvas
-> Grid: 0.127mm (5mil) 或 0.254mm (10mil)
```

- 布局时用大网格（0.5mm / 1mm）
- 精细操作时用小网格（0.127mm / 0.05mm）

### 语言设置

```
Preferences -> Preferences -> Common -> Language
-> 选择简体中文 / English
```

- 部分翻译不完整，建议使用英文
- 新手可以先用中文熟悉界面

## 1.9 命令行启动

KiCad 支持从命令行直接启动各工具：

```bash
# 启动项目管理器
kicad

# 直接打开原理图编辑器
kicad-sch

# 直接打开 PCB 编辑器
kicad-pcb

# 直接打开符号编辑器
kicad-cli sym

# 直接打开封装编辑器
kicad-cli fp
```

### 使用 kicad-cli 批量操作

```bash
# 导出原理图 PDF
kicad-cli sch export pdf --output output.pdf my_project.kicad_sch

# 导出 Gerber 文件
kicad-cli pcb export gerbers --output gerber_dir/ my_project.kicad_pcb

# 导出 BOM
kicad-cli sch export bom --output bom.csv my_project.kicad_sch

# 运行设计规则检查
kicad-cli pcb drc my_project.kicad_pcb
```
