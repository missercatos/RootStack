# 常见问题与技巧

## 10.1 库与元件

### 问题：找不到符号/封装库

```
原因: 未安装库 或 库路径未配置
解决:
1. 检查是否安装了符号库和封装库
   Linux: sudo apt install kicad-symbols kicad-footprints
2. 检查库表配置
   Preferences → Manage Symbol Libraries
   Preferences → Manage Footprint Libraries
3. 确认库路径正确
```

### 问题：符号库列表为空

```
原因: sym-lib-table 文件损坏或缺失
解决:
1. 删除项目目录下的 sym-lib-table
2. 重启 KiCad，会自动重建
3. 或手动创建全局 sym-lib-table
```

### 问题：封装与符号不匹配

```
原因: 封装名称或引脚编号不对应
解决:
1. 检查符号的引脚编号
2. 检查封装的焊盘编号
3. 确保两者一致（1,2,3... 或 A1,A2...）
```

### 问题：从 Datasheet 创建封装

```
方法 1: 手动创建（封装编辑器）
方法 2: 使用 uConfig 工具
  GitHub: https://github.com/RC2019/uConfig
  功能: 从 PDF Datasheet 提取引脚定义
方法 3: 使用 SnapEDA / Ultra Librarian
  网站: https://www.snapeda.com
  网站: https://www.ultralibrarian.com
```

## 10.2 原理图

### 问题：ERC 报错 "Pin not connected"

```
原因: 元件引脚未连接
解决:
1. 检查是否有未连接的引脚
2. 如果确实不需要连接，添加无连接标记（X）
3. 如果是电源引脚，确保连接到电源网络
```

### 问题：ERC 报错 "Multiple net names"

```
原因: 同一网络有多个标签名
解决:
1. 检查网络标签是否一致
2. 确保同一网络使用相同名称
3. 删除多余的标签
```

### 问题：元件编号重复

```
原因: 手动添加元件时未自动编号
解决:
工具 → 填充标注元件编号 → 重新标注
```

### 问题：原理图导入 PCB 时报错

```
原因: 原理图与 PCB 不同步
解决:
1. 在原理图编辑器中运行 ERC
2. 修复所有错误
3. 重新导入到 PCB
4. 使用 "更新 PCB" 而不是 "导入"
```

## 10.3 PCB 编辑

### 问题：DRC 报错 "Clearance violation"

```
原因: 走线之间间距太小
解决:
1. 移动走线增加间距
2. 或修改设计规则中的间距要求
3. Preferences → PCB Editor → Design Rules → Constraints
```

### 问题：DRC 报错 "Track width too small"

```
原因: 走线宽度小于最小值
解决:
1. 选择走线 → 右键 → 走线属性 → 增加宽度
2. 或修改设计规则中的最小宽度
```

### 问题：铜皮未填充

```
原因: 铜皮需要手动填充
解决:
按 B 重新填充所有铜皮区域
或右键铜皮 → 重新填充
```

### 问题：飞线太多看不清

```
解决:
1. 按 U 选取同网络所有走线
2. 按 I 高亮选中网络
3. 逐个网络布线
4. 布线完成后隐藏飞线
```

### 问题：3D 模型不显示

```
原因: 封装未关联 3D 模型
解决:
1. 双击封装 → 封装属性
2. 检查 "3D Model" 字段
3. 添加 .step 或 .wrl 文件路径
4. 或从封装库中关联
```

## 10.4 输出与制造

### 问题：Gerber 文件缺少层

```
原因: Plot 对话框中未选择所有需要的层
解决:
1. 文件 → 绘图
2. 确保选择所有需要的层：
   - F.Cu, B.Cu（铜层）
   - F.SilkS, B.SilkS（丝印）
   - F.Mask, B.Mask（阻焊）
   - Edge.Cuts（板框）
3. 点击 "绘图" 生成
```

### 问题：钻孔文件格式错误

```
原因: 钻孔文件格式不匹配
解决:
1. 生成钻孔文件时选择正确的格式
2. Excellon 格式（最常用）
3. 单位选择 mm
4. 检查制造商要求
```

### 问题：BOM 文件缺少元件

```
原因: 部分元件未标注或未分配封装
解决:
1. 在原理图中检查所有元件是否已标注
2. 检查所有元件是否已分配封装
3. 重新生成 BOM
```

## 10.5 效率技巧

### 交叉探测（Cross-probing）

```
功能: 在原理图和 PCB 之间快速定位
使用:
1. 在原理图中选中元件
2. PCB 编辑器中对应元件自动高亮
3. 反之亦然
设置: Preferences → Common → Cross-probing
```

### 选择相同网络

```
功能: 快速选择同一网络的所有走线
使用:
1. 选中一条走线
2. 按 U 选取同网络所有走线
3. 按 I 高亮选中网络
```

### 全局编辑

```
功能: 批量修改同类对象
使用:
1. 选中一个对象
2. 右键 → 选择所有相同类型
3. 修改属性
```

### 模板复用

```
功能: 复用已有的设计模块
使用:
1. 选择要复用的区域
2. 复制（Ctrl+C）
3. 粘贴（Ctrl+V）
4. KiCad 会自动更新元件编号
```

### 快速切换层

```
PCB 编辑器中：
1. 按 ~ 快速切换到另一面
2. 按 Ctrl+Shift+数字 切换到指定层
3. 点击右侧层管理面板切换
```

### 隐藏/显示层

```
1. 点击层名称切换显示/隐藏
2. 按 Ctrl+Shift+点击层 → 只显示该层
3. 右键层 → 隐藏其他层
```


### Git 管理 KiCad 项目

```
1. 初始化 Git 仓库
2. 添加 .gitignore
3. 提交项目文件
4. 定期提交变更
5. 使用分支进行并行设计
```

### 文件冲突处理

```
KiCad 文件是文本格式，可以合并
但建议：
1. 同一时间只有一人编辑同一文件
2. 使用 Git 分支管理不同设计
3. 定期同步主分支
```

## 10.7 性能优化

### 大型项目优化

```
1. 关闭不必要的层显示
2. 减少 3D 模型加载
3. 使用代理（代理模式）
4. 分层设计减少原理图复杂度
```

### 内存使用

```
1. 关闭不需要的编辑器
2. 清理未使用的库
3. 定期保存和重启
```
