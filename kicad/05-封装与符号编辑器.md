# 封装与符号编辑器

## 5.1 符号编辑器

### 打开方式
```
方式 1：项目管理器 → 点击 "Symbol Editor" 按钮
方式 2：原理图编辑器 → 工具 → 符号编辑器
方式 3：快捷键（无默认快捷键，需自定义）
```

### 界面布局
```
┌──────────────────────────────────────────┐
│ 文件  编辑  视图  工具  帮助              │
├──────────────────────────────────────────┤
│ [保存] [撤销] [重做] [放大] [缩小]       │
├──────────────────────────────────────────┤
│ 左侧: 符号库浏览器                       │
│ ┌────────────────────────┐               │
│ │ Device                 │               │
│ │  ├─ R (电阻)          │               │
│ │  ├─ C (电容)          │               │
│ │  ├─ L (电感)          │               │
│ │  └─ ...               │               │
│ │ Connector              │               │
│ │ MCU                    │               │
│ └────────────────────────┘               │
├──────────────────────────────────────────┤
│                  画布区域                │
│          （绘制/编辑符号的地方）         │
├──────────────────────────────────────────┤
│ 右侧: 属性面板                           │
│  - 符号名称                               │
│  - 引脚列表                               │
│  - 属性编辑                               │
└──────────────────────────────────────────┘
```

### 创建新符号
```
1. 文件 → 新建库（或打开已有库）
2. 工具 → 新建符号
3. 输入符号名称
4. 在画布上绘制符号：
   - 添加引脚（Pin）
   - 绘制图形（线条、矩形、圆弧）
   - 设置引脚属性
5. 保存
```

### 引脚定义
```
双击引脚打开属性对话框：

│ 编号: 1          [可编辑]  │
│ 类型: Input      [下拉]    │
│ 电气类型:        [下拉]    │
│ 隐藏: ☐                    │
│ 长度: 100 mils  [可编辑]  │
│ 方向: Right      [下拉]    │
└─────────────────────────────┘
```

### 引脚电气类型

| 类型 | 说明 | 图标 |
|------|------|------|
| Input | 输入引脚 | -> |
| Output | 输出引脚 | -> |
| Bidirectional | 双向引脚 | <-> |
| Tri-state | 三态引脚 | <-> |
| Passive | 被动引脚（电阻/电容） | - |
| Free | 自由引脚 | - |
| Unspecified | 未指定 | - |
| Power In | 电源输入 | * |
| Power Out | 电源输出 | * |
| Open Collector | 开集输出 | - |
| Open Emitter | 开射输出 | - |
| No Connect | 无连接 | x |

### 符号绘制工具

```
工具栏常用工具：
  - 直线（Line）：绘制符号边框
  - 矩形（Rectangle）：绘制元件主体
  - 圆弧（Arc）：绘制圆弧线段
  - 多边形（Polygon）：绘制任意形状
  - 文本（Text）：添加注释文本
  - 引脚（Pin）：放置电气引脚
```

### 常用快捷键

```
符号编辑器快捷键：
  P       - 放置引脚
  R       - 旋转选中对象
  X       - 水平镜像
  Y       - 垂直镜像
  M       - 移动对象
  E       - 编辑属性
  Ctrl+Z  - 撤销
  Ctrl+Y  - 重做
  Ctrl+S  - 保存
  Delete  - 删除选中对象
```

### 创建新封装
```
1. 文件 → 新建库（或打开已有库）
2. 工具 → 新建封装
3. 输入封装名称
4. 在画布上放置焊盘：
   - 添加通孔焊盘（Through Hole）
   - 添加贴片焊盘（SMD）
   - 添加表面贴装焊盘
5. 绘制丝印层轮廓
6. 关联 3D 模型
7. 保存
```

### 焊盘类型

| 类型 | 说明 | 用途 |
|------|------|------|
| Through Hole | 通孔焊盘 | DIP 芯片、连接器 |
| SMD | 表面贴装焊盘 | 贴片元件 |
| NPTH | 非电镀通孔 | 安装孔 |

### 焊盘形状
| 形状 | 说明 |
|------|------|
| Circle | 圆形 |

| Roundrect | 圆角矩形 |

### 封装绘制流程

```
标准封装绘制步骤：

1. 查阅数据手册获取精确尺寸
2. 新建封装并设置参考名称
3. 放置焊盘并设置编号
4. 根据数据手册调整焊盘位置
5. 绘制丝印层轮廓（F.SilkS）
6. 绘制装配层轮廓（F.CrtYd）
7. 添加参考编号和值文本
8. 设置封装原点（通常在中心或引脚 1）
9. 关联 3D 模型
10. 运行 DRC 检查
```

## 5.3 库管理

### 本地库 vs 全局库
```
项目级库：只在当前项目中可用
  -> sym-lib-table / fp-lib-table（项目目录下）

全局库：所有项目共享
  -> ~/.config/kicad/9.0/sym-lib-table
  -> ~/.config/kicad/9.0/fp-lib-table
```

### 添加第三方库
```
1. 下载库文件（.kicad_sym 或 .pretty 目录）
2. 放到本地目录
3. 在 KiCad 中添加：
   Preferences -> Manage Symbol Libraries -> 添加库
   Preferences -> Manage Footprint Libraries -> 添加库
```

## 5.5 符号与封装的关联

### 映射关系

```
符号引脚编号 <-> 封装焊盘编号

对应规则：
  符号引脚 1   ->  封装焊盘 1
  符号引脚 2   ->  封装焊盘 2

注意事项：
  - 编号必须完全匹配
  - 多单元符号需设置正确的单元映射
```

## 5.6 DRC 与常见问题

### 常见错误及解决

```
问题 1：引脚与封装不对应
  原因：符号引脚编号与封装焊盘编号不一致
  解决：检查数据手册，修正编号映射

问题 2：封装焊盘偏移
  原因：坐标输入错误或单位混淆
  解决：以原点为基准重新计算坐标

问题 3：3D 模型显示异常
  原因：模型单位与封装单位不匹配
  解决：在 3D 查看器中调整缩放比例

问题 4：丝印缺失
  原因：未在 F.SilkS 层绘制轮廓
  解决：切换到丝印层并绘制元件外形
```
