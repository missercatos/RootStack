# MySQL 01 - 安装与配置

MySQL 是世界上最流行的开源关系型数据库之一，是 LAMP/LNMP 技术栈的核心。本章覆盖多平台安装、服务管理、客户端连接、配置文件与字符集问题，最后给出忘记 root 密码时的自救流程。全程以 **MySQL 8.x** 为准。

---

## 一、多平台安装

### 1.1 各平台安装方式一览

| 平台 | 方式 | 命令 |
|------|------|------|
| Windows | winget | `winget install Oracle.MySQL` |
| Windows | 官方安装包 | 官网下载 mysql-installer，图形向导安装 |
| macOS | Homebrew | `brew install mysql` |
| Ubuntu/Debian | apt | `sudo apt install mysql-server` |
| Arch Linux | pacman | `sudo pacman -S mysql` |
| 任意平台 | Docker | 见下文一键命令 |

### 1.2 Windows

```powershell
# 方法一：winget（Windows 10/11 自带）
winget install Oracle.MySQL

# 方法二：官方安装包
# 前往 https://dev.mysql.com/downloads/installer/
# 下载 mysql-installer-community，选择 Server only 或 Custom
# 安装向导中设置 root 密码，端口保持默认 3306
```

安装完成后 `mysqld` 与 `mysql` 位于 `C:\Program Files\MySQL\MySQL Server 8.0\bin`，建议手动加入 PATH。

### 1.3 macOS

```bash
brew install mysql

# 首次启动（不随开机自启）
mysql.server start

# 设为开机自启的后台服务
brew services start mysql
```

### 1.4 Ubuntu / Debian

```bash
sudo apt update
sudo apt install mysql-server -y

# 安装后自动启动，执行安全初始化（设置密码策略、移除匿名用户等）
sudo mysql_secure_installation
```

> Ubuntu 的 MySQL 8 默认 root 使用 `auth_socket` 插件，系统 root 用户直接 `sudo mysql` 即可登录，无需密码。要改为密码登录见第五章用户管理。

### 1.5 Arch Linux

```bash
sudo pacman -S mysql

# Arch 安装后必须先初始化数据目录
sudo mariadb-install-db --user=mysql --basedir=/usr --datadir=/var/lib/mysql
sudo systemctl enable --now mysqld
```

### 1.6 Docker 一键运行

```bash
docker run -d \
  --name mysql8 \
  -e MYSQL_ROOT_PASSWORD=123456 \
  -e MYSQL_DATABASE=testdb \
  -p 3306:3306 \
  -v mysql_data:/var/lib/mysql \
  mysql:8.0

# 进入容器内的客户端
docker exec -it mysql8 mysql -uroot -p123456
```

### 1.7 验证安装

```bash
mysql --version          # 查看客户端版本
mysqladmin -u root -p version   # 查看服务端版本与运行状态
```

## 二、服务管理命令

| 操作 | systemd (Linux) | macOS brew services | Windows cmd |
|------|-----------------|---------------------|-------------|
| 启动 | `sudo systemctl start mysqld` | `brew services start mysql` | `net start mysql80` |
| 停止 | `sudo systemctl stop mysqld` | `brew services stop mysql` | `net stop mysql80` |
| 重启 | `sudo systemctl restart mysqld` | `brew services restart mysql` | 先 stop 再 start |
| 开机自启 | `sudo systemctl enable mysqld` | `brew services start mysql` | 服务属性中设置 |
| 查看状态 | `sudo systemctl status mysqld` | `brew services list` | `sc query mysql80` |

> Ubuntu 下服务名可能是 `mysql` 而非 `mysqld`：`sudo systemctl start mysql`。Windows 服务名带版本号（如 `mysql80`），以安装时为准。

## 三、客户端连接

### 3.1 本地连接

```bash
# -u 用户名  -p 密码交互输入（推荐，避免密码进 shell 历史）
mysql -u root -p

# 明文指定密码（仅测试环境用）
mysql -u root -p123456

# 不指定库直接进入后，用 USE 切换
mysql -u appuser -p testdb   # 直接连接到 testdb 库
```

登录成功后提示符变为 `mysql>`，常用状态命令：

```sql
SELECT VERSION();     -- 服务端版本
SELECT USER();        -- 当前登录用户@主机
SHOW DATABASES;       -- 列出所有数据库
EXIT;                 -- 退出（QUIT 或 \q 同效）
```

### 3.2 远程连接

```bash
mysql -h 192.168.1.100 -P 3306 -u appuser -p
# -h 主机  -P 端口（大写 P）  -u 用户  -p 密码
```

远程连不上时按三步排查：

```sql
-- 第一步：确认用户被授权从任意主机连接（% 表示任意主机）
SELECT user, host FROM mysql.user WHERE user = 'appuser';

-- 第二步：授予远程访问权限
CREATE USER 'appuser'@'%' IDENTIFIED BY 'StrongPass123!';
GRANT ALL PRIVILEGES ON *.* TO 'appuser'@'%';
FLUSH PRIVILEGES;

-- 第三步：确认服务端监听了公网地址而非仅 127.0.0.1（看 bind-address 配置）
SHOW VARIABLES LIKE 'bind_address';
```

同时确认防火墙放行 3306 端口：

```bash
# Ubuntu ufw 示例
sudo ufw allow 3306/tcp
```

## 四、配置文件

### 4.1 配置文件位置

| 平台 | 路径 |
|------|------|
| Windows | `C:\ProgramData\MySQL\MySQL Server 8.0\my.ini` |
| macOS (Homebrew) | `/opt/homebrew/etc/my.cnf`（Intel 机型在 `/usr/local/etc/my.cnf`） |
| Ubuntu/Debian | `/etc/mysql/mysql.conf.d/mysqld.cnf`（总入口 `/etc/mysql/my.cnf`） |
| Arch/CentOS | `/etc/my.cnf` |
| Docker | 挂载配置文件到容器的 `/etc/mysql/conf.d/` |

修改配置后必须重启服务才生效：

```bash
sudo systemctl restart mysqld
```

### 4.2 常用配置项

```ini
[mysqld]
# 监听端口
port = 3306

# 监听地址：默认只听本机；允许远程改为 0.0.0.0（注意安全）
bind-address = 0.0.0.0

# 最大并发连接数（默认 151）
max_connections = 500

# 服务端默认字符集（MySQL 8 默认已是 utf8mb4）
character-set-server = utf8mb4
collation-server = utf8mb4_unicode_ci

# InnoDB 缓冲池大小，物理内存的 50%~70%（默认 128M 偏小）
innodb_buffer_pool_size = 2G

# 慢查询日志
slow_query_log = ON
long_query_time = 2
slow_query_log_file = /var/log/mysql/slow.log

[client]
default-character-set = utf8mb4
```

验证配置是否生效：

```sql
SHOW VARIABLES LIKE 'max_connections';
SHOW VARIABLES LIKE 'character_set_server';
```

## 五、字符集问题：utf8 vs utf8mb4

这是 MySQL 最经典的坑：**MySQL 的 `utf8` 是残缺实现，最多只存 3 字节**，无法保存 emoji 和部分生僻字（4 字节 UTF-8 字符），写入会报 `Incorrect string value` 错误。

| 项目 | utf8（utf8mb3） | utf8mb4 |
|------|-----------------|---------|
| 最大字节 | 3 字节 | 4 字节 |
| emoji 支持 | 否，报错或截断 | 是 |
| 生僻汉字 | 部分 missing | 完整支持 |
| 结论 | 不要用 | **统一使用** |

正确做法：

```sql
-- 建库建表显式指定 utf8mb4
CREATE DATABASE mydb CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

CREATE TABLE t (
    name VARCHAR(100)
) CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

关于排序规则（collation）：

| 排序规则 | 特点 |
|----------|------|
| `utf8mb4_general_ci` | 速度快，比较粗糙，大小写不敏感 |
| `utf8mb4_unicode_ci` | 基于标准 Unicode 排序，多语言更准确 |
| `utf8mb4_0900_ai_ci` | MySQL 8 默认，Unicode 9.0，性能与准确度兼顾 |

排查已有表的字符集：

```sql
SHOW CREATE TABLE t;                       -- 查看建表语句中的字符集
SHOW FULL COLUMNS FROM t;                  -- 查看每列字符集
ALTER TABLE t CONVERT TO CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;  -- 整表转换
```

## 六、重置 root 密码

忘记 root 密码时，利用 `skip-grant-tables`（跳过权限校验）模式进入后改密。以下为 Linux 流程，Windows 思路相同（改用服务方式启动并加参数）。

### 6.1 标准流程

```bash
# 第一步：停止 MySQL 服务
sudo systemctl stop mysqld

# 第二步：跳过权限表启动（后台运行）
sudo mysqld_safe --skip-grant-tables --skip-networking &

# 第三步：无密码直接登录
mysql -u root
```

```sql
-- 第四步：刷新权限后修改密码
FLUSH PRIVILEGES;
ALTER USER 'root'@'localhost' IDENTIFIED BY 'NewPass@2026';
EXIT;
```

```bash
# 第五步：重启到正常模式
sudo killall mysqld
sudo systemctl start mysqld
mysql -u root -p'NewPass@2026'   # 验证新密码
```

### 6.2 注意事项

| 要点 | 说明 |
|------|------|
| `FLUSH PRIVILEGES` 必须先执行 | skip-grant-tables 下内存中未加载授权表，先刷新才能 ALTER USER |
| `--skip-networking` 建议加上 | 该模式下任何人都能免密登录，禁掉网络防止被外部趁虚而入 |
| 操作期间数据库裸奔 | 尽快完成，改完立即重启恢复正常模式 |
| 密码策略报错 | MySQL 8 默认要求含大小写数字特殊符号且长度至少 8 位 |

## 七、本章小结

| 主题 | 关键命令/结论 |
|------|--------------|
| 安装 | winget / brew / apt / pacman / docker run 五条路任选 |
| 服务管理 | systemctl start/stop/restart mysqld |
| 远程连接 | `mysql -h IP -P 3306 -u user -p` + GRANT 授权 + bind-address 放开 |
| 配置文件 | Linux 在 /etc/my.cnf 或 /etc/mysql/，改完必须重启 |
| 字符集 | 永远用 utf8mb4，不要用 MySQL 的假 utf8 |
| 忘记密码 | skip-grant-tables 启动 → FLUSH PRIVILEGES → ALTER USER |
