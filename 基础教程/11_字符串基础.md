# 基础教程第十一章: 字符串基础  📚(Strings)
## ==========================================================================

## 📋 章节概述

字符串是程序中最常用的数据类型之一，用于表示和处理文本数据。C++ 中有两种字符串
表示方式：C 风格字符串（字符数组）和 C++ 标准库的 std::string 类。本章将讲解
两种方式的使用方法、string 类的常用操作（拼接、查找、截取、替换、比较）、字符串
与数字的互相转换、getline 读取整行输入以及字符串的遍历方式。

#### 1.1 C 风格字符串（char[]）

C 风格字符串是以 '\0' 结尾的字符数组。

```cpp
#include <iostream>
#include <cstring>

int main() {
    char str1[] = "Hello";
    char str2[20] = "World";
    char str3[20];

    std::cout << "str1: " << str1 << std::endl;
    std::cout << "长度: " << strlen(str1) << std::endl;

    strcpy(str3, str1);
    std::cout << "复制: " << str3 << std::endl;

    strcat(str3, " ");
    strcat(str3, str2);
    std::cout << "拼接: " << str3 << std::endl;

    std::cout << "比较: " << strcmp(str1, str2) << std::endl;
    return 0;
}
```

常用 C 字符串函数（`<cstring>`）：
- `strlen(s)` — 返回字符串长度
- `strcpy(dest, src)` — 复制字符串
- `strcat(dest, src)` — 拼接字符串
- `strcmp(s1, s2)` — 比较字符串（0 相等，负值 s1<s2，正值 s1>s2）

#### 1.2 std::string 基本操作

std::string 是 C++ 标准库提供的字符串类，使用更安全方便。

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s1 = "Hello";
    std::string s2("World");
    std::string s3;

    s3 = s1 + " " + s2;
    std::cout << s3 << std::endl;
    std::cout << "长度: " << s3.length() << std::endl;
    std::cout << "第一个字符: " << s3[0] << std::endl;
    std::cout << "最后一个字符: " << s3.back() << std::endl;

    std::cout << "是否为空: " << s3.empty() << std::endl;

    s3 += "!";
    std::cout << "追加后: " << s3 << std::endl;
    return 0;
}
```

#### 1.3 string 声明与初始化的多种方式

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s1;
    std::string s2 = "Hello";
    std::string s3("World");
    std::string s4(5, 'A');
    std::string s5 = s2;
    std::string s6(s2, 1, 3);

    std::cout << "s1: '" << s1 << "'" << std::endl;
    std::cout << "s2: " << s2 << std::endl;
    std::cout << "s3: " << s3 << std::endl;
    std::cout << "s4: " << s4 << std::endl;
    std::cout << "s5: " << s5 << std::endl;
    std::cout << "s6: " << s6 << std::endl;
    return 0;
}
```

输出：
```
s1: ''
s2: Hello
s3: World
s4: AAAAA
s5: Hello
s6: ell
```

#### 2.1 string 常用方法——find

```cpp
#include <iostream>
#include <string>

int main() {
    std::string text = "Hello World, Hello C++";

    size_t pos = text.find("Hello");
    std::cout << "第一次出现位置: " << pos << std::endl;

    pos = text.find("Hello", 1);
    std::cout << "第二次出现位置: " << pos << std::endl;

    pos = text.find("Python");
    if (pos == std::string::npos) {
        std::cout << "未找到 Python" << std::endl;
    }

    pos = text.rfind("Hello");
    std::cout << "最后一次出现位置: " << pos << std::endl;
    return 0;
}
```

#### 2.2 string 常用方法——substr

```cpp
#include <iostream>
#include <string>

int main() {
    std::string str = "Hello World";

    std::string sub1 = str.substr(0, 5);
    std::cout << "前5个字符: " << sub1 << std::endl;

    std::string sub2 = str.substr(6);
    std::cout << "第6个字符起: " << sub2 << std::endl;

    std::string filename = "document.txt";
    size_t dot = filename.rfind('.');
    std::string name = filename.substr(0, dot);
    std::string ext = filename.substr(dot + 1);
    std::cout << "文件名: " << name << ", 扩展名: " << ext << std::endl;
    return 0;
}
```

#### 2.3 string 常用方法——replace

```cpp
#include <iostream>
#include <string>

int main() {
    std::string str = "Hello World";

    str.replace(6, 5, "C++");
    std::cout << str << std::endl;

    std::string text = "I like cats. cats are cute.";
    std::string from = "cats";
    std::string to = "dogs";
    size_t pos = 0;
    while ((pos = text.find(from, pos)) != std::string::npos) {
        text.replace(pos, from.length(), to);
        pos += to.length();
    }
    std::cout << text << std::endl;
    return 0;
}
```

#### 2.6 getline 读取整行

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name;
    std::cout << "请输入你的全名: ";
    std::getline(std::cin, name);
    std::cout << "你好, " << name << "!" << std::endl;

    int age;
    std::cout << "请输入年龄: ";
    std::cin >> age;
    std::cin.ignore();

    std::string address;
    std::cout << "请输入地址: ";
    std::getline(std::cin, address);
    std::cout << "年龄: " << age << ", 地址: " << address << std::endl;
    return 0;
}
```

注意：在 `cin >>` 之后使用 `getline` 之前，需要调用 `cin.ignore()` 清除缓冲区中的换行符。

#### 2.7 字符串遍历

```cpp
#include <iostream>
#include <string>

int main() {
    std::string str = "Hello";

    for (size_t i = 0; i < str.length(); i++) {
        std::cout << str[i] << " ";
    }
    std::cout << std::endl;

    for (char c : str) {
        std::cout << c << " ";
    }
    std::cout << std::endl;

    for (auto it = str.begin(); it != str.end(); ++it) {
        std::cout << *it << " ";
    }
    std::cout << std::endl;
    return 0;
}
```

#### 3.1 案例一：统计单词个数

```cpp
#include <iostream>
#include <string>

int countWords(const std::string& text) {
    int count = 0;
    bool inWord = false;

    for (char c : text) {
        if (c == ' ' || c == '\t' || c == '\n') {
            inWord = false;
        } else {
            if (!inWord) {
                count++;
                inWord = true;
            }
        }
    }
    return count;
}

int main() {
    std::string text;
    std::cout << "输入一段文字: ";
    std::getline(std::cin, text);
    std::cout << "单词个数: " << countWords(text) << std::endl;
    return 0;
}
```

#### 3.2 案例二：字符串回文判断

```cpp
#include <iostream>
#include <string>
#include <algorithm>

bool isPalindrome(const std::string& str) {
    std::string cleaned;
    for (char c : str) {
        if (std::isalpha(c)) {
            cleaned += std::tolower(c);
        }
    }

    std::string reversed = cleaned;
    std::reverse(reversed.begin(), reversed.end());
    return cleaned == reversed;
}

int main() {
    std::string tests[] = {"racecar", "A man a plan a canal Panama", "hello"};

    for (const auto& s : tests) {
        std::cout << "\"" << s << "\" 是回文: "
                  << (isPalindrome(s) ? "是" : "否") << std::endl;
    }
    return 0;
}
```

#### 3.3 案例三：简易 CSV 解析器

```cpp
#include <iostream>
#include <string>
#include <vector>

std::vector<std::string> split(const std::string& str, char delimiter) {
    std::vector<std::string> tokens;
    std::string token;
    size_t start = 0;
    size_t end = str.find(delimiter);

    while (end != std::string::npos) {
        tokens.push_back(str.substr(start, end - start));
        start = end + 1;
        end = str.find(delimiter, start);
    }
    tokens.push_back(str.substr(start));
    return tokens;
}

int main() {
    std::string csv = "Alice,25,Engineer,Beijing";
    std::vector<std::string> fields = split(csv, ',');

    std::cout << "姓名: " << fields[0] << std::endl;
    std::cout << "年龄: " << fields[1] << std::endl;
    std::cout << "职业: " << fields[2] << std::endl;
    std::cout << "城市: " << fields[3] << std::endl;
    return 0;
}
```

#### 3.4 案例四：字符串加密（凯撒密码）

```cpp
#include <iostream>
#include <string>

std::string encrypt(const std::string& text, int shift) {
    std::string result = text;
    for (char& c : result) {
        if (std::isupper(c)) {
            c = (c - 'A' + shift) % 26 + 'A';
        } else if (std::islower(c)) {
            c = (c - 'a' + shift) % 26 + 'a';
        }
    }
    return result;
}

std::string decrypt(const std::string& text, int shift) {
    return encrypt(text, 26 - shift);
}

int main() {
    std::string message = "Hello World";
    int shift = 3;

    std::string encrypted = encrypt(message, shift);
    std::cout << "加密: " << encrypted << std::endl;

    std::string decrypted = decrypt(encrypted, shift);
    std::cout << "解密: " << decrypted << std::endl;
    return 0;
}
```

> > **解析**: 两者都是在字符串中查找字符 'a' 的第一次出现位置，结果相同。前者查找单个字符，后者查找子字符串，但在这个例子中效果一致。

> [!question] 判断题 8

> [!question] 判断题 9

> [!question] 选择题 1
> 以下哪个方法可以获取 string 的 C 风格字符串表示？

> - [ ] D. A 和 B 都可以

> > 正确答案: D

> [!question] 选择题 2
> `std::string s = "abcdef"; s.substr(2, 3)` 的结果是？

> - [ ] B. "cde"
> - [ ] C. "bcd"
> - [ ] D. "def"
>
> > [!success]- 点击查看答案
> > 正确答案: B
> > **解析**: substr(2, 3) 从位置 2（第三个字符 'c'）开始截取 3 个字符，得到 "cde"。

> [!question] 选择题 3
> 以下哪种方式可以正确读取含空格的整行输入？
> - [ ] A. `std::cin >> str;`
> - [ ] B. `std::getline(std::cin, str);`
> - [ ] C. `std::cin.get(str);`
> - [ ] D. `scanf("%s", str);`
>
> > [!success]- 点击查看答案
> > 正确答案: B
> > **解析**: `cin >>` 遇到空格就停止读取，getline 读取整行直到换行符。C 和 D 不适用于 std::string。

> [!question] 选择题 4
> `std::stoi("99999999999")` 可能会发生什么？
> - [ ] A. 返回最大 int 值

> - [ ] D. 截断为较小数字
>
> > [!success]- 点击查看答案
> > 正确答案: C
> > **解析**: 当数值超出 int 的表示范围时，stoi 会抛出 std::out_of_range 异常。

> [!question] 选择题 5
> 以下代码输出什么？
> ```cpp
> std::string s = "Hello";

> - [ ] B. Jello
> - [ ] C. Jllo
> - [ ] D. Hello
>
> > [!success]- 点击查看答案
> > 正确答案: B
> > **解析**: replace(0, 1, "J") 将位置 0 开始的 1 个字符（'H'）替换为 "J"，结果为 "Jello"。

> [!question] 选择题 6
> string 的 `+` 运算符和 `append()` 方法的区别是？
> - [ ] A. + 创建新字符串，append 原地修改
> - [ ] B. + 更快
> - [ ] C. append 只能追加单个字符
> - [ ] D. 没有区别
>
> > [!success]- 点击查看答案
> > 正确答案: A
> > **解析**: `s1 + s2` 创建一个新的字符串对象，`s1.append(s2)` 或 `s1 += s2` 在 s1 原地追加，避免创建临时对象。

> [!question] 选择题 7
> 以下哪种遍历方式不能修改字符串中的字符？
> - [ ] A. `for (char& c : str)`
> - [ ] B. `for (size_t i = 0; i < str.size(); i++) str[i]`
> - [ ] C. `for (char c : str)`
> - [ ] D. `for (auto& c : str)`
>
> > [!success]- 点击查看答案
> > 正确答案: C
> > **解析**: `for (char c : str)` 中 c 是值拷贝，修改 c 不影响原字符串。其他方式通过引用或下标可以修改。

> [!question] 选择题 8
> `std::string("Hello").find("ll")` 的返回值是？
> - [ ] A. 0
> - [ ] B. 2
> - [ ] C. 3
> - [ ] D. 1
>
> > [!success]- 点击查看答案
> > 正确答案: B
> > **解析**: "Hello" 中 "ll" 从位置 2 开始（H=0, e=1, l=2），find 返回第一次匹配的起始位置 2。

> [!question] 选择题 9
> 以下哪种方式可以将 int 变量转为 string？
> - [ ] A. `std::to_string(num)`
> - [ ] B. `std::string(num)`
> - [ ] C. `(std::string)num`
> - [ ] D. `std::stoi(num)`
>
> > [!success]- 点击查看答案
> > 正确答案: A
> > **解析**: std::to_string() 是 C++11 提供的数字转字符串的标准方法。B 和 C 语法不合法，D 是字符串转 int。

> [!question] 选择题 10
> 以下代码有什么问题？
> ```cpp
> int n;
> std::string line;
> std::cin >> n;
> std::getline(std::cin, line);
> ```
> - [ ] A. 编译错误
> - [ ] B. line 会读到空字符串，因为缓冲区中残留换行符
> - [ ] C. n 的值会出错
> - [ ] D. 没有问题
>
> > [!success]- 点击查看答案
> > 正确答案: B
> > **解析**: `cin >> n` 后缓冲区中残留换行符，getline 立即读到换行符返回空字符串。应在两者之间加 `std::cin.ignore()` 清除换行符。
