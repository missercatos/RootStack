# 基础教程第八章: 循环结构  📚(Loop Structures)
## ==========================================================================

## 📋 章节概述

循环是程序设计中最基础也是最重要的控制结构之一。通过循环，程序可以重复执行一段
代码直到满足特定条件为止。C++ 提供了三种基本循环结构：for 循环、while 循环和
do-while 循环。本章将详细讲解每种循环的语法与使用场景，介绍 break/continue 控制
语句、嵌套循环、循环变量作用域、常见循环模式以及 C++11 引入的 range-based for 循环。

## ==========================================================================
### 📖 第一节: 基础语法与概念
## ==========================================================================

#### 1.1 for 循环

for 循环由三个部分组成：初始化表达式、循环条件和步进表达式。

```cpp
#include <iostream>

int main() {
    for (int i = 0; i < 5; i++) {
        std::cout << "i = " << i << std::endl;
    }
    return 0;
}
```

执行流程：
1. 执行初始化表达式（`int i = 0`），仅执行一次
2. 判断条件（`i < 5`），为真则执行循环体
3. 执行循环体
4. 执行步进表达式（`i++`）
5. 回到步骤 2

#### 1.2 while 循环

while 循环在每次迭代前检查条件，条件为真时执行循环体。

```cpp
#include <iostream>

int main() {
    int count = 0;
    while (count < 5) {
        std::cout << "count = " << count << std::endl;
        count++;
    }
    return 0;
}
```

#### 1.3 do-while 循环

do-while 循环至少执行一次循环体，然后再检查条件。

```cpp
#include <iostream>

int main() {
    int num;
    do {
        std::cout << "请输入一个正数: ";
        std::cin >> num;
    } while (num <= 0);

    std::cout << "你输入的是: " << num << std::endl;
    return 0;
}
```

#### 1.4 break 与 continue

- `break`：立即跳出当前循环
- `continue`：跳过本次迭代的剩余部分，进入下一次迭代

```cpp
#include <iostream>

int main() {
    for (int i = 0; i < 10; i++) {
        if (i == 3) continue;
        if (i == 7) break;
        std::cout << i << " ";
    }
    // 输出: 0 1 2 4 5 6
    return 0;
}
```

#### 1.5 循环变量作用域

在 for 循环初始化部分声明的变量，其作用域仅限于该循环。

```cpp
#include <iostream>

int main() {
    for (int i = 0; i < 3; i++) {
        std::cout << i << std::endl;
    }
    // 此处无法访问 i，编译错误
    // std::cout << i << std::endl;

    int j;
    for (j = 0; j < 3; j++) {
        // ...
    }
    // j 在循环外仍可访问，值为 3
    std::cout << "j = " << j << std::endl;
    return 0;
}
```

#### 2.1 嵌套循环

循环可以嵌套使用，外层循环每执行一次，内层循环完整执行一轮。

```cpp
#include <iostream>

int main() {
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 3; j++) {
            std::cout << "(" << i << "," << j << ") ";
        }
        std::cout << std::endl;
    }
    return 0;
}
```

输出：
```
(1,1) (1,2) (1,3) 
(2,1) (2,2) (2,3) 
(3,1) (3,2) (3,3) 
```

#### 2.2 嵌套循环中的 break

break 只能跳出它所在的最内层循环。

```cpp
#include <iostream>

int main() {
    for (int i = 0; i < 5; i++) {
        for (int j = 0; j < 5; j++) {
            if (j == 3) break;
            std::cout << "(" << i << "," << j << ") ";
        }
        std::cout << std::endl;
    }
    return 0;
}
```

#### 2.3 死循环与退出

有时需要使用死循环配合条件退出：

```cpp
#include <iostream>

int main() {
    while (true) {
        int input;
        std::cout << "输入数字 (0 退出): ";
        std::cin >> input;
        if (input == 0) break;
        std::cout << "你输入了: " << input << std::endl;
    }
    return 0;
}
```

等效的 for 写法：

```cpp
for (;;) {
    // 死循环体
}
```

#### 2.4 常见循环模式

**累加模式：**

```cpp
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
```

**计数模式：**

```cpp
int count = 0;
for (int i = 0; i < n; i++) {
    if (arr[i] > 0) count++;
}
```

**查找模式：**

```cpp
int target = 42;
bool found = false;
for (int i = 0; i < n; i++) {
    if (arr[i] == target) {
        found = true;
        break;
    }
}
```

**遍历模式：**

```cpp
for (int i = 0; i < n; i++) {
    std::cout << arr[i] << " ";
}
```

#### 2.5 range-based for 循环（C++11）

C++11 引入了基于范围的 for 循环，简化容器和数组的遍历：

```cpp
#include <iostream>
#include <vector>

int main() {
    int arr[] = {10, 20, 30, 40, 50};

    for (int x : arr) {
        std::cout << x << " ";
    }
    std::cout << std::endl;

    std::vector<std::string> names = {"Alice", "Bob", "Charlie"};
    for (const auto& name : names) {
        std::cout << name << std::endl;
    }
    return 0;
}
```

使用引用可以修改元素：

```cpp
int arr[] = {1, 2, 3, 4, 5};
for (int& x : arr) {
    x *= 2;
}
// arr 变为 {2, 4, 6, 8, 10}
```

#### 3.1 案例一：打印乘法口诀表

```cpp
#include <iostream>
#include <iomanip>

int main() {
    for (int i = 1; i <= 9; i++) {
        for (int j = 1; j <= i; j++) {
            std::cout << j << "×" << i << "=" << std::setw(2) << i * j << " ";
        }
        std::cout << std::endl;
    }
    return 0;
}
```

#### 3.2 案例二：判断素数

```cpp
#include <iostream>

bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) return false;
    }
    return true;
}

int main() {
    std::cout << "100以内的素数: ";
    for (int i = 2; i <= 100; i++) {
        if (isPrime(i)) {
            std::cout << i << " ";
        }
    }
    std::cout << std::endl;
    return 0;
}
```

#### 3.3 案例三：猜数字游戏

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>

int main() {
    std::srand(std::time(nullptr));
    int secret = std::rand() % 100 + 1;
    int guess;
    int attempts = 0;

    std::cout << "猜一个1-100之间的数字!" << std::endl;

    do {
        std::cout << "你的猜测: ";
        std::cin >> guess;
        attempts++;

        if (guess > secret) {
            std::cout << "太大了!" << std::endl;
        } else if (guess < secret) {
            std::cout << "太小了!" << std::endl;
        }
    } while (guess != secret);

    std::cout << "恭喜! 你用了 " << attempts << " 次猜对了!" << std::endl;
    return 0;
}
```

#### 3.4 案例四：使用 range-based for 统计单词

```cpp
#include <iostream>
#include <vector>
#include <string>

int main() {
    std::vector<std::string> words = {"hello", "world", "cpp", "programming", "loop"};

    int longWords = 0;
    for (const auto& word : words) {
        if (word.length() > 4) {
            longWords++;
        }
    }

    std::cout << "长度超过4的单词有 " << longWords << " 个" << std::endl;
    return 0;
}
```

> > 正确答案: B
> > **解析**: 当 i 增加到 3 时，条件 i==3 成立，执行 break 跳出循环，此时 i 的值为 3。

> [!question] 选择题 2
> 以下哪个循环会执行循环体 0 次？
> - [ ] A. `do { } while(false);`
> - [ ] B. `while(false) { }`
> - [ ] C. `for(int i=0; i<0; i++) { }`
> - [ ] D. B 和 C 都是
>
> > [!success]- 点击查看答案
> > 正确答案: D
> > **解析**: while(false) 条件一开始为假，不执行。for 循环中 0<0 为假，也不执行。do-while 至少执行一次。

> [!question] 选择题 3
> 以下代码执行后 `sum` 的值是？
> ```cpp
> int sum = 0;
> for (int i = 1; i <= 10; i++) {
>     if (i % 2 == 0) continue;
>     sum += i;
> }
> ```
> - [ ] A. 55
> - [ ] B. 30
> - [ ] C. 25
> - [ ] D. 20
>
> > [!success]- 点击查看答案
> > 正确答案: C
> > **解析**: continue 跳过偶数，只累加奇数：1+3+5+7+9 = 25。

> [!question] 选择题 4
> range-based for 循环 `for (auto x : vec)` 中 x 是什么？
> - [ ] A. 元素的引用
> - [ ] B. 元素的指针
> - [ ] C. 元素的拷贝
> - [ ] D. 元素的迭代器
>
> > [!success]- 点击查看答案
> > 正确答案: C
> > **解析**: 不带引用符号 `&` 时，x 是容器中每个元素的值拷贝，修改 x 不会影响原容器。

> [!question] 选择题 5
> 以下哪种情况适合使用 do-while 而非 while？
> - [ ] A. 遍历数组
> - [ ] B. 需要先执行操作再判断是否继续
> - [ ] C. 已知循环次数
> - [ ] D. 需要使用 break
>
> > [!success]- 点击查看答案
> > 正确答案: B
> > **解析**: do-while 的特点是先执行后判断，适合至少需要执行一次的场景，如用户输入验证。

> [!question] 选择题 6
> 下面哪段代码可以正确实现从 10 到 1 的倒计数输出？
> - [ ] A. `for (int i = 10; i > 0; i--)`
> - [ ] B. `for (int i = 10; i >= 0; i--)`
> - [ ] C. `for (int i = 10; i > 1; i--)`
> - [ ] D. `for (int i = 1; i <= 10; i++)`
>
> > [!success]- 点击查看答案
> > 正确答案: A
> > **解析**: 从 10 开始，条件 i>0（即 i>=1），每次递减，依次输出 10,9,8,...,1。

> [!question] 选择题 7
> 以下代码有什么问题？
> ```cpp
> for (int i = 0; i < 10; i++) {
>     // ...
> }
> std::cout << i;
> ```
> - [ ] A. 运行时错误
> - [ ] B. 编译错误，i 超出作用域
> - [ ] C. 输出 10
> - [ ] D. 输出 9
>
> > [!success]- 点击查看答案
> > 正确答案: B
> > **解析**: 在 for 循环初始化部分声明的变量 i 作用域仅限于循环内部，在循环外访问 i 会导致编译错误。

> [!question] 选择题 8
> 以下循环将打印多少个星号？
> ```cpp
> for (int i = 0; i < 3; i++) {
>     for (int j = 0; j <= i; j++) {
>         std::cout << "*";
>     }
> }
> ```
> - [ ] A. 3
> - [ ] B. 6
> - [ ] C. 9
> - [ ] D. 4
>
> > [!success]- 点击查看答案
> > 正确答案: B
> > **解析**: i=0 时打印 1 个，i=1 时打印 2 个，i=2 时打印 3 个，共 1+2+3=6 个。

> [!question] 选择题 9
> 以下代码的目的是什么？
> ```cpp
> int n = 12345, digits = 0;
> while (n > 0) {
>     n /= 10;
>     digits++;
> }
> ```
> - [ ] A. 计算 n 的各位数字之和
> - [ ] B. 计算 n 的位数
> - [ ] C. 反转 n 的数字
> - [ ] D. 判断 n 是否为回文数
>
> > [!success]- 点击查看答案
> > 正确答案: B
> > **解析**: 每次将 n 除以 10（去掉最后一位），同时计数器加 1，直到 n 为 0，最终 digits 即为 n 的位数。

> [!question] 选择题 10
> 要遍历 `std::vector<int> v` 并修改每个元素使其翻倍，正确的写法是？
> - [ ] A. `for (int x : v) { x *= 2; }`
> - [ ] B. `for (int& x : v) { x *= 2; }`
> - [ ] C. `for (const int& x : v) { x *= 2; }`
> - [ ] D. `for (auto* x : v) { x *= 2; }`
>
> > [!success]- 点击查看答案
> > 正确答案: B
> > **解析**: 使用引用 `int&` 才能修改原容器中的元素。A 是值拷贝修改无效，C 是 const 引用不允许修改，D 语法错误。
