1.1 Hello World 程序
---------------------

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```

这是最简单的 C++ 程序。逐行分析：

- `#include <iostream>`：预处理指令，引入标准输入输出流库
- `int main()`：程序入口函数，操作系统从这里开始执行程序
- `std::cout`：标准输出流对象，用于向控制台输出内容
- `<<`：插入运算符，将右侧数据送入左侧流对象
- `std::endl`：换行并刷新缓冲区
- `return 0`：返回 0 表示程序正常结束

1.2 main 函数详解
------------------

main 函数是每个 C++ 程序的唯一入口点。它有两种标准形式：

```cpp
int main() {
    return 0;
}

int main(int argc, char* argv[]) {
    return 0;
}
```

- `argc`：命令行参数个数（argument count）
- `argv`：命令行参数数组（argument vector）
- 返回值 0 表示成功，非零值表示错误

```cpp
#include <iostream>

int main(int argc, char* argv[]) {
    std::cout << "参数个数: " << argc << std::endl;
    for (int i = 0; i < argc; i++) {
        std::cout << "argv[" << i << "] = " << argv[i] << std::endl;
    }
    return 0;
}
```

1.3 #include <iostream>
------------------------

`#include` 是预处理指令，在编译之前将指定头文件的内容插入到当前文件中。

- `<iostream>`：标准输入输出流，提供 cin、cout、cerr、clog
- `<>`：在系统标准目录中搜索头文件
- `""`：先在当前目录搜索，再搜索系统目录

```cpp
#include <iostream>   // 系统头文件
#include "myfile.h"   // 用户自定义头文件
```

1.4 cout 输出
--------------

`std::cout` 配合插入运算符 `<<` 实现输出，可以连续输出多个数据：

```cpp
#include <iostream>

int main() {
    int age = 20;
    double height = 1.75;
    std::string name = "张三";

    std::cout << "姓名: " << name << std::endl;
    std::cout << "年龄: " << age << std::endl;
    std::cout << "身高: " << height << "m" << std::endl;

    std::cout << "姓名: " << name
              << ", 年龄: " << age
              << ", 身高: " << height << "m" << std::endl;

    return 0;
}
```

1.5 cin 输入
-------------

`std::cin` 配合提取运算符 `>>` 从键盘读取数据：

```cpp
#include <iostream>

int main() {
    int a, b;
    std::cout << "请输入两个整数: ";
    std::cin >> a >> b;
    std::cout << "它们的和是: " << a + b << std::endl;
    return 0;
}
```

cin 以空白字符（空格、制表符、换行）作为分隔符，自动跳过前导空白。

```cpp
#include <iostream>
#include <string>

int main() {
    std::string word;
    std::cout << "输入一个单词: ";
    std::cin >> word;
    std::cout << "你输入了: " << word << std::endl;

    std::cin.ignore();
    std::string line;
    std::cout << "输入一整行: ";
    std::getline(std::cin, line);
    std::cout << "整行内容: " << line << std::endl;

    return 0;
}
```

1.6 endl 与 '\n' 的区别
-------------------------

```cpp
#include <iostream>

int main() {
    std::cout << "使用 endl" << std::endl;   // 换行 + 刷新缓冲区
    std::cout << "使用 \\n" << '\n';          // 仅换行，不刷新缓冲区

    // 在大量输出时，'\n' 性能更好
    for (int i = 0; i < 10000; i++) {
        std::cout << i << '\n';  // 比 endl 快得多
    }

    return 0;
}
```

- `std::endl`：输出换行符并立即刷新输出缓冲区（flush）
- `'\n'`：仅输出换行字符，不刷新缓冲区
- 在高频输出场景中，使用 `'\n'` 可显著提升性能

2.1 编译运行流程
-----------------

C++ 程序从源代码到可执行文件需要经历四个阶段：

```
源代码(.cpp) → 预处理 → 编译 → 汇编 → 链接 → 可执行文件
```

具体步骤：

```bash
# 一步完成编译和链接
g++ hello.cpp -o hello

# 分步操作
g++ -E hello.cpp -o hello.i    # 预处理：展开宏、处理 #include
g++ -S hello.i -o hello.s      # 编译：生成汇编代码
g++ -c hello.s -o hello.o      # 汇编：生成目标文件（机器码）
g++ hello.o -o hello            # 链接：链接库文件，生成可执行文件

# 运行
./hello
```

各阶段的作用：
- **预处理**：处理 `#include`、`#define`、条件编译等指令
- **编译**：将预处理后的代码翻译为汇编语言
- **汇编**：将汇编代码转换为机器码（目标文件 .o）
- **链接**：将目标文件与库文件合并，解析外部符号引用

2.2 printf/scanf 对比
-----------------------

C++ 兼容 C 语言的 printf/scanf，需要 `#include <cstdio>`：

```cpp
#include <iostream>
#include <cstdio>

int main() {
    int age = 25;
    double score = 95.5;
    char name[] = "李四";

    // C 风格
    printf("姓名: %s, 年龄: %d, 成绩: %.1f\n", name, age, score);
    
    // C++ 风格
    std::cout << "姓名: " << name << ", 年龄: " << age
              << ", 成绩: " << score << std::endl;

    // C 风格输入
    int x;
    printf("请输入一个整数: ");
    scanf("%d", &x);
    printf("你输入了: %d\n", x);

    // C++ 风格输入
    int y;
    std::cout << "请输入一个整数: ";
    std::cin >> y;
    std::cout << "你输入了: " << y << std::endl;

    return 0;
}
```

printf 常用格式说明符：

| 说明符 | 含义 | 示例 |
|--------|------|------|
| `%d` | 整数 | `printf("%d", 42)` |
| `%f` | 浮点数 | `printf("%f", 3.14)` |
| `%s` | 字符串 | `printf("%s", "hello")` |
| `%c` | 字符 | `printf("%c", 'A')` |
| `%lld` | long long | `printf("%lld", 123LL)` |
| `%x` | 十六进制 | `printf("%x", 255)` |

cout vs printf 对比：
- cout 类型安全，不会因格式说明符错误导致未定义行为
- printf 格式化更紧凑，在竞赛编程中常用
- cout 可扩展，支持自定义类型的输出重载
- printf 在某些场景下性能更好

2.3 格式化输出（setw / setprecision）
---------------------------------------

使用 `<iomanip>` 头文件中的操控器实现格式化：

```cpp
#include <iostream>
#include <iomanip>

int main() {
    // setw：设置输出宽度（仅对下一个输出有效）
    std::cout << std::setw(10) << "Name"
              << std::setw(10) << "Score" << std::endl;
    std::cout << std::setw(10) << "Alice"
              << std::setw(10) << 95.5 << std::endl;
    std::cout << std::setw(10) << "Bob"
              << std::setw(10) << 87.3 << std::endl;

    std::cout << "---" << std::endl;

    // setprecision：设置浮点数精度
    double pi = 3.141592653589793;

    std::cout << std::setprecision(3) << pi << std::endl;   // 3.14（有效数字3位）
    std::cout << std::fixed << std::setprecision(3) << pi << std::endl;  // 3.142（小数点后3位）
    std::cout << std::scientific << std::setprecision(3) << pi << std::endl;  // 3.142e+00

    std::cout << "---" << std::endl;

    // 对齐方式
    std::cout << std::fixed << std::setprecision(2);
    std::cout << std::left << std::setw(15) << "商品"
              << std::right << std::setw(10) << "价格" << std::endl;
    std::cout << std::left << std::setw(15) << "苹果"
              << std::right << std::setw(10) << 5.50 << std::endl;
    std::cout << std::left << std::setw(15) << "香蕉"
              << std::right << std::setw(10) << 3.20 << std::endl;

    std::cout << "---" << std::endl;

    // setfill：设置填充字符
    std::cout << std::setfill('*') << std::setw(20) << "Hello" << std::endl;
    std::cout << std::setfill('0') << std::setw(8) << 42 << std::endl;

    return 0;
}
```

常用格式化操控器：

| 操控器 | 作用 | 持续性 |
|--------|------|--------|
| `setw(n)` | 设置输出宽度 | 仅下一次 |
| `setprecision(n)` | 设置精度 | 持续有效 |
| `fixed` | 定点表示法 | 持续有效 |
| `scientific` | 科学计数法 | 持续有效 |
| `left` | 左对齐 | 持续有效 |
| `right` | 右对齐 | 持续有效 |
| `setfill(c)` | 设置填充字符 | 持续有效 |
| `hex/oct/dec` | 进制输出 | 持续有效 |

```cpp
#include <iostream>
#include <iomanip>

int main() {
    int num = 255;
    std::cout << "十进制: " << std::dec << num << std::endl;
    std::cout << "八进制: " << std::oct << num << std::endl;
    std::cout << "十六进制: " << std::hex << num << std::endl;
    std::cout << "十六进制(大写): " << std::hex << std::uppercase << num << std::endl;

    std::cout << std::dec;

    std::cout << std::boolalpha << true << ", " << false << std::endl;
    std::cout << std::noboolalpha << true << ", " << false << std::endl;

    return 0;
}
```

3.1 案例一：简易计算器
-----------------------

```cpp
#include <iostream>
#include <iomanip>

int main() {
    double num1, num2;
    char op;

    std::cout << "简易计算器" << std::endl;
    std::cout << "请输入表达式 (如 3.5 + 2.1): ";
    std::cin >> num1 >> op >> num2;

    std::cout << std::fixed << std::setprecision(4);

    switch (op) {
        case '+':
            std::cout << num1 << " + " << num2 << " = " << num1 + num2 << std::endl;
            break;
        case '-':
            std::cout << num1 << " - " << num2 << " = " << num1 - num2 << std::endl;
            break;
        case '*':
            std::cout << num1 << " * " << num2 << " = " << num1 * num2 << std::endl;
            break;
        case '/':
            if (num2 == 0) {
                std::cout << "错误: 除数不能为零!" << std::endl;
            } else {
                std::cout << num1 << " / " << num2 << " = " << num1 / num2 << std::endl;
            }
            break;
        default:
            std::cout << "不支持的运算符: " << op << std::endl;
    }

    return 0;
}
```

3.3 案例三：交互式个人信息录入
-------------------------------

```cpp
#include <iostream>
#include <iomanip>
#include <string>

int main() {
    std::string name;
    int age;
    double height, weight;
    char gender;

    std::cout << "=== 个人信息录入系统 ===" << std::endl;

    std::cout << "请输入姓名: ";
    std::getline(std::cin, name);

    std::cout << "请输入性别 (M/F): ";
    std::cin >> gender;

    std::cout << "请输入年龄: ";
    std::cin >> age;

    std::cout << "请输入身高(cm): ";
    std::cin >> height;

    std::cout << "请输入体重(kg): ";
    std::cin >> weight;

    double bmi = weight / ((height / 100.0) * (height / 100.0));

    std::cout << "\n=== 信息确认 ===" << std::endl;
    std::cout << std::fixed << std::setprecision(1);
    std::cout << std::left << std::setw(12) << "姓名:" << name << std::endl;
    std::cout << std::setw(12) << "性别:" << (gender == 'M' ? "男" : "女") << std::endl;
    std::cout << std::setw(12) << "年龄:" << age << " 岁" << std::endl;
    std::cout << std::setw(12) << "身高:" << height << " cm" << std::endl;
    std::cout << std::setw(12) << "体重:" << weight << " kg" << std::endl;
    std::cout << std::setw(12) << "BMI:" << std::setprecision(2) << bmi << std::endl;

    if (bmi < 18.5)
        std::cout << "体重状况: 偏瘦" << std::endl;
    else if (bmi < 24.0)
        std::cout << "体重状况: 正常" << std::endl;
    else if (bmi < 28.0)
        std::cout << "体重状况: 偏胖" << std::endl;
    else
        std::cout << "体重状况: 肥胖" << std::endl;

    return 0;
}
```
