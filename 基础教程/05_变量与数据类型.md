## 📋 章节概述

变量是程序中存储数据的基本单元，数据类型决定了变量能存储什么样的数据以及占用
多少内存。本章将全面讲解 C++ 的基本数据类型（int、float、double、char、bool、

sizeof 运算符，整数溢出问题，类型转换（隐式转换、显式转换、static_cast），
以及 ASCII 码的概念与应用。

1.1 基本数据类型
-----------------

C++ 提供了多种内置数据类型：

| 类型 | 大小(典型) | 范围 | 用途 |
|------|-----------|------|------|
| `bool` | 1 字节 | true/false | 布尔值 |
| `char` | 1 字节 | -128 ~ 127 | 字符 |
| `int` | 4 字节 | -2^31 ~ 2^31-1 | 整数 |
| `long long` | 8 字节 | -2^63 ~ 2^63-1 | 大整数 |
| `float` | 4 字节 | ±3.4e38 (7位精度) | 单精度浮点 |
| `double` | 8 字节 | ±1.7e308 (15位精度) | 双精度浮点 |

```cpp
#include <iostream>

int main() {
    bool isReady = true;
    char grade = 'A';
    int count = 100;
    long long bigNum = 9223372036854775807LL;
    float pi_f = 3.14159f;
    double pi_d = 3.141592653589793;

    std::cout << "bool: " << isReady << std::endl;
    std::cout << "char: " << grade << std::endl;
    std::cout << "int: " << count << std::endl;
    std::cout << "long long: " << bigNum << std::endl;
    std::cout << "float: " << pi_f << std::endl;
    std::cout << "double: " << pi_d << std::endl;

    return 0;
}
```

其他整数类型：

```cpp
#include <iostream>

int main() {
    short s = 32767;              // 至少 16 位
    unsigned int u = 4294967295;  // 无符号，范围 0 ~ 2^32-1
    unsigned char uc = 255;       // 0 ~ 255
    long l = 2147483647L;         // 至少 32 位

    std::cout << "short: " << s << std::endl;
    std::cout << "unsigned int: " << u << std::endl;
    std::cout << "unsigned char: " << (int)uc << std::endl;
    std::cout << "long: " << l << std::endl;

    return 0;
}
```

1.2 变量声明与初始化
---------------------

C++ 中变量必须先声明后使用。有多种初始化方式：

```cpp
#include <iostream>

int main() {
    // 声明不初始化（值不确定，局部变量包含垃圾值）
    int a;

    // 拷贝初始化
    int b = 10;

    // 直接初始化
    int c(20);

    // 列表初始化（C++11，推荐）
    int d{30};
    int e = {40};

    // 列表初始化会检查窄化转换
    // int f{3.14};  // 错误！double 到 int 是窄化转换

    // 多变量声明
    int x = 1, y = 2, z = 3;

    std::cout << "b=" << b << " c=" << c << " d=" << d << " e=" << e << std::endl;
    std::cout << "x=" << x << " y=" << y << " z=" << z << std::endl;

    return 0;
}
```

1.3 sizeof 运算符
-------------------

sizeof 返回类型或变量占用的字节数：

```cpp
#include <iostream>

int main() {
    std::cout << "sizeof(bool) = " << sizeof(bool) << std::endl;
    std::cout << "sizeof(char) = " << sizeof(char) << std::endl;
    std::cout << "sizeof(short) = " << sizeof(short) << std::endl;
    std::cout << "sizeof(int) = " << sizeof(int) << std::endl;
    std::cout << "sizeof(long) = " << sizeof(long) << std::endl;
    std::cout << "sizeof(long long) = " << sizeof(long long) << std::endl;
    std::cout << "sizeof(float) = " << sizeof(float) << std::endl;
    std::cout << "sizeof(double) = " << sizeof(double) << std::endl;

    int arr[10];
    std::cout << "sizeof(arr) = " << sizeof(arr) << std::endl;
    std::cout << "数组元素个数 = " << sizeof(arr) / sizeof(arr[0]) << std::endl;

    return 0;
}
```

1.4 ASCII 码
--------------

char 类型本质上存储的是整数（ASCII 码值），每个字符对应一个数字：

```cpp
#include <iostream>

int main() {
    char ch = 'A';
    std::cout << "字符: " << ch << std::endl;
    std::cout << "ASCII值: " << (int)ch << std::endl;

    // 常用 ASCII 值
    // 'A' = 65, 'Z' = 90
    // 'a' = 97, 'z' = 122
    // '0' = 48, '9' = 57

    // 大写转小写
    char upper = 'H';
    char lower = upper + 32;
    std::cout << upper << " -> " << lower << std::endl;

    // 字符与数字的转换
    char digit = '7';
    int num = digit - '0';
    std::cout << "字符 '" << digit << "' 的数值是 " << num << std::endl;

    // 打印 ASCII 表的一部分
    for (int i = 32; i < 127; i++) {
        std::cout << i << "=" << (char)i << "  ";
        if ((i - 31) % 10 == 0) std::cout << std::endl;
    }
    std::cout << std::endl;

    return 0;
}
```

2.1 const 与 constexpr
------------------------

const 声明运行时常量，constexpr 声明编译时常量：

```cpp
#include <iostream>

int getSize() {
    return 10;
}

constexpr int square(int x) {
    return x * x;
}

int main() {
    const int MAX_SIZE = 100;       // 运行时常量
    // MAX_SIZE = 200;              // 错误！不能修改 const 变量

    const int size = getSize();     // 运行时确定的常量

    constexpr int ARRAY_SIZE = 50;  // 编译时常量
    constexpr int result = square(5);  // 编译时计算

    // constexpr int x = getSize(); // 错误！getSize() 不是 constexpr 函数

    int arr[ARRAY_SIZE];            // constexpr 可用于数组大小

    std::cout << "MAX_SIZE = " << MAX_SIZE << std::endl;
    std::cout << "ARRAY_SIZE = " << ARRAY_SIZE << std::endl;
    std::cout << "square(5) = " << result << std::endl;

    return 0;
}
```

const 与 constexpr 的区别：
- `const`：值在初始化后不可修改，可以在运行时确定
- `constexpr`：值必须在编译时就能确定，更强的约束
- constexpr 变量隐含 const 属性

2.2 auto 类型推导
------------------

C++11 引入 auto 关键字，让编译器自动推导变量类型：

```cpp
#include <iostream>
#include <vector>
#include <map>

int main() {
    auto i = 42;           // int
    auto d = 3.14;         // double
    auto f = 3.14f;        // float
    auto c = 'A';          // char
    auto b = true;         // bool
    auto ll = 100LL;       // long long
    auto s = std::string("hello");  // std::string

    std::cout << "i 的类型大小: " << sizeof(i) << std::endl;
    std::cout << "d 的类型大小: " << sizeof(d) << std::endl;

    // auto 在复杂类型中特别有用
    std::vector<int> vec = {1, 2, 3, 4, 5};
    for (auto it = vec.begin(); it != vec.end(); ++it) {
        std::cout << *it << " ";
    }
    std::cout << std::endl;

    // 范围 for 循环中使用 auto
    for (auto& val : vec) {
        val *= 2;
    }

    for (const auto& val : vec) {
        std::cout << val << " ";
    }
    std::cout << std::endl;

    // auto 不能用于函数参数（C++20 前）
    // auto 声明时必须初始化
    // auto x;  // 错误！

    return 0;
}
```

2.3 整数溢出
--------------

当运算结果超出类型表示范围时，会发生溢出：

```cpp
#include <iostream>
#include <climits>

int main() {
    std::cout << "int 最大值: " << INT_MAX << std::endl;
    std::cout << "int 最小值: " << INT_MIN << std::endl;

    int max_int = INT_MAX;
    std::cout << "INT_MAX = " << max_int << std::endl;
    std::cout << "INT_MAX + 1 = " << max_int + 1 << std::endl;  // 溢出！变为负数

    unsigned int u = 0;
    std::cout << "0u - 1 = " << u - 1 << std::endl;  // 无符号下溢，变为最大值

    // 检测溢出
    int a = 2000000000;
    int b = 2000000000;
    // int c = a + b;  // 溢出！
    long long c = (long long)a + b;  // 用更大类型避免溢出
    std::cout << "a + b = " << c << std::endl;

    // 乘法溢出
    int x = 100000;
    // int y = x * x;  // 溢出！
    long long y = (long long)x * x;  // 正确
    std::cout << "100000^2 = " << y << std::endl;

    return 0;
}
```

有符号整数溢出是**未定义行为**，无符号整数溢出是**定义良好的**（模 2^n 运算）。

2.4 类型转换
--------------

C++ 支持隐式转换、C 风格显式转换和 C++ 风格转换：

```cpp
#include <iostream>

int main() {
    // === 隐式转换（自动提升） ===
    int i = 42;
    double d = i;              // int → double（安全，无精度损失）
    std::cout << "int→double: " << d << std::endl;

    double pi = 3.14159;
    int truncated = pi;        // double → int（截断小数部分，可能丢失信息）
    std::cout << "double→int: " << truncated << std::endl;

    char ch = 'A';
    int ascii = ch;            // char → int（提升）
    std::cout << "char→int: " << ascii << std::endl;

    // 算术运算中的隐式提升
    int a = 5;
    double b = 2.0;
    auto result = a / b;       // int 提升为 double，结果为 2.5
    std::cout << "5 / 2.0 = " << result << std::endl;

    int x = 5, y = 2;
    std::cout << "5 / 2 = " << x / y << std::endl;        // 整数除法 = 2
    std::cout << "5 / 2.0 = " << x / 2.0 << std::endl;    // 浮点除法 = 2.5

    return 0;
}
```

```cpp
#include <iostream>

int main() {
    // === C 风格显式转换 ===
    double pi = 3.14159;
    int n1 = (int)pi;          // C 风格强制转换
    std::cout << "(int)3.14159 = " << n1 << std::endl;

    // === C++ static_cast（推荐） ===
    int n2 = static_cast<int>(pi);
    std::cout << "static_cast<int>(3.14159) = " << n2 << std::endl;

    // static_cast 用于安全的类型转换
    int numerator = 7;
    int denominator = 2;
    double ratio = static_cast<double>(numerator) / denominator;
    std::cout << "7 / 2 = " << ratio << std::endl;

    // char 与 int 之间的转换
    int code = 72;
    char letter = static_cast<char>(code);
    std::cout << "ASCII " << code << " = '" << letter << "'" << std::endl;

    return 0;
}
```

C++ 四种命名转换运算符：
- `static_cast<T>`：编译时检查的安全转换（最常用）
- `dynamic_cast<T>`：运行时多态类型转换
- `const_cast<T>`：移除或添加 const 属性
- `reinterpret_cast<T>`：底层位模式重新解释（最危险）

3.2 案例二：安全的整数运算
---------------------------

```cpp
#include <iostream>
#include <climits>

bool safeAdd(int a, int b, int& result) {
    if (b > 0 && a > INT_MAX - b) return false;
    if (b < 0 && a < INT_MIN - b) return false;
    result = a + b;
    return true;
}

bool safeMultiply(int a, int b, int& result) {
    if (a == 0 || b == 0) {
        result = 0;
        return true;
    }
    if (a > 0 && b > 0 && a > INT_MAX / b) return false;
    if (a < 0 && b < 0 && a < INT_MAX / b) return false;
    if (a > 0 && b < 0 && b < INT_MIN / a) return false;
    if (a < 0 && b > 0 && a < INT_MIN / b) return false;
    result = a * b;
    return true;
}

int main() {
    int a = 2000000000, b = 1000000000;
    int result;

    if (safeAdd(a, b, result)) {
        std::cout << a << " + " << b << " = " << result << std::endl;
    } else {
        std::cout << a << " + " << b << " = 溢出!" << std::endl;
        long long safe_result = static_cast<long long>(a) + b;
        std::cout << "使用 long long: " << safe_result << std::endl;
    }

    int x = 100000, y = 100000;
    if (safeMultiply(x, y, result)) {
        std::cout << x << " * " << y << " = " << result << std::endl;
    } else {
        std::cout << x << " * " << y << " = 溢出!" << std::endl;
        long long safe_result = static_cast<long long>(x) * y;
        std::cout << "使用 long long: " << safe_result << std::endl;
    }

    return 0;
}
```

3.3 案例三：字符统计与转换工具
-------------------------------

```cpp
#include <iostream>
#include <string>

int main() {
    std::string input;
    std::cout << "请输入一段文本: ";
    std::getline(std::cin, input);

    int upperCount = 0, lowerCount = 0;
    int digitCount = 0, spaceCount = 0, otherCount = 0;

    std::string converted = input;

    for (size_t i = 0; i < input.length(); i++) {
        char ch = input[i];

        if (ch >= 'A' && ch <= 'Z') {
            upperCount++;
            converted[i] = ch + 32;
        } else if (ch >= 'a' && ch <= 'z') {
            lowerCount++;
            converted[i] = ch - 32;
        } else if (ch >= '0' && ch <= '9') {
            digitCount++;
        } else if (ch == ' ') {
            spaceCount++;
        } else {
            otherCount++;
        }
    }

    std::cout << "\n--- 统计结果 ---" << std::endl;
    std::cout << "大写字母: " << upperCount << " 个" << std::endl;
    std::cout << "小写字母: " << lowerCount << " 个" << std::endl;
    std::cout << "数字: " << digitCount << " 个" << std::endl;
    std::cout << "空格: " << spaceCount << " 个" << std::endl;
    std::cout << "其他字符: " << otherCount << " 个" << std::endl;

    std::cout << "\n大小写互换: " << converted << std::endl;

    return 0;
}
```
