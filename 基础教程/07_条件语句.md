## 📋 章节概述

条件语句是程序流程控制的核心，它让程序能够根据不同条件执行不同的代码分支。
本章将详细讲解 C++ 中的 if/else/else if 语句、switch/case 语句的用法，包括
嵌套条件的编写技巧、条件表达式的短路求值特性，以及初学者容易踩的常见陷阱
（如 `==` 与 `=` 混淆、悬挂 else 问题等），帮助初学者写出逻辑清晰、正确可靠
的条件判断代码。

1.1 if 语句
-------------

if 语句根据条件表达式的真假决定是否执行某段代码：

```cpp
#include <iostream>

int main() {
    int score;
    std::cout << "请输入成绩: ";
    std::cin >> score;

    // 单分支 if
    if (score >= 60) {
        std::cout << "及格" << std::endl;
    }

    // 双分支 if-else
    if (score >= 60) {
        std::cout << "通过考试" << std::endl;
    } else {
        std::cout << "未通过考试" << std::endl;
    }

    return 0;
}
```

1.2 if / else if / else 多分支
---------------------------------

```cpp
#include <iostream>

int main() {
    int score;
    std::cout << "请输入成绩(0-100): ";
    std::cin >> score;

    if (score >= 90) {
        std::cout << "优秀 (A)" << std::endl;
    } else if (score >= 80) {
        std::cout << "良好 (B)" << std::endl;
    } else if (score >= 70) {
        std::cout << "中等 (C)" << std::endl;
    } else if (score >= 60) {
        std::cout << "及格 (D)" << std::endl;
    } else {
        std::cout << "不及格 (F)" << std::endl;
    }

    return 0;
}
```

注意：else if 链从上到下依次判断，一旦某个条件为 true，执行对应代码块后跳过
后续所有分支。

1.3 switch / case 语句
------------------------

switch 语句用于多个固定值的分支判断：

```cpp
#include <iostream>

int main() {
    int day;
    std::cout << "输入星期几(1-7): ";
    std::cin >> day;

    switch (day) {
        case 1:
            std::cout << "星期一" << std::endl;
            break;
        case 2:
            std::cout << "星期二" << std::endl;
            break;
        case 3:
            std::cout << "星期三" << std::endl;
            break;
        case 4:
            std::cout << "星期四" << std::endl;
            break;
        case 5:
            std::cout << "星期五" << std::endl;
            break;
        case 6:
            std::cout << "星期六" << std::endl;
            break;
        case 7:
            std::cout << "星期日" << std::endl;
            break;
        default:
            std::cout << "无效输入" << std::endl;
            break;
    }

    return 0;
}
```

switch 的关键要素：
- `switch(表达式)`：表达式必须是整数类型或枚举类型
- `case 常量:`：每个 case 后是编译时常量
- `break;`：跳出 switch，不写 break 会"穿透"到下一个 case
- `default:`：没有任何 case 匹配时执行

1.4 case 穿透（fall-through）
-------------------------------

```cpp
#include <iostream>

int main() {
    int month;
    std::cout << "输入月份(1-12): ";
    std::cin >> month;

    int days;
    switch (month) {
        case 1: case 3: case 5: case 7:
        case 8: case 10: case 12:
            days = 31;
            break;
        case 4: case 6: case 9: case 11:
            days = 30;
            break;
        case 2:
            days = 28;
            break;
        default:
            days = -1;
            break;
    }

    if (days > 0) {
        std::cout << month << "月有 " << days << " 天" << std::endl;
    } else {
        std::cout << "无效月份" << std::endl;
    }

    return 0;
}
```

利用 case 穿透可以让多个值共享同一段代码，但如果是无意的穿透则是常见 bug。
C++17 提供 `[[fallthrough]]` 属性显式标记有意的穿透：

```cpp
switch (level) {
    case 3:
        std::cout << "高级权限" << std::endl;
        [[fallthrough]];
    case 2:
        std::cout << "中级权限" << std::endl;
        [[fallthrough]];
    case 1:
        std::cout << "基本权限" << std::endl;
        break;
    default:
        std::cout << "无权限" << std::endl;
        break;
}
```

2.1 嵌套条件
--------------

条件语句可以嵌套使用，但层次过深会降低可读性：

```cpp
#include <iostream>

int main() {
    int age;
    char gender;
    double height;

    std::cout << "输入年龄: ";
    std::cin >> age;
    std::cout << "输入性别(M/F): ";
    std::cin >> gender;
    std::cout << "输入身高(cm): ";
    std::cin >> height;

    // 嵌套条件
    if (age >= 18) {
        if (gender == 'M') {
            if (height >= 170) {
                std::cout << "符合男性入伍标准" << std::endl;
            } else {
                std::cout << "身高不达标" << std::endl;
            }
        } else if (gender == 'F') {
            if (height >= 160) {
                std::cout << "符合女性入伍标准" << std::endl;
            } else {
                std::cout << "身高不达标" << std::endl;
            }
        }
    } else {
        std::cout << "年龄不足18岁" << std::endl;
    }

    return 0;
}
```

用逻辑运算符减少嵌套层次（推荐写法）：

```cpp
#include <iostream>

int main() {
    int age;
    char gender;
    double height;

    std::cout << "输入年龄: ";
    std::cin >> age;
    std::cout << "输入性别(M/F): ";
    std::cin >> gender;
    std::cout << "输入身高(cm): ";
    std::cin >> height;

    if (age < 18) {
        std::cout << "年龄不足18岁" << std::endl;
    } else if (gender == 'M' && height >= 170) {
        std::cout << "符合男性入伍标准" << std::endl;
    } else if (gender == 'F' && height >= 160) {
        std::cout << "符合女性入伍标准" << std::endl;
    } else {
        std::cout << "条件不符" << std::endl;
    }

    return 0;
}
```

2.2 条件表达式短路求值
------------------------

逻辑运算符 `&&` 和 `||` 具有短路求值特性，可以用于条件判断中的安全保护：

```cpp
#include <iostream>
#include <string>

int main() {
    // && 短路：左边为 false 时，右边不会执行
    int divisor = 0;
    if (divisor != 0 && 100 / divisor > 5) {
        std::cout << "条件成立" << std::endl;
    } else {
        std::cout << "安全：避免了除零" << std::endl;
    }

    // || 短路：左边为 true 时，右边不会执行
    std::string name = "admin";
    if (name == "admin" || name == "root") {
        std::cout << "管理员登录" << std::endl;
    }

    // 利用短路进行边界检查
    int arr[] = {10, 20, 30, 40, 50};
    int index = 7;
    if (index >= 0 && index < 5 && arr[index] > 25) {
        std::cout << "arr[" << index << "] > 25" << std::endl;
    } else {
        std::cout << "索引越界或条件不满足" << std::endl;
    }

    // 空指针保护
    int* ptr = nullptr;
    if (ptr != nullptr && *ptr > 0) {
        std::cout << "指针值: " << *ptr << std::endl;
    } else {
        std::cout << "空指针，安全跳过" << std::endl;
    }

    return 0;
}
```

2.3 常见陷阱：== 与 = 的混淆
-------------------------------

```cpp
#include <iostream>

int main() {
    int x = 10;

    // 陷阱：= 是赋值，== 是比较
    if (x = 5) {  // 警告！这是赋值，x变为5，条件永远为true（5非零）
        std::cout << "x 现在是 " << x << std::endl;  // 输出 5
    }

    // 正确写法
    x = 10;
    if (x == 5) {
        std::cout << "x 等于 5" << std::endl;
    } else {
        std::cout << "x 不等于 5" << std::endl;
    }

    // 防御性写法：将常量放在左边（Yoda 条件）
    if (5 == x) {  // 如果误写成 5 = x 会编译错误，容易发现
        std::cout << "x 等于 5" << std::endl;
    }

    return 0;
}
```

2.4 常见陷阱：悬挂 else
--------------------------

```cpp
#include <iostream>

int main() {
    int x = 1, y = 2;

    // 悬挂 else 问题：else 与最近的未匹配 if 配对
    // 以下缩进具有误导性
    if (x > 0)
        if (y > 0)
            std::cout << "x和y都大于0" << std::endl;
    else  // 这个 else 与 if(y>0) 配对，不是 if(x>0)!
        std::cout << "实际是y不大于0的情况" << std::endl;

    std::cout << "---" << std::endl;

    // 明确意图的正确写法（使用大括号）
    if (x > 0) {
        if (y > 0) {
            std::cout << "x和y都大于0" << std::endl;
        }
    } else {
        std::cout << "x不大于0" << std::endl;
    }

    return 0;
}
```

**最佳实践**：始终使用大括号 `{}` 包裹 if/else 的代码块，即使只有一条语句。
这样可以避免悬挂 else 和后续维护时添加代码引入 bug。

2.5 C++17 if 初始化语句
--------------------------

C++17 允许在 if 和 switch 中使用初始化语句：

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> scores = {{"Alice", 95}, {"Bob", 87}};

    // C++17: if 带初始化
    if (auto it = scores.find("Alice"); it != scores.end()) {
        std::cout << it->first << ": " << it->second << std::endl;
    } else {
        std::cout << "未找到" << std::endl;
    }
    // it 的作用域仅限于 if-else 块内

    // C++17: switch 带初始化
    switch (int val = 42 % 3; val) {
        case 0:
            std::cout << "能被3整除" << std::endl;
            break;
        case 1:
            std::cout << "余数为1" << std::endl;
            break;
        case 2:
            std::cout << "余数为2" << std::endl;
            break;
    }

    return 0;
}
```

3.1 案例一：简易菜单系统
--------------------------

```cpp
#include <iostream>

int main() {
    int choice;

    while (true) {
        std::cout << "\n====== 主菜单 ======" << std::endl;
        std::cout << "1. 查看余额" << std::endl;
        std::cout << "2. 存款" << std::endl;
        std::cout << "3. 取款" << std::endl;
        std::cout << "4. 退出" << std::endl;
        std::cout << "请选择: ";
        std::cin >> choice;

        double balance = 1000.0;
        double amount;

        switch (choice) {
            case 1:
                std::cout << "当前余额: " << balance << " 元" << std::endl;
                break;
            case 2:
                std::cout << "输入存款金额: ";
                std::cin >> amount;
                if (amount > 0) {
                    balance += amount;
                    std::cout << "存款成功，余额: " << balance << " 元" << std::endl;
                } else {
                    std::cout << "金额无效" << std::endl;
                }
                break;
            case 3:
                std::cout << "输入取款金额: ";
                std::cin >> amount;
                if (amount > 0 && amount <= balance) {
                    balance -= amount;
                    std::cout << "取款成功，余额: " << balance << " 元" << std::endl;
                } else if (amount > balance) {
                    std::cout << "余额不足" << std::endl;
                } else {
                    std::cout << "金额无效" << std::endl;
                }
                break;
            case 4:
                std::cout << "感谢使用，再见！" << std::endl;
                return 0;
            default:
                std::cout << "无效选择，请重新输入" << std::endl;
                break;
        }
    }

    return 0;
}
```

3.3 案例三：日期有效性验证
-----------------------------

```cpp
#include <iostream>

bool isLeapYear(int year) {
    return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
}

int getDaysInMonth(int year, int month) {
    switch (month) {
        case 1: case 3: case 5: case 7:
        case 8: case 10: case 12:
            return 31;
        case 4: case 6: case 9: case 11:
            return 30;
        case 2:
            return isLeapYear(year) ? 29 : 28;
        default:
            return -1;
    }
}

int main() {
    int year, month, day;
    std::cout << "输入日期 (年 月 日): ";
    std::cin >> year >> month >> day;

    bool valid = true;
    std::string error;

    if (year < 1 || year > 9999) {
        valid = false;
        error = "年份必须在 1-9999 之间";
    } else if (month < 1 || month > 12) {
        valid = false;
        error = "月份必须在 1-12 之间";
    } else {
        int maxDays = getDaysInMonth(year, month);
        if (day < 1 || day > maxDays) {
            valid = false;
            error = "日期超出范围，该月最多 " + std::to_string(maxDays) + " 天";
        }
    }

    if (valid) {
        std::cout << year << "年" << month << "月" << day << "日 是有效日期" << std::endl;

        if (isLeapYear(year)) {
            std::cout << year << " 年是闰年" << std::endl;
        } else {
            std::cout << year << " 年是平年" << std::endl;
        }

        std::string weekdays[] = {"日", "一", "二", "三", "四", "五", "六"};
        int y = year, m = month;
        if (m < 3) { m += 12; y--; }
        int w = (day + 13 * (m + 1) / 5 + y + y / 4 - y / 100 + y / 400) % 7;
        std::cout << "星期" << weekdays[(w + 6) % 7] << std::endl;
    } else {
        std::cout << "无效日期: " << error << std::endl;
    }

    return 0;
}
```
