## ==========================================================================
C++ 算法技巧 — 前缀和 (Prefix Sum)
## ==========================================================================

前缀和是一种预处理技术，通过 O(n) 预处理后实现 O(1) 区间求和，是优化暴力累加的核心手段。

**前置知识**: [[数组]]、[[循环]]

## --------------------------------------------------------------------------
### 一维前缀和
## --------------------------------------------------------------------------

给定数组 a[1..n]，定义前缀和数组 pre[i] = a[1] + a[2] + ... + a[i]。

**递推公式**: `pre[i] = pre[i-1] + a[i]`，其中 `pre[0] = 0`。

**区间求和**: `sum[l..r] = pre[r] - pre[l-1]`

```cpp
#include <iostream>
using namespace std;
const int N = 100005;
int a[N], pre[N];

int main() {
    int n, q;
    cin >> n >> q;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        pre[i] = pre[i - 1] + a[i];
    }
    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << pre[r] - pre[l - 1] << endl;
    }
    return 0;
}
```

## --------------------------------------------------------------------------
### 二维前缀和
## --------------------------------------------------------------------------

给定矩阵 a[1..n][1..m]，定义 pre[i][j] = 以 (1,1) 为左上角、(i,j) 为右下角的子矩阵元素和。

**递推公式**: `pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i][j]`

**子矩阵求和**: 矩形 (x1,y1) 到 (x2,y2) 的和为:
`sum = pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1]`

```cpp
#include <iostream>
using namespace std;
const int N = 1005;
int a[N][N], pre[N][N];

int main() {
    int n, m, q;
    cin >> n >> m >> q;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            cin >> a[i][j];
            pre[i][j] = pre[i-1][j] + pre[i][j-1]
                      - pre[i-1][j-1] + a[i][j];
        }
    while (q--) {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        int ans = pre[x2][y2] - pre[x1-1][y2]
                - pre[x2][y1-1] + pre[x1-1][y1-1];
        cout << ans << endl;
    }
    return 0;
}
```

## --------------------------------------------------------------------------
### P5638 光骓者的荣耀
## --------------------------------------------------------------------------

题目: 一条长度为 n 的道路，第 i 段需要时间 a[i]。传送器可以跳过恰好 k 段连续道路。
求从起点到终点的最短时间。

思路: 前缀和维护道路总时间。枚举传送器的起始位置，被跳过的 k 段时间和 = pre[i+k-1] - pre[i-1]，
答案 = 总时间 - 最大可跳过时间。

```cpp
#include <iostream>
using namespace std;
const int N = 1000005;
long long a[N], pre[N];

int main() {
    int n, k;
    cin >> n >> k;
    for (int i = 1; i < n; i++) {
        cin >> a[i];
        pre[i] = pre[i - 1] + a[i];
    }
    long long maxSkip = 0;
    for (int i = 1; i + k - 1 < n; i++) {
        long long skip = pre[i + k - 1] - pre[i - 1];
        if (skip > maxSkip) maxSkip = skip;
    }
    cout << pre[n - 1] - maxSkip << endl;
    return 0;
}
```

## --------------------------------------------------------------------------
### P3131 [USACO16JAN] Subsequences Summing to Sevens
## --------------------------------------------------------------------------

题目: N头牛排成一行，每头牛有一个编号ID。求一个连续区间，使得编号之和能被7整除，且区间最长。

思路: pre[i] 表示前 i 头牛编号之和。若 pre[r] ≡ pre[l-1] (mod 7)，则区间 [l,r] 的和能被 7 整除。
记录每个 mod 值最早出现的位置。

```cpp
#include <iostream>
using namespace std;
const int N = 50005;
int first[7];

int main() {
    int n, sum = 0, ans = 0;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        sum = (sum + x) % 7;
        if (first[sum] == 0 && sum != 0)
            first[sum] = i;
        else if (i - first[sum] > ans)
            ans = i - first[sum];
    }
    cout << ans << endl;
    return 0;
}
```

> **题目**: 给n个整数，求和能被k整除的最长连续子数组长度。
> 
> **提示**: 利用前缀和mod k相同的性质
> 
> > [!success]- 点击查看参考答案
> > ```cpp
> > #include <iostream>
#include <cstring>
using namespace std;
int first[100005];
int main(){
    int n,k,ans=0,sum=0;cin>>n>>k;
    memset(first,-1,sizeof(first));
    first[0]=0;
    for(int i=1;i<=n;i++){
        int x;cin>>x;
        sum=((sum+x)%k+k)%k;
        if(first[sum]!=-1) ans=max(ans,i-first[sum]);
        else first[sum]=i;
    }
    cout<<ans;return 0;
}
