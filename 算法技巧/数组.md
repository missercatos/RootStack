### P1046 [NOIP2005 普及组] 陶陶摘苹果
## --------------------------------------------------------------------------

题目: 陶陶有一个最多能摘到高度+30cm（板凳）的范围。输入10个苹果的高度以及陶陶
手伸直能探到的最大高度，输出能摘到的苹果数量。

思路: 用数组存储苹果高度，逐个判断是否在可摘范围内。

```cpp
#include <iostream>
using namespace std;
int main() {
    int a[10], h, cnt = 0;
    for (int i = 0; i < 10; i++) cin >> a[i];
    cin >> h;
    h += 30;
    for (int i = 0; i < 10; i++)
        if (a[i] <= h) cnt++;
    cout << cnt << endl;
    return 0;
}
```

## --------------------------------------------------------------------------
### P1047 [NOIP2005 普及组] 校门外的树
## --------------------------------------------------------------------------

题目: 长度为L的马路上有L+1棵树，要挖掉M个区间内的树，问最后还剩多少棵树？

思路: 用布尔数组标记每棵树是否存在，然后统计。

```cpp
#include <iostream>
using namespace std;
int main() {
    int L, M;
    cin >> L >> M;
    bool tree[10001] = {true}; // 实际需全部初始化为true
    fill(tree, tree + L + 1, true);
    for (int i = 0; i < M; i++) {
        int u, v;
        cin >> u >> v;
        for (int j = u; j <= v; j++)
            tree[j] = false;
    }
    int cnt = 0;
    for (int i = 0; i <= L; i++)
        if (tree[i]) cnt++;
    cout << cnt << endl;
    return 0;
}
```

## --------------------------------------------------------------------------
### P1428 小鱼比可爱
## --------------------------------------------------------------------------

题目: N条鱼从左到右排成一列，每条鱼想知道自己左边有多少条不及自己可爱的鱼（眼值的严格大于）。
输出每条鱼左边比它小的鱼的个数。

思路: 双重循环，对每条鱼扫描其左侧所有鱼。

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, a[100];
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];
    for (int i = 0; i < n; i++) {
        int cnt = 0;
        for (int j = 0; j < i; j++)
            if (a[j] < a[i]) cnt++;
        cout << cnt << " ";
    }
    return 0;
}
```

### P2141 [NOIP2014 普及组] 珠心算测验
## --------------------------------------------------------------------------

题目: 给定n个不同的正整数，问其中有多少个数恰好等于集合中另外两个不同的数之和。

思路: 用数组标记哪些数出现过，然后两两枚举检查和是否在标记数组中。

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, a[101], exist[20001] = {0}, ans = 0;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        exist[a[i]] = 1;
    }
    for (int i = 0; i < n - 1; i++)
        for (int j = i + 1; j < n; j++) {
            int sum = a[i] + a[j];
            if (sum <= 20000 && exist[sum] > 0) {
                ans++;
                exist[sum] = -1;  // 标记为已统计，避免重复
            }
        }
    cout << ans << endl;
    return 0;
}
```
