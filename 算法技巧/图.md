## --------------------------------------------------------------------------
### P3371 [模板] 单源最短路径（弱化版）
## --------------------------------------------------------------------------

题目: 给定有向图，求从源点s到每个顶点的最短路径。可能存在重边和自环。

思路: 使用Dijkstra算法（无负权）或SPFA。

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

typedef pair<int, int> pii;
const int INF = 0x3f3f3f3f;
int n, m, s, dist[10005];
vector<pii> g[10005];

int main() {
    cin >> n >> m >> s;
    for (int i = 1; i <= n; i++) dist[i] = INF;
    for (int i = 0, u, v, w; i < m; i++) {
        cin >> u >> v >> w;
        g[u].push_back({v, w});
    }
    priority_queue<pii, vector<pii>, greater<pii>> pq;
    dist[s] = 0;
    pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d != dist[u]) continue;
        for (auto [v, w] : g[u]) {
            if (dist[v] > dist[u] + w) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    for (int i = 1; i <= n; i++)
        cout << (dist[i] == INF ? 0x7fffffff : dist[i]) << " ";
    return 0;
}
```

## --------------------------------------------------------------------------
### P4779 [模板] 单源最短路径（标准版）
## --------------------------------------------------------------------------

题目: 同P3371，但n,m≤10^5，必须使用堆优化的Dijkstra。

思路: 使用邻接表+优先队列(pair<距离,顶点>)的Dijkstra，复杂度O(m log n)。

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

typedef pair<int,int> pii;
const int INF = 1e9;
int n, m, s, dist[100005];
vector<pii> g[100005];
bool vis[100005];

int main() {
    cin >> n >> m >> s;
    for (int i = 1; i <= n; i++) dist[i] = INF;
    for (int i = 0, u, v, w; i < m; i++) {
        cin >> u >> v >> w;
        g[u].push_back({v, w});
    }
    priority_queue<pii, vector<pii>, greater<pii>> pq;
    dist[s] = 0;
    pq.push({0, s});
    while (!pq.empty()) {
        int u = pq.top().second; pq.pop();
        if (vis[u]) continue;
        vis[u] = true;
        for (auto [v, w] : g[u]) {
            if (dist[v] > dist[u] + w) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    for (int i = 1; i <= n; i++)
        cout << dist[i] << " ";
    return 0;
}
```

## --------------------------------------------------------------------------
### P3366 [模板] 最小生成树
## --------------------------------------------------------------------------

题目: 给定无向图，求最小生成树的边权和；若不连通则输出"orz"。

思路: Kruskal算法：边按权值排序，使用并查集判断连通性，不构成环则加入生成树。

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

struct Edge { int u, v, w; } e[200005];
int fa[5005];

int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }
bool cmp(Edge a, Edge b) { return a.w < b.w; }

int main() {
    int n, m, ans = 0, cnt = 0;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) fa[i] = i;
    for (int i = 0; i < m; i++)
        cin >> e[i].u >> e[i].v >> e[i].w;
    sort(e, e + m, cmp);
    for (int i = 0; i < m; i++) {
        int fu = find(e[i].u), fv = find(e[i].v);
        if (fu != fv) {
            fa[fu] = fv;
            ans += e[i].w;
            cnt++;
            if (cnt == n - 1) break;
        }
    }
    if (cnt == n - 1) cout << ans << endl;
    else cout << "orz" << endl;
    return 0;
}
```

#### 判断题

> [!question] 判断题 1
> Dijkstra算法不能处理负权边。 （ ）
> - [ ] ✅ 正确
> - [ ] ❌ 错误
>
> > [!success]- 点击查看答案
> > 答案: 正确
> > 
> > **解析**: Dijkstra基于贪心（已确定的最短路不会更新），负权边会破坏这个性质。

> [!question] 判断题 2
> 堆优化Dijkstra的时间复杂度是O(m log n)。 （ ）
> - [ ] ✅ 正确
> - [ ] ❌ 错误
>
> > [!success]- 点击查看答案
> > 答案: 正确
> > 
> > **解析**: 使用优先队列（堆）优化后，每条边松弛一次O(log n)，总O(m log n)。

> [!question] 判断题 3
> Kruskal算法使用并查集判断是否构成环。 （ ）
> - [ ] ✅ 正确
> - [ ] ❌ 错误
>
> > [!success]- 点击查看答案
> > 答案: 正确
> > 
> > **解析**: 加入边前检查两端点是否已连通（同一集合），是则跳过避免环。

> [!question] 判断题 4
> 最小生成树包含n-1条边（n个顶点）。 （ ）
> - [ ] ✅ 正确
> - [ ] ❌ 错误
>
> > [!success]- 点击查看答案
> > 答案: 正确
> > 
> > **解析**: n个顶点的树恰好有n-1条边，这是树的基本性质。

> [!question] 判断题 5
> 邻接矩阵适合稠密图，邻接表适合稀疏图。 （ ）

> - [ ] ❌ 错误
>
> > [!success]- 点击查看答案
> > 答案: 正确
> > 
> > **解析**: 邻接矩阵空间O(n²)适合稠密图，邻接表空间O(n+m)适合稀疏图。

> [!question] 判断题 7
> 有向图的最短路径和无向图的处理方式完全相同。 （ ）

> [!question] 判断题 8

> [!question] 判断题 9

> > 答案: 正确
> > 
> > **解析**: 堆优化中，第一次出队的dist值就是最终最短距离（贪心性质保证）。

> [!question] 判断题 10

> > 答案: 正确
