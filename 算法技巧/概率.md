## --------------------------------------------------------------------------
### P1297 [国家集训队] 单选错位
## --------------------------------------------------------------------------

题目: 有n道单选题，每道题有a_i个选项。由于答题卡串行，第i题的答案填在了第i+1题的位置
（最后一题的答案填在了第1题位置）。求做对题目的期望数量。

思路: 每道题做对的概率 = 当前题与上一题选项相等时同时选对的概率。相邻两题做对概率
= min(a_i, a_{i-1}) / (a_i × a_{i-1})。线性期望相加。

```cpp
#include <cstdio>
#include <algorithm>
using namespace std;
int a[10000005];

int main() {
    int n, A, B, C;
    scanf("%d%d%d%d%d", &n, &A, &B, &C, a + 1);
    for (int i = 2; i <= n; i++)
        a[i] = ((long long)a[i - 1] * A + B) % 100000001;
    for (int i = 1; i <= n; i++)
        a[i] = a[i] % C + 1;
    double ans = 0;
    for (int i = 1; i < n; i++)
        ans += min(a[i], a[i + 1]) / (double)(a[i] * a[i + 1]);
    ans += min(a[n], a[1]) / (double)(a[n] * a[1]);
    printf("%.3f\n", ans);
    return 0;
}
```

## --------------------------------------------------------------------------
### P1654 OSU!
## --------------------------------------------------------------------------

题目: 有n次操作，第i次成功的概率为p_i，成功得1分。连续x次成功可获得x^3的分数，
分数从0开始每遇到失败就重置。求最终总分的期望值。

思路: 利用三次方展开 (x+1)^3 = x^3 + 3x^2 + 3x + 1，维护x的一次期望和二次期望。

```cpp
#include <cstdio>
using namespace std;

int main() {
    int n;
    scanf("%d", &n);
    double ans = 0, e1 = 0, e2 = 0;
    for (int i = 0; i < n; i++) {
        double p;
        scanf("%lf", &p);
        ans += p * (3 * e2 + 3 * e1 + 1);
        e2 = p * (e2 + 2 * e1 + 1);
        e1 = p * (e1 + 1);
    }
    printf("%.1f\n", ans);
    return 0;
}
```

## --------------------------------------------------------------------------
### P2719 搞笑世界杯
## --------------------------------------------------------------------------

题目: 有2n张票，其中n张售给A队粉丝，n张售给B队粉丝。所有座位排成一行，
座位按顺序出售。当场上只剩一种球迷在排队时就称"搞笑"，求最后出现"搞笑"局面时
已经售出的座位数的期望值。

思路: 动态规划，dp[i][j]表示还剩i张A票和j张B票时继续卖出到结束的期望售出票数。
当i=0或j=0时局面出现，不再继续卖。转移方程：dp[i][j] = (i/(i+j))(1+dp[i-1][j]) + (j/(i+j))(1+dp[i][j-1])。
从dp[n][n]逆推即可。

```cpp
#include <cstdio>
using namespace std;
double dp[1255][1255];

int main() {
    int n;
    scanf("%d", &n);
    n /= 2;
    for (int i = 1; i <= n; i++) dp[i][0] = dp[0][i] = 0;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            dp[i][j] = i / (double)(i + j) * (dp[i - 1][j] + 1)
                     + j / (double)(i + j) * (dp[i][j - 1] + 1);
    printf("%.4f\n", dp[n][n]);
    return 0;
}
```

(注: 此题也可用组合数学推导出公式解: E = (C(2n,n) - 1) * n / C(2n-1,n-1))
```

> [!question] 动手练习 2
> **题目**: n次独立伯努利试验，每次成功概率p，求连续成功次数期望的最大值的近似模拟。
> 
> **提示**: 蒙特卡洛模拟，重复多次取平均
> 
> > [!success]- 点击查看参考答案
> > ```cpp
> > #include <cstdio>
#include <cstdlib>
#include <ctime>
#include <algorithm>
using namespace std;
int main(){
    srand(time(0));
    int n,T=100000;
    double p;
    scanf("%d%lf",&n,&p);
    double total=0;
    for(int t=0;t<T;t++){
        int mx=0,cur=0;
        for(int i=0;i<n;i++){
            if((double)rand()/RAND_MAX<p) cur++;
            else cur=0;
            mx=max(mx,cur);
        }
        total+=mx;
    }
    printf("%.2f\n",total/T);
    return 0;
}
> > ```

> [!question] 动手练习 3
> **题目**: 实现搞笑世界杯的概率DP。
> 
> **输入**: 2n（总票数），输出期望售出票数（保留4位小数）
> 
> > [!success]- 点击查看参考答案

    for(int i=1;i<=n;i++)
