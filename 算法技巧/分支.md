分支结构通过判断条件决定程序的执行路径，是控制流程最基础的逻辑。

## --------------------------------------------------------------------------
### P5712 输出苹果 (Apples)
## --------------------------------------------------------------------------

题目: 输入一个整数n，表示苹果数量。若只有1个苹果则输出"Today, I ate 1 apple."，
否则输出"Today, I ate n apples."（英文中单复数不同）。

思路: 判断n是否等于1，分别输出不同的字符串。

```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    if (n == 1)
        cout << "Today, I ate 1 apple." << endl;
    else
        cout << "Today, I ate " << n << " apples." << endl;
    return 0;
}
```

### P5711 数的性质
## --------------------------------------------------------------------------

题目: 给定一个整数N，判断是奇数还是偶数，以及能被3整除或能被5整除但不能同时被3和5整除。

思路: 用if-else嵌套，注意区分"能被3或5整除，但不能同时被3和5整除"需要使用异或逻辑。

```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cin >> n;
    if (n % 2 == 0) cout << "偶数 "; else cout << "奇数 ";

    bool d3 = (n % 3 == 0), d5 = (n % 5 == 0);
    if (d3 && d5) cout << "能同时被3和5整除";
    else if (d3 || d5) cout << "能被3或5整除，但不能同时被3和5整除";
    else cout << "既不能被3整除也不能被5整除";
    return 0;
}
```

## --------------------------------------------------------------------------
### P4414 [COCI2006-2007#2] ABC
## --------------------------------------------------------------------------

题目: 给出三个整数A、B、C，以及"A"、"B"、"C"的排列顺序ABC，按该排列输出三个整数。

思路: 将三个数排好序，然后根据要求的顺序映射输出。

```cpp
#include <iostream>
#include <algorithm>
using namespace std;
int main() {
    int a[3]; string s;
    cin >> a[0] >> a[1] >> a[2] >> s;
    sort(a, a + 3);
    cout << a[s[0] - 'A'] << " " << a[s[1] - 'A'] << " " << a[s[2] - 'A'];
    return 0;
}
```

### P1422 小玉家的电费
## --------------------------------------------------------------------------

题目: 阶梯电价：150度以下每度0.4463元，151~400度每度0.4663元，401度以上每度0.5663元。
输入用电量，输出电费（保留一位小数）。

思路: 分支判断电费所属区间，分段计算。

```cpp
#include <cstdio>
int main() {
    int x; scanf("%d", &x);
    double ans = 0;
    if (x <= 150) ans = x * 0.4463;
    else if (x <= 400) ans = 150 * 0.4463 + (x - 150) * 0.4663;
    else ans = 150 * 0.4463 + 250 * 0.4663 + (x - 400) * 0.5663;
    printf("%.1f\n", ans);
    return 0;
}
```
