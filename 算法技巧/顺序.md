## ==========================================================================
C++ 算法技巧 — 顺序结构 (Sequence)
## ==========================================================================

顺序结构是最基本的程序结构，按语句先后顺序依次执行。

**前置知识**: 无（最基础）

## --------------------------------------------------------------------------
### P1001 A+B Problem
## --------------------------------------------------------------------------

题目: 输入两个整数a和b，输出它们的和。

思路: 最基本的输入→计算→输出流程。

```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
    return 0;
}
```

## --------------------------------------------------------------------------
### P1421 小玉买文具
## --------------------------------------------------------------------------

题目: 班主任给小玉a元b角，每支铅笔c角，问最多能买多少支？（1元=10角）

思路: 统一单位后做整数除法。

```cpp
#include <iostream>
using namespace std;
int main() {
    int a, b;
    cin >> a >> b;
    int total = a * 10 + b;
    cout << total / 19 << endl;
    return 0;
}
```

## --------------------------------------------------------------------------
### P5707 上学迟到
## --------------------------------------------------------------------------

题目: yy需要s分钟到达学校，8:00必须到达，问她最晚何时出发？学校要求不迟于8:00，
需要提前24小时内的时间（不含8:00当天）。注意输出格式HH:MM。

思路: 计算出发时间相对于前一天的剩余分钟数，注意0点之间的借位。

```cpp
#include <cstdio>
int main() {
    int s, v;
    scanf("%d%d", &s, &v);
    int t = (s + v - 1) / v + 10;  // 通勤+垃圾分类
    int total = 8 * 60 - t;
    if (total < 0) total += 24 * 60;
    printf("%02d:%02d\n", total / 60, total % 60);
    return 0;
}
```

## --------------------------------------------------------------------------
### P2181 对角线
## --------------------------------------------------------------------------

题目: 对于一个n个顶点的凸多边形，它的任何三条对角线都不会交于一点。请求出图形中对角线交点的个数。

思路: 四顶点确定一个交点，组合数C(n,4)。

```cpp
#include <iostream>
using namespace std;
int main() {
    unsigned long long n;
    cin >> n;
    cout << n * (n - 1) / 2 * (n - 2) / 3 * (n - 3) / 4 << endl;
    return 0;
}
```

> `n*(n-1)/2*(n-2)/3*(n-3)/4` 中除法的顺序有什么讲究？

> - [ ] B. 保证每步除法都能整除
> - [ ] C. 为了防止溢出
