C++ 算法技巧 — 循环 (Loop)

循环结构用于重复执行一段代码，是处理批量数据、迭代计算的核心机制。

## --------------------------------------------------------------------------
### P1423 小玉在游泳
## --------------------------------------------------------------------------

题目: 小玉每一步游的距离是上一步的98%。第一步游2米，问需要多少步才能游超过s米？

思路: while循环累计距离，每一步距离乘以0.98，直到总距离超过目标值。

```cpp
#include <iostream>
using namespace std;
int main() {
    double s;
    cin >> s;
    double step = 2.0, total = 0;
    int cnt = 0;
    while (total < s) {
        total += step;
        step *= 0.98;
        cnt++;
    }
    cout << cnt << endl;
    return 0;
}
```

## --------------------------------------------------------------------------
### P1035 [NOIP2002 普及组] 级数求和
## --------------------------------------------------------------------------

题目: 求最小的n使得和谐级数 S_n = 1+1/2+1/3+...+1/n > k。

思路: while循环不断累加倒数，直到超过k。

```cpp
#include <iostream>
using namespace std;
int main() {
    int k, n = 0;
    double s = 0;
    cin >> k;
    while (s <= k) {
        n++;
        s += 1.0 / n;
    }
    cout << n << endl;
    return 0;
}
```

## --------------------------------------------------------------------------
### P1307 [NOIP2011 普及组] 数字反转
## --------------------------------------------------------------------------

题目: 给定一个整数N，反转它的各位数字。如123变成321，-380变成-83。

思路: while循环取个位、去掉个位、拼接到结果。注意负号处理。

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, rev = 0;
    cin >> n;
    int sign = (n < 0) ? -1 : 1;
    n = abs(n);
    while (n) {
        rev = rev * 10 + n % 10;
        n /= 10;
    }
    cout << rev * sign << endl;
    return 0;
}
```

## --------------------------------------------------------------------------
### P1980 [NOIP2013 普及组] 计数问题
## --------------------------------------------------------------------------

题目: 试计算在区间1到n的所有整数中，数字x出现了多少次。例如1~11中1出现了4次。

思路: 双重循环，外层遍历1到n，内层逐一取位判断。

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, x, cnt = 0;
    cin >> n >> x;
    for (int i = 1; i <= n; i++) {
        int t = i;
        while (t) {
            if (t % 10 == x) cnt++;
            t /= 10;
        }
    }
    cout << cnt << endl;
    return 0;
}
```
