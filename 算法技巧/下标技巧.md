## ==========================================================================
C++ 算法技巧 — 下标技巧 (Indexing Techniques)
## ==========================================================================

下标技巧是算法竞赛中最基础也最灵活的技巧之一，涉及数组下标的映射、转换、偏移和压缩，
直接影响程序的正确性和效率。

**前置知识**: [[数组]]、[[循环]]、[[排序]]

## --------------------------------------------------------------------------
### 下标偏移（从 0 开始 vs 从 1 开始）
## --------------------------------------------------------------------------

在动态规划和前缀和问题中，常用 1-based 下标避免边界判断。

```cpp
// 0-based: 需要检查边界
int dp[1005][1005];
dp[i][j] = dp[i-1][j] + dp[i][j-1];  // i=0或j=0时会越界！

// 1-based: 自然避免了 i-1=0 的越界问题
int dp[1005][1005] = {0};
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        dp[i][j] = dp[i-1][j] + dp[i][j-1] + a[i][j];
```

**经验法则**:
- 前缀和、差分、DP: 优先用 **1-based**
- 原始输入、STL: 通常用 **0-based**
- 混合使用时注意转换: `a_1based[i] = input[i-1]`

## --------------------------------------------------------------------------
### 下标映射（离散化 / 坐标压缩）
## --------------------------------------------------------------------------

当数据范围很大但实际使用的值很少时，将原值映射到紧凑范围。

```cpp
// 离散化：将大范围值压缩到 [1, m]
#include <iostream>
#include <algorithm>
using namespace std;
int a[100005], tmp[100005];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        tmp[i] = a[i];
    }
    sort(tmp, tmp + n);
    int m = unique(tmp, tmp + n) - tmp;  // 去重后的数量
    // a[i] 被映射为 lower_bound(tmp, tmp+m, a[i]) - tmp + 1
    for (int i = 0; i < n; i++)
        a[i] = lower_bound(tmp, tmp + m, a[i]) - tmp + 1;
    return 0;
}
```

## --------------------------------------------------------------------------
### 负数下标处理
## --------------------------------------------------------------------------

当数组下标可能为负（如坐标轴、信息学问题），需要加上偏移量。

```cpp
// 处理 -1000 到 1000 的范围
const int OFFSET = 1005;
int cnt[2010];  // 大小 = 范围 + OFFSET

int& at(int idx) {
    return cnt[idx + OFFSET];
}

// 使用
at(-500) = 10;
cout << at(300) << endl;
```

## --------------------------------------------------------------------------
### P1047 [NOIP2005 普及组] 校门外的树
## --------------------------------------------------------------------------

题目: 长度为 L 的马路上有树，挖掉 M 个区间的树，求剩余数量。

思路: 用布尔数组标记每棵树是否存在。1-based 下标方便与区间端点对应。
详见 [[数组]] 同题。

```cpp
#include <iostream>
using namespace std;
bool tree[10005];

int main() {
    int L, M;
    cin >> L >> M;
    for (int i = 0; i <= L; i++) tree[i] = true;
    while (M--) {
        int u, v;
        cin >> u >> v;
        for (int i = u; i <= v; i++)
            tree[i] = false;
    }
    int cnt = 0;
    for (int i = 0; i <= L; i++)
        if (tree[i]) cnt++;
    cout << cnt << endl;
    return 0;
}
```

### P1957 口算练习题
## --------------------------------------------------------------------------

题目: 给出一系列算式，判断是加法还是减法运算，输出竖式格式（对齐数字位数）。

思路: 利用下标定位数字位数，用字符数组模拟竖式对齐输出。

```cpp
#include <iostream>
#include <string>
#include <cstring>
using namespace std;

int main() {
    int n;
    cin >> n;
    while (n--) {
        string s, a, b;
        char op;
        cin >> s;
        if (s[0] >= 'a' && s[0] <= 'z') {
            op = s[0];
            cin >> a >> b;
        } else {
            a = s;
            cin >> b;
        }
        int len = max(a.size(), b.size()) + 1;
        cout << a << endl;
        cout << b << endl;
        for (int i = 0; i < len; i++) cout << '-';
        cout << endl;
    }
    return 0;
}
```
