## CSS基础：红队学习路线

CSS (Cascading Style Sheets) 负责网页的**样式和布局**。红队视角下，CSS不仅是美化工具，更是：

1. **XSS辅助**：配合HTML实现CSS注入 → CSS键记录 → 数据外泄
2. **信息窃取**：利用CSS选择器探测页面内容、用户状态
3. **侧信道**：通过CSS读取用户浏览器历史、窃取CSRF Token

### 学习重点

1. **选择器系统**：理解`.class` `#id` `[attr]`如何匹配元素——这是CSS注入攻击的基础
2. **@规则**：`@import`跨域加载——CSS数据泄露的核心
3. **伪类**：`:visited`历史探测、`:focus`状态感知
4. **CSS变量**：CSS自定义属性的泄露面

### 学习顺序

01 → 04 递进学习。先理解选择器语法，再学注入攻击，最后掌握数据泄露和侧信道技术。
