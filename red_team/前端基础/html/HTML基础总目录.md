## HTML基础：红队学习路线

HTML 是 Web 前端的三驾马车之一（HTML/CSS/JS），负责定义网页的**结构和语义**。

对于红队，HTML 不仅是基础，更是 XSS、CSRF、Clickjacking、HTML 注入等攻击的直接载体。

### 学习重点

1. **DOM树结构**：攻击触达页面元素的根本
2. **表单机制**：理解 CSRF 的数据提交本质
3. **iframe 行为**：Clickjacking 和沙箱逃逸的基础
4. **HTML解析特性**：绕过过滤器的关键（HTML解析器 vs XSS过滤器）

按编号 01 → 04 顺序学习。每一节都标注了红队实战中的具体应用场景。
