### CTF 中操作系统相关考点

| 考点 | 说明 | 常用命令 |
|------|------|---------|
| 文件操作 | 查看/搜索文件中的 flag | `ls`、`find`、`grep`、`cat` |
| 权限 | 目录/文件读写权限限制 | `chmod`、`sudo`、`su` |
| 进程管理 | 后门进程、可疑进程排查 | `ps`、`top`、`kill` |
| 网络连接 | 端口监听、连接查看 | `netstat`、`ss`、`lsof` |
| 日志分析 | 从服务器日志找 flag | `tail`、`grep`、`awk` |
| Python 沙箱 | Python 沙箱逃逸 | 导入模块绕过、`os.system()` |
| Bash 相关 | Bash 脚本、环境变量、PATH 利用 | `echo`、`export`、`env` |

### 终端常用命令速查

| 命令 | 用途 | CTF 典型用法 |
|------|------|-------------|
| `grep -r "flag" .` | 递归搜索当前目录所有文件 | 找 flag 的第一步 |
| `find / -name "*.txt"` | 全盘搜索 txt 文件 | 手动探测 flag 路径 |
| `strings 文件` | 提取二进制文件中的可读字符串 | Misc 隐写/逆向找 flag |
| `nc IP PORT` | 连接 TCP 端口 | Pwn 题、反弹 shell |
| `curl -s URL` | 发 HTTP 请求 | Web 题最常用 |
| `python3 -c "..."` | 执行一段 Python | 快速计算、编码转换 |
| `echo "xxx" \| base64 -d` | base64 解码 | Cookie/参数解码 |

### 核心心法

操作系统知识不是背命令表，而是在**做题中顺手记住**：
- 碰到文件 → 试试 `grep`、`find`、`strings`
- 碰到网络 → 试试 `curl`、`nc`
- 碰到编码 → 试试 `base64`、`python`
