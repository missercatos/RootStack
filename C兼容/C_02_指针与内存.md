# C 语言 —— 指针与内存管理
## ============================================================

指针是 C 语言的核心，也是 C++ 底层机制的基础。理解 C 指针模型，就能理解 C++ 的 this 指针、动态内存、虚表机制。

## 指针基础

指针是**存储地址的变量**。

```c
int   x  = 42;        // 普通变量
int*  p  = &x;        // p 存储 x 的地址
printf("%d\n", *p);   // *p 解引用 → 42（读取 x）
*p = 100;             // 通过指针修改 x
printf("%d\n", x);    // 100

printf("%p\n", (void*)&x);  // 打印地址
```

**声明解读**（从右向左读）：

```c
int*   p;    // p 是指针 → 指向 int
int**  pp;   // pp 是指针 → 指向 "指针" → 指向 int
void*  vp;   // 通用指针，可指向任意类型
```

## 指针与数组

数组名是首元素地址（常量，不可改）。指针算术：`ptr + n` 偏移 `n * sizeof(元素类型)` 字节。

```c
int arr[5] = {10, 20, 30, 40, 50};

int* p = arr;             // p 指向 arr[0]
printf("%d\n", *p);       // 10
printf("%d\n", *(p+2));   // 30  (p+2 偏移 2*4=8 字节)
printf("%d\n", p[2]);     // 30  (语法糖：等价于 *(p+2))

// 遍历
for (int* it = arr; it < arr + 5; it++)
    printf("%d ", *it);   // 10 20 30 40 50
```

> 指针算术是 STL 迭代器设计的底层模型，也是 C++ 教程中 `++p` 遍历数组的汇编解释基础。

## `const` 与指针（重点）

这是理解 C++ 中 `T* const` 和 `const T*`（即 this 指针类型）的前提：

```c
int x = 1, y = 2;

// 1. 指向常量的指针（不能通过 p 改目标，但 p 可改指向）
const int* p1 = &x;
// *p1 = 10;     // 错误！不能修改目标
p1 = &y;         // 可以改指向

// 2. 常量指针（p 本身不可改，但可通过 p 改目标）
int* const p2 = &x;
*p2 = 10;        // 可以修改目标
// p2 = &y;      // 错误！不能改指向

// 3. 指向常量的常量指针（都不能改）
const int* const p3 = &x;
// *p3 = 10;     // 错误
// p3 = &y;      // 错误
```

> 记忆口诀：**const 在 `*` 左边 → 指向内容不可改；const 在 `*` 右边 → 指针本身不可改。**

在 C++ 中，非 `const` 成员函数的 `this` 类型为 `T* const`（指针本身不可改，但可以改对象），`const` 成员函数的 `this` 为 `const T* const`（都不可改）。

## 动态内存：`malloc` / `free`

堆内存由程序员手动管理。`malloc` 分配，`free` 释放。忘记释放 → 内存泄漏，重复释放 → 崩溃。

```c
#include <stdlib.h>

// 分配数组
int n = 10;
int* arr = (int*)malloc(n * sizeof(int));
if (arr == NULL) {
    // 分配失败（内存耗尽）
    return 1;
}
for (int i = 0; i < n; i++) arr[i] = i * 10;
free(arr);   // 必须释放！
arr = NULL;  // 好习惯：释放后置空
```

`malloc` 与 C++ `new` 的区别：

| | `malloc` | `new` |
|:--|:---------|:------|
| 语言 | C | C++ |
| 分配方式 | `malloc(size)` | `new Type` 或 `new Type[n]` |
| 构造函数 | 不调用 | **调用** |
| 释放 | `free` | `delete` / `delete[]` |
| 返回值 | `void*`（需强转） | 正确类型指针 |
| 失败 | 返回 `NULL` | 抛出 `std::bad_alloc` |

> C++ 的 `new` = `malloc` + 构造函数调用。这是 C++ 教程 [[04_动态内存]] 的核心内容。

## 函数指针

函数名代表函数地址。函数指针用于回调。

```c
// 声明：pFunc 是指向 "接受两个 int、返回 int 的函数" 的指针
int (*pFunc)(int, int);

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

pFunc = add;
printf("%d\n", pFunc(3, 5));   // 8
pFunc = &sub;                  // 等价于 pFunc = sub
printf("%d\n", pFunc(3, 5));   // -2
```

> 在 C++ 中，虚函数表（vtable）本质就是函数指针数组。详见 [[../汇编基础/ASM_03_C++在汇编层的体现]]。

## 多级指针

```c
int  x   = 42;
int* p   = &x;     // 一级指针
int** pp = &p;     // 二级指针

printf("%d\n", **pp);  // 42（两次解引用）
```

多级指针在 C++ 中少见（用引用替代），但在 C 的链表/树操作中常见（如 `ListNode**` 用于修改头指针）。
