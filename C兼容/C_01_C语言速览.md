# C 语言速览 —— 看懂 C++ 教程中的 C 代码
## ============================================================

本文件覆盖阅读 C++ 教程所需的最小 C 语言知识。C 是 C++ 的子集（大体），理解 C 是理解 C++ 底层机制的关键。

## 基本类型

C 的类型系统比 C++ 精简，没有 `bool`（C99 前）、没有引用、没有类：

| 类型 | 大小 (64位 Linux) | 说明 |
|:-----|:-----|:-----|
| `char` | 1B | 字符/小整数 |
| `short` | 2B | 短整数 |
| `int` | 4B | 整数 |
| `long` | 8B | 长整数 |
| `long long` | 8B | 长长整数 |
| `float` | 4B | 单精度浮点 |
| `double` | 8B | 双精度浮点 |
| `void*` | 8B | 通用指针 |
| `size_t` | 8B | `sizeof` 返回的无符号整数类型 |

```c
#include <stdio.h>   // printf
#include <stddef.h>  // size_t

int main(void) {
    int    a = 42;
    double b = 3.14;
    char   c = 'X';
    size_t n = sizeof(int);   // n = 4
    printf("a=%d, b=%.2f, c=%c, sizeof(int)=%zu\n", a, b, c, n);
    return 0;
}
```

## 控制流

与 C++ 几乎一致。`if`/`else`、`for`、`while`、`do-while`、`switch` 语法相同。

```c
for (int i = 0; i < 5; i++) {
    if (i % 2 == 0) continue;
    printf("%d ", i);  // 1 3
}
```

## 函数

C 没有函数重载、默认参数、模板。声明必须指定返回类型（无 `auto`）。

```c
// 函数声明（通常在 .h 文件）
int add(int x, int y);

// 函数定义（通常在 .c 文件）
int add(int x, int y) {
    return x + y;
}
```

## 数组

C 数组是定长的连续内存块。数组名退化为指针。

```c
int arr[5] = {1, 2, 3, 4, 5};   // 栈上分配
arr[0] = 10;                      // 等价于 *(arr + 0) = 10

// 数组名退化为指针
int* p = arr;                     // p 指向 arr[0]
printf("%d\n", *(p + 2));         // arr[2] = 3
```

## 字符串

C 没有 `std::string`。字符串是 `char` 数组，以 `\0`（空字符）结尾。

```c
#include <string.h>

char s1[] = "hello";                  // 栈上，含 '\0'
char s2[32];
strcpy(s2, s1);                       // 复制
size_t len = strlen(s1);              // len = 5（不含 '\0'）

printf("%s has %zu chars\n", s2, len);
```

> C 风格字符串是指针/数组操作的常见来源，详见 [[C_02_指针与内存]]。

## 动态内存

C 用 `malloc`/`free`（而非 `new`/`delete`），返回 `void*`，需手动转换。

```c
#include <stdlib.h>

int* p = (int*)malloc(10 * sizeof(int));  // 分配10个int
if (p == NULL) { /* 分配失败 */ }
for (int i = 0; i < 10; i++) p[i] = i;
free(p);  // 释放

// 单个对象
int* single = (int*)malloc(sizeof(int));
*single = 42;
free(single);
```

> `malloc` 与 `new` 的区别详见 [[C_02_指针与内存]]。

## 输出

C 用 `printf`（格式化输出）和 `puts`（简单字符串）。

```c
#include <stdio.h>

printf("整数: %d, 浮点: %.2f, 字符: %c, 字符串: %s, 指针: %p\n",
       42, 3.14159, 'A', "hello", (void*)0x1234);
puts("一行文本");
```

## 与 C++ 的主要区别速查

| 特性 | C | C++ |
|:-----|:--|:---|
| 头文件 | `<stdio.h>` | `<cstdio>` |
| 动态分配 | `malloc`/`free` | `new`/`delete` |
| 字符串 | `char[]` + `\0` | `std::string` |
| 布尔 | `int`（C99 前） | `bool` |
| 引用 | 无 | `int&` |
| 函数重载 | 无 | 有 |
| 类/对象 | 无 | 有 |
| 命名空间 | 无 | 有 |

> 从 C 过渡到 C++ 时最常见的点：`struct` 声明、`typedef`、`#define` 宏，详见 [[C_03_struct_typedef_宏]]。
