# 发行版命令速查表

> 跨发行版命令对照大全。无论你从 Debian 切换到 Arch，还是在 CentOS 和 Alpine 之间反复横跳，这张表帮你快速找到对应的命令。记住核心概念：**不同发行版的工具名称不同，但要做的事情是一样的。**

---

## 一、软件包管理

### 1.1 仓库索引操作

| 操作 | apt (Debian/Ubuntu) | dnf (Fedora/RHEL) | pacman (Arch) | zypper (openSUSE) | apk (Alpine) | nix (NixOS) | emerge (Gentoo) |
|------|---------------------|-------------------|---------------|-------------------|--------------|-------------|-----------------|
| 更新包索引 | `apt update` | `dnf check-update` | `pacman -Sy` | `zypper refresh` | `apk update` | `nix-channel --update` | `emerge --sync` |
| 刷新并升级全部 | `apt update && apt upgrade` | `dnf upgrade` | `pacman -Syu` | `zypper update` | `apk upgrade` | `nixos-rebuild switch --upgrade` | `emerge -uDN @world` |
| 列出仓库中包 | `apt list` | `dnf list available` | `pacman -Sl` | `zypper search -s` | `apk search -v` | `nix search nixpkgs` | `eix <pkg>` |
| 列出已安装包 | `apt list --installed` | `dnf list installed` | `pacman -Q` | `zypper search -i` | `apk info` | `nix-env -q` | `qlist -I` |
| 查看包信息 | `apt show <pkg>` | `dnf info <pkg>` | `pacman -Si <pkg>` | `zypper info <pkg>` | `apk info <pkg>` | `nix-env -qaP --description <pkg>` | `emerge -s <pkg>` |
| 查看已装包信息 | `apt show <pkg>` | `dnf info <pkg>` | `pacman -Qi <pkg>` | `zypper info <pkg>` | `apk info -L <pkg>` | `nix-env -qa --description <pkg>` | `equery m <pkg>` |
| 搜索包 | `apt search <kw>` | `dnf search <kw>` | `pacman -Ss <kw>` | `zypper search <kw>` | `apk search <kw>` | `nix search nixpkgs <kw>` | `emerge --search <kw>` |
| 搜索含文件的包 | `apt-file search <f>` | `dnf provides <f>` | `pacman -F <f>` | `zypper se --provides <f>` | `apk info -W <f>` | — | `equery b <f>` |

### 1.2 安装操作

| 操作 | apt | dnf | pacman | zypper | apk | nix | emerge |
|------|-----|-----|--------|--------|-----|-----|--------|
| 安装包 | `apt install <pkg>` | `dnf install <pkg>` | `pacman -S <pkg>` | `zypper install <pkg>` | `apk add <pkg>` | `nix-env -iA nixpkgs.<pkg>` | `emerge <pkg>` |
| 安装本地包 | `dpkg -i <file>.deb` | `dnf install <file>.rpm` | `pacman -U <file>.pkg.tar.zst` | `zypper install <file>.rpm` | `apk add --allow-untrusted <file>.apk` | — | — |
| 跳过依赖检查 | — | `dnf install --setopt=tsflags=nodocs <pkg>` | `pacman -Sdd <pkg>` | `zypper install --no-recommends <pkg>` | — | — | `emerge --nodeps <pkg>` |
| 只下载不安装 | `apt download <pkg>` | `dnf download <pkg>` | `pacman -Sw <pkg>` | `zypper download <pkg>` | `apk fetch <pkg>` | — | `emerge -f <pkg>` |
| 安装软件包组 | `apt install <group>` | `dnf groupinstall <grp>` | `pacman -S <group>` | `zypper install -t pattern <pat>` | — | — | `emerge --select <set>` |

### 1.3 卸载操作

| 操作 | apt | dnf | pacman | zypper | apk | nix | emerge |
|------|-----|-----|--------|--------|-----|-----|--------|
| 移除包 | `apt remove <pkg>` | `dnf remove <pkg>` | `pacman -R <pkg>` | `zypper remove <pkg>` | `apk del <pkg>` | `nix-env -e <pkg>` | `emerge -C <pkg>` |
| 移除+依赖 | `apt autoremove <pkg>` | `dnf autoremove <pkg>` | `pacman -Rs <pkg>` | `zypper rm -u <pkg>` | `apk del <pkg>` | — | `emerge --depclean <pkg>` |
| 移除+依赖+配置 | `apt purge <pkg>` | — | `pacman -Rns <pkg>` | — | — | — | — |
| 清除孤立包 | `apt autoremove` | `dnf autoremove` | `pacman -Qdtq \| pacman -Rs -` | `zypper packages --orphaned` | — | `nix-collect-garbage -d` | `emerge --depclean` |
| 清理缓存 | `apt clean` | `dnf clean all` | `pacman -Sc` | `zypper clean` | `apk cache clean` | `nix-store --gc` | `eclean-dist` |

### 1.4 仓库管理

| 操作 | apt | dnf | pacman | zypper | apk | nix | emerge |
|------|-----|-----|--------|--------|-----|-----|--------|
| 添加仓库 | `add-apt-repository <repo>` | `dnf config-manager --add-repo <url>` | 编辑 `/etc/pacman.conf` | `zypper addrepo <url> <name>` | 编辑 `/etc/apk/repositories` | 编辑 `/etc/nixos/configuration.nix` | `layman -a <overlay>` |
| 列出仓库 | `apt-cache policy` | `dnf repolist` | `pacman -Sl` | `zypper repos` | `cat /etc/apk/repositories` | `nix-channel --list` | `layman -l` |
| 启用/禁用仓库 | 编辑 `/etc/apt/sources.list` | `dnf config-manager --set-enabled <repo>` | 编辑 `/etc/pacman.conf` | `zypper mr -e/-d <repo>` | 注释/取消注释 `/etc/apk/repositories` | — | `layman -a/-d <overlay>` |
| 锁版本 | `apt-mark hold <pkg>` | `dnf versionlock add <pkg>` | 编辑 `/etc/pacman.conf` IgnorePkg | `zypper addlock <pkg>` | — | — | `/etc/portage/package.mask` |

## 二、服务管理

### 2.1 systemd（现代发行版通用）

| 操作 | 命令 |
|------|------|
| 启动服务 | `systemctl start <unit>` |
| 停止服务 | `systemctl stop <unit>` |
| 重启服务 | `systemctl restart <unit>` |
| 重载配置 | `systemctl reload <unit>` |
| 查看状态 | `systemctl status <unit>` |
| 开机自启 | `systemctl enable <unit>` |
| 取消自启 | `systemctl disable <unit>` |
| 启用并启动 | `systemctl enable --now <unit>` |
| 列出所有单元 | `systemctl list-units` |
| 列出所有服务 | `systemctl list-units --type=service` |
| 列出失败的 | `systemctl --failed` |
| 查看启动日志 | `systemctl status <unit>` 或 `journalctl -u <unit>` |
| 重新加载 systemd | `systemctl daemon-reload` |
| 编辑单元文件 | `systemctl edit <unit> --full` |

### 2.2 非 systemd 发行版

| 操作 | OpenRC (Gentoo/Alpine) | runit (Void) | S6 |
|------|------------------------|-------------|-----|
| 启动服务 | `rc-service <svc> start` | `sv start <svc>` | `s6-rc -u change <svc>` |
| 停止服务 | `rc-service <svc> stop` | `sv stop <svc>` | `s6-rc -d change <svc>` |
| 重启服务 | `rc-service <svc> restart` | `sv restart <svc>` | — |
| 查看状态 | `rc-service <svc> status` | `sv status <svc>` | `s6-svstat <dir>` |
| 开机自启 | `rc-update add <svc>` | `ln -s /etc/sv/<svc> /var/service/` | `s6-rc-db add <svc>` |
| 列出服务 | `rc-status` | `sv status /var/service/*` | `s6-rc -a list` |

## 三、网络配置

### 3.1 网络管理工具

| 操作 | NetworkManager | systemd-networkd | netplan | ifupdown (Debian旧) | 通用/手动 |
|------|---------------|------------------|---------|---------------------|----------|
| 查看接口 | `nmcli dev status` | `networkctl list` | `netplan status` | `ifconfig -a` | `ip addr show` |
| 查看详情 | `nmcli dev show <if>` | `networkctl status <if>` | — | — | `ip -s link show <if>` |
| 连接 WiFi | `nmcli dev wifi connect <ssid>` | 配置 `.network` 文件 | 配置 YAML | `/etc/network/interfaces` | `iwctl` / `wpa_supplicant` |
| 设静态 IP | `nmcli con mod <name> ipv4.addresses ...` | `.network` 文件 Address= | YAML addresses: | `/etc/network/interfaces` | `ip addr add <ip>/<mask> dev <if>` |
| 启用接口 | `nmcli con up <name>` | `networkctl up <if>` | `netplan apply` | `ifup <if>` | `ip link set <if> up` |
| 禁用接口 | `nmcli con down <name>` | `networkctl down <if>` | — | `ifdown <if>` | `ip link set <if> down` |
| 查看路由 | `nmcli con show <name> \| grep ipv4.routes` | `networkctl status` | — | `route -n` | `ip route show` |
| DNS 配置 | `nmcli con mod <name> ipv4.dns "8.8.8.8"` | `/etc/systemd/resolved.conf` | YAML nameservers: | `/etc/resolv.conf` | `resolvectl` |

## 五、防火墙

| 操作 | iptables/nftables | firewalld (RHEL系) | ufw (Debian/Ubuntu) |
|------|-------------------|---------------------|----------------------|
| 查看规则 | `iptables -L -n -v` / `nft list ruleset` | `firewall-cmd --list-all` | `ufw status verbose` |
| 开启防火墙 | `systemctl start iptables` | `systemctl start firewalld` | `ufw enable` |
| 放行端口 | `iptables -A INPUT -p tcp --dport <p> -j ACCEPT` | `firewall-cmd --add-port=<p>/tcp` | `ufw allow <p>/tcp` |
| 永久规则 | `iptables-save` | `firewall-cmd --add-port=<p>/tcp --permanent` | 默认永久 |
| 封禁 IP | `iptables -A INPUT -s <ip> -j DROP` | `firewall-cmd --add-rich-rule='rule ...'` | `ufw deny from <ip>` |
| 删除规则 | `iptables -D INPUT <num>` | `firewall-cmd --remove-port=<p>/tcp` | `ufw delete allow <p>` |
| 默认策略 | `iptables -P INPUT DROP` | `firewall-cmd --set-default-zone=drop` | `ufw default deny` |
| 保存规则 | `iptables-save > /etc/iptables/rules.v4` | `firewall-cmd --runtime-to-permanent` | 自动保存 |

## 六、日志管理

| 操作 | 命令 |
|------|------|
| 查看系统日志 | `journalctl` |
| 查看内核日志 | `journalctl -k` 或 `dmesg` |

| 实时跟踪日志 | `journalctl -f` |
| 查看本次启动 | `journalctl -b` |
| 查看上次启动 | `journalctl -b -1` |
| 按时间范围 | `journalctl --since "2024-01-01" --until "2024-01-02"` |

| 日志占用空间 | `journalctl --disk-usage` |
| 清理旧日志 | `journalctl --vacuum-size=500M` |
| 传统 syslog 文件 | `/var/log/syslog`, `/var/log/messages`, `/var/log/auth.log` |

## 九、发行版默认配置路径

| 配置项 | Debian/Ubuntu | RHEL/Fedora | Arch | Alpine | NixOS |
|--------|--------------|-------------|------|--------|-------|
| 包仓库 | `/etc/apt/sources.list` | `/etc/yum.repos.d/*.repo` | `/etc/pacman.conf`, `/etc/pacman.d/mirrorlist` | `/etc/apk/repositories` | `/etc/nixos/configuration.nix` |
| 网络配置 | `/etc/network/interfaces` | `/etc/sysconfig/network-scripts/` | `/etc/systemd/network/` | `/etc/network/interfaces` | `/etc/nixos/configuration.nix` |
| DNS | `/etc/resolv.conf` | `/etc/resolv.conf` | `/etc/resolv.conf` | `/etc/resolv.conf` | `networking.nameservers` in config |
| 防火墙 | ufw / iptables | firewalld / iptables | iptables / nftables | iptables | `networking.firewall` in config |
| 日志 | `/var/log/` + journald | `/var/log/` + journald | `/var/log/` + journald | `/var/log/` | journald only |
| 用户/组 | `/etc/passwd`, `/etc/group` | 同 | 同 | 同 | 声明式 `users.users.<name>` |
| init 系统 | systemd | systemd | systemd | OpenRC / busybox | systemd |
| 包缓存 | `/var/cache/apt/archives/` | `/var/cache/dnf/` | `/var/cache/pacman/pkg/` | `/etc/apk/cache/` | `/nix/store/` |
