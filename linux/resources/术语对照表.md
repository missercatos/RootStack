# Linux 术语对照表

> 一份面向中文读者的 Linux 术语英汉对照表。每个术语包含英文原文、中文译名和简明解释，按类别编排，方便查阅。建议搭配 Obsidian 的[[双向链接]]功能，加深对概念网络的理解。

---

## 一、内核与核心概念

| 英文 | 中文 | 解释 |
|------|------|------|
| Kernel | 内核 | 操作系统的核心程序，直接管理硬件资源，提供系统调用接口给用户空间 |
| Monolithic Kernel | 宏内核 | 将全部系统服务（内存管理、文件系统、设备驱动等）运行在内核空间的设计，Linux 采用此架构 |
| Microkernel | 微内核 | 只将最基本的功能（IPC、调度）放在内核空间，其余服务在用户态运行的设计，如 Minix |
| Kernel Module | 内核模块 | 可动态加载和卸载的内核代码片段，如设备驱动，通过 `modprobe` 管理 |
| System Call | 系统调用 | 用户程序请求内核服务的编程接口，如 `open()`、`read()`、`write()`、`fork()` |
| Kernel Space | 内核空间 | 内存中由内核独占的地址区域，拥有硬件完全访问权限 |
| User Space | 用户空间 | 内存中供用户程序运行的地址区域，受限于内核保护机制 |
| Context Switch | 上下文切换 | CPU 从一个进程/线程切换到另一个时，保存和恢复寄存器状态的过程 |
| Interrupt | 中断 | 硬件或软件向 CPU 发送的信号，使其暂停当前任务转而执行中断处理程序 |
| Sysfs | 系统文件系统 | 挂载于 `/sys` 的虚拟文件系统，以树状结构暴露内核对象信息 |
| Procfs | 进程文件系统 | 挂载于 `/proc` 的虚拟文件系统，提供进程和系统信息的接口 |
| Device Tree | 设备树 | 描述硬件组件拓扑的数据结构，常见于 ARM/LoongArch/RISC-V 嵌入式系统 |
| eBPF | 扩展伯克利包过滤器 | 允许在内核中安全运行沙箱化程序的技术，用于追踪、网络、安全、可观测性 |
| io_uring | 环形 I/O | Linux 5.1 引入的高性能异步 I/O 框架，通过共享环形缓冲区减少系统调用开销 |

## 二、进程与调度

| 英文 | 中文 | 解释 |
|------|------|------|
| Process | 进程 | 程序的运行实例，拥有独立的地址空间、文件描述符和资源 |
| Thread | 线程 | 进程内的执行流，多个线程共享同一个地址空间和文件描述符 |
| PID | 进程标识符 | 唯一标识一个进程的整数编号 |
| PPID | 父进程标识符 | 创建该进程的父进程的 PID |
| TID | 线程标识符 | 唯一标识一个线程的整数编号 |
| Daemon | 守护进程 | 在后端持续运行的系统服务，通常不直接与终端交互 |
| Zombie | 僵尸进程 | 已终止但父进程未调用 `wait()` 回收其退出状态的进程 |
| Orphan | 孤儿进程 | 父进程已终止但自身仍在运行的进程，通常被 init (PID 1) 收养 |
| Scheduler | 调度器 | 内核中决定哪个进程在何时使用 CPU 的子系统（如 CFS, EEVDF 等） |
| Nice | 谦让值 | 进程优先级调节值，范围 -20（最高优先级）到 19（最低优先级） |
| Fork | 分叉 | `fork()` 系统调用，创建当前进程的副本作为子进程 |
| Exec | 执行 | `exec*()` 族系统调用，将当前进程替换为新的程序镜像 |
| Signal | 信号 | 进程间的一种异步通知机制，如 SIGKILL（9）、SIGTERM（15）、SIGINT（2） |
| IPC | 进程间通信 | 不同进程之间交换数据的机制，包括管道、消息队列、共享内存、信号量、套接字 |
| Cgroup | 控制组 | 限制、统计和隔离一组进程资源使用的内核机制，是容器的基石 |
| Namespace | 命名空间 | 为进程提供隔离的全局资源视图（PID、网络、挂载点、UTS、IPC、用户、Cgroup等） |

## 三、内存与存储

| 英文 | 中文 | 解释 |
|------|------|------|
| Virtual Memory | 虚拟内存 | 让每个进程有独立地址空间的技术，通过页表映射到物理内存 |
| Physical Memory | 物理内存 | 实际安装在机器上的 RAM 内存条容量 |
| Page | 页 | 内存管理的最小单位（通常 4KB），也是虚拟内存与物理内存之间映射的基本单元 |
| Page Table | 页表 | 记录虚拟页到物理页映射关系的数据结构，多级页表可节省空间 |
| TLB | 旁路转换缓冲 | CPU 内部的高速缓存，用于加速虚拟地址到物理地址的转换 |
| Swap | 交换空间 | 磁盘上的一块区域，当物理内存不足时，将不常用的内存页写出到交换空间 |
| Paging | 分页 | 内存管理的一种方式，将进程的地址空间分成固定大小的页 |
| Segmentation | 分段 | 早期内存管理方式，按逻辑段（代码段、数据段、栈）划分内存 |
| OOM Killer | 内存耗尽杀手 | 内核在内存极度不足时自动杀掉进程的机制 |
| Page Fault | 缺页异常 | 访问不在物理内存中的虚拟页时触发的异常，触发页面调入 |
| Huge Pages | 大页 | 2MB 或 1GB 大小的内存页，减少 TLB 条目数量，提高性能 |
| DMA | 直接内存访问 | 允许硬件设备绕过 CPU 直接读写系统内存的技术 |
| NUMA | 非一致内存访问 | 多处理器架构下，每个 CPU 有自己的本地内存，访问本地内存比远程快 |
| Mmap | 内存映射 | `mmap()` 系统调用，将文件或设备映射到内存地址空间 |

## 四、文件系统

| 英文 | 中文 | 解释 |
|------|------|------|
| Filesystem | 文件系统 | 在存储设备上组织和管理数据的方法和数据结构 |
| Inode | 索引节点 | 文件元数据的数据结构，存储文件的权限、大小、时间戳、数据块指针等信息 |
| Block | 块 | 文件系统中数据存取的最小单位（通常 4KB） |
| Superblock | 超级块 | 存储整个文件系统总体信息的数据结构（总块数、空闲块、inode 数等） |
| Dentries | 目录项缓存 | 内核中缓存目录名到 inode 映射的数据结构，加速路径解析 |
| Mount | 挂载 | 将文件系统关联到目录树中某个目录的操作 |
| Mount Point | 挂载点 | 文件系统挂载的目录位置 |
| Symlink | 符号链接 | 指向另一个文件或目录路径的特殊文件，类似 Windows 的快捷方式 |
| Hard Link | 硬链接 | 指向同一 inode 的多个文件名，删除任一硬链接不影响数据 |
| Journal | 日志 | 文件系统中记录待写操作的区域，用于崩溃后恢复一致性（[[42-文件系统深入]]） |
| Copy-on-Write | 写时复制 | 修改数据时不原地改写，而是写到新位置后更新指针的技术，Btrfs 和 ZFS 的核心特性 |
| LVM | 逻辑卷管理 | 在物理存储上抽象出逻辑卷的系统，支持快照、扩容、跨盘聚合等 |
| RAID | 独立磁盘冗余阵列 | 多块磁盘组合以提升性能或冗余的技术方案（0, 1, 5, 10, 6 等级别） |
| FSCK | 文件系统检查 | 检查和修复文件系统一致性的工具 |
| FUSE | 用户空间文件系统 | 允许在用户态实现文件系统驱动的框架，见 [[49-FUSE与虚拟文件系统]] |
| Tmpfs | 临时文件系统 | 完全存储在内存中的文件系统，重启后数据消失 |
| OverlayFS | 叠加文件系统 | 将多个目录叠加成一个统一视图的联合文件系统，Docker 使用此技术 |
| Btrfs | B-Tree 文件系统 | 支持 CoW、快照、子卷、压缩、RAID 的现代 Linux 文件系统 |
| ZFS | Z 文件系统 | 源自 Solaris 的企业级文件系统，支持 CoW、快照、去重、校验 |

## 五、Shell 与命令行

| 英文 | 中文 | 解释 |
|------|------|------|
| Shell | 壳层 | 用户与操作系统内核之间的命令行解释器，如 Bash、Zsh、Fish、Nushell |
| Bash | Bourne Again Shell | 最广泛使用的 Linux Shell，是大多数发行版的默认 Shell |
| Terminal | 终端 | 提供命令行交互界面的程序，分为物理终端和终端模拟器（如 Alacritty, kitty, foot） |
| Environment Variable | 环境变量 | 存储配置信息的变量，如 `$PATH`, `$HOME`, `$USER`，可被子进程继承 |
| Alias | 别名 | 为长命令定义的快捷短名称，如 `alias ll='ls -la'` |
| Pipe | 管道 | 将一个命令的标准输出连接到另一个命令的标准输入，符号为 `\|` |
| Redirection | 重定向 | 将输入输出流导向到文件或其他目的地，如 `>`, `<`, `2>&1` |
| Wildcard | 通配符 | 用于文件名匹配的特殊字符，如 `*`（任意字符）、`?`（单个字符） |
| Glob | 全局匹配 | Shell 对通配符模式展开为文件列表的过程 |
| Completion | 补全 | Shell 自动补全命令、文件名、参数的功能，按 Tab 触发 |
| Script | 脚本 | 包含一系列 Shell 命令的文本文件，可逐行自动执行 |
| Shebang | 解释器行 | 脚本第一行的 `#!/bin/bash`，指定执行脚本的解释器 |
| Subshell | 子壳层 | 当前 Shell 的子进程，通过 `()` 或 `$()` 创建，拥有独立的变量上下文 |
| Job Control | 作业控制 | 管理前台/后台任务的机制，`jobs`, `fg`, `bg`, `Ctrl+Z` |

## 六、软件包管理

| 英文 | 中文 | 解释 |
|------|------|------|
| Package Manager | 包管理器 | 管理软件安装、升级、卸载和依赖解析的工具 |
| Repository | 软件仓库 | 集中存储软件包的服务器位置 |
| Dependency | 依赖 | 软件运行所需要的其他软件包 |
| Dependency Resolution | 依赖解析 | 自动计算和安装所需依赖包的过程 |
| Package Format | 包格式 | 软件包的封装格式，如 `.deb`（Debian）、`.rpm`（RHEL）、`.pkg.tar.zst`（Arch） |
| Binary Package | 二进制包 | 包含预编译可执行文件的软件包 |
| Source Package | 源码包 | 包含源码和构建脚本的软件包，需自行编译 |
| Meta Package | 元包 | 本身不包含文件，只声明依赖，用于一次性安装一组软件 |
| Orphan Package | 孤儿包 | 已安装但不再被其他包依赖的软件包 |
| Pinning | 版本锁定 | 指定软件包的安装来源或固定其特定版本 |
| Rolling Release | 滚动发行 | 持续发布最新软件的更新模式，不分固定版本，如 Arch Linux |
| Point Release | 定点发行 | 按固定周期发布新版本的更新模式，如 Ubuntu 24.04 |
| AUR | Arch 用户仓库 | Arch Linux 社区维护的软件包仓库，用户可提交 PKGBUILD 脚本 |
| Flake | 片 | Nix 生态中的一种依赖管理和可复现构建单元，包含输入、输出和锁文件 |
| Nix Store | Nix 存储 | NixOS 中 `/nix/store/` 目录，以内容哈希存储不可变软件包 |

## 七、网络

| 英文 | 中文 | 解释 |
|------|------|------|
| Socket | 套接字 | 网络通信的端点抽象，由 IP 地址和端口号组成 |
| TCP | 传输控制协议 | 面向连接的可靠传输协议 |
| UDP | 用户数据报协议 | 无连接的不可靠传输协议 |
| IP Address | IP 地址 | 互联网协议地址，用于标识网络设备 |
| Subnet Mask | 子网掩码 | 用于划分网络地址和主机地址的掩码 |
| Gateway | 网关 | 连接不同网络的设备，通常是路由器的地址 |
| DNS | 域名系统 | 将域名解析为 IP 地址的分布式系统 |
| DHCP | 动态主机配置协议 | 自动分配 IP 地址的网络协议 |
| VLAN | 虚拟局域网 | 在交换机上逻辑分割的广播域 |
| Bridge | 网桥 | 连接两个网络段并在链路层转发的设备 |
| Bonding | 链路聚合 | 将多个物理网卡捆绑为一个逻辑接口以提高带宽或冗余 |
| Firewall | 防火墙 | 控制网络流量的安全系统，如 iptables, nftables, firewalld, ufw |
| Proxy | 代理 | 转发客户端请求到目标服务器的中间服务器 |
| Reverse Proxy | 反向代理 | 接收客户端请求并将其转发到后端服务器的代理，如 Nginx, Caddy |
| Load Balancer | 负载均衡器 | 将流量分发到多个后端服务器的设备或软件 |
| NAT | 网络地址转换 | 将私有 IP 地址映射为公共 IP 地址的技术 |
| MTU | 最大传输单元 | 网络层单次可传输的最大数据包大小 |
| TUN/TAP | 隧道/分接 | 虚拟网络设备，`tun` 处理三层 IP 流量，`tap` 处理二层以太网帧 |

## 八、安全

| 英文 | 中文 | 解释 |
|------|------|------|
| UID | 用户标识符 | 唯一标识一个用户的整数，`root` 的 UID 为 0 |
| GID | 组标识符 | 唯一标识一个用户组的整数 |
| Permission | 权限 | 文件访问控制，分为可读(r)、可写(w)、可执行(x)三类，分别作用于属主、属组、其他人 |
| Umask | 用户掩码 | 创建新文件/目录时的默认权限掩码，通常为 022 |
| Setuid | 设置用户 ID | 执行文件时进程拥有文件属主的权限，`passwd` 命令即使用此机制 |
| Setgid | 设置组 ID | 执行文件时拥有文件属组的权限；用于目录时，新文件继承目录的属组 |
| Sticky Bit | 粘滞位 | 用于目录时，只有文件属主和 root 可以删除目录中文件，如 `/tmp` |
| Capabilities | 权能 | Linux 将 root 超级权限细分为多个独立能力，可单独授予进程 |
| SELinux | 安全增强式 Linux | 由 NSA 开发的强制访问控制系统，策略定义主体对客体的访问权限 |
| AppArmor | 应用程序装甲 | 基于路径的强制访问控制框架，Ubuntu 默认启用的替代 SELinux 的方案 |
| PAM | 可插拔认证模块 | 管理认证、授权、会话的一套模块化框架，控制 login、ssh、sudo 等 |
| SSH | 安全壳 | 加密的远程登录协议，默认端口 22 |
| Keyring | 密钥环 | 内核中存储密钥的安全机制 |
| LUKS | Linux 统一密钥设置 | 磁盘加密标准，用于全盘加密和数据保护 |
| TPM | 可信平台模块 | 硬件安全芯片，可存储密钥、度量系统完整性、支持远程证明 |
| Secure Boot | 安全启动 | UEFI 标准，确保启动时只加载被签名信任的引导程序和内核 |

## 九、容器与虚拟化

| 英文 | 中文 | 解释 |
|------|------|------|
| Container | 容器 | 操作系统级别的轻量级虚拟化，利用 namespace 和 cgroup 隔离开销极少 |
| Image | 镜像 | 容器的只读模板，包含运行程序所需的文件系统、库和配置 |
| Docker | 码头工人 | 最流行的容器运行时和镜像管理工具 |
| Podman | 容器管理器 | Red Hat 推出的无守护进程容器引擎，兼容 Docker CLI |
| Kubernetes (K8s) | 八分之七 | 容器编排平台，自动化容器的部署、扩展和管理 |
| Pod | 容器组 | K8s 中最小的调度单元，包含一个或多个共享网络和存储的容器 |
| OCI | 开放容器标准 | 容器镜像格式和运行时的开放行业标准 |
| Hypervisor | 虚拟机监视器 | 管理和运行虚拟机的软件，如 KVM, QEMU, Xen, VirtualBox |
| KVM | 基于内核的虚拟机 | Linux 内核内置的虚拟化技术，将内核转化为 Hypervisor |
| Virtio | 虚拟 I/O | 半虚拟化环境下高效 I/O 的标准框架 |

## 十、桌面与图形

| 英文 | 中文 | 解释 |
|------|------|------|
| X11 (X Window System) | X 窗口系统 | 传统的 Linux 图形显示协议，已有 40 年历史 |
| Wayland | 向陆(暂译名) | X11 的现代替代者，设计更简洁安全，实现见 [[51-Wayland深入指南]] |
| XDG | 跨桌面组 | `freedesktop.org` 制定的桌面环境互操作标准（如 `.desktop` 文件、文件管理器命令等） |
| Compositor | 合成器 | 将多个窗口缓冲区合成最终画面的程序。Wayland 合成器同时承担显示服务器和窗口管理器角色 |
| WM | 窗口管理器 | 管理窗口位置、大小、装饰的程序，分为平铺式（tiling）和堆叠式（stacking） |
| Desktop Environment | 桌面环境 | 完整的桌面生态，包含面板、文件管理器、设置工具等，如 GNOME、KDE Plasma、Xfce |
| D-Bus | 桌面总线 | 进程间通信的高级总线机制，支持方法和信号 |
| PipeWire | 管道丝 | 低延迟多媒体框架，统一替代 PulseAudio 和 JACK |
| PulseAudio | 脉冲音频 | Linux 音频服务守护进程，曾被广泛使用但已逐渐被 PipeWire 取代 |
| DRM/KMS | 直接渲染管理器/内核模式设置 | 内核中管理 GPU 和显示的子系 |
| Mesa | 台地 | 开源的 OpenGL/Vulkan 驱动实现 |
| HiDPI | 高分辨率 | 高像素密度显示器（如 Retina 屏），需要应用程序支持缩放 |
