# STL 容器速通 — queue (队列)

queue（队列）是先进先出（FIFO，First In First Out）的容器适配器。它对底层容器（默认 deque）进行封装，限制只能在队尾插入、队首删除。最先入队的元素最先出队，就像排队买票，先到先服务。

> 想深入理解队列这一抽象数据类型的原理、顺序队列与循环队列的实现，请见 [[数据结构/F_队列_Queue]]。

## 一、优缺点

| 优点 | 缺点 |
|------|------|
| push / pop / front / back 全为 O(1) | 只能访问队首和队尾两端 |
| 接口简单，FIFO 语义清晰 | 没有迭代器，不能遍历 |
| 可指定底层容器（deque/list） | 没有下标访问，没有 operator[] |
| 是 BFS 的天然载体 | 没有 clear()，清空需手动 |

## 二、适用场景

| 场景 | 说明 |
|------|------|
| BFS 广度优先搜索 | 按层次逐层扩展节点 |
| 约瑟夫环 / 报数游戏 | 出队再入队模拟轮转 |
| 滑动缓存 / LRU 雏形 | 先进先出淘汰最早元素 |
| 生产者消费者 | 缓冲待处理的任务 |
| 轮转调度 | Round Robin 进程调度 |

## 三、成员函数总览

| 函数 | 说明 | 时间复杂度 |
|------|------|-----------|
| `q.push(x)` | 队尾插入 | O(1) |
| `q.emplace(args...)` | 队尾原位构造 | O(1) |
| `q.pop()` | 删除队首（无返回值） | O(1) |
| `q.front()` | 返回队首引用 | O(1) |
| `q.back()` | 返回队尾引用 | O(1) |
| `q.size()` | 元素个数 | O(1) |
| `q.empty()` | 是否为空 | O(1) |
| `q.swap(q2)` | 交换两个队列 | O(1) |

## 四、动手实践（渐进操作）

下面按"创建 → size/empty → 插入 → 访问 → 修改 → 删除 → 遍历 → 清空"的顺序逐步练习。每一步只给提示与陷阱，请你对照"成员函数总览"自己把代码敲出来。

### 步骤 1：创建

> [!tip] 自己动手
> 函数：包含头文件 `<queue>`；用 `queue<int>` 声明默认队列（底层 deque）；想换底层写 `queue<int, list<int>>`；拷贝已有队列用 `queue<int> b(a)`。
> 陷阱：queue 不支持 `{1,2,3}` 列表初始化，元素只能逐个 push。

### 步骤 2：size / empty

> [!tip] 自己动手
> 函数：`size()` 取元素个数，`empty()` 判断是否为空。
> 陷阱：任何 `front()` / `back()` / `pop()` 之前都先用 `empty()` 判空，对空队列操作是未定义行为。

### 步骤 3：插入（push）

> [!tip] 自己动手
> 函数：`push(x)` 在队尾入队；`emplace(args...)` 在队尾原位构造。
> 陷阱：只能从队尾进，无法从队首或中间插入。

### 步骤 4：访问（front / back）

> [!tip] 自己动手
> 函数：`front()` 看队首（下一个出队的），`back()` 看队尾（最后入队的），二者都返回引用。
> 陷阱：queue 没有 `top()`，也没有 `operator[]`；想看的只能是首尾两端，访问前先判空。

### 步骤 5：修改

> [!tip] 自己动手
> 函数：`front()` 和 `back()` 返回可写引用，直接给它们赋值即可修改首尾元素。
> 陷阱：中间元素无法直接访问或修改。

### 步骤 6：删除（pop）

> [!tip] 自己动手
> 函数：`pop()` 删除队首元素。
> 陷阱：`pop()` 返回 void，想拿被删的值必须先 `front()` 取值再 `pop()`；注意删的是队首不是队尾。

### 步骤 7：遍历

> [!tip] 自己动手
> 函数：queue 没有迭代器，无法 for 遍历；要输出全部元素只能写 `while (!empty())`，反复 `front()` 输出后再 `pop()`。
> 陷阱：这种"遍历"会清空队列；要保留数据请先拷贝副本再遍历。

### 步骤 8：清空

> [!tip] 自己动手
> 函数：queue 没有 `clear()`；可用 `while (!empty()) pop();` 逐个弹出，或用 `q = queue<int>();` 整体替换为空队列。
> 陷阱：不要去找 `clear()`，它不存在。

## 五、经典实战

### 马的遍历 BFS（洛谷 P1443）

```cpp
#include <iostream>
#include <queue>
#include <cstring>
#include <cstdio>
using namespace std;

int dist[405][405];
int dx[] = {-2,-2,-1,-1,1,1,2,2};
int dy[] = {-1,1,-2,2,-2,2,-1,1};

int main() {
    memset(dist, -1, sizeof(dist));
    int n, m, sx, sy;
    cin >> n >> m >> sx >> sy;
    queue<pair<int,int>> q;
    dist[sx][sy] = 0;
    q.push({sx, sy});
    while (!q.empty()) {
        auto [x, y] = q.front(); q.pop();
        for (int i = 0; i < 8; i++) {
            int nx = x + dx[i], ny = y + dy[i];
            if (nx>=1 && nx<=n && ny>=1 && ny<=m && dist[nx][ny]==-1) {
                dist[nx][ny] = dist[x][y] + 1;
                q.push({nx, ny});
            }
        }
    }
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) printf("%-5d", dist[i][j]);
        printf("\n");
    }
    return 0;
}
```

### 约瑟夫问题（洛谷 P1996）

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    queue<int> q;
    for (int i = 1; i <= n; i++) q.push(i);
    while (!q.empty()) {
        for (int i = 1; i < m; i++) {     // 前 m-1 个出队再入队
            q.push(q.front());
            q.pop();
        }
        cout << q.front() << " ";         // 第 m 个出列
        q.pop();
    }
    return 0;
}
```

## 八、自己动手

> [!question] 练习题 1
> 在 n×m 网格迷宫中，从起点 (1,1) 到终点 (n,m) 求最短步数，`.` 为通路、`#` 为墙。
>
> 提示：用 `queue<pair<int,int>>` 做 BFS，配合 dist 数组记录步数与判重；从 q.front() 取当前格，向四方向扩展后 q.pop()。
> 陷阱：标记访问要在"入队时"而非"出队时"，否则同一格会被重复入队导致超时；终点不可达要输出无解。

> [!question] 练习题 2
> 模拟约瑟夫报数游戏：n 个人围圈，每数到 m 淘汰一人，输出淘汰顺序。
>
> 提示：把 1..n 全部 push 入队；每轮把前 m-1 个 `front()` 重新 push 到队尾再 pop，第 m 个直接出队并记录。
> 陷阱：注意是数 m 次而非移动 m 次，循环要执行 m-1 次搬运；队列为空即结束。

> [!question] 练习题 3
> 实现机器翻译内存模拟：内存最多存 m 个单词，依次查询 n 个单词，不在内存中则记一次外查并装入，满了先淘汰最早进入的。输出外查次数。
>
> 提示：用 `queue<int>` 维护内存中单词的进入顺序，配合一个布尔数组标记是否在内存；命中不动队列，未命中且满时 pop 队首并清其标记。
> 陷阱：命中已在内存的单词时绝不能再次入队，否则同一单词会占多个位置导致计数错误。
