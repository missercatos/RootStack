# STL 容器速通 — stack (栈)

stack（栈）是后进先出（LIFO，Last In First Out）的容器适配器。它不是一个独立的底层结构，而是对其他容器（默认 deque）的封装，只暴露"栈顶"这一端的操作。最后压入的元素最先弹出，就像一摞盘子，只能从顶上取放。

> 想深入理解栈这一抽象数据类型的原理、数组栈与链栈的实现，请见 [[数据结构/B_栈_Stack]]。

## 一、优缺点

| 优点 | 缺点 |
|------|------|
| push / pop / top 全为 O(1) | 只能访问栈顶，无法访问中间元素 |
| 接口极简，不易用错 | 没有迭代器，不能遍历 |
| 语义清晰，代码可读性高 | 没有下标访问，没有 operator[] |
| 可指定底层容器（deque/vector/list） | 没有 clear()，清空需手动 |

## 二、适用场景

| 场景 | 说明 |
|------|------|
| 括号匹配 | 遇左括号压栈，遇右括号弹栈匹配 |
| 表达式求值 | 操作数栈配合运算符优先级 |
| DFS 非递归实现 | 用显式栈模拟系统调用栈 |
| 单调栈 | 求下一个更大 / 更小元素 |
| 撤销操作 | 记录历史，撤销时弹栈 |

## 三、成员函数总览

| 函数 | 说明 | 时间复杂度 |
|------|------|-----------|
| `st.push(x)` | 压入栈顶 | O(1) |
| `st.emplace(args...)` | 原位构造并压入 | O(1) |
| `st.pop()` | 弹出栈顶（无返回值） | O(1) |
| `st.top()` | 返回栈顶引用 | O(1) |
| `st.size()` | 元素个数 | O(1) |
| `st.empty()` | 是否为空 | O(1) |
| `st.swap(st2)` | 交换两个栈 | O(1) |

## 四、动手实践（渐进操作）

下面按"创建 → size/empty → 插入 → 访问 → 修改 → 删除 → 遍历 → 清空"的顺序逐步练习。每一步只给提示与陷阱，请你对照"成员函数总览"自己把代码敲出来。

### 步骤 1：创建

> [!tip] 自己动手
> 函数：包含头文件 `<stack>`；用 `stack<int>` 声明默认栈（底层是 deque）；想换底层写 `stack<int, vector<int>>`；拷贝已有栈用 `stack<int> b(a)`。
> 陷阱：stack 不支持 `{1,2,3}` 这样的列表初始化，元素只能一个个 push 进去。

### 步骤 2：size / empty

> [!tip] 自己动手
> 函数：`size()` 取元素个数，`empty()` 判断是否为空。
> 陷阱：养成习惯——任何 `top()` / `pop()` 之前都先用 `empty()` 判空，对空栈操作是未定义行为。

### 步骤 3：插入（push）

> [!tip] 自己动手
> 函数：`push(x)` 把元素压到栈顶；`emplace(args...)` 在栈顶原位构造（适合复杂对象）。
> 陷阱：栈只有一个开口，无法把元素插到中间或底部，插入方向始终是栈顶。

### 步骤 4：访问（top）

> [!tip] 自己动手
> 函数：`top()` 返回栈顶元素的引用（只读它不会删除）。
> 陷阱：stack 没有 `front()` / `back()`，也没有 `operator[]`，唯一访问入口就是 `top()`；访问前先判空。

### 步骤 5：修改

> [!tip] 自己动手
> 函数：`top()` 返回的是可写引用，直接给 `top()` 赋值即可修改栈顶元素。
> 陷阱：只能改栈顶，栈中其它位置的元素无法直接修改。

### 步骤 6：删除（pop）

> [!tip] 自己动手
> 函数：`pop()` 弹出（删除）栈顶元素。
> 陷阱：`pop()` 返回值是 void，想拿到被删的值必须先 `top()` 取值再 `pop()`；空栈调用 `pop()` 是未定义行为。

### 步骤 7：遍历

> [!tip] 自己动手
> 函数：stack 没有迭代器，无法用 for 循环遍历；若一定要输出全部元素，只能写一个 `while (!empty())` 循环，反复 `top()` 输出后再 `pop()`。
> 陷阱：这种"遍历"会把栈清空；如需保留原数据，先拷贝一份再遍历副本。

### 步骤 8：清空

> [!tip] 自己动手
> 函数：stack 没有 `clear()`；可用 `while (!empty()) pop();` 逐个弹出，或用 `st = stack<int>();` 整体替换为空栈。
> 陷阱：不要去找 `clear()`，它根本不存在。

## 五、经典实战

### 表达式括号匹配（洛谷 P1739）

```cpp
#include <iostream>
#include <string>
#include <stack>
using namespace std;

int main() {
    string s;
    getline(cin, s);
    stack<char> st;
    bool ok = true;
    for (char c : s) {
        if (c == '(') st.push(c);
        else if (c == ')') {
            if (st.empty()) { ok = false; break; }
            st.pop();
        }
    }
    cout << (ok && st.empty() ? "YES" : "NO") << endl;
    return 0;
}
```

### 单调栈：下一个更大元素

```cpp
#include <iostream>
#include <stack>
#include <vector>
using namespace std;

int main() {
    int n; cin >> n;
    vector<int> a(n), ans(n, -1);
    for (int i = 0; i < n; i++) cin >> a[i];
    stack<int> st; // 存下标，对应值单调递减
    for (int i = 0; i < n; i++) {
        while (!st.empty() && a[st.top()] < a[i]) {
            ans[st.top()] = i;
            st.pop();
        }
        st.push(i);
    }
    for (int i = 0; i < n; i++) cout << ans[i] << " ";
    return 0;
}
```

## 八、自己动手

> [!question] 练习题 1
> 输入一个仅含 `()`、`[]`、`{}` 的括号串，判断是否完全匹配，匹配输出 YES 否则 NO。
>
> 提示：用 `stack<char>`，遇左括号 push，遇右括号先判 `empty()` 再比对 `top()` 是否为对应左括号。
> 陷阱：右括号到来时栈已空说明多余右括号；遍历结束后栈非空说明有未闭合的左括号。两种情况都要判 NO。

> [!question] 练习题 2
> 输入一个十进制正整数 n，用栈将其转换为二进制并输出。
>
> 提示：循环 `n % 2` 的结果 `push` 入栈，`n /= 2`，最后反复 `top()` + `pop()` 输出即得正序二进制。
> 陷阱：n 为 0 时需特判输出 0；不要忘记 pop() 无返回值，取值靠 top()。

> [!question] 练习题 3
> 给定 n 个整数，对每个元素求"下一个更大元素"的下标（不存在为 -1），要求 O(n)。
>
> 提示：维护一个存下标的单调栈，对应值从栈底到栈顶递减；新元素到来时，把所有 `a[top()] < a[i]` 的下标 pop 并填答案。
> 陷阱：栈中存的是下标而非值；循环结束后仍在栈里的下标，其答案保持 -1。
