STL 容器教程 — set & multiset (有序集合)
## ==========================================================================

## 本章概述

`set` 是基于**红黑树**的集合容器：它只存 **元素本身（就是 key），没有 value**，按 **key 自动升序排列**，元素唯一。插入、查找、删除都是 O(log n)。可以把它理解为"有序版的 unordered_set"——既去重又排序，还支持 `lower_bound` / `upper_bound` 找前驱后继。`multiset` 与 set 几乎相同，但**允许重复元素**。

本章采用手把手渐进式教学，每一步只提示该用哪个函数、要避开哪些陷阱，**代码请自己动手敲**，敲完编译看输出。

> 底层数据结构详解：红黑树的旋转、变色、平衡维护等原理见 [[数据结构/E_红黑树_RedBlackTree]]。本章侧重容器使用。

## --------------------------------------------------------------------------
### 适用场景与优劣分析
## --------------------------------------------------------------------------

| 优点 | 缺点 |
|:------|:------|
| 同时完成去重与排序，遍历自动升序 | 单次操作 O(log n)，比哈希表 O(1) 慢 |
| 支持 lower_bound / upper_bound，可找前驱后继 | 红黑树节点有指针开销，缓存不友好 |
| 最坏复杂度稳定 O(log n)，不会被卡 | 元素必须可比较（需 `<` 或比较器） |
| 迭代器在插入/删除后仍有效（除被删者外） | 只存单值，需键值对时要用 map |

**适用场景：**

| 场景 | 说明 |
|:------|:------|
| 去重 + 有序遍历 | 一步完成去重和排序 |
| 找前驱/后继 | lower_bound / upper_bound 求小于/大于某值的最近元素 |
| 动态维护有序集合 | 边插入边查询第 K 小、范围内元素 |
| 模拟平衡树 | 大部分平衡树操作 set 都能胜任 |

**set vs unordered_set：**

| | set | unordered_set |
|:----|:-----|:---------------|
| 底层 | 红黑树 | 哈希表 |
| 插入/查找 | O(log n) | O(1) 均摊 |
| 有序 | 是（升序） | 否 |
| 范围查询 | 支持 lower_bound/upper_bound | 不支持 |
| 内存 | 较小 | 较大 |

**选 set**：需要有序遍历或前驱后继查询。
**选 unordered_set**：纯判重不要顺序，追求 O(1)（见 [[容器类/11_unordered_set_multiset]]）。

> 重点提醒：`set` 没有 `operator[]`，因为它只存值没有 value。判断存在用 `count` / `find` / `contains`。

## --------------------------------------------------------------------------
### 第一步：创建容器
## --------------------------------------------------------------------------

> 自己动手 1
> - 包含头文件 `<set>`。
> - 声明一个存 `int` 的空集合，例如 `std::set<int> s;`。
> - 想要降序时可写 `std::set<int, std::greater<int>> s2;`。
> - 陷阱：自定义类型作元素时必须能比较——重载 `operator<` 或提供比较器。

## --------------------------------------------------------------------------
### 第二步：size() 与 empty()
## --------------------------------------------------------------------------

| 函数 | 作用 | 返回值 |
|:------|:------|:------|
| `size()` | 返回元素数量 | `size_t` |
| `empty()` | 判断是否为空 | `bool` |

> 自己动手 2
> - 对空集合调用 `s.size()`（应为 0）和 `s.empty()`（应为 true）。

## --------------------------------------------------------------------------
### 第三步：插入元素（多种方式对比）
## --------------------------------------------------------------------------

set 自动去重，**重复插入同一值不会增加元素**。

| 方式 | 写法 | 返回值 | 特点 |
|:------|:------|:------|:------|
| `insert(x)` | `s.insert(42)` | `pair<iterator, bool>` | 最常用，`bool` 表示是否插入成功（已存在则 false） |
| `emplace(x)` | `s.emplace(42)` | `pair<iterator, bool>` | 原位构造，避免临时对象，C++11 |

> 自己动手 3
> - 用 `insert()` 插入 `42`、`7`，用 `emplace()` 插入 `100`。
> - 再 `insert(42)` 一次，接住返回值的 `.second`，观察为 `false`（去重）。
> - 打印 `size()`，应为 3。
> - 陷阱：去重后 `42` 只保留一份；没有 `operator[]`，别想着 `s[42] = ...`。

## --------------------------------------------------------------------------
### 第四步：判断元素是否存在
## --------------------------------------------------------------------------

| 函数 | 作用 | 注意 |
|:------|:------|:------|
| `count(x)` | 元素出现次数（set 中 0 或 1） | 不会插入新元素 |
| `contains(x)` | C++20 直接返回 `bool` | 最直观 |
| `find(x)` | 返回迭代器 / `end()` | 找到后还能继续操作 |

> 自己动手 4
> - 用 `s.count(42)` 判断存在（应为 1），`s.count(999)` 判断不存在（应为 0）。
> - 陷阱：set 没有 `operator[]`，不能用 `s[x]` 判断存在。

## --------------------------------------------------------------------------
### 第五步：访问/读取（find 取值）
## --------------------------------------------------------------------------

| 查找方式 | 语法 | 返回 | 适用 |
|:------|:------|:------|:------|
| `count(x)` | `s.count(x)` | 0 或 1 | 只想知道在不在 |
| `find(x)` | `s.find(x)` | 迭代器 / `end()` | 找到后还要操作（如删除） |

> 自己动手 5
> - 用 `auto it = s.find(100);`，判断 `it != s.end()` 后用 `*it` 取出元素值。
> - 重点：set 的元素就是值本身，用 `*it` 取出，**不是** `it->second`（那是 map 的写法）。
> - 陷阱：对不存在的值 `find` 返回 `end()`，解引用 `end()` 是未定义行为，务必先判断。

## --------------------------------------------------------------------------
### 第六步：修改元素（为什么不能直接改）
## --------------------------------------------------------------------------

set 的元素是 **const（只读）** 的，不能通过迭代器修改（`*it = 8;` 会编译报错）。

**原因**：元素的值就是它在红黑树中的排序依据。如果允许直接改值，就会破坏有序性，整棵树就乱了。

正确的"修改"方式是：**删除旧值 + 插入新值**。

> 自己动手 6
> - 想把 `7` 改成 `8`：先 `s.erase(7)`，再 `s.insert(8)`。
> - 用 `count` 验证：`s.count(8)` 应为 1，`s.count(7)` 应为 0。
> - 陷阱：不要尝试 `*it = 新值`，元素是 const 改不了。

## --------------------------------------------------------------------------
### 第七步：删除元素
## --------------------------------------------------------------------------

| 删除方式 | 写法 | 返回 | 说明 |
|:------|:------|:------|:------|
| 按值删除 | `s.erase(x)` | 删除个数（0 或 1） | 删不存在的值返回 0，安全 |
| 按迭代器删除 | `s.erase(it)` | 下一个迭代器 | 需先 `find` |
| 按区间删除 | `s.erase(first, last)` | 下一个迭代器 | 删除 `[first, last)` |

> 自己动手 7
> - 用 `s.erase(100)` 按值删除，接住返回值看是否删成功。
> - 用 `find` 拿到 `42` 的迭代器后用 `s.erase(it)` 删除。
> - 陷阱：`erase(it)` 后 `it` 失效；遍历删除要用返回的新迭代器（`it = s.erase(it);`）。

## --------------------------------------------------------------------------
### 第八步：遍历（多种方式 + 对比 + 推荐）
## --------------------------------------------------------------------------

set 遍历**保证按 key 升序**——这是与 unordered_set 的核心差异。

| 方式 | 写法 | 性能 | 推荐度 |
|:------|:------|:------|:------|
| `const auto&` | `for (const auto& x : s)` | 零拷贝 | 最推荐（元素本就只读） |
| 迭代器 | `for (auto it = s.begin(); it != s.end(); ++it)` 用 `*it` | 零拷贝 | 需边遍历边删除时 |
| 反向遍历 | `for (auto it = s.rbegin(); it != s.rend(); ++it)` | 零拷贝 | 需降序输出时 |
| `auto` 值拷贝 | `for (auto x : s)` | 每次拷贝 | int 等小类型可用，大对象不推荐 |

**推荐**：日常遍历用 `const auto& x`，需降序用反向迭代器，边遍历边删用正向迭代器。

> 自己动手 8
> - 插入若干乱序值（如先 30 再 10 再 20），用 `for (const auto& x : s)` 遍历打印。
> - 重点：观察输出一定是升序（10,20,30），无论插入顺序——这是 set 有序的体现。
> - set 元素全是 const，不存在"用 `auto&` 改值"的写法。

## --------------------------------------------------------------------------
### 第九步：清空容器
## --------------------------------------------------------------------------

> 自己动手 9
> - 用 `s.clear()` 清空，再用 `size()`（0）和 `empty()`（true）验证。

## --------------------------------------------------------------------------
### 特色操作：lower_bound / upper_bound 找前驱后继
## --------------------------------------------------------------------------

因为 set 有序，可以高效查找前驱（小于 x 的最大元素）和后继（大于 x 的最小元素）。

| 函数 | 作用 | 返回 |
|:------|:------|:------|
| `lower_bound(x)` | 第一个 **≥ x** 的迭代器 | 迭代器 / `end()` |
| `upper_bound(x)` | 第一个 **> x** 的迭代器 | 迭代器 / `end()` |
| `equal_range(x)` | 返回 `pair<lower_bound, upper_bound>` | pair |

> 自己动手（重要）
> - 在含 {1,3,5,7,9} 的 set 中，用 `s.lower_bound(4)` 找第一个 ≥ 4 的元素（应指向 5）。
> - 求"前驱"（小于 x 的最大值）：`prev(s.lower_bound(x))`，注意先判断不是 `begin()`。
> - 求"后继"（大于 x 的最小值）：`s.upper_bound(x)`，注意判断不是 `end()`。
> - 陷阱：`lower_bound` 是 ≥（含等于），`upper_bound` 是 >（不含等于），别记反。

## --------------------------------------------------------------------------
### 补充：multiset（允许重复元素）
## --------------------------------------------------------------------------

| | `set` | `multiset` |
|:-----|:-------|:-------|
| 元素唯一性 | 唯一（去重） | 允许重复 |
| `count(x)` | 0 或 1 | 可大于 1 |
| `erase(x)` | 删 0 或 1 个 | **删除所有**等于 x 的元素 |
| 只删一个重复值 | 不适用 | `erase(find(x))` |

> 自己动手（选做）
> - 创建 `multiset<int> ms;`，插入两个 `5` 和一个 `8`，用 `ms.count(5)` 验证为 2。
> - 陷阱：`erase(5)` 会删掉所有的 `5`；只想删一个用 `erase(find(5))`。

### 动手练习题

> [!question] 练习题 1
> **题目**: 输入 n 个整数，使用 set 去重并按升序输出，同时输出去除了多少个重复元素。
>
> **输入示例**:
> ```
> 8
> 3 1 4 1 5 9 2 6
> ```
> **输出示例**:
> ```
> 去重后: 1 2 3 4 5 6 9
> 去除了 1 个重复元素
> ```

> [!question] 练习题 2
> **题目**: 给定一个有序集合和 q 次查询，每次查询一个数 x，输出集合中 x 的前驱（小于 x 的最大值）和后继（大于 x 的最小值）。不存在则输出 "NONE"。使用 set 的 lower_bound / upper_bound 实现。
>
> **输入示例**:
> ```
> 5
> 1 3 5 7 9
> 3
> 4
> 1
> 10
> ```
> **输出示例**:
> ```
> 前驱:3 后继:5
> 前驱:NONE 后继:3
> 前驱:9 后继:NONE
> ```

> [!question] 练习题 3
> **题目**: 使用 multiset 模拟一个动态数据流，支持三种操作：1) 插入一个数；2) 删除一个数（只删一个）；3) 输出当前最小值和最大值。
>
> **输入示例**:
> ```
> 7
> 1 5
> 1 3
> 1 8
> 3
> 2 3
> 3
> 1 1
> ```
> **输出示例**:
> ```
> min=3 max=8
> min=5 max=8
> ```
