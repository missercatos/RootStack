## ==========================================================================
STL 容器教程 — unordered_map & unordered_multimap (无序映射)
## ==========================================================================

## 本章概述

`unordered_map` 是基于**哈希表**的键值对容器，平均 O(1) 插入、查找、删除。
本章采用**手把手渐进式教学**——每一步都让你自己动手写代码、看输出，
逐步从"创建第一对键值对"到"掌握全部操作"。

> 底层数据结构详解：哈希表的冲突解决、负载因子、再哈希等底层原理见 [[数据结构/G_哈希表_HashTable]]。

## --------------------------------------------------------------------------
### 适用场景与优劣分析
## --------------------------------------------------------------------------

**优点：**
- 平均 O(1) 插入/查找/删除——比 map 的 O(log n) 更快
- key 无序，适合"只存不管顺序"的需求
- 支持自定义类型作为 key（需提供哈希函数和 `==` 运算符）

**缺点：**
- 内存占用比 map 大（桶数组有多余空间）
- 遍历顺序不固定（与插入顺序无关）
- 不支持范围查询（`lower_bound` 等有序操作）
- 最坏情况退化为 O(n)（全部 key 哈希到同一桶）

**选择建议：**

| 需求              | 选容器                                                  |
| :-------------- | :--------------------------------------------------- |
| 快速查找，不关心顺序      | `unordered_map`                                      |
| 需要按 key 排序遍历    | `map`（见 [[容器类/10_map_multimap]]）                     |
| 只需存 key 无 value | `unordered_set`（见 [[容器类/11_unordered_set_multiset]]） |
| 允许重复 key        | `unordered_multimap`                                 |

## --------------------------------------------------------------------------
### 第一步：头文件与第一个键值对
## --------------------------------------------------------------------------

`unordered_map` 是一个**键值对集合**——每个元素由一个 key（键）和一个 value（值）组成。
就像字典：key 是生词，value 是释义。`std::pair` 是键值对的基本存储单元。关于 pair 的完整用法见 [[容器类/01_pair]]。

**自己动手**：创建一个 cpp 文件，声明一个 `unordered_map`（建议 key 用 string，value 用 int），
用 `operator[]` 插入第一对键值对，然后用 `size()` 和 `empty()` 查看容器状态。

> 提示：头文件是 `<unordered_map>`，`size()` 返回元素个数，`empty()` 返回是否为空。

## --------------------------------------------------------------------------
### 第二步：三种插入键值对的方式
## --------------------------------------------------------------------------

`unordered_map` 支持三种插入方式，各有特点：

| 方式 | 语法 | key 已存在时 | 推荐场景 |
|:------|:------|:------|:------|
| `operator[]` | `dict[k] = v` | 覆盖 | 需要覆盖，或"存在就改、不存在就建" |
| `insert()` | `dict.insert({k, v})` | 不插入，返回 `pair<it, bool>` | 仅不存在时插入，需要知道是否成功 |
| `emplace()` | `dict.emplace(k, v)` | 不插入 | 最高效，原位构造避免临时对象 (C++11) |

**自己动手**：对你的 `unordered_map` 分别用三种方式插入数据，每次插入后打印 `size()`。
其中 `insert()` 请用 `auto [it, ok]` 接收返回值并打印插入是否成功。

> 注意：`operator[]` 会覆盖已有 key 的值；`insert` 和 `emplace` 不会。

## --------------------------------------------------------------------------
### 第三步：判断 key 是否存在
## --------------------------------------------------------------------------

| 函数 | 作用 | 注意 |
|:------|:------|:------|
| `count(k)` | key 出现次数（map 中 0 或 1） | 不会插入新元素 |
| `contains(k)` | C++20 新增，相当于 count > 0 | 更直观 |

**自己动手**：用 `count()` 检查一个存在的 key 和一个不存在的 key，打印结果。
然后试试用 `dict["不存在的key"]` 会发生什么——再看 `size()` 的变化。

> 关键：`operator[]` 访问不存在的 key 时会**自动插入**默认值，所以不能用它来判断存在性。

## --------------------------------------------------------------------------
### 第四步：三种访问/读取方式
## --------------------------------------------------------------------------

| 方式 | 语法 | 不存在时 | 推荐场景 |
|:------|:------|:------|:------|
| `operator[]` | `dict[k]` | 插入默认值 | 确认 key 存在，或"不存在就创建" |
| `at()` | `dict.at(k)` | 抛 `std::out_of_range` 异常 | 必须存在，不存在视为 bug |
| `find()` | `dict.find(k)` | 返回 `end()` | 最安全，无副作用，推荐 |

**自己动手**：分别用三种方式读取同一个 key 的值。对 `find()`，请判断迭代器是否等于 `end()`，
如果不是则通过 `it->first` 和 `it->second` 输出 key 和 value。

## --------------------------------------------------------------------------
### 第五步：修改与删除
## --------------------------------------------------------------------------

**自己动手 — 修改**：用 `operator[]` 修改一个已有 key 的 value；然后试试通过 `find()` 拿到迭代器后修改 `it->second`；
最后试用 C++17 的 `insert_or_assign()` 覆盖一个已有 key 的值。打印 `size()` 确认没变多。

**自己动手 — 删除**：用 `erase(key)` 删除一个元素，打印返回值（删除的个数）和删除后的 `size()`。
再用 `find()` + `erase(it)` 删除另一个元素。注意 `erase(it)` 后该迭代器立即失效。

## --------------------------------------------------------------------------
### 第六步：遍历 — 四种方式对比
## --------------------------------------------------------------------------

| 方式 | 写法 | 性能 | 可修改 value | 推荐 |
|:------|:------|:------|:------|:------|
| `auto& [k, v]` (C++17) | 结构化绑定 | 零拷贝 | 可 | 最推荐 |
| 迭代器 | `it->first` / `it->second` | 零拷贝 | 可 | 需要删除当前元素时 |
| `const auto&` | `kv.first` / `kv.second` | 零拷贝 | 不可 | 只读遍历 |
| `auto` (值拷贝) | 拷贝 pair | 每次拷贝 | 改副本无效 | 不推荐 |

**自己动手**：用上述四种方式遍历你的容器。观察输出顺序——注意 `unordered_map` 的遍历顺序**不保证与插入顺序一致**，
取决于哈希值和桶分布。再尝试只遍历 value > 某个阈值的键值对（在循环中加 `if` 判断）。

## --------------------------------------------------------------------------
### 第七步：自定义 key 类型
## --------------------------------------------------------------------------

如果 key 是自定义类型（如结构体），必须提供哈希函数和 `==` 运算符。

**自己动手**：定义一个结构体 `struct Point { int x, y; };`，实现 `operator==`，
定义一个哈希函数对象 `struct PointHash { size_t operator()(const Point& p) const; }`（提示：`x * 131 + y`），
然后创建 `unordered_map<Point, string, PointHash>`，插入几对数据并遍历。

## --------------------------------------------------------------------------
### 补充：unordered_multimap（允许重复 key）
## --------------------------------------------------------------------------

| | `unordered_map` | `unordered_multimap` |
|:-----|:-------|:-------|
| key 唯一性 | key 唯一 | 允许重复 key |
| `operator[]` | 支持 | 不支持 |
| `count(k)` | 0 或 1 | 可大于 1 |
| 相同 key 的遍历 | — | 用 `equal_range(k)` |

**自己动手**：创建 `unordered_multimap<string, int>`，对同一个 key 插入两个不同的 value，
用 `count()` 查看数量，用 `equal_range()` 遍历该 key 的所有 value。

### 动手练习题

> [!question] 练习题 1：频率统计
> **题目**: 读取一行英文句子，统计每个单词的出现次数（不区分大小写），输出单词和次数。
> 
> **输入示例**:
> ```
> hello world hello cpp world world
> ```
> **预期输出**:
> ```
> hello: 2
> world: 3
> cpp: 1
> ```

> [!question] 练习题 2：第一个不重复字符
> **题目**: 给定字符串，找到第一个只出现一次的字符并输出其位置（下标从 0 开始），没有则输出 -1。
> 要求：用 unordered_map 统计频率，只遍历两遍。
>
> **输入示例**:
> ```
> leetcode
> ```
> **预期输出**:
> ```
> l (下标 0)
> ```

> [!question] 练习题 3：字母异位词分组
> **题目**: 给定 n 个字符串，将字母异位词（相同字母不同排列）分为一组输出。
> 提示：用排序后的字符串作为 key。
>
> **输入示例**:
> ```
> 6
> eat tea tan ate nat bat
> ```
> **预期输出**:
> ```
> eat tea ate
> tan nat
> bat
> ```
