## ==========================================================================
STL 容器教程 — vector (动态数组)
## ==========================================================================

## 本章概述

`vector` 是 C++ 最常用的容器，本质是一个能自动扩容的**动态数组**。
本章采用手把手渐进式教学，每一步让你自己写代码、看输出。

底层是一段连续内存。当 `push_back` 时若 `size == capacity`，vector 会申请更大内存（通常翻倍），把旧元素整体搬迁过去，再释放旧内存。扩容瞬间所有指向旧内存的迭代器、指针、引用全部失效。

> 头文件：`#include <vector>`。

## --------------------------------------------------------------------------
### 适用场景与优劣分析
## --------------------------------------------------------------------------

| 优点 | 缺点 |
|:------|:------|
| O(1) 随机访问（`operator[]`），缓存友好 | 头部/中间插入删除为 O(n)（要移动后续元素） |
| 尾部插入均摊 O(1)，自动扩容 | 扩容时整体搬迁，迭代器/指针失效 |
| 自动管理内存，无需手动 new/delete | capacity 可能大于 size，存在内存浪费 |
| 与 sort/二分等 STL 算法无缝配合 | 频繁扩容有拷贝开销，需 reserve 优化 |

| 场景 | 说明 |
|:------|:------|
| 替代 C 风格数组 | 不确定数据量时，vector 自动扩容 |
| 邻接表存图 | `vector<int> g[N]` 存每个顶点的邻居 |
| 动态规划临时空间 | `vector<int> dp(n+1)`，长度运行时确定 |
| 批量排序/二分 | 配合 `sort()`、`lower_bound()` 等算法 |
| 二维矩阵 | `vector<vector<int>> mat(n, vector<int>(m))` |

## --------------------------------------------------------------------------
### 第一步：创建 vector
## --------------------------------------------------------------------------

**自己动手**：创建以下几种 vector，然后用 `size()` 和 `empty()` 查看状态：
- 空 vector（默认构造）
- 指定大小的 vector（如 `vector<int> v(5)`）
- 指定大小和初始值的 vector（如 `vector<int> v(5, 100)`）
- 用初始化列表创建（如 `vector<int> v{1,2,3,4,5}`）
- 从另一个 vector 拷贝构造

> 提示：`size()` 返回元素个数，`empty()` 返回是否为空。和 string 一样。

## --------------------------------------------------------------------------
### 第二步：尾部插入 —— push_back vs emplace_back
## --------------------------------------------------------------------------

| 方式 | 语法 | 开销 | 推荐 |
|:------|:------|:------|:------|
| `push_back()` | `v.push_back(x)` | 先构造临时对象，再拷贝/移动到容器 | 老代码常用 |
| `emplace_back()` | `v.emplace_back(args...)` | 直接在容器内构造，省掉临时对象 | 推荐 (C++11) |

**自己动手**：对一个空 vector 依次 push_back 几个整数，每次插入后打印 `size()`。
再试试 emplace_back 的效果。

> 核心原则：能用 `emplace_back` 就不用 `push_back`。

## --------------------------------------------------------------------------
### 第三步：随机访问 —— operator[] vs at()
## --------------------------------------------------------------------------

| 方式 | 语法 | 越界时 | 推荐 |
|:------|:------|:------|:------|
| `operator[]` | `v[i]` | 未定义行为 | 确信不会越界时 |
| `at()` | `v.at(i)` | 抛出 `std::out_of_range` | 需要边界检查时 |
| `front()` | `v.front()` | 空 vector 时未定义行为 | 访问首元素 |
| `back()` | `v.back()` | 空 vector 时未定义行为 | 访问尾元素 |
| `data()` | `v.data()` | 返回底层数组指针 | 需要传给 C 接口时 |

**自己动手**：用 `operator[]` 循环访问并打印所有元素。然后故意写一个越界的下标记试 `at()`——观察异常提示。

## --------------------------------------------------------------------------
### 第四步：size vs capacity —— 性能关键
## --------------------------------------------------------------------------

这是 vector 最容易误解的两个概念：

| 函数 | 含义 | 示例值 |
|:------|:------|:------|
| `size()` | 当前实际存放的元素个数 | 5 |
| `capacity()` | 已分配内存能容纳的元素个数 | 8 |

**自己动手**：创建一个空 vector，循环 push_back 20 个元素，每次插入后打印 `size()` 和 `capacity()`。
观察 capacity 是否在 size 追上它时跳跃增长（通常 1→2→4→8→16→32 等翻倍模式）。

| 函数 | 作用 |
|:------|:------|
| `reserve(n)` | 预分配至少 n 个元素的容量，避免多次扩容 |
| `resize(n)` | 改变 size 为 n（超出的截断，不足的用默认值填充） |
| `shrink_to_fit()` | 请求释放多余容量（编译器可选实现） |

**自己动手**：用 `reserve(100)` 预分配容量后，再 push_back 100 个元素——观察 capacity 是否一直保持 100 不变。
再试试 `resize(3)` 把一个有 10 个元素的 vector 截断为 3 个。

## --------------------------------------------------------------------------
### 第五步：中间插入与删除（O(n)，慎用）
## --------------------------------------------------------------------------

**自己动手**：
- 用 `insert(it, value)` 在 vector 中间插入一个元素（用 `begin() + N` 定位），打印 `size()`
- 用 `erase(it)` 删除中间某个元素，再打印 `size()`
- 用 `pop_back()` 删除最后一个元素
- 尝试用 `erase(begin, end)` 范围删除一段元素

> 注意：insert 和 erase 在 O(n) 时间（需要移动后续所有元素）。频繁在中间操作应该考虑 `list`（见 [[容器类/08_list_forward_list]]）。

## --------------------------------------------------------------------------
### 第六步：遍历 —— 五种方式对比
## --------------------------------------------------------------------------

| 方式 | 写法 | 性能 | 可修改 | 推荐 |
|:------|:------|:------|:------|:------|
| 索引 | `for (int i = 0; i < v.size(); i++)` | 无额外开销 | 可 | 需要下标时 |
| auto& | `for (auto& x : v)` | 零拷贝 | 可 | 最推荐，简洁 |
| const auto& | `for (const auto& x : v)` | 零拷贝 | 不可 | 只读遍历 |
| 迭代器 | `for (auto it = v.begin(); it != v.end(); ++it)` | 零拷贝 | 可 | 需要删除当前元素时 |
| auto (值拷贝) | `for (auto x : v)` | 每次拷贝 | 改副本无效 | 不推荐 |

**自己动手**：用五种方式遍历同一个 vector 并打印元素。比较哪种最简洁。

## --------------------------------------------------------------------------
### 第七步：其他常用操作
## --------------------------------------------------------------------------

**自己动手**：
- 用 `clear()` 清空所有元素，再打印 `size()` 和 `capacity()`（注意：clear 后 capacity 不变）
- 用 `v.empty()` 判断是否为空
- 用 `v1 == v2` 比较两个 vector 是否完全相同
- 用 `v1 = v2` 赋值拷贝
- 用 `sort(v.begin(), v.end())` 排序，然后用 `unique` + `erase` 去重
- 二维 vector：`vector<vector<int>> mat(3, vector<int>(4, 0))` 创建 3x4 矩阵

> **题目**: 读取 n 个整数存入 vector，然后输出倒序（从最后一个到第一个）。
