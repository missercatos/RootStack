## ==========================================================================
STL 容器速通 — vector (动态数组)
## ==========================================================================

vector 是 C++ 最常用的容器，底层是连续内存的数组，支持 O(1) 随机访问和尾部增删。

## --------------------------------------------------------------------------
## 一、适用场景
## --------------------------------------------------------------------------

| 场景 | 说明 |
|------|------|
| 替代 C 风格数组 | 不知道数据量时，vector 自动扩容 |
| 邻接表存图 | `vector<int> g[N]` 存每个顶点的邻居 |
| 动态规划临时空间 | `vector<int> dp(n+1)` — 长度运行时确定 |
| 批量排序/二分 | 配合 `sort()`, `lower_bound()` 等 STL 算法 |
| 二维矩阵 | `vector<vector<int>> mat(n, vector<int>(m))` |

## --------------------------------------------------------------------------
## 二、声明与初始化
## --------------------------------------------------------------------------

```cpp
#include <vector>
using namespace std;

vector<int> v1;                     // 空 vector
vector<int> v2(10);                 // 10 个元素，值默认 0
vector<int> v3(10, 5);              // 10 个元素，值全为 5
vector<int> v4 = {1, 2, 3, 4};      // 列表初始化
vector<int> v5(v4);                 // 拷贝构造
vector<int> v6(v4.begin(), v4.end()); // 迭代器范围构造
vector<vector<int>> mat(3, vector<int>(4, -1)); // 3行4列，初始值为-1
```

## --------------------------------------------------------------------------
## 三、成员函数总览
## --------------------------------------------------------------------------

### 容量 (Capacity)

| 函数 | 说明 |
|------|------|
| `v.size()` | 返回元素个数 O(1) |
| `v.empty()` | 返回是否为空 O(1) |
| `v.capacity()` | 返回已分配内存能容纳的元素数 |
| `v.resize(n)` | 调整大小为 n，多则删，少则默认补 0 |
| `v.resize(n, val)` | 调整大小，多者以 val 填充 |
| `v.reserve(n)` | 预留至少 n 个元素的内存（不改变 size） |
| `v.shrink_to_fit()` | 请求释放多余内存 (C++11) |

### 元素访问 (Element Access)

| 函数 | 说明 |
|------|------|
| `v[i]` | 下标访问，不检查越界 |
| `v.at(i)` | 下标访问，越界抛出 `std::out_of_range` |
| `v.front()` | 返回第一个元素 |
| `v.back()` | 返回最后一个元素 |
| `v.data()` | 返回底层数组指针 |

### 修改 (Modifiers)

| 函数 | 说明 |
|------|------|
| `v.push_back(x)` | 尾部添加元素 |
| `v.pop_back()` | 删除尾部元素 |
| `v.insert(pos, x)` | 在 pos 位置插入 x |
| `v.insert(pos, n, x)` | 在 pos 位置插入 n 个 x |
| `v.insert(pos, first, last)` | 插入迭代器范围 |
| `v.erase(pos)` | 删除 pos 位置的元素 |
| `v.erase(first, last)` | 删除 [first, last) 区间 |
| `v.clear()` | 清空所有元素 |
| `v.emplace_back(args...)` | 尾部原位构造元素 (C++11) |
| `v.emplace(pos, args...)` | 指定位置原位构造 (C++11) |

### 迭代器

| `v.begin()` / `v.end()` | 正向迭代器 |
| `v.rbegin()` / `v.rend()` | 反向迭代器 |

## 四、洛谷实战
## --------------------------------------------------------------------------

### P1046 陶陶摘苹果

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> h(10);
    for (int i = 0; i < 10; i++) cin >> h[i];
    int reach, cnt = 0;
    cin >> reach;
    reach += 30;
    for (int x : h)
        if (x <= reach) cnt++;
    cout << cnt << endl;
    return 0;
}
```

### P1047 校门外的树

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int L, M;
    cin >> L >> M;
    vector<bool> tree(L + 1, true);
    for (int i = 0; i < M; i++) {
        int u, v;
        cin >> u >> v;
        for (int j = u; j <= v; j++)
            tree[j] = false;
    }
    int cnt = 0;
    for (bool t : tree)
        if (t) cnt++;
    cout << cnt << endl;
    return 0;
}
```

### P1177 快速排序

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    sort(a.begin(), a.end());
    for (int x : a) cout << x << " ";
    return 0;
}
```

> [!question] 判断题 3
> `push_back()` 的均摊时间复杂度是 O(1)。 （ ）
> - [ ] ✅ 正确
> - [ ] ❌ 错误
>
> > [!success]- 点击查看答案
> > 答案: 正确
> > 
> > **解析**: 虽然扩容时需要 O(n) 拷贝，但由于每次扩容容量翻倍，均摊下来每次 push_back 是 O(1)。

> [!question] 判断题 4
> `v.size()` 和 `v.capacity()` 返回的值始终相等。 （ ）
> - [ ] ✅ 正确
> - [ ] ❌ 错误
>
> > [!success]- 点击查看答案
> > 答案: 错误
> > 
> > **解析**: `size()` 是当前元素个数，`capacity()` 是已分配内存能容纳的元素数。capacity >= size。

> [!question] 判断题 5
> 在 vector 中间插入元素的时间复杂度是 O(n)。 （ ）
> - [ ] ✅ 正确
> - [ ] ❌ 错误
>
> > [!success]- 点击查看答案
> > 答案: 正确
> > 
> > **解析**: 中间插入需要将后面的元素逐个后移，时间复杂度为 O(n)。

> [!question] 判断题 6
> `v[i]` 和 `v.at(i)` 的唯一区别是后者会进行越界检查。 （ ）
> - [ ] ✅ 正确
> - [ ] ❌ 错误
>
> > [!success]- 点击查看答案
> > 答案: 正确
> > 
> > **解析**: `v[i]` 不检查越界，`v.at(i)` 越界时抛出 `std::out_of_range` 异常。

> [!question] 判断题 7
> `v.reserve(100)` 会改变 vector 的 size。 （ ）
> - [ ] ✅ 正确
> - [ ] ❌ 错误
>
> > [!success]- 点击查看答案
> > 答案: 错误
> > 
> > **解析**: `reserve` 只预留内存（改变 capacity），不改变 size。`resize` 才改变 size。

> [!question] 判断题 8
> vector 扩容时通常将容量扩大为原来的 2 倍。 （ ）
> - [ ] ✅ 正确
> - [ ] ❌ 错误
>
> > [!success]- 点击查看答案
> > 答案: 正确
> > 
> > **解析**: 多数实现中 vector 扩容为原来的 2 倍（GCC）或 1.5 倍（MSVC），以保证均摊 O(1)。

> [!question] 判断题 9
> `emplace_back` 比 `push_back` 总是更高效。 （ ）
> - [ ] ✅ 正确
> - [ ] ❌ 错误
>
> > [!success]- 点击查看答案
> > 答案: 错误
> > 
> > **解析**: 对于基本类型和已有对象，两者效率相当。emplace_back 的优势在于可以原位构造，避免临时对象的拷贝/移动。

> [!question] 判断题 10
> `v.clear()` 会释放 vector 占用的内存。 （ ）
> - [ ] ✅ 正确
> - [ ] ❌ 错误
>
> > [!success]- 点击查看答案
> > 答案: 错误
> > 
> > **解析**: `clear()` 只清空元素（size 变 0），不释放内存（capacity 不变）。要释放内存需用 `shrink_to_fit()` 或交换技巧。

> [!question] 选择题 10
> 以下哪种方法可以真正释放 vector 占用的内存？
> - [ ] A. `v.clear();`
> - [ ] B. `v.resize(0);`
> - [ ] C. `vector<int>().swap(v);`
> - [ ] D. `v.reserve(0);`
