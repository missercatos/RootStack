STL 容器教程 — pair (键值对)
## ==========================================================================

## 本章概述

`std::pair` 是最简单的"容器"——它把两个值打包成一个整体。它是 `map`、`unordered_map` 等关联容器的基础元素类型。
严格来说 pair 不是传统容器（没有 size/empty/迭代器），但它是一切键值对容器的基石。

头文件：`#include <utility>`（但通常通过 `<map>` 或 `<unordered_map>` 间接引入即可）。

## --------------------------------------------------------------------------
### 适用场景与优劣分析
## --------------------------------------------------------------------------

| 优点 | 缺点 |
|:------|:------|
| 极轻量，仅两个成员的 struct | 只能存两个元素，不能动态增减 |
| 自带比较运算符（按字典序） | 没有迭代器，不能遍历"pair 内部" |
| C++17 结构化绑定支持 | first/second 名字不够语义化（可用 struct 替代） |
| 函数多返回值的经典方案 | 嵌套 pair 可读性差（如 `pair<int, pair<int,int>>`） |

| 场景 | 说明 |
|:------|:------|
| 函数多返回值 | 一个函数返回两个不同类型的值 |
| map/unordered_map 的存储单元 | `map<K,V>::value_type` 就是 `pair<const K, V>` |
| 优先队列中存储优先级+数据 | `priority_queue<pair<int, string>>` |
| 临时打包 | 需要把两个数据当作一个整体传递时 |

## --------------------------------------------------------------------------
### 第一步：创建 pair
## --------------------------------------------------------------------------

**自己动手**：用以下三种方式创建 pair，然后用 `.first` 和 `.second` 输出：
- `pair<string, int> p1("apple", 5);` —— 直接构造
- `auto p2 = make_pair("banana", 3);` —— make_pair 工厂函数
- `pair<string, int> p3{"cherry", 7};` —— C++11 初始化列表

> 提示：C++17 起推荐直接用花括号：`auto p = pair{"orange", 2};`（CTAD 自动推导）。

## --------------------------------------------------------------------------
### 第二步：访问和修改
## --------------------------------------------------------------------------

**自己动手**：
- 用 `.first` 和 `.second` 访问和修改 pair 的两个成员
- 尝试用 C++17 结构化绑定：`auto [key, value] = p;` 然后分别输出 key 和 value

> pair 的元素不叫 key/value——它们叫 first/second。只有在 map 的语境下，first 才扮演 key 的角色，second 扮演 value 的角色。

## --------------------------------------------------------------------------
### 第三步：pair 的比较
## --------------------------------------------------------------------------

pair 自带所有六个比较运算符（`==`, `!=`, `<`, `<=`, `>`, `>=`），按**字典序**比较：先比 first，first 相同再比 second。

**自己动手**：创建 `pair<int, int> a{1, 5}` 和 `pair<int, int> b{1, 3}`，比较 `a < b` 和 `a == b`，
预测并验证结果。

> 注意：如果 first 相等，则比较 second——所以 `{1, 5} > {1, 3}`。这是使 pair 能直接放入 `set<pair>` 或 `map<pair>` 的原因。

## --------------------------------------------------------------------------
### 第四步：pair 的常见用途
## --------------------------------------------------------------------------

**1. 函数返回多个值**

**自己动手**：写一个函数，接收一个整数数组，返回最小值和最大值（用 pair）。

```cpp
// 函数声明提示：
pair<int, int> findMinMax(const vector<int>& v);
// 调用方可以用 auto [minVal, maxVal] = findMinMax(vec);
```

**2. 在 map 中插入元素（insert 返回值）**

**自己动手**：创建一个 `map<string, int>`，用 `insert({"key", value})` 插入，用 `auto [it, ok] = map.insert(...)` 接收返回值。检查 `ok` 判断是否插入成功。

关于 map 的完整用法见 [[容器类/10_map_multimap]]。

**3. 在优先队列中存优先级**

**自己动手**：创建 `priority_queue<pair<int, string>>`（默认大顶堆，按 first 排序）。push 几对数据，用 top() 查看堆顶。

关于 priority_queue 的完整用法见 [[容器类/07_priority_queue]]。

### 动手练习题

> [!question] 练习题 1
> **题目**: 写一个函数，接收一个 vector 和一个目标值 target，返回 vector 中第一个等于 target 的元素的下标和一个 bool 表示是否找到。用 pair 返回。
>
> 提示：`pair<int, bool>` 或 `pair<size_t, bool>`，找不到时下标返回什么由你决定（如 -1 或 npos）。

> [!question] 练习题 2
> **题目**: 创建一个 `set<pair<int, int>>`，插入几个点坐标，(1,2), (3,1), (2,5), (1,1)，遍历输出观察排序顺序。
>
> 提示：观察输出判断是按什么顺序排列的（先 x 后 y 的字典序）。

> [!question] 练习题 3
> **题目**: 使用 `pair<int, string>` 在 priority_queue 中模拟一个"排队系统"——数字代表优先级（数字越小越优先），字符串代表名字。用 `greater` 实现小顶堆。
>
> 提示：`priority_queue<pair<int, string>, vector<pair<int, string>>, greater<>> pq;`
