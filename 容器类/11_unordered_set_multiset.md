## ==========================================================================
STL 容器教程 — unordered_set & unordered_multiset (无序集合)
## ==========================================================================

## 本章概述

`unordered_set` 是基于**哈希表**的集合容器：它只存 **key（值本身），没有 value**，自动**去重**，平均 O(1) 插入、查找、删除。可以把它理解为"去掉了 value 的 `unordered_map`"——只关心"这个元素在不在"，不关心它对应什么。

本章采用手把手渐进式教学，每一步只提示你该用哪个函数、要避开哪些陷阱，**代码请自己动手敲**，敲完编译看输出，逐步从"放进第一个元素"走到"掌握全部操作"。

> 底层数据结构详解：哈希表的冲突解决、负载因子、再哈希等原理见 [[数据结构/G_哈希表_HashTable]]。本章侧重容器使用，底层原理在数据结构章节深入讲解。

## --------------------------------------------------------------------------
### 适用场景与优劣分析
## --------------------------------------------------------------------------

| 优点 | 缺点 |
|:------|:------|
| 平均 O(1) 插入、查找、删除，判重极快 | 元素无序，遍历顺序不固定（与插入顺序无关） |
| 自动去重，重复插入同一值只保留一份 | 不支持范围查询（无 lower_bound / upper_bound） |
| 适合"判重""标记访问过"等只需集合语义的场景 | 内存占用比 set 大（桶数组有冗余空间） |
| 写法简洁，单值集合无需关心键值对 | 最坏退化为 O(n)（数据被构造成大量哈希冲突时） |

**适用场景：**

| 场景 | 说明 |
|:------|:------|
| 快速判重 | 判断某元素是否出现过，O(1) 完成 |
| 标记访问 | 图遍历、BFS/DFS 中记录访问过的节点 |
| 求交集/差集 | 用一个集合作查询表，O(1) 判断另一组数据是否命中 |
| 去重 | 一批数据去掉重复，不要求顺序时首选 |

**选择建议：**

| 需求 | 选容器 |
|:------|:------|
| 快速判重，不关心顺序 | `unordered_set` |
| 需要按值有序遍历 | `set`（见 [[容器类/09_set_multiset]]） |
| 需要存 key→value 键值对 | `unordered_map`（见 [[容器类/12_unordered_map_multimap]]） |
| 允许重复元素 | `unordered_multiset` |

> 重点提醒：`unordered_set` 没有 `operator[]`。它只有 key 没有 value，`s[x]` 这种写法毫无意义。判断元素是否存在请用 `count()` / `find()` / `contains()`。

## --------------------------------------------------------------------------
### 第一步：创建容器
## --------------------------------------------------------------------------

`unordered_set` 是一个**值的集合**，每个元素就是一个独立且互不重复的值，类似"会员名单"：只关心某人在不在名单上，名单没有顺序。

> 自己动手 1
> - 包含头文件 `<unordered_set>`。
> - 声明一个存放 `int` 的空集合，例如 `std::unordered_set<int> s;`。
> - 编译命令：`g++ -std=c++17 demo.cpp -o demo && ./demo`。
> - 陷阱：头文件是 `<unordered_set>`，不是 `<set>`，也没有 `<hash_set>`（那是已废弃的旧扩展）。

集合里的每个值既是元素也是 key，没有单独的 value。

## --------------------------------------------------------------------------
### 第二步：size() 与 empty()
## --------------------------------------------------------------------------

在继续之前，先学会用 `size()` 和 `empty()` 查看容器状态。后面每一步你都可以随时调用它们，跟踪元素数量变化。

| 函数 | 作用 | 返回值 |
|:------|:------|:------|
| `size()` | 返回当前元素数量 | `size_t`（无符号整数） |
| `empty()` | 判断容器是否为空 | `bool`：空为 `true`，非空为 `false` |

> 自己动手 2
> - 对刚创建的空集合调用 `s.size()` 和 `s.empty()`，打印结果，应分别是 `0` 和"空"。
> - 陷阱：`empty()` 返回的是 `bool`，直接 `cout` 会输出 `0/1`，想看中文可用三目运算符。

## --------------------------------------------------------------------------
### 第三步：插入元素（多种方式对比）
## --------------------------------------------------------------------------

`unordered_set` 主要有两种插入方式。注意：**重复插入同一个值不会增加元素**（自动去重）。

| 方式 | 写法 | 返回值 | 特点 |
|:------|:------|:------|:------|
| `insert(x)` | `s.insert(42)` | `pair<iterator, bool>` | 最常用，`bool` 表示是否插入成功（已存在则 false） |
| `emplace(x)` | `s.emplace(42)` | `pair<iterator, bool>` | 原位构造，避免临时对象，C++11 起 |

`insert` 返回的 pair 中，`first` 是指向该元素的迭代器，`second` 为 `true` 表示插入成功，`false` 表示元素已存在（被去重，未插入）。

> 自己动手 3
> - 用 `insert()` 插入 `42`、`7`，用 `emplace()` 插入 `100`。
> - 再用 `insert()` 插入一次 `42`，接住返回值（可用 C++17 结构化绑定 `auto [it, ok] = s.insert(42);`），打印 `ok` 观察去重。
> - 最后打印 `size()`，应为 `3`。
> - 陷阱：去重后 `42` 只保留一份；不要误以为插了两次就有两个。

## --------------------------------------------------------------------------
### 第四步：判断元素是否存在
## --------------------------------------------------------------------------

集合最常用的操作就是"判断某个值在不在"。

| 函数 | 作用 | 注意 |
|:------|:------|:------|
| `count(x)` | 元素出现次数（set 中只能是 0 或 1） | 不会插入新元素 |
| `contains(x)` | C++20 新增，直接返回 `bool` | 比 `count(x) > 0` 更直观 |

> 自己动手 4
> - 用 `s.count(42)` 判断 `42` 是否存在（应为 1），用 `s.count(999)` 判断不存在的值（应为 0）。
> - 若编译器支持 C++20，试试 `s.contains(42)`。
> - 陷阱：绝对不能用 `s[42]` 判断存在——没有 `operator[]`，编译都过不了。

## --------------------------------------------------------------------------
### 第五步：访问/读取（find 获取迭代器）
## --------------------------------------------------------------------------

当你"找到元素后还要做点什么"（比如紧接着删除它），就用 `find(x)`：返回指向该元素的迭代器，找不到返回 `end()`。

| 查找方式 | 语法 | 返回 | 适用 |
|:------|:------|:------|:------|
| `count(x)` | `s.count(x)` | 0 或 1 | 只想知道在不在 |
| `find(x)` | `s.find(x)` | 迭代器 / `end()` | 找到后还要操作（如删除） |

> 自己动手 5
> - 用 `auto it = s.find(100);`，判断 `it != s.end()`，成立时打印元素值。
> - 重点：set 的元素就是值本身，取值用 `*it`，**不是** `it->second`（那是 map 的写法）。
> - 陷阱：对不存在的值 `find` 返回 `end()`，解引用 `end()` 是未定义行为，务必先判断。

## --------------------------------------------------------------------------
### 第六步：修改元素（为什么不能直接改）
## --------------------------------------------------------------------------

`unordered_set` 的元素是 **const（只读）** 的，你不能通过迭代器修改它的值（`*it = 8;` 会编译报错）。

**原因**：元素的值就是它在哈希表中的"定位依据"（哈希值决定它落在哪个桶）。如果允许直接改值，它就会待在错误的桶里，整个哈希表就乱了。

正确的"修改"方式是：**删除旧值 + 插入新值**。

> 自己动手 6
> - 想把 `7` 改成 `8`：先 `s.erase(7)`，再 `s.insert(8)`。
> - 用 `count` 验证：`s.count(8)` 应为 1，`s.count(7)` 应为 0。
> - 陷阱：不要尝试 `*it = 新值`，元素是 const 改不了。

## --------------------------------------------------------------------------
### 第七步：删除元素
## --------------------------------------------------------------------------

| 删除方式 | 写法 | 返回 | 说明 |
|:------|:------|:------|:------|
| 按值删除 | `s.erase(x)` | 删除个数（0 或 1） | 安全，删不存在的值返回 0 不报错 |
| 按迭代器删除 | `s.erase(it)` | 下一个迭代器 | 需先 `find` 拿到 `it` |

> 自己动手 7
> - 用 `s.erase(100)` 按值删除，接住返回值看删了几个。
> - 用 `find` 拿到 `42` 的迭代器后用 `s.erase(it)` 删除。
> - 陷阱：`erase(it)` 之后 `it` 立即失效，不能再使用；删不存在的值用 `erase(x)` 是安全的（返回 0）。

## --------------------------------------------------------------------------
### 第八步：遍历（多种方式 + 对比 + 推荐）
## --------------------------------------------------------------------------

| 方式 | 写法 | 性能 | 推荐度 |
|:------|:------|:------|:------|
| `const auto&` | `for (const auto& x : s)` | 零拷贝 | 最推荐（元素本就只读） |
| 迭代器 | `for (auto it = s.begin(); it != s.end(); ++it)` 用 `*it` | 零拷贝 | 需在遍历中删除时使用 |
| `auto` 值拷贝 | `for (auto x : s)` | 每次拷贝 | int 等小类型可用，大对象不推荐 |

**推荐**：日常遍历用 `const auto& x`，零拷贝又安全。需要边遍历边删除时改用迭代器写法。

> 自己动手 8
> - 先 `clear()` 再插入 `10`、`20`、`30`，用 `for (const auto& x : s)` 打印。
> - 再用迭代器写法打印一次，对比结果。
> - 重点：`unordered_set` 遍历顺序**不保证**与插入顺序一致，取决于哈希值和桶分布。需要有序遍历请改用 `set`。
> - 陷阱：set 元素全是 const，不存在"用 `auto&` 改 value"的写法（那是 map 才有的）。

## --------------------------------------------------------------------------
### 补充：unordered_multiset（允许重复元素）
## --------------------------------------------------------------------------

`unordered_multiset` 与 `unordered_set` 用法几乎相同，唯一区别是**允许重复元素**：

| | `unordered_set` | `unordered_multiset` |
|:-----|:-------|:-------|
| 元素唯一性 | 唯一（去重） | 允许重复 |
| `count(x)` | 0 或 1 | 可大于 1 |
| `erase(x)` | 删 0 或 1 个 | **删除所有**等于 x 的元素 |
| 只删一个重复值 | 不适用 | `erase(find(x))` |

> 自己动手（选做）
> - 创建 `std::unordered_multiset<int> ums;`，插入两个 `5` 和一个 `8`，用 `count(5)` 验证为 2。
> - 陷阱：`erase(5)` 会删掉所有的 `5`。只想删一个时，用 `erase(find(5))`。

### 动手练习题

> [!question] 练习题 1：去重保序输出
> **题目**: 输入 n 个整数，去重后按**首次出现顺序**输出（unordered_set 本身无序，需配合记录顺序），并输出去重后元素个数。
>
> **输入示例**:
> ```
> 8
> 3 1 4 1 5 9 3 5
> ```
> **预期输出**:
> ```
> 5
> 3 1 4 5 9
> ```

> [!question] 练习题 2：两数组交集
> **题目**: 给定两个整数数组 A 和 B，求它们的交集（结果不含重复）。用 unordered_set 实现 O(n+m) 算法。
>
> **输入示例**:
> ```
> 5
> 1 2 3 4 5
> 4
> 3 4 5 6
> ```
> **预期输出**:
> ```
> 3 4 5
> ```

> [!question] 练习题 3：最长连续序列
> **题目**: 给定 n 个无序整数，找出最长连续数字序列的长度。要求用 unordered_set 实现 O(n) 算法（提示：只从"序列起点"开始向后数）。
>
> **输入示例**:
> ```
> 6
> 100 4 200 1 3 2
> ```
> **预期输出**:
> ```
> 4
> ```
> （最长连续序列为 1,2,3,4）
