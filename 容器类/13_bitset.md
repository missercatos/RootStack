## ==========================================================================
STL 容器速通 — bitset (位集)
## ==========================================================================

bitset 是固定长度的二进制位数组，每位占用 1 bit，支持位运算和多种成员函数，极其高效。

## --------------------------------------------------------------------------
## 一、适用场景
## --------------------------------------------------------------------------

| 场景 | 说明 |
|------|------|
| 状态压缩 DP | 用位表示物品选取状态 |
| 集合运算 | 并集、交集、子集判定 — O(n/64) |
| 筛法/标记 | 比 `vector<bool>` 更高效，每 bit 存一个标记 |
| 可达性 DP | bitset 优化背包/可达性，bitset<<1 相当于转移 |
| 图的矩阵运算 | 邻接矩阵压缩、传递闭包等 |

## --------------------------------------------------------------------------
## 二、声明与初始化
## --------------------------------------------------------------------------

```cpp
#include <bitset>
using namespace std;

bitset<8> b1;                        // 全 0: 00000000
bitset<8> b2(42);                    // 十进制 42 → 00101010
bitset<8> b3(string("1100"));        // 字符串 → 00001100（低位对齐右端）
bitset<8> b4(string("1010"), 2, 3);  // 从 pos=2 取 3 位

// 也可以用二进制字面量初始化（GCC 扩展）
bitset<8> b5(0b10101010);
```

### 长度必须编译期确定

```cpp
// bitset 长度必须是编译期常量
const int N = 1000;
bitset<N> vis; // OK

// int n; cin >> n; bitset<n> vis; // 错误! n 不是编译期常量
// 需要运行时长度 → 用 vector<bool> 或 boost::dynamic_bitset
```

## --------------------------------------------------------------------------
## 三、成员函数与操作总览
## --------------------------------------------------------------------------

### 位运算（全部 O(n/64)，n 为位数）

| 操作 | 说明 |
|------|------|
| `b[i]` | 访问第 i 位（可读写，0 为最低位） |
| `b.test(i)` | 测试第 i 位是否为 1（越界会抛异常） |
| `b.set()` | 全部置 1 |
| `b.set(i, v)` | 第 i 位置为 v (0 或 1) |
| `b.reset()` | 全部置 0 |
| `b.reset(i)` | 第 i 位置 0 |
| `b.flip()` | 全部翻转 |
| `b.flip(i)` | 第 i 位翻转 |
| `~b` | 按位取反 |
| `b1 & b2`, `b1 \| b2`, `b1 ^ b2` | 按位与/或/异或 |
| `b << n`, `b >> n` | 左移/右移 n 位 |

### 其他成员

| 函数 | 说明 |
|------|------|
| `b.size()` | 总位数（编译期固定） |
| `b.count()` | 返回 1 的个数 |
| `b.any()` | 是否存在 1 |
| `b.none()` | 是否全为 0 |
| `b.all()` | 是否全为 1 (C++11) |
| `b.to_string()` | 转为 string（高位在前） |
| `b.to_ulong()` | 转为 unsigned long |
| `b.to_ullong()` | 转为 unsigned long long |
| `b._Find_first()` | 第一个 1 的位置（GCC 扩展，非标准） |
| `b._Find_next(i)` | i 之后第一个 1 的位置（GCC 扩展） |

### P1036 选数（状态压缩 bitset 生成子集）

```cpp
// n 个数选 k 个，求和为素数的方案数
#include <iostream>
#include <bitset>
using namespace std;

int a[21], n, k, ans;

bool isPrime(int x) {
    if (x < 2) return false;
    for (int i = 2; i * i <= x; i++)
        if (x % i == 0) return false;
    return true;
}

int main() {
    cin >> n >> k;
    for (int i = 0; i < n; i++) cin >> a[i];
    for (int mask = 0; mask < (1 << n); mask++) {
        bitset<21> b(mask);
        if (b.count() != k) continue; // 恰好选 k 个
        int sum = 0;
        for (int i = 0; i < n; i++)
            if (b[i]) sum += a[i];
        if (isPrime(sum)) ans++;
    }
    cout << ans << endl;
    return 0;
}
```

### P2347 砝码称重（bitset 优化 DP）

```cpp
// 砝码有 1g/2g/3g/5g/10g/20g 六种，各有若干，问能称出的不同重量数
#include <iostream>
#include <bitset>
using namespace std;

int cnt[7];
int w[7] = {0, 1, 2, 3, 5, 10, 20};

int main() {
    for (int i = 1; i <= 6; i++) cin >> cnt[i];
    bitset<1001> dp;
    dp[0] = 1;
    for (int i = 1; i <= 6; i++) {
        for (int j = 0; j < cnt[i]; j++)
            dp |= dp << w[i];
    }
    cout << "Total=" << dp.count() - 1 << endl; // 减掉重量 0
    return 0;
}
```

### P5020 [NOIP2018 提高组] 货币系统

```cpp
// 给定 n 种面额，找出最小等价面额集合
#include <iostream>
#include <algorithm>
#include <bitset>
using namespace std;

int a[105];

int main() {
    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        for (int i = 0; i < n; i++) cin >> a[i];
        sort(a, a + n);
        bitset<25001> dp;
        dp[0] = 1;
        int ans = 0;
        for (int i = 0; i < n; i++) {
            if (!dp[a[i]]) ans++; // 若 a[i] 不能被之前的凑出，它必须加入
            for (int j = a[i]; j <= a[n - 1]; j++)
                if (dp[j - a[i]]) dp[j] = 1;
            // bitset 优化: dp |= dp << a[i];
            // 但需要即时判断，所以此处用普通循环
        }
        // 以上是普通循环写法，bitset 优化版如下:
        /*
        bitset<25001> dp2; dp2[0] = 1;
        int ans2 = 0;
        for (int i = 0; i < n; i++) {
            if (!dp2[a[i]]) ans2++;
            dp2 |= dp2 << a[i];
        }
        */
        cout << ans << endl;
    }
    return 0;
}
```

> [!question] 判断题 1
> bitset 的每一位只占 1 bit 内存。 （ ）
> - [ ] ✅ 正确
> - [ ] ❌ 错误
>
> > [!success]- 点击查看答案
> > 答案: 正确
> > 
> > **解析**: bitset 内部用紧凑的位存储，每个元素只占 1 bit，比 `bool` 数组（通常 1 byte）节省 8 倍。

> [!question] 判断题 2
> bitset 的长度可以在运行时动态确定。 （ ）
> - [ ] ✅ 正确
> - [ ] ❌ 错误
>
> > [!success]- 点击查看答案
> > 答案: 错误
> > 
> > **解析**: bitset 的长度是模板参数，必须在编译期确定。运行时动态长度需用 `vector<bool>` 或 `boost::dynamic_bitset`。

> [!question] 判断题 3
> bitset 的位运算（如 `&`、`|`）时间复杂度是 O(n/64)（n 为位数）。 （ ）
> - [ ] ✅ 正确
> - [ ] ❌ 错误
>
> > [!success]- 点击查看答案
> > 答案: 正确
> > 
> > **解析**: bitset 以 64 位（或 32 位）为一组进行批量位运算，总复杂度为 O(n/W)，W 为机器字长。

> [!question] 判断题 4

> [!question] 判断题 9
