## ==========================================================================
STL 容器教程 — string (字符串)
## ==========================================================================

## 本章概述

`std::string` 是 C++ 处理字符串的标配。底层是连续存储的动态字符数组（类似 `vector<char>`），
但提供了丰富的字符串专用操作：拼接、查找替换、子串截取、数值互转等。
本章采用手把手渐进式教学。

> 头文件：`#include <string>`。`using namespace std;` 后直接用 `string` 即可。

## --------------------------------------------------------------------------
### 适用场景与优劣分析
## --------------------------------------------------------------------------

| 优点 | 缺点 |
|:------|:------|
| 自动管理内存，支持动态增长 | 比 `char[]` 略有额外开销 |
| 丰富的成员函数（查找、替换、截取等） | `find` 朴素匹配最坏 O(n*m) |
| 支持 `+`、`==`、`<` 等运算符 | 频繁拼接可能触发多次扩容/拷贝 |
| 与 `stoi`/`to_string` 等数值转换无缝配合 | `operator[]` 越界是未定义行为 |

| 场景 | 说明 |
|:------|:------|
| 输入大整数字符串 | 高精度运算的载体 |
| 字符串匹配与查找 | 用 `find()` 快速定位子串 |
| 拼接与裁剪 | `+`、`substr()` 方便操作 |
| 读入整行文本 | `getline()` 读带空格的字符串 |
| 字典序比较 | 直接使用 `<`、`>` 等比较运算符 |

## --------------------------------------------------------------------------
### 第一步：创建 string
## --------------------------------------------------------------------------

**自己动手**：用以下方式创建 string，然后打印 `size()` 和 `empty()`：
- 空串 `string s;`
- 从 C 字符串 `string s("hello");`
- 重复字符 `string s(5, 'a');`
- 拷贝构造 `string s2(s1);`
- 取子串 `string s(other, pos, count);`

## --------------------------------------------------------------------------
### 第二步：size vs length
## --------------------------------------------------------------------------

**自己动手**：在一个非空 string 上同时调用 `size()` 和 `length()`，打印两者——它们完全相同。

> `size()` 和 `length()` 在 string 中是**完全等价**的，返回值都是字符个数（不是字节数）。

## --------------------------------------------------------------------------
### 第三步：拼接
## --------------------------------------------------------------------------

| 方式 | 语法 | 说明 |
|:------|:------|:------|
| `+` 运算符 | `s1 + s2` | 最简洁 |
| `+=` 运算符 | `s += "world"` | 追加 |
| `append()` | `s.append("...")` | 功能最全（可指定追加子串） |

**自己动手**：创建两个 string，分别用 `+`、`+=` 和 `append()` 拼接，每次拼接后打印结果和 `size()`。

> 注意：`+` 每次都会创建临时 string 对象。在循环中大量拼接推荐 `+=` 或先 `reserve()` 预分配。

## --------------------------------------------------------------------------
### 第四步：访问单个字符
## --------------------------------------------------------------------------

| 方式 | 语法 | 越界时 |
|:------|:------|:------|
| `operator[]` | `s[i]` | 未定义行为 |
| `at()` | `s.at(i)` | 抛出 `std::out_of_range` |
| `front()` | `s.front()` | 空串时未定义行为 |
| `back()` | `s.back()` | 空串时未定义行为 |

**自己动手**：用 for 循环 + `operator[]` 遍历打印每个字符；然后故意越界用 `at()` 测试异常。

## --------------------------------------------------------------------------
### 第五步：查找与截取
## --------------------------------------------------------------------------

| 函数 | 作用 |
|:------|:------|
| `find(str)` | 从前向后查找子串，返回第一次出现的位置 |
| `rfind(str)` | 从后向前查找子串 |
| `find_first_of(str)` | 查找 str 中任一字符第一次出现的位置 |
| `find_last_of(str)` | 查找 str 中任一字符最后一次出现的位置 |
| `substr(pos, count)` | 截取子串 |

> 查找失败返回 `string::npos`（一个很大的无符号数，等价于 `-1` 转 `size_t`）。

**自己动手**：
- 在一个长字符串中用 `find()` 查找子串，判断是否等于 `npos`
- 用 `substr(pos, count)` 截取一段子串并输出
- 用 `rfind()` 查找某个字符最后一次出现的位置

## --------------------------------------------------------------------------
### 第六步：插入、替换与删除
## --------------------------------------------------------------------------

**自己动手**：
- 用 `insert(pos, str)` 在指定位置插入字符串，打印结果
- 用 `replace(pos, count, str)` 替换一段子串
- 用 `erase(pos, count)` 删除一段字符
- 用 `clear()` 清空整个字符串
- 用 `pop_back()` 删除最后一个字符

每次修改后打印 `size()` 确认变化。

## --------------------------------------------------------------------------
### 第七步：比较
## --------------------------------------------------------------------------

string 支持直接用 `==`、`!=`、`<`、`>`、`<=`、`>=` 做**字典序比较**（逐字符比较 ASCII/Unicode 值）。

**自己动手**：比较 `"apple"` 和 `"apply"`，预测并验证 `s1 < s2` 的结果。

> 也可用 `compare()` 成员函数（返回负/零/正，类似 C 的 `strcmp`）。

## --------------------------------------------------------------------------
### 第八步：数值转换
## --------------------------------------------------------------------------

| 函数 | 方向 |
|:------|:------|
| `to_string(val)` | 数值 → string |
| `stoi(s)` | string → int |
| `stol(s)` | string → long |
| `stod(s)` | string → double |

**自己动手**：把 `3.14` 转成 string，再把 `"12345"` 转成 int，把 `"3.14"` 转成 double。

> 注意：`stoi("123abc")` 会只解析前段 `123` 而忽略 `abc`——如果必须整个字符串都是数字，
> 可用 `s.find_first_not_of("0123456789") == npos` 先验证。

## --------------------------------------------------------------------------
### 第九步：遍历
## --------------------------------------------------------------------------

| 方式 | 写法 | 性能 | 可修改 | 推荐 |
|:------|:------|:------|:------|:------|
| 索引 | `for (size_t i = 0; i < s.size(); i++)` | 无额外开销 | 可 | 需要下标时 |
| auto& | `for (char& c : s)` | 零拷贝 | 可 | 需要修改字符时 |
| const auto& | `for (char c : s)` | 每次拷贝 | 不可 | 不推荐 |
| 迭代器 | `for (auto it = s.begin(); it != s.end(); ++it)` | 零拷贝 | 可 | 老式写法 |

**自己动手**：用四种方式遍历并打印字符串，注意 `auto&` 方式可以直接修改原字符串中的字符。

## --------------------------------------------------------------------------
### 第十步：读入带空格的整行
## --------------------------------------------------------------------------

`cin >> s` 遇到空格就停止。读入整行用 `getline(cin, s)`。

**自己动手**：用 `getline` 读入一行包含空格的英文句子，然后统计其中某个字母出现的次数。

### 动手练习题

> [!question] 练习题 1
> **题目**: 读取一行字符串，将其中的小写字母全部转为大写，输出。
>
> 提示：用 `getline` 读入，遍历 + `toupper()` 或 ASCII 运算（`c - 32`）。

> [!question] 练习题 2
> **题目**: 读取一个字符串和一个子串，统计子串在主串中出现了多少次（可重叠）。
>
> 提示：用 `find` 循环查找，每次找到后从下一位置继续。

> [!question] 练习题 3
> **题目**: 读取两个大整数（字符串形式，长度可达 1000 位），计算它们的和并以字符串输出。
>
> 提示：模拟竖式加法——从末尾逐位相加，处理进位。用 `push_back` 或 `insert(0, char)`。
