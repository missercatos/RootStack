## ==========================================================================
STL 容器教程 — list & forward_list (链表)
## ==========================================================================

## 本章概述

`list` 是基于**双向链表**的容器，`forward_list` 是基于**单向链表**的容器。它们的核心特点是：**在已知位置处插入/删除是 O(1)**（只改指针，不搬移元素），但**不支持随机访问**（没有 `operator[]` 和 `at()`），按下标取元素需要 O(n) 遍历。`list` 还有一组专属成员函数：`sort` / `unique` / `reverse` / `merge` / `splice`。

本章采用手把手渐进式教学，每一步只提示该用哪个函数、要避开哪些陷阱，**代码请自己动手敲**，敲完编译看输出。

> 底层数据结构详解：单向/双向链表的节点结构、指针操作、与数组的对比见 [[数据结构/D_链表_LinkedList]]。本章侧重容器使用。

## --------------------------------------------------------------------------
### 适用场景与优劣分析
## --------------------------------------------------------------------------

| 优点 | 缺点 |
|:------|:------|
| 已知位置插入/删除 O(1)，比 vector 的 O(n) 快得多 | 不支持随机访问，按下标取元素 O(n) |
| 插入/删除不会使其他迭代器失效（vector 会） | 缓存不友好，节点分散在内存各处 |
| splice 可 O(1) 整段移动元素，不拷贝 | 每个节点有额外指针开销（list 两个，forward_list 一个） |
| 自带 sort/merge/unique 等链表专属操作 | 不能用 std::sort（list 需用成员 sort） |

**适用场景：**

| 场景 | 说明 |
|:------|:------|
| 频繁中间插入/删除 | 已知迭代器位置时 O(1) |
| LRU 缓存 | list 维护访问顺序，配合 unordered_map 做 O(1) 查找 |
| 需要稳定迭代器 | 插入/删除不影响其他元素的迭代器 |
| 大对象整段搬移 | splice 只改指针，不拷贝元素 |

**list vs forward_list：**

| 特性 | list | forward_list |
|:------|:------|:-------------|
| 方向 | 双向 | 单向 |
| 节点指针数 | 2 个（prev + next） | 1 个（next） |
| push_front / pop_front | 有 | 有 |
| push_back / pop_back | 有 | **无**（尾部操作需 O(n)） |
| rbegin / rend（反向遍历） | 有 | **无** |
| size() | O(1) | **无**（需 std::distance 计算） |
| 插入接口 | insert（在 pos 前） | insert_after（在 pos 后） |

**竞赛建议**：绝大多数场景用 vector 即可，list 仅用于需要 splice 或保证迭代器不失效的特殊场景。

> 重点提醒：list 不支持随机访问，没有 `operator[]` 和 `at()`，访问只能用迭代器或 `front()` / `back()`。

## --------------------------------------------------------------------------
### 第一步：创建容器
## --------------------------------------------------------------------------

> 自己动手 1
> - 包含头文件 `<list>`（list）或 `<forward_list>`（forward_list）。
> - 声明空 list：`std::list<int> l;`；可用 `std::list<int> l3 = {1, 2, 3};` 列表初始化。
> - 也可 `std::list<int> l2(5, 10);` 创建 5 个值为 10 的元素。
> - 陷阱：list 和 forward_list 在不同头文件，别混用。

## --------------------------------------------------------------------------
### 第二步：size() 与 empty()
## --------------------------------------------------------------------------

| 函数 | 作用 | list | forward_list |
|:------|:------|:------|:------|
| `size()` | 元素数量 | 有，O(1) | **无** |
| `empty()` | 是否为空 | 有 | 有 |

> 自己动手 2
> - 对 list 调用 `l.size()` 和 `l.empty()`。
> - 陷阱：forward_list **没有** `size()`，要数个数得用 `std::distance(fl.begin(), fl.end())`（O(n)）。

## --------------------------------------------------------------------------
### 第三步：插入元素（多种方式对比）
## --------------------------------------------------------------------------

| 方式 | 写法 | 位置 | 说明 |
|:------|:------|:------|:------|
| `push_back(x)` | `l.push_back(5)` | 尾部 | list 有，forward_list 无 |
| `push_front(x)` | `l.push_front(5)` | 头部 | 两者都有 |
| `emplace_back / emplace_front` | `l.emplace_back(5)` | 尾/头 | 原位构造，C++11 |
| `insert(pos, x)` | `l.insert(it, 5)` | 在 `it` **之前** | list 用 |
| `emplace(pos, x)` | `l.emplace(it, 5)` | 在 `it` 之前 | 原位构造 |
| `insert_after(pos, x)` | `fl.insert_after(it, 5)` | 在 `it` **之后** | forward_list 用 |

> 自己动手 3
> - 用 `push_back` 加几个元素到尾部，用 `push_front` 加一个到头部。
> - 用 `insert(it, x)` 在某迭代器位置前插入（`it` 可由 `l.begin()`、`next(l.begin())` 等得到）。
> - 陷阱：list 的 `insert` 在 pos **之前**插入；forward_list 没有 insert，只有 `insert_after`（在 pos **之后**），且头插要配合 `before_begin()`。

## --------------------------------------------------------------------------
### 第四步：判断元素是否存在
## --------------------------------------------------------------------------

list/forward_list **没有** `find` 和 `count` 成员函数，需用 `<algorithm>` 里的 `std::find`：

| 方式 | 写法 | 复杂度 | 返回 |
|:------|:------|:------|:------|
| `std::find` | `std::find(l.begin(), l.end(), x)` | O(n) | 迭代器 / `end()` |
| `std::count` | `std::count(l.begin(), l.end(), x)` | O(n) | 出现次数 |

> 自己动手 4
> - 包含 `<algorithm>`，用 `auto it = std::find(l.begin(), l.end(), x);`，判断 `it != l.end()` 是否存在。
> - 陷阱：链表查找只能 O(n) 线性扫描，没有像 set/map 那样的 O(log n) 查找。频繁查找请考虑别的容器。

## --------------------------------------------------------------------------
### 第五步：访问/读取元素
## --------------------------------------------------------------------------

| 方式 | 写法 | 说明 |
|:------|:------|:------|
| `front()` | `l.front()` | 首元素 |
| `back()` | `l.back()` | 尾元素（forward_list 无 back） |
| 迭代器 | `*it` | 用 `begin()` 前进到目标位置 |

> 自己动手 5
> - 用 `l.front()` 和 `l.back()` 读首尾元素。
> - 想访问"第 3 个元素"：用 `auto it = l.begin(); std::advance(it, 2);` 再 `*it`。
> - 重点：**没有 `l[2]` 和 `l.at(2)`**！list 不支持随机访问，这是与 vector 最大的区别。
> - 陷阱：对空容器调用 `front()` / `back()` 是未定义行为，先判 `empty()`。

## --------------------------------------------------------------------------
### 第六步：修改元素
## --------------------------------------------------------------------------

list 的元素可以修改（不像 set/map 的 key 那样只读）。

> 自己动手 6
> - 用 `l.front() = 99;` 改首元素，`l.back() = 88;` 改尾元素。
> - 通过迭代器：`*it = 新值;`。
> - 陷阱：要改"第 i 个"元素，仍需先用迭代器走到那里（O(n)），不能 `l[i] = x`。

## --------------------------------------------------------------------------
### 第七步：删除元素
## --------------------------------------------------------------------------

| 删除方式 | 写法 | 说明 |
|:------|:------|:------|
| `pop_back()` / `pop_front()` | `l.pop_back()` | 删尾/删头（forward_list 无 pop_back） |
| `erase(pos)` | `l.erase(it)` | 删 `it` 处元素，返回下一个迭代器 |
| `erase(first, last)` | `l.erase(a, b)` | 删区间 `[a, b)` |
| `remove(x)` | `l.remove(5)` | 删除**所有**值为 x 的元素 |
| `remove_if(pred)` | `l.remove_if(pred)` | 按条件删除 |
| `erase_after(pos)` | `fl.erase_after(it)` | forward_list：删 `it` 之后的元素 |

> 自己动手 7
> - 用 `l.pop_front()` 删头，`l.remove(5)` 删掉所有值为 5 的元素。
> - 遍历删除模式：`for (auto it = l.begin(); it != l.end(); ) { if (cond) it = l.erase(it); else ++it; }`。
> - 陷阱：`erase(it)` 后 `it` 失效，必须接住它的返回值继续；别在循环里直接 `++it` 又 `erase(it)`。

## --------------------------------------------------------------------------
### 第八步：遍历（多种方式 + 对比 + 推荐）
## --------------------------------------------------------------------------

| 方式 | 写法 | 适用 | 推荐度 |
|:------|:------|:------|:------|
| `const auto&` | `for (const auto& x : l)` | 只读遍历 | 最推荐（只读） |
| `auto&` | `for (auto& x : l)` | 遍历中修改元素 | 需改值时 |
| 正向迭代器 | `for (auto it = l.begin(); it != l.end(); ++it)` | 需边遍历边删 | 删除场景 |
| 反向迭代器 | `for (auto it = l.rbegin(); it != l.rend(); ++it)` | 逆序遍历 | list 可用，**forward_list 不可** |

**推荐**：只读用 `const auto& x`，改值用 `auto& x`，边遍历边删用正向迭代器。

> 自己动手 8
> - 用 `for (const auto& x : l)` 打印所有元素。
> - 重点：forward_list 是单向链表，**没有 rbegin/rend**，无法反向遍历。
> - 陷阱：链表迭代器只能 `++`/`--`（forward_list 只能 `++`），不能 `it + 2` 这种跳跃（那是随机访问迭代器才有的）。

## --------------------------------------------------------------------------
### 第九步：清空容器
## --------------------------------------------------------------------------

> 自己动手 9
> - 用 `l.clear()` 清空，再用 `l.empty()`（true）验证（list 还可用 `size()` 看是否为 0）。

## --------------------------------------------------------------------------
### 特有操作：sort / unique / reverse / merge / splice
## --------------------------------------------------------------------------

这是 list 区别于其他容器的专属能力。

| 函数 | 作用 | 注意 |
|:------|:------|:------|
| `l.sort()` | 排序，O(n log n) | **不能用 std::sort**（见下方重点） |
| `l.sort(cmp)` | 自定义比较排序 | 传入比较器 |
| `l.unique()` | 删除**相邻**重复元素 | 需先 sort 才能全局去重 |
| `l.reverse()` | 反转链表 | O(n)，只改指针方向 |
| `l.merge(other)` | 合并两个**已排序**的 list | 合并后 other 变空 |
| `l.splice(pos, other)` | 把 other 全部元素移到 pos 前 | O(1)，不拷贝元素 |

> 重点：list 有自己专属的 `sort` 成员函数，**不能用 `std::sort`**。因为 `std::sort` 要求随机访问迭代器，而 list 只有双向迭代器。请务必用 `l.sort()`。

> 自己动手（重要）
> - 用 `l.sort()` 排序，再 `l.unique()` 去重（注意 unique 只删相邻重复，要先 sort）。
> - 用 `l.reverse()` 反转，观察输出顺序倒过来。
> - 两个已排序的 list 用 `a.merge(b)` 合并，合并后 `b` 变空。
> - 陷阱：`unique()` 不排序，直接对乱序 list 用它只会删掉相邻的重复；想完全去重要先 `sort()`。

## --------------------------------------------------------------------------
### 补充：forward_list 的特殊接口
## --------------------------------------------------------------------------

单向链表无法直接拿到前驱，所以 forward_list 用 `before_begin()` 表示"首元素之前的位置"，并用 `_after` 系列接口。

| 函数 | 作用 |
|:------|:------|
| `fl.before_begin()` | 首元素之前的虚拟位置 |
| `fl.insert_after(pos, x)` | 在 pos 之后插入 |
| `fl.emplace_after(pos, x)` | 在 pos 之后原位构造 |
| `fl.erase_after(pos)` | 删除 pos 之后的元素 |
| `fl.push_front(x)` / `fl.pop_front()` | 头部操作 |

> 自己动手（选做）
> - 在 forward_list 头部插入：用 `fl.insert_after(fl.before_begin(), x)`。
> - 陷阱：forward_list 没有 push_back、pop_back、back、rbegin、size，操作时间时刻提醒自己"只能向后"。

### 动手练习题

> [!question] 练习题 1
> **题目**: 使用 list 实现约瑟夫环问题：n 个人围成一圈，从第 1 个人开始报数，报到 m 的人出列。输出出列顺序。
>
> **输入示例**:
> ```
> 7 3
> ```
> **输出示例**:
> ```
> 3 6 2 7 5 1 4
> ```

> [!question] 练习题 2
> **题目**: 使用 list 实现简单的文本编辑器：支持在光标位置插入字符、删除光标前的字符、光标左移、光标右移。输入操作序列，输出最终字符串。
>
> **输入示例**:
> ```
> abcDE[[[de
> ```
> （`[` 表示光标左移，字母照常插入）
> **输出示例**:
> ```
> deabcDE
> ```

> [!question] 练习题 3
> **题目**: 实现一个简单的 LRU 缓存：容量为 k，支持 get(key) 和 put(key, value) 操作。使用 list + unordered_map 实现 O(1) 的 get 和 put，输出每次 get 的结果（不存在输出 -1）。
>
> **输入示例**:
> ```
> 2
> put 1 10
> put 2 20
> get 1
> put 3 30
> get 2
> ```
> **输出示例**:
> ```
> 10
> -1
> ```
