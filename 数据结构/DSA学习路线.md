# DSA 数据结构与算法 学习路线 (C++ 实现)

## 学习方式

每条学习步骤遵循四步法：

1. 通读概念 -- 理解数据结构的定义、性质、适用场景
2. 手写实现 -- 不看参考代码，用 C++ 手动实现核心操作
3. STL 练习 -- 用标准库容器/算法做题，熟悉接口
4. 洛谷刷题 -- 按章节做推荐题目，每章 2-5 题

> 每章建议分 2-3 天完成：概念+手写、STL用法+案例、习题+刷题。

---

重点: 链表类型与内存布局、手动实现单向/双向链表全部操作、快慢指针。

配合算法: [[../算法/算法技巧/双指针]] -- 快慢指针部分

必须手写的结构: 单向链表、双向链表

### Step 3: [[B_栈_Stack]] -- 栈

重点: 栈的概念、函数调用栈原理、手动实现数组栈/链表栈、括号匹配、中缀转后缀、表达式求值。

> 预计: 2 天

### Step 5: [[Q_排序_八大排序_Sorting]] -- 八大排序

学习顺序:
1. 冒泡排序 -> 选择排序 -> 插入排序 (O(n^2) 三种)
2. 希尔排序 (插入排序的改进)
3. 归并排序 (分治思想入门)
4. 快速排序 (分治 + 枢轴选择 + 优化策略)
5. 堆排序 (学完堆之后回来看)
6. 基数排序 (了解即可)

配合算法:
- [[../算法/算法技巧/递推递归]] -- 分治与递归思想
- [[../算法/算法技巧/暴力枚举]] -- 基本思路

必须手写的排序: 冒泡、插入、归并、快排

洛谷刷题: P1177 快速排序、P1059 明明的随机数、P1093 奖学金

> 预计: 3 天

### Step 6: [[../算法/算法技巧/二分查找]] -- 二分查找 (算法补充)

内容: lower_bound/upper_bound 手写、二分查找变体、STL binary_search。

## 学习节奏建议

```
Phase 1 (两周): 线性结构集训 -- 每天 1 个数据结构 + 少量算法题
Phase 2 (两周): 核心结构 -- 每 2-3 天一个主题，多手写
Phase 3 (两周): 算法专题 -- 每天一个算法技巧，大量刷题
Phase 4 (一到两周): 图论 -- 算法综合应用
Phase 5 (剩余时间): 选学进阶
```

每一章的标准动作:
1. 阅读本章文件（先概念，再代码）
2. 关掉文件，手写核心数据结构的实现
3. 用 STL 快速刷 2-3 道洛谷题
4. 阅读本章推荐的相关算法技巧文件
