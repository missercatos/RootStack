## 莫队算法

### 概述

莫队算法是一种离线分块算法，用于解决序列上的区间查询问题。若区间 $[l,r]$ 的答案能 $O(1)$ 扩展到相邻区间 $[l-1,r],[l+1,r],[l,r+1],[l,r-1]$，则可在 $O(n\sqrt{n})$ 复杂度内求出所有询问。

### 排序与分块

以 $l$ 所在块编号为第一关键字，$r$ 为第二关键字排序。块大小取 $S = n/\sqrt{m}$ 时最优，总复杂度 $O(n\sqrt{m})$。

**奇偶排序优化**：奇数块 $r$ 升序，偶数块 $r$ 降序，减少 $r$ 指针回跳，可提速约 30%。

```cpp
int unit;
struct Node {
  int l, r, id;
  bool operator<(const Node &x) const {
    if (l / unit != x.l / unit) return l < x.l;
    return (l / unit) & 1 ? r < x.r : r > x.r;
  }
};
```

### 模版框架

```cpp
void move(int pos, int sign) { /* update nowAns */ }

void solve() {
  int block = ceil(pow(n, 0.5));
  sort(q, q + m);
  int l = 1, r = 0;
  for (int i = 0; i < m; ++i) {
    while (l > q[i].l) move(--l, 1);
    while (r < q[i].r) move(++r, 1);
    while (l < q[i].l) move(l++, -1);
    while (r > q[i].r) move(r--, -1);
    ans[q[i].id] = nowAns;
  }
}
```

**四个 while 顺序**：必须先扩大区间（`--l` / `++r`），再缩小区间（`l++` / `r--`），否则会导致 $l > r+1$ 使维护出错。
