## 组合数学基础

### 排列与组合

- 排列：$\mathrm A_n^m = n(n-1)\cdots(n-m+1) = \dfrac{n!}{(n-m)!}$
- 组合：$\dbinom{n}{m} = \dfrac{n!}{m!(n-m)!}$
- 二项式定理：$(a+b)^n = \sum_{i=0}^n \dbinom{n}{i} a^{n-i}b^i$
- 多重集排列：$\dfrac{n!}{n_1!\,n_2!\cdots n_k!}$

### Lucas 定理

对于素数 $p$，有：

$$
\binom{n}{k} \equiv \binom{\lfloor n/p\rfloor}{\lfloor k/p\rfloor} \binom{n \bmod p}{k \bmod p} \pmod p
$$

```cpp
long long lucas(long long n, long long k, long long p) {
  if (k == 0) return 1;
  return C(n % p, k % p, p) * lucas(n / p, k / p, p) % p;
}
```

### Catalan 数

$$
C_n = \frac{1}{n+1}\binom{2n}{n} = \frac{(2n)!}{n!(n+1)!},
\quad C_n = \binom{2n}{n} - \binom{2n}{n+1}
$$

递推：$C_n = \frac{4n-2}{n+1}C_{n-1}$，$C_0 = 1$

应用：合法括号序列、二叉树计数、出栈序列、网格路径（不越过对角线）。

### 容斥原理

$$
\left|\bigcup_{i=1}^n S_i\right| = \sum_{i}|S_i| - \sum_{i<j}|S_i\cap S_j| + \cdots + (-1)^{n-1}|S_1\cap\cdots\cap S_n|
$$
