## 快速幂与模运算

### 核心概念

**快速幂**（二进制取幂）在 $O(\log n)$ 时间内计算 $a^n$，核心思想是将指数按二进制分解：

$$
a^n = a^{n_0 2^0} \times a^{n_1 2^1} \times \cdots \times a^{n_t 2^t}
$$

### 模运算性质

- 加法：$(a + b) \bmod p = (a \bmod p + b \bmod p) \bmod p$
- 乘法：$(a \times b) \bmod p = (a \bmod p \times b \bmod p) \bmod p$
- 幂运算可在中间过程取模

### 代码实现

```cpp
long long binpow(long long a, long long b, long long p) {
 long long res = 1;
 while (b > 0) {
 if (b & 1) res = res * a % p;
 a = a * a % p;
 b >>= 1;
 }
 return res;
}
```

### 光速幂（底数固定）

块长 $s = \sqrt{n}$，预处理 $a^0 \sim a^{s-1}$ 和 $a^0, a^s, \ldots, a^{\lfloor p/s\rfloor s}$，$O(1)$ 回答查询。
