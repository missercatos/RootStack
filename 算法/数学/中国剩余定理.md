## 中国剩余定理

### CRT（模数两两互质）

求解一元线性同余方程组（$n_1,\dots,n_k$ 两两互质）：

$$
\begin{cases}
x \equiv a_1 \pmod{n_1} \\
x \equiv a_2 \pmod{n_2} \\
\quad\vdots \\
x \equiv a_k \pmod{n_k}
\end{cases}
$$

**步骤**：
1. 计算 $n = \prod n_i$
2. 对每个 $i$，计算 $m_i = n / n_i$，求 $m_i$ 在模 $n_i$ 下的逆元 $m_i^{-1}$，得 $c_i = m_i \cdot m_i^{-1}$
3. 解：$x \equiv \sum a_i c_i \pmod n$

```cpp
LL crt(int k, LL* a, LL* r) {
  LL n = 1, ans = 0;
  for (int i = 1; i <= k; i++) n = n * r[i];
  for (int i = 1; i <= k; i++) {
    LL m = n / r[i], b, y;
    exgcd(m, r[i], b, y);
    ans = (ans + a[i] * m * b % n) % n;
  }
  return (ans % n + n) % n;
}
```

### EXCRT（模数不互质）

两两合并。设两个方程 $x \equiv a_1 \pmod{m_1}$、$x \equiv a_2 \pmod{m_2}$：

转化为 $m_1p - m_2q = a_2 - a_1$，用 EXGCD 求解。若 $\gcd(m_1,m_2) \nmid (a_2-a_1)$ 则无解。合并后模数为 $\operatorname{lcm}(m_1,m_2)$。

```cpp
LL excrt(int k, LL* a, LL* m) {
  LL ans = a[1], M = m[1];
  for (int i = 2; i <= k; i++) {
    LL x, y, d = exgcd(M, m[i], x, y);
    if ((a[i] - ans) % d) return -1;
    x = (a[i] - ans) / d * x % (m[i] / d);
    ans += x * M;
    M = M / d * m[i];
    ans = (ans % M + M) % M;
  }
  return ans;
}
```
