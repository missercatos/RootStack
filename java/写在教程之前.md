本java教程并不适用于完全初学者来学习，如果是没有接触过编程的小白在阅读本教程会感觉很费力。

本教程是基于对C语言的理解之上进行解释的，很多内容默认学习者已经掌握基本的编程思想。
假如你是在学习C语言或者cpp之后再学习的本教程，那么理解起来应该相对轻松。
如果是学习了非C的其他编程语言，比如python,虽然不如像C程序员一样方便阅读，但是本教程还囊括了基础部分，依然可以阅读。

而假如说你是真正的初学者，没有接触过编程，那么本教程将会推荐你阅读一下其他教程。

本教程虽然有给出关于IDE的选择和环境变量的配置相关章节，但是基于有其他环境变量配置经验的学习者来说的，仅给出了不同环境和IDE的相对区别，而没有给出细致教学内容。
