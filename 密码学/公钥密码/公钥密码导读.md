# 公钥密码 导读

本目录收录公钥密码（Public-Key Cryptography）的笔记与总结。

## 参考书籍

- 《Introduction to Modern Cryptography》— Jonathan Katz, Yehuda Lindell, CRC Press（第3版，2020）
- 《Applied Cryptography: Protocols, Algorithms and Source Code in C》— Bruce Schneier, Wiley
- 《Handbook of Applied Cryptography》— Menezes, van Oorschot, Vanstone, CRC Press
- 《Cryptography Made Simple》— Nigel Smart, Springer
- 《Foundations of Cryptography》— Oded Goldreich, Cambridge University Press

## GitHub 仓库 & 在线资源

- [RsaCtfTool](https://github.com/RsaCtfTool/RsaCtfTool) — RSA 攻击自动化工具集
- [jvdsn/crypto-attacks](https://github.com/jvdsn/crypto-attacks) — 全面的密码攻击代码库
- [PyCryptodome](https://github.com/Legrandin/pycryptodome) — RSA/ElGamal 实现
- [CryptoHack - RSA](https://cryptohack.org/challenges/rsa/) — RSA 方向练习

## 覆盖内容

RSA 全套攻击（共模/低指数/Wiener/Boneh-Durfee/Coppersmith）、ElGamal、Paillier、Rabin 密码系统
