# 密码协议 导读

本目录收录密码协议（Cryptographic Protocols）的笔记与总结。

## 参考书籍

- 《Security Engineering: A Guide to Building Dependable Distributed Systems》— Ross Anderson, Wiley（免费在线版）
- 《Cryptography and Network Security: Principles and Practice》— William Stallings, Pearson
- 《Real-World Cryptography》— David Wong, Manning Publications
- TLS 1.3 标准 (RFC 8446)、SSH 协议文档

## GitHub 仓库 & 在线资源

- [TLS-Attacker](https://github.com/tls-attacker/TLS-Attacker) — TLS 协议攻击框架
- [OpenSSL](https://github.com/openssl/openssl) — TLS/SSL 参考实现
- [Noise Protocol Framework](https://github.com/noiseprotocol/noise_spec) — 现代安全协议
- [Signal Protocol](https://github.com/signalapp/libsignal) — 端到端加密协议实现

## 覆盖内容

TLS 1.3、Diffie-Hellman 密钥交换、身份认证协议、Kerberos、端到端加密协议、中间人攻击
