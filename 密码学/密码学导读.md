*密码学是计算机学习相对重要的一部分，CTF领域极为重要，算法领域也会有所涉及*

本来是想把密码学部分放在red_team里面作为CTF教程的一部分的，但是考虑到密码学的应用不止在这一方面，于是单独列一个类。

在CTF领域里，Crypto（密码）是极为重要的一个比赛方向，因此需要特意去学习密码学。至少要清楚各种RSA攻击，做到运用和分辨（共模、低指数、Wiener、Boneh-Durfee、Coppersmith），同时还要善于使用离散对数（Pohlig-Hellman、Baby-step Giant-step），学会ECC基础。高阶需要学会格密码（LLL算法解背包、近似GCD、Hidden Number Problem）、同态加密、侧信道分析、协议攻击（ECDSA nonce reuse、Shamir秘密共享）。以上这些都是密码学领域或是密码学与其他学科的交叉领域。

而在算法领域内，密码学在ACM/ICPC等算法竞赛中属于冷门方向，出现的概率极低，远不如图论、DP、数据结构、数论这些核心领域重要。但也需要掌握模运算、快速幂、GCD、逆元这些数论基础，以及RSA的基本原理。

本导读主要是面向CTF领域的，也可以深化到渗透、漏洞挖掘等的可能性领域。

## CTF—Crypto学习规划

### 基础层面

需要掌握模运算、GCD/逆元、数论基础、对称加密（AES、DES模式攻击）、异或特性这些知识。

- **模运算与数论基础**：模加/模乘、快速幂、费马小定理、欧拉定理、扩展欧几里得算法求逆元
 - → 详见 [[初等数论/]] 目录
- **异或特性**：自反性（a xor a = 0）、与明文/密钥关系、多字节XOR密钥恢复（重合指数法、频率分析）
- **对称加密攻击**：
 - ECB模式：字节翻转攻击、字节复制攻击
 - CBC模式：padding oracle attack、IV可控攻击
 - CTR/GCM：nonce重用导致密钥流相同
 - DES：弱密钥、三重DES兼容性
- **古典密码**（扩展）：单表替换（频率分析）、维吉尼亚（Kasiski测试、重合指数）、Playfair
 - → 后续详见 [[古典密码/]] 目录

### 进阶层面

- **RSA各攻击识别特征**：

| 攻击类型 | 适用场景 | 关键特征 |
|---------|---------|---------|
| 共模攻击 | 相同n不同e | n相同，e互素，gcd(e1,e2)=1 |
| 低指数攻击 | e很小 | e=3且m较小，或广播攻击（同一m加密多次） |
| Wiener攻击 | d过小 | d < n^0.25，连分数展开 |
| Boneh-Durfee | d稍大 | d < n^0.292，格攻击 |
| Coppersmith | 已知部分p/m | 已知p高位/低位，或已知m高位/低位 |
| Franklin-Reiter | 相关消息 | 同一n下两消息线性相关 |
| Hastad广播 | e小且多次加密 | 同一e对同一m多次加密（CRT恢复） |
| 私钥泄露 | d已知 | 分解n，或n已知全部分解 |

- **离散对数**：
 - Pohlig-Hellman：阶光滑时可用，分解阶后CRT组合
 - Baby-step Giant-step：时间复杂度O(sqrt(n))，空间换时间
 - Pollard's rho：更低空间开销
 - Index Calculus：对特定群高效
- **ECC基础**：
 - 椭圆曲线群运算、标量乘法
 - ECDLP问题及攻击（Pohlig-Hellman、Smart攻击（异常曲线）、MOV攻击）
 - 曲线参数安全选择（奇异/异常曲线判别）

- → 详见 [[公钥密码/]]、[[椭圆曲线密码/]] 目录

### 高阶层面

#### 格密码（Lattice-based Cryptography）

格密码是当前CTF Crypto高阶题目的核心，几乎所有"难下手的题目"最终都会归约到格上。

- **LLL算法**：格基约简算法，核心工具。需理解其输入输出、运行时间、约简质量
- **背包密码体制（Merkle-Hellman）**：经典子集和问题，可用LLL格攻击破解
- **近似GCD问题（AGCD）**：给定一组近似为某个大数倍数的数，恢复该大数。是部分同态加密的安全基础
- **Hidden Number Problem（HNP）**：已知随机数的高位，恢复完整随机数。常见于ECDSA nonce部分泄露场景
- **其他格攻击应用**：构造格解线性同余、解多元Coppersmith、解带约束方程组

→ 详见 [[格密码/]] 目录

#### 同态加密

- **部分同态加密（PHE）**：Paillier（加法同态）、ElGamal（乘法同态）
- **近似同态加密（SWHE）→ 全同态加密（FHE）**：Gentry方案、BFV、CKKS
- CTF中常见：Paillier加密下的加法/乘法操作构造攻击，或利用同态性质绕过验证
- 主要发力点：理解密文运算后解密结果的变化、噪声增长

→ 详见 [[同态加密/]] 目录（后续扩展）

#### 侧信道分析（Side-Channel Analysis）

- **时序攻击**：不同输入导致不同运算时间，泄露信息。最简单的CTF形式：字符逐一比较泄露秘密
- **功耗分析**（SPA/DPA）：简单功耗分析/差分功耗分析，需硬件环境，较少出现在CTF
- **故障注入**：改变计算中间结果，如RSA-CRT的故障攻击（BellCore攻击）
- **缓存侧信道**：Flush+Reload、Prime+Probe，可用于跨进程泄露密钥

→ 详见 [[侧信道分析/]] 目录（后续扩展）

#### 协议攻击

- **ECDSA nonce重用**：两次签名使用相同k值，可直接恢复私钥。若k部分已知（如k高位泄露），可构造格攻击（HNP）
- **Shamir秘密共享**：阈下信道、Lagrange插值恢复秘密、参与者合谋攻击
- **Diffie-Hellman协议**：中间人攻击、静态DH私钥泄露、g阶非素数（Pohlig-Hellman攻击）
- **数字信封/混合加密**：协议逻辑漏洞导致的降级攻击

→ 详见 [[密码协议/]] 目录

## 常用工具

| 工具 | 用途 | 掌握程度 |
|------|------|---------|
| SageMath | 数论运算、格LLL、离散对数、多项式求解 | 必备，需熟练使用Zmod()、factor()、LLL()、discrete_log() |
| Python PyCryptodome | RSA/AES/DES/ECC的加解密与签名 | 必备，能快速实现加解密代码 |
| Python z3-solver | 符号约束求解，已知部分信息的RSA/格问题 | 进阶，适合自动化求解方程组 |
| RsaCtfTool | 集成多种RSA攻击的自动化工具 | 辅助，快速鉴别攻击类型 |
| hash_extender | 哈希长度扩展攻击（MD5/SHA1/SHA256） | 辅助，用于特定题型 |
| CyberChef | 在线数据转换、编码解码 | 辅助，快速验证和调试 |

→ 详见 [[工具/]] 目录（后续扩展）
