# 哈希函数 导读

本目录收录密码哈希函数（Cryptographic Hash Functions）的笔记与总结。

## 参考书籍

- 《Handbook of Applied Cryptography》— Alfred J. Menezes, Paul C. van Oorschot, Scott A. Vanstone, CRC Press（免费在线版）
- 《Understanding Cryptography》— Christof Paar, Jan Pelzl, Springer（哈希相关章节）
- NIST FIPS 180-4 (SHA-1/SHA-2)、FIPS 202 (SHA-3) 标准文档
- 《Real-World Cryptography》— David Wong, Manning Publications

## GitHub 仓库 & 在线资源

- [HashPump](https://github.com/bwall/HashPump) — 哈希长度扩展攻击工具
- [hashcat](https://github.com/hashcat/hashcat) — GPU 加速密码破解
- [SHA-3 参考实现](https://github.com/nemequ/sha3) — NIST 标准参考代码
- [CryptoHack - Hash Functions](https://cryptohack.org/challenges/hash-functions/) — 哈希函数练习

## 覆盖内容

MD5/SHA-1/SHA-2/SHA-3、长度扩展攻击、碰撞攻击、Merkle-Damgård 与海绵结构、HMAC、生日攻击
