# 后量子密码 导读

本目录收录后量子密码（Post-Quantum Cryptography）的笔记与总结。

## 参考书籍

- 《Post-Quantum Cryptography》— Daniel J. Bernstein, Johannes Buchmann, Erik Dahmen, Springer
- NIST FIPS 203 (ML-KEM/Kyber)、FIPS 204 (ML-DSA/Dilithium)、FIPS 205 (SLH-DSA/SPHINCS+)
- 《Quantum Computing Since Democritus》— Scott Aaronson, Cambridge University Press
- 《An Introduction to Mathematical Cryptography》— Hoffstein, Pipher, Silverman（后量子章节）

## GitHub 仓库 & 在线资源

- [liboqs](https://github.com/open-quantum-safe/liboqs) — NIST PQC 算法 C 库
- [awesome-post-quantum](https://github.com/veorq/awesome-post-quantum) — 后量子密码资源合集
- [pqcrypto](https://github.com/rustpq/pqcrypto) — Rust 后量子密码库
- [pq-crystals/kyber](https://github.com/pq-crystals/kyber) — Kyber (ML-KEM) 参考实现

## 覆盖内容

格基后量子（Kyber/Dilithium/Falcon）、码基（Classic McEliece/HQC）、哈希基（SPHINCS+）、多变量密码
