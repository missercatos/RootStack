# 密钥管理 导读

本目录收录密钥管理（Key Management）与 PKI 的笔记与总结。

## 参考书籍

- 《Understanding PKI: Concepts, Standards, and Deployment Considerations》— Carlisle Adams, Steve Lloyd, Addison-Wesley
- NIST SP 800-57 Part 1 Rev.5 — Recommendation for Key Management
- 《Security Engineering: A Guide to Building Dependable Distributed Systems》— Ross Anderson, Wiley（PKI 章节）
- 《Bulletproof SSL and TLS》— Ivan Ristic, Feisty Duck

## GitHub 仓库 & 在线资源

- [certbot](https://github.com/certbot/certbot) — Let's Encrypt ACME 客户端
- [easy-rsa](https://github.com/OpenVPN/easy-rsa) — 轻量 CA 管理工具
- [certificate-transparency](https://github.com/google/certificate-transparency) — 证书透明度
- [cfssl](https://github.com/cloudflare/cfssl) — Cloudflare PKI/TLS 工具

PKI 体系、X.509 证书、CA 层级模型、密钥派生/包装/轮换、随机数安全、HSM
