# 工具 导读

本目录收录密码学常用工具（Tools）的笔记与教程。

## 参考书籍

- SageMath 官方文档 — https://doc.sagemath.org/
- PyCryptodome 文档 — https://pycryptodome.readthedocs.io/
- Z3 Theorem Prover 指南（"Theory in Practice"）
- 《Understanding Cryptography》配套资源 — https://www.crypto-textbook.com/

## GitHub 仓库 & 在线资源

- [SageMath](https://github.com/sagemath/sage) — 密码学必备数学系统
- [CyberChef](https://github.com/gchq/CyberChef) — 在线编解码/密码分析
- [RsaCtfTool](https://github.com/RsaCtfTool/RsaCtfTool) — RSA 攻击工具集
- [jvdsn/crypto-attacks](https://github.com/jvdsn/crypto-attacks) — 密码攻击代码库
- [FeatherDuster](https://github.com/nccgroup/featherduster) — 自动化密码分析
- [xortool](https://github.com/hellman/xortool) — 多字节 XOR 密码分析
- [HashPump](https://github.com/bwall/HashPump) — 哈希长度扩展攻击
- [FactorDB API](http://factordb.com/) — 在线分解查询
- [Z3 Prover](https://github.com/Z3Prover/z3) — 约束求解器
- [quipqiup](https://quipqiup.com/) — 自动替换密码破解

## 覆盖内容

SageMath 入门、PyCryptodome 使用、Z3 约束求解、RSA 攻击工具链、CyberChef 使用技巧
