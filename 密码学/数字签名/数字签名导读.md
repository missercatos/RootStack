# 数字签名 导读

本目录收录数字签名（Digital Signatures）的笔记与总结。

## 参考书籍

- 《Digital Signatures》— Jonathan Katz, Springer
- 《Handbook of Applied Cryptography》— Menezes, van Oorschot, Vanstone, CRC Press（签名相关章节）
- 《Understanding Cryptography》— Christof Paar, Jan Pelzl, Springer（签名章节）
- 《An Introduction to Mathematical Cryptography》— Hoffstein, Pipher, Silverman, Springer

## GitHub 仓库 & 在线资源

- [python-rsa](https://github.com/sybrenstuvel/python-rsa) — Python RSA 签名实现
- [ed25519-donna](https://github.com/floodyberry/ed25519-donna) — Ed25519 参考实现
- [jvdsn/crypto-attacks](https://github.com/jvdsn/crypto-attacks) — ECDSA nonce 重用攻击等
- [CryptoHack - Signatures](https://cryptohack.org/challenges/signatures/) — 数字签名练习

## 覆盖内容

RSA-PSS、DSA、ECDSA、EdDSA/Ed25519、盲签名、环签名、BLS 签名
