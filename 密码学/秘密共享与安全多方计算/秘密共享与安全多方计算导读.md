# 秘密共享与安全多方计算 导读

本目录收录秘密共享（Secret Sharing）与安全多方计算（Secure Multiparty Computation）的笔记与总结。

## 参考书籍

- 《Secure Multiparty Computation and Secret Sharing》— Ronald Cramer, Ivan Bjerre Damgård, Jesper Buus Nielsen, Cambridge University Press
- 《Efficient Secure Two-Party Protocols: Techniques and Constructions》— Carmit Hazay, Yehuda Lindell, Springer
- 《A Pragmatic Introduction to Secure Multi-Party Computation》— David Evans, Vladimir Kolesnikov, Mike Rosulek（免费在线版）

## GitHub 仓库 & 在线资源

- [MP-SPDZ](https://github.com/data61/MP-SPDZ) — 多方安全计算框架（最全面的实现）
- [ABY](https://github.com/encryptogroup/ABY) — 两方混合协议计算
- [EMP-toolkit](https://github.com/emp-toolkit) — 高效安全计算工具集
- [awesome-mpc](https://github.com/rdragos/awesome-mpc) — MPC 资源合集
- [Shamir 秘密共享 Python 实现](https://github.com/sinfonier/shamir)

## 覆盖内容

Shamir 秘密共享、Lagrange 插值、GMW/BGW 协议、姚氏混淆电路、GC 协议、敌手模型
