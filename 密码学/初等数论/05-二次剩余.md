# 二次剩余

## 定义

设 $p$ 为奇素数，$a$ 为整数且 $p \nmid a$。若存在 $x$ 使 $x^2 \equiv a \pmod p$，称 $a$ 为模 $p$ 的**二次剩余**（Quadratic Residue, QR），否则称**二次非剩余**（Quadratic Non-residue, QNR）。

模 $p$ 的 $p-1$ 个非零元素中，恰好一半是 QR，一半是 QNR。

## 勒让德符号（Legendre Symbol）

$$\left(\frac{a}{p}\right) = \begin{cases}
1 & \text{若 } a \text{ 是模 } p \text{ 的 QR} \\
-1 & \text{若 } a \text{ 是模 } p \text{ 的 QNR} \\
0 & \text{若 } p \mid a
\end{cases}$$

**欧拉准则**（Euler's Criterion）：

$$\left(\frac{a}{p}\right) \equiv a^{(p-1)/2} \pmod p$$

这是判断二次剩余最直接的方法。

```
function legendre(a, p):
    # p 为奇素数
    result = pow(a, (p - 1) // 2, p)
    if result == p - 1:
        return -1
    return result  # 0 or 1
```

**雅可比符号**（Jacobi Symbol）：勒让德符号的推广，允许模数为任意奇数。计算时不需要分解模数，可以像分数一样约分。

但对于雅可比符号值为 1 的情况，不能断定 $a$ 是 QR（因为分子分母可以各贡献一个 $-1$ 负负得正）。这是某些密码协议的安全性基础。

## 二次剩余在密码学中的应用

### Goldwasser-Micali 加密

这是一个概率公钥加密方案。密文比明文长很多，但它是第一个被证明语义安全的加密方案。

密钥生成：$n = pq$，选一个 QNR $y$ 使 $\left(\frac{y}{p}\right) = \left(\frac{y}{q}\right) = -1$。
- 公钥：$(n, y)$
- 私钥：$(p, q)$

加密：对每个比特 $b$，选随机 $r \in \mathbb{Z}_n^*$，输出 $c = r^2 \cdot y^b \bmod n$。

解密：判断 $c$ 模 $p$ 是否为 QR——若 <i>是</i>，$b=0$；<i>否</i>，$b=1$。

**我的见解**：这个方案虽然不实用（密文膨胀严重），但它建立了"二次剩余判定困难性"与加密安全的联系。后来的很多方案都用了同样思维——把代数难题直接转化为加密安全性证明。

### Rabin 加密

$c \equiv m^2 \pmod n$（$n = pq$），解密即求平方根。

解密需要同时求模 $p$ 和模 $q$ 的平方根，然后用 CRT 合并。模奇素数的平方根可以用 Tonelli-Shanks 算法。

```
function sqrt_mod_prime(a, p):
    # 求 x 使 x^2 ≡ a (mod p)
    assert legendre(a, p) == 1
    if p % 4 == 3:
        # 简单情况
        x = pow(a, (p + 1) // 4, p)
        return x, p - x
    # 否则走 Tonelli-Shanks
    return tonelli_shanks(a, p)
```

## Tonelli-Shanks 算法

模奇素数 $p$ 下求平方根最通用算法。

```
function tonelli_shanks(n, p):
    # 求 x 使 x^2 ≡ n (mod p)
    if pow(n, (p - 1) // 2, p) != 1:
        return None  # no solution

    # 将 p-1 写为 Q * 2^S
    Q, S = p - 1, 0
    while Q % 2 == 0:
        Q //= 2
        S += 1

    # 找一个二次非剩余 z
    z = 2
    while pow(z, (p - 1) // 2, p) != p - 1:
        z += 1

    M, c, t, R = S, pow(z, Q, p), pow(n, Q, p), pow(n, (Q + 1) // 2, p)

    while True:
        if t == 0:
            return 0
        if t == 1:
            return R

        # 找到最小的 i 使 t^(2^i) ≡ 1 (mod p)
        i = 1
        temp = (t * t) % p
        while temp != 1:
            temp = (temp * temp) % p
            i += 1

        b = pow(c, 1 << (M - i - 1), p)
        M, c, t, R = i, (b * b) % p, (t * b * b) % p, (R * b) % p
```

**我的见解**：Tonelli-Shanks 的理解关键是它把问题转化为在循环群中找某个元素生成元的离散对数。如果觉得难，先掌握 $p \equiv 3 \pmod 4$ 的特殊情形，这覆盖了大约一半的素数，而且模 $p$ 求平方根时直接用公式 $x = a^{(p+1)/4} \bmod p$ 即可。

## 二次剩余与模 $n$ 平方根

模 $n$（合数）的平方根与因数分解等价：

- 若已知 $n$ 分解，可以分别在模 $p$ 和模 $q$ 下求平方根再用 CRT 合并
- 若知道 $x^2 \equiv y^2 \pmod n$ 且 $x \not\equiv \pm y \pmod n$，则 $\gcd(x-y, n)$ 给出 $n$ 的一个非平凡因子

这是二次筛法（QS）、数域筛法（NFS）等现代因数分解算法的核心思想。

### 编程练习：Rabin 解密

已知 $n = pq$ 分解和密文 $c$，求解 $m$ 满足 $m^2 \equiv c \pmod n$。

```python
def rabin_decrypt(c, p, q):
    r = pow(c, (p + 1) // 4, p) if p % 4 == 3 else tonelli_shanks(c, p)
    s = pow(c, (q + 1) // 4, q) if q % 4 == 3 else tonelli_shanks(c, q)
    n = p * q
    x1 = crt([r, s], [p, q])
    x2 = crt([r, -s % q], [p, q])
    x3 = crt([-r % p, s], [p, q])
    x4 = crt([-r % p, -s % q], [p, q])
    return [x1, x2, x3, x4]
```

**注意**：Rabin 解密得到四个可能的明文，需要用冗余信息（如 padding 或明文结构）确定正确的那个。
