# 二次剩余

二次剩余理论在密码学中有两个直接应用：Goldwasser-Micali 概率加密和 Rabin 加密。更深层地，它是数域筛法（NFS）等现代分解算法的基础。

---

## 定义

设 $p$ 为奇素数，$a$ 为整数且 $p \nmid a$。若存在 $x$ 使：

$$x^2 \equiv a \pmod p$$

则称 $a$ 为模 $p$ 的**二次剩余**（Quadratic Residue, QR），记作 $a \in \mathrm{QR}_p$；否则称为**二次非剩余**（Quadratic Non-residue, QNR），记作 $a \in \mathrm{QNR}_p$。

**计数**：模 $p$ 的 $\mathbb{Z}_p^*$ 中，QR 和 QNR 各占一半，即各 $\frac{p-1}{2}$ 个。因为映射 $x \mapsto x^2$ 是 $\mathbb{Z}_p^* \to \mathrm{QR}_p$ 的 2-to-1 满射。

---

## 勒让德符号

### 定义

$$\left(\frac{a}{p}\right) = \begin{cases}
1 & \text{若 } a \in \mathrm{QR}_p \\
-1 & \text{若 } a \in \mathrm{QNR}_p \\
0 & \text{若 } p \mid a
\end{cases}$$

### 欧拉准则

$$\left(\frac{a}{p}\right) \equiv a^{(p-1)/2} \pmod p$$

**证明**：由费马小定理 $a^{p-1} \equiv 1 \pmod p$，故 $a^{(p-1)/2} \equiv \pm 1$。

若 $a \equiv x^2$，则 $a^{(p-1)/2} \equiv x^{p-1} \equiv 1 \pmod p$。

反之，若 $a^{(p-1)/2} \equiv 1 \pmod p$，考虑原根 $g$，设 $a = g^t$。则 $g^{t(p-1)/2} \equiv 1$，故 $(p-1) \mid \frac{t(p-1)}{2}$，即 $t$ 为偶数，$a$ 为平方。

```
function legendre(a, p):
    result = pow(a, (p - 1) // 2, p)
    if result == p - 1:
        return -1
    return result  # 0 or 1
```

### 二次互反律

Gauss 称其为"黄金定理"。对不同的奇素数 $p, q$：

$$\left(\frac{p}{q}\right)\left(\frac{q}{p}\right) = (-1)^{\frac{p-1}{2}\cdot\frac{q-1}{2}}$$

即 $p$ 和 $q$ 模彼此的二次剩余关系由它们模 4 的余数决定：仅当 $p \equiv q \equiv 3 \pmod 4$ 时，二者符号相反。

**补充公式**：

$$\left(\frac{-1}{p}\right) = (-1)^{\frac{p-1}{2}} = \begin{cases}
1 & \text{若 } p \equiv 1 \pmod 4 \\
-1 & \text{若 } p \equiv 3 \pmod 4
\end{cases}$$

$$\left(\frac{2}{p}\right) = (-1)^{\frac{p^2-1}{8}} = \begin{cases}
1 & \text{若 } p \equiv \pm 1 \pmod 8 \\
-1 & \text{若 } p \equiv \pm 3 \pmod 8
\end{cases}$$

## 雅可比符号

勒让德符号的推广，允许分母为任意奇数 $m$。设 $m = \prod p_i^{e_i}$：

$$\left(\frac{a}{m}\right) = \prod \left(\frac{a}{p_i}\right)^{e_i}$$

计算雅可比符号时不需要分解 $m$，可像分数一样"约分"后套用互反律。但雅可比符号 $\left(\frac{a}{m}\right) = 1$ 不能推出 $a$ 是模 $m$ 的 QR（因为分子分母可各贡献 $-1$ 负负得正）。

### 雅可比符号的运用

确定素数 $p$ 是 $10^9+7$ 级的大数时，直接判断 QR 需要原根或二次互反律的快速计算。雅可比符号以 $O(\log^2 n)$ 时间完成判定，无需分解。

## Tonelli-Shanks 算法

求模奇素数 $p$ 下的平方根，即解 $x^2 \equiv n \pmod p$。

### 算法步骤

```
function tonelli_shanks(n, p):
    if legendre(n, p) != 1:
        return None  # no solution

    # Step 1: 提取因子2
    Q, S = p - 1, 0
    while Q % 2 == 0:
        Q //= 2
        S += 1

    # Step 2: 找二次非剩余 z
    z = 2
    while legendre(z, p) != -1:
        z += 1

    # Step 3: 初始化
    M, c, t, R = S, pow(z, Q, p), pow(n, Q, p), pow(n, (Q + 1) // 2, p)

    # Step 4: 循环迭代
    while True:
        if t == 0:
            return 0
        if t == 1:
            return R

        i = 1
        temp = (t * t) % p
        while temp != 1:
            temp = (temp * temp) % p
            i += 1

        b = pow(c, 1 << (M - i - 1), p)
        M, c, t, R = i, (b * b) % p, (t * b * b) % p, (R * b) % p
```

**我的见解**：Tonelli-Shanks 实质是把平方根问题归约到循环群中求某个元素的离散对数。若只求实用，最常见的特殊情况 $p \equiv 3 \pmod 4$ 即可直接计算 $x \equiv n^{(p+1)/4} \pmod p$，覆盖近似一半的素数。

### Cipolla 算法（替代方案）

求 $t, \omega$ 满足 $n = t^2 - \omega^2$，在二次扩域 $\mathbb{F}\_{p}[\sqrt{\omega^2-n}]$ 中计算 $(t + \sqrt{\omega^2-n})^{(p+1)/2}$。与 Tonelli-Shanks 相比，Cipolla 不需要非剩余 $z$ 的预搜索。

## Solovay-Strassen 素性测试

利用欧拉准则：若 $n$ 为素数，对所有 $a$ 有 $a^{(n-1)/2} \equiv \left(\frac{a}{n}\right) \pmod n$。该测试比费马测试更严格——Carmichael 数无法欺骗 Solovay-Strassen，但仅被 Miller-Rabin 严格支配。

```
function solovay_strassen(n, k=10):
    if n == 2:
        return True
    if n % 2 == 0:
        return False
    repeat k times:
        a = randint(2, n - 1)
        x = legendre(a, n)
        if x == 0:
            return False
        if pow(a, (n - 1) // 2, n) != x % n:
            return False
    return True
```

## 二次剩余在密码学中的应用

### Goldwasser-Micali 加密

第一个被证明语义安全的公钥加密方案。

- 密钥生成：$n = pq$，选 QNR $y$ 使 $\left(\frac{y}{p}\right) = \left(\frac{y}{q}\right) = -1$
- 公钥：$(n, y)$；私钥：$(p, q)$
- 加密：对每个比特 $b$，$c = r^2 \cdot y^b \bmod n$（$r$ 随机）
- 解密：判断 $\left(\frac{c}{p}\right)$——若为 1，$b=0$；否则 $b=1$

### Rabin 加密

$c \equiv m^2 \pmod n$（$n = pq$）。解密需要同时求模 $p$ 和模 $q$ 的平方根，再经 CRT 合并得到四个可能的 $m$。

```
function sqrt_mod_prime(a, p):
    assert legendre(a, p) == 1
    if p % 4 == 3:
        x = pow(a, (p + 1) // 4, p)
        return x, p - x
    return tonelli_shanks(a, p)
```

**计算练习**：已知 $p = 101$，$q = 103$，$c = 2091$，用 Rabin 解密得到四个候选 $m$，并用明文特征确定正确值。

```python
def rabin_decrypt(c, p, q):
    r = pow(c, (p + 1) // 4, p) if p % 4 == 3 else tonelli_shanks(c, p)
    s = pow(c, (q + 1) // 4, q) if q % 4 == 3 else tonelli_shanks(c, q)
    n = p * q
    x1 = crt([r, s], [p, q])
    x2 = crt([r, -s % q], [p, q])
    x3 = crt([-r % p, s], [p, q])
    x4 = crt([-r % p, -s % q], [p, q])
    return [x1, x2, x3, x4]
```
