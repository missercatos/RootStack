# 欧拉定理、费马小定理与特殊同余式

本章是 RSA 公钥密码的数学核心。没有这些定理，公钥密码可能到今天还没有诞生。

---

## 欧拉函数 $\varphi(n)$

### 定义

$$\varphi(n) = |\{k \in \mathbb{Z}^+ \mid 1 \le k \le n,\ \gcd(k, n) = 1\}|$$

即小于等于 $n$ 且与 $n$ 互素的正整数个数。

### 计算公式

1. **素数的幂**：若 $p$ 为素数，
 $$\varphi(p) = p - 1$$
 $$\varphi(p^k) = p^k - p^{k-1} = p^{k-1}(p-1)$$

2. **积性**：若 $\gcd(m, n) = 1$，
 $$\varphi(mn) = \varphi(m)\varphi(n)$$

3. **一般公式**：由算术基本定理 $n = \prod p_i^{e_i}$，
 $$\varphi(n) = n \prod_{p \mid n} \left(1 - \frac{1}{p}\right)$$

**积性证明**：当 $\gcd(m, n) = 1$ 时，CRT 给出双射 $\mathbb{Z}_{mn} \cong \mathbb{Z}_m \times \mathbb{Z}_n$，它将 $\mathbb{Z}_{mn}^*$ 映射到 $\mathbb{Z}_m^* \times \mathbb{Z}_n^*$，故 $|\mathbb{Z}_{mn}^*| = |\mathbb{Z}_m^*| \cdot |\mathbb{Z}_n^*|$。

```
function euler_phi(n):
 result = n
 p = 2
 while p * p <= n:
 if n % p == 0:
 while n % p == 0:
 n //= p
 result = result // p * (p - 1)
 p += 1 if p == 2 else 2
 if n > 1:
 result = result // n * (n - 1)
 return result
```

## 费马小定理

### 定理

若 $p$ 为素数且 $\gcd(a, p) = 1$，则：

$$a^{p-1} \equiv 1 \pmod p$$

**等价形式**：对任意整数 $a$：$a^p \equiv a \pmod p$。

### 证明一（组合方法）

考虑二项式展开 $(a+1)^p$：

$$(a+1)^p = \sum_{k=0}^p \binom{p}{k} a^k$$

对 $1 \le k \le p-1$，$\binom{p}{k} = p \cdot \frac{(p-1)!}{k!(p-k)!}$ 是 $p$ 的倍数。故：

$$(a+1)^p \equiv a^p + 1 \pmod p$$

由归纳法得 $a^p \equiv a \pmod p$，约去 $a$（当 $\gcd(a,p)=1$）得 $a^{p-1} \equiv 1 \pmod p$。

### 证明二（群论方法）

$\mathbb{Z}_p^*$ 是 $p-1$ 阶乘法群。由 Lagrange 定理，群中任意元素的阶整除群阶，故 $a^{p-1} \equiv 1 \pmod p$。

### 应用：素性测试与求逆

费马小定理的逆否命题：若存在 $a$ 使 $a^{n-1} \not\equiv 1 \pmod n$，则 $n$ 必为合数。但 Carmichael 数 $n = 561$ 对**所有** $\gcd(a, n)=1$ 都满足 $a^{n-1} \equiv 1 \pmod n$，故费马测试不可靠。

**求模逆元**（模数为素数时）：

$$a^{-1} \equiv a^{p-2} \pmod p$$

```python
mod_inverse_via_fermat = lambda a, p: pow(a, p - 2, p)
```

## 欧拉定理

### 定理

费马小定理的推广：若 $\gcd(a, n) = 1$，则：

$$a^{\varphi(n)} \equiv 1 \pmod n$$

当 $n = p$（素数）时 $\varphi(p) = p-1$，退化为费马小定理。

### 证明（群论）

$\mathbb{Z}_n^*$ 是 $\varphi(n)$ 阶乘法群。$\mathbb{Z}_n^*$ 中任意元素 $a$ 的阶整除 $\varphi(n)$，故 $a^{\varphi(n)} \equiv 1$。

### 证明（集合方法）

设简化剩余系 $R = \{r_1, r_2, \dots, r_{\varphi(n)}\}$。乘以 $a$ 后得 $\{a r_1, \dots, a r_{\varphi(n)}\}$，仍为简化剩余系（$\gcd(a,n)=1$ 保证）。故：

$$\prod_{i=1}^{\varphi(n)} r_i \equiv \prod_{i=1}^{\varphi(n)} a r_i \equiv a^{\varphi(n)} \prod_{i=1}^{\varphi(n)} r_i \pmod n$$

两边约去与 $n$ 互素的 $\prod r_i$，得 $a^{\varphi(n)} \equiv 1 \pmod n$。

## 威尔逊定理

### 定理

$p$ 为素数当且仅当：

$$(p-1)! \equiv -1 \pmod p$$

### 证明

若 $p$ 为素数，$\mathbb{Z}_p^*$ 中元素与其逆元配对。$a = a^{-1}$ 的元素满足 $a^2 \equiv 1$，即 $a \equiv \pm 1$。其余 $\varphi(p) - 2$ 个元素两两互为逆元，乘积为 $1$。故 $(p-1)! \equiv 1 \cdot (-1) \cdot 1 = -1 \pmod p$。

反之，若 $p$ 为合数且 $(p-1)! \equiv -1 \pmod p$，则 $p \mid ((p-1)! + 1)$。但若 $p$ 有真因子 $d$，则 $d \mid (p-1)!$，从而 $d \mid 1$，矛盾。

学术价值大于实用价值。

## 卡迈克尔函数 $\lambda(n)$

### 定义

$\lambda(n)$ 是模 $n$ 下乘法群的**指数**（exponent），即使得 $a^{\lambda(n)} \equiv 1 \pmod n$ 对所有 $\gcd(a, n) = 1$ 成立的最小正整数。

对 RSA 模数 $n = pq$：

$$\lambda(n) = \operatorname{lcm}(p-1, q-1)$$

**对比**：$\varphi(n) = (p-1)(q-1)$，而 $\lambda(n)$ 可能更小。例如 $p=3, q=5$，则 $\varphi(15)=8$，$\lambda(15)=4$。

实际上 RSA 中只需满足 $ed \equiv 1 \pmod{\lambda(n)}$ 即可，不一定要模 $\varphi(n)$。

```python
def carmichael(p, q):
 return lcm(p - 1, q - 1)
```

PKCS#1 标准倾向于使用 $\lambda(n)$ 而非 $\varphi(n)$。如果不熟悉卡迈克尔函数，在推导私钥参数时会绕弯路。

## RSA 解密正确性的完整证明

### 用欧拉定理

$ed \equiv 1 \pmod{\varphi(n)}$，即 $ed = 1 + k\varphi(n)$。

$$c^d \equiv (m^e)^d \equiv m^{ed} \equiv m^{1 + k\varphi(n)} \equiv m \cdot (m^{\varphi(n)})^k \equiv m \cdot 1^k \equiv m \pmod n$$

该证明要求 $\gcd(m, n) = 1$。

### 用 CRT（覆盖 $\gcd(m, n) \neq 1$ 情形）

若 $\gcd(m, n) \neq 1$，即 $p \mid m$ 或 $q \mid m$。此时从欧拉定理的角度 $m^{\varphi(n)} \not\equiv 1 \pmod p$。

CRT 方法：先证 $m^{ed} \equiv m \pmod p$ 和 $m^{ed} \equiv m \pmod q$，再由 CRT 得 $m^{ed} \equiv m \pmod n$。

- 若 $p \mid m$，两边模 $p$ 均 $\equiv 0$，显然成立
- 若 $p \nmid m$，由费马小定理 $m^{p-1} \equiv 1 \pmod p$，又 $ed \equiv 1 \pmod{p-1}$（因为 $ed \equiv 1 \pmod{\lambda(n)}$ 且 $\lambda(n) \mid (p-1)$），故 $m^{ed} \equiv m \pmod p$

## 常见应用

### 已知部分分解求 $d$

若已知 $n$ 的一个素因子 $p$，则 $q = n/p$，$\varphi(n) = (p-1)(q-1)$，$d \equiv e^{-1} \pmod{\varphi(n)}$。

### $p-1$ 光滑的分解

若 $p-1$ 的所有素因子 $\le B$，则 Pollard $p-1$ 算法可在 $O(B \log B)$ 时间内分解 $n$。

**原理**（基于费马小定理）：计算 $a = 2^{B!} \bmod n$。若 $p-1 \mid B!$，则 $a \equiv 2^{B!} \equiv 1 \pmod p$，于是 $p \mid (a-1)$。

```python
def pollard_pm1(n, B=2**20):
 a = 2
 for j in range(2, B):
 a = pow(a, j, n)
 d = gcd(a - 1, n)
 if 1 < d < n:
 return d
 return None
```
