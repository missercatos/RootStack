# 欧拉定理、费马小定理与特殊同余式

本章是 RSA 的理论核心。没有这三个定理，公钥密码可能到今天还没诞生。

## 欧拉函数 $\varphi(n)$

$\varphi(n)$ 表示小于等于 $n$ 且与 $n$ 互素的正整数个数。

计算规则：

1. 若 $p$ 为素数，$\varphi(p) = p-1$
2. 若 $p$ 为素数，$\varphi(p^k) = p^k - p^{k-1} = p^{k-1}(p-1)$
3. 若 $\gcd(m, n) = 1$，$\varphi(mn) = \varphi(m)\varphi(n)$（积性函数）
4. 若 $n = \prod p_i^{e_i}$，$\varphi(n) = n \prod (1 - \frac{1}{p_i})$

```
function euler_phi(n):
    result = n
    p = 2
    while p * p <= n:
        if n % p == 0:
            while n % p == 0:
                n //= p
            result = result // p * (p - 1)
        p += 1 if p == 2 else 2
    if n > 1:
        result = result // n * (n - 1)
    return result
```

## 费马小定理

若 $p$ 为素数，$\gcd(a, p) = 1$，则

$$a^{p-1} \equiv 1 \pmod p$$

这是整个数论中最重要的定理之一。

等价形式：
- $a^p \equiv a \pmod p$（对任意 $a$ 成立）

**我的见解**：费马小定理的绝妙之处是把看似不相关的指数运算和同余联系了起来。RSA 中 $e \cdot d \equiv 1 \pmod{p-1}$ 的选取就源于此——解密时 $m^{ed} \equiv m \pmod p$ 能成立，核心就是费马小定理。

### 应用：快速判定合数

费马小定理的逆否命题给出一个快速素性测试：若存在 $a$ 使 $a^{n-1} \not\equiv 1 \pmod n$，则 $n$ 必为合数。这就是费马素性测试。

但存在合数（Carmichael 数）对所有的 $a$ 都满足 $a^{n-1} \equiv 1$，比如 $561 = 3 \times 11 \times 17$。因此实际使用 Miller-Rabin。

### 应用：求模逆元

结合费马小定理，当模 $p$ 为素数时：

$$a^{-1} \equiv a^{p-2} \pmod p$$

```python
mod_inverse_via_fermat = lambda a, p: pow(a, p-2, p)
```

**注意**：这只在模数为素数时有效。通用情况仍要用扩展欧几里得。

## 欧拉定理

费马小定理的推广：若 $\gcd(a, n) = 1$，则

$$a^{\varphi(n)} \equiv 1 \pmod n$$

当 $n = p$ 为素数时 $\varphi(p) = p-1$，退化为费马小定理。

欧拉定理的几何直觉：在简化剩余系中不断乘以 $a$ 会 ${\varphi(n)}$ 步后回到自身，因为简化剩余系的大小恰好是 $\varphi(n)$。

### 应用：RSA 解密正确性证明

RSA 中 $ed \equiv 1 \pmod{\varphi(n)}$，即 $ed = 1 + k\varphi(n)$。

$$c^d \equiv m^{ed} \equiv m^{1 + k\varphi(n)} \equiv m \cdot (m^{\varphi(n)})^k \equiv m \cdot 1^k \equiv m \pmod n$$

于是解密得到原始明文。

## 特殊同余式与模数性质

### 威尔逊定理

$p$ 为素数当且仅当 $(p-1)! \equiv -1 \pmod p$。

学术价值大于实用价值。CTF 中出现频率极低。

### 卡迈克尔函数 $\lambda(n)$

比 $\varphi(n)$ 更精确的指数周期。对于 RSA：

$$\lambda(n) = \operatorname{lcm}(p-1, q-1)$$

实际上 RSA 中 $ed \equiv 1 \pmod{\lambda(n)}$ 就足够了，不一定要模 $\varphi(n)$。PKCS#1 标准也倾向于使用 $\lambda(n)$。

```python
from math import gcd, lcm
def carmichael(p, q):
    return lcm(p - 1, q - 1)
```

**我的见解**：较新的密码学题目开始用 $\lambda(n)$ 代替 $\varphi(n)$ 出题。如果不熟悉卡迈克尔函数，做私钥相关推导时会多绕弯路。

## 常见应用

### 已知部分分解

若已知 $n$ 的部分素因子（如 $p$），直接计算 $\varphi(n) = (p-1)(q-1)$ 即可求 $d$。

```python
p = 12345678901234567891
q = n // p
phi = (p - 1) * (q - 1)
d = pow(e, -1, phi)  # Python 3.8+
m = pow(c, d, n)
```

### $p-1$ 光滑的分解

若 $p-1$ 只有小素因子，可以用 Pollard's $p-1$ 算法分解。核心原理就是费马小定理。

```python
def pollard_pm1(n, B=2**20):
    a = 2
    for j in range(2, B):
        a = pow(a, j, n)
        d = gcd(a - 1, n)
        if 1 < d < n:
            return d
    return None
```

这个方法在 $p-1$ 的所有素因子都不超过 $B$ 时有效。
