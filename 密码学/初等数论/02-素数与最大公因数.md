# 素数与最大公因数

素数是一切整数的"原子"。本章从素数的严格定义出发，完整覆盖素数判定、因数分解、最大公因数与扩展欧几里得算法。

---

## 素数

### 定义

大于 1 的整数 $p$ 称为**素数**，当且仅当其正因数只有 1 和 $p$ 自身：

$$p > 1 \text{ 为素数} \iff \forall d \in \mathbb{Z}^+,\ d \mid p \implies d = 1 \lor d = p$$

### 等价定义（欧几里得引理）

$p$ 为素数的充要条件是：对任意整数 $a, b$，

$$p \mid ab \implies p \mid a \ \lor\ p \mid b$$

这个性质是算术基本定理唯一性证明的核心。

### 欧几里得定理：素数无限

**定理**：素数有无穷多个。

**证明**（经典反证法）：假设仅有有限个素数 $p_1, p_2, \dots, p_k$。构造 $N = p_1 p_2 \cdots p_k + 1$。$N$ 必有素因子 $q$。若 $q$ 属于 $\{p_1, \dots, p_k\}$，则 $q \mid N$ 且 $q \mid p_1 \cdots p_k$，从而 $q \mid (N - p_1 \cdots p_k) = 1$，矛盾。故 $q$ 必为新的素数，与假设矛盾。

$$\#\{\text{素数}\} = \infty$$

## 素数筛法

### 埃拉托斯特尼筛法

对有限范围内找素数最高效的方法之一。

```
function sieve_of_eratosthenes(n):
 is_prime = [True] * (n + 1)
 is_prime[0] = is_prime[1] = False
 for i in range(2, int(sqrt(n)) + 1):
 if is_prime[i]:
 for j in range(i * i, n + 1, i):
 is_prime[j] = False
 return [i for i, p in enumerate(is_prime) if p]
```

**正确性**：合数 $m$ 的最小素因子 $p \le \sqrt{m}$，因此当 $i$ 遍历至 $\sqrt{n}$ 时，所有合数均被标记。

### 线性筛（欧拉筛）

埃筛中一个合数可能被多次标记（如 $12 = 2 \times 6 = 3 \times 4$）。线性筛确保每个合数只被其**最小素因子**标记一次。

```
function linear_sieve(n):
 primes = []
 is_prime = [True] * (n + 1)
 for i in range(2, n + 1):
 if is_prime[i]:
 primes.append(i)
 for p in primes:
 if i * p > n:
 break
 is_prime[i * p] = False
 if i % p == 0:
 break # p 是 i 的最小素因子，退出
 return primes
```

**关键**：`if i % p == 0: break` 保证每个合数只被标记一次。为什么？若 $i$ 有素因子 $p$，则对任意更大的 $p' > p$，$i \cdot p'$ 的最小素因子是 $p$ 而非 $p'$，应由外层循环的后续 $i$ 处理。

## 素数判定

### 试除法

验证 $n$ 是否为素数，检查 $2$ 到 $\sqrt{n}$ 的所有整数：

```
function is_prime_trial(n):
 if n < 2:
 return False
 if n == 2:
 return True
 if n % 2 == 0:
 return False
 i = 3
 while i * i <= n:
 if n % i == 0:
 return False
 i += 2
 return True
```

时间复杂度 $O(\sqrt{n})$，对大数不可行。

### Miller-Rabin 素性测试

概率性测试，对密码学应用足够可靠。

**数学基础**：对奇素数 $n$，设 $n - 1 = 2^s d$（$d$ 奇数）。则对任意 $\gcd(a, n) = 1$，以下之一必成立：

1. $a^d \equiv 1 \pmod n$
2. 存在 $0 \le r < s$ 使 $a^{2^r d} \equiv -1 \pmod n$

这是因为 $\mathbb{Z}_n^*$ 是循环群（$n$ 为素数时）或至少其阶 $n-1$ 的每个 2-幂次步都有唯一平方根。

```
function miller_rabin(n, k=10):
 if n < 2:
 return False
 if n == 2 or n == 3:
 return True
 if n % 2 == 0:
 return False
 s, d = 0, n - 1
 while d % 2 == 0:
 s += 1
 d //= 2
 repeat k times:
 a = randint(2, n - 2)
 x = pow(a, d, n)
 if x == 1 or x == n - 1:
 continue
 for _ in range(s - 1):
 x = pow(x, 2, n)
 if x == n - 1:
 break
 else:
 return False # composite
 return True # probable prime
```

**错误概率**：单次测试将合数误判为素数的概率 $\le \frac{1}{4}$；$k$ 次后 $\le 4^{-k}$。

### Carmichael 数

存在合数 $n$ 满足对所有与 $n$ 互素的 $a$ 都有 $a^{n-1} \equiv 1 \pmod n$。这样的合数称为 **Carmichael 数**，最小的是 $561 = 3 \times 11 \times 17$。

**Korselt 准则**：$n$ 是 Carmichael 数当且仅当：
1. $n$ 无平方因子（$n = p_1 p_2 \cdots p_k$，$p_i$ 两两不同）
2. 对所有 $p_i \mid n$，$(p_i - 1) \mid (n - 1)$

```
def is_carmichael(n):
 if miller_rabin(n):
 return False
 factors = factorize(n) # 假设已有分解
 for p in factors:
 if is_prime(p):
 if (n - 1) % (p - 1) != 0:
 return False
 return all(e == 1 for _, e in factors) # 无平方因子
```

**我的见解**：Carmichael 数就是"能骗过费马测试"的数，这就是为什么实际不用费马测试而用 Miller-Rabin。

## 因数分解

### 试除法

```
function trial_division(n):
 factors = []
 for p in primes_upto(sqrt(n)):
 while n % p == 0:
 factors.append(p)
 n //= p
 if n > 1:
 factors.append(n)
 return factors
```

### Pollard's Rho 算法

利用 Floyd 循环检测，在随机序列中找到因子。

**数学原理**：设 $f(x) = (x^2 + c) \bmod n$，迭代 $x_{i+1} = f(x_i)$。序列在模 $n$ 的周期 $O(\sqrt{n})$，但在模 $p \mid n$ 的周期 $O(\sqrt{p})$。用 Floyd 算法检测模 $p$ 下的碰撞，碰撞点差值 $\gcd(|x_{2i} - x_i|, n)$ 给出 $p$。

```
function pollard_rho(n):
 if n % 2 == 0:
 return 2
 if miller_rabin(n):
 return n
 while True:
 c = randint(1, n - 1)
 f = lambda x: (x * x + c) % n
 x, y, d = 2, 2, 1
 while d == 1:
 x = f(x)
 y = f(f(y))
 d = gcd(abs(x - y), n)
 if d != n:
 return d
```

**计算练习**：用 Pollard's Rho 分解 $n = 1000000000000000003 \times 1000000000000000061$（验算乘积值），提取两个素因子。

## 扩展欧几里得算法

### 定理（Bézout）

对任意整数 $a, b$ 不全为零，存在整数 $x, y$ 使得：

$$ax + by = \gcd(a, b)$$

**证明**（构造性）：算法本身即构造。

### 递归实现

```
function extended_gcd(a, b):
 if b == 0:
 return (a, 1, 0)
 g, x1, y1 = extended_gcd(b, a % b)
 x = y1
 y = x1 - (a // b) * y1
 return (g, x, y)
```

### 矩阵形式

每次迭代相当于矩阵乘法：

$$\begin{pmatrix} a \\ b \end{pmatrix} =
\begin{pmatrix} q_1 & 1 \\ 1 & 0 \end{pmatrix}
\begin{pmatrix} b \\ r_1 \end{pmatrix} =
\prod_{i=1}^{k} \begin{pmatrix} q_i & 1 \\ 1 & 0 \end{pmatrix}
\begin{pmatrix} \gcd(a,b) \\ 0 \end{pmatrix}$$

这为理解连分数与欧几里得算法的关系提供了代数组角。

### 求模逆元

若 $\gcd(a, n) = 1$，则 $\exists x$ 使 $ax \equiv 1 \pmod n$，即 $x = a^{-1} \bmod n$。

```python
def mod_inverse(a, n):
 g, x, _ = extended_gcd(a, n)
 if g != 1:
 return None
 return x % n
```

**我的见解**：扩展欧几里得是密码学中调用最频繁的算法——RSA 密钥生成、CRT 加速、ElGamal 解密都要用它。

## 算术基本定理在数论中的运用

许多问题可通过素因子分解简化：

| 命题 | 证明思路 |
|------|---------|
| $d \mid ab$ 不意味 $d \mid a$ 或 $d \mid b$ | 反例：$6 \mid 2 \times 3$ 但不整除任一 |
| $\gcd(a, a+1) = 1$ | 分解代入，相邻数无公共因子 |
| $a^n \mid b^n \implies a \mid b$ | 两边比指数 |
| $\gcd(a, b) = 1 \land a \mid bc \implies a \mid c$ | 欧几里得引理 |

**计算练习**：用 Fermat 分解法分解 $n = pq$，其中 $p, q$ 相差很小（$|p-q| < n^{1/4}$）。

```python
def fermat_factor(n):
 a = isqrt(n)
 if a * a < n:
 a += 1
 b2 = a * a - n
 while b2 >= 0:
 b = isqrt(b2)
 if b * b == b2:
 return a - b, a + b
 a += 1
 b2 = a * a - n
 return None
```
