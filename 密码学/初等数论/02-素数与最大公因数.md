# 素数与最大公因数

## 素数

大于 1 且只能被 1 和自身整除的整数称为素数（质数）。素数分布是整个数论最迷人的话题之一。

### 素数判定

最简单的试除法：

```
function is_prime_trial(n):
    if n < 2:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False
    i = 3
    while i * i <= n:
        if n % i == 0:
            return False
        i += 2
    return True
```

时间复杂度 $O(\sqrt{n})$，对大数不可行。

### Miller-Rabin 素性测试

密码学中真正使用的是概率性测试，速度快且足够可靠。

核心思想：对奇素数 $n$，设 $n-1 = 2^s d$（$d$ 奇数），则以下两条必成立其一：

1. $a^d \equiv 1 \pmod n$
2. 存在 $0 \le r < s$ 使得 $a^{2^r d} \equiv -1 \pmod n$

```
function miller_rabin(n, k=10):
    if n < 2:
        return False
    if n == 2 or n == 3:
        return True
    if n % 2 == 0:
        return False

    # n-1 = 2^s * d, d odd
    s, d = 0, n - 1
    while d % 2 == 0:
        s += 1
        d //= 2

    repeat k times:
        a = randint(2, n - 2)
        x = pow(a, d, n)
        if x == 1 or x == n - 1:
            continue
        for _ in range(s - 1):
            x = pow(x, 2, n)
            if x == n - 1:
                break
        else:
            return False  # composite
    return True  # probable prime
```

**我的见解**：大多数应用场景不会让你手动写 Miller-Rabin（直接用 `sympy.isprime`），但理解算法原理有助于判断给定的"大素数"是否可能不是真正的素数。

## 素数筛法

要快速枚举一定范围内的所有素数，用筛法。

### 埃拉托斯特尼筛法

```
function sieve_of_eratosthenes(n):
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    for i in range(2, int(sqrt(n)) + 1):
        if is_prime[i]:
            for j in range(i * i, n + 1, i):
                is_prime[j] = False
    return [i for i, p in enumerate(is_prime) if p]
```

### 线性筛（欧拉筛）

埃筛的问题是同一个合数可能被标记多次。线性筛保证每个合数只被其最小素因子筛掉一次。

```
function linear_sieve(n):
    primes = []
    is_prime = [True] * (n + 1)
    for i in range(2, n + 1):
        if is_prime[i]:
            primes.append(i)
        for p in primes:
            if i * p > n:
                break
            is_prime[i * p] = False
            if i % p == 0:
                break
    return primes
```

**在算法中的应用**：筛法用于分析数论相关的算法效率。例如分解时若某个素因子在 $10^6$ 量级，可以先筛出小素数再试除。

## 因数分解

算术基本定理告诉我们分解存在，但没告诉我们怎么找。大整数分解是 RSA 安全性的基石。

### 试除法

最简单也最慢，适合分解小因子。

```
function trial_division(n):
    factors = []
    for p in primes_upto(sqrt(n)):
        while n % p == 0:
            factors.append(p)
            n //= p
    if n > 1:
        factors.append(n)  # n is prime
    return factors
```

### Pollard's Rho 算法

适合提取中等大小的素因子（$10^{10}$ 到 $10^{20}$ 量级）。

核心思想：用随机函数 $f(x) = (x^2 + c) \bmod n$ 产生序列，利用生日悖论找到碰撞。

```
function pollard_rho(n):
    if n % 2 == 0:
        return 2
    if miller_rabin(n):
        return n
    while True:
        c = randint(1, n - 1)
        f = lambda x: (x * x + c) % n
        x, y, d = 2, 2, 1
        while d == 1:
            x = f(x)
            y = f(f(y))
            d = gcd(abs(x - y), n)
        if d != n:
            return d
```

**计算练习**：给定合数 $n = 1000000000000000003 \times 1000000000000000061$（乘积值），试用 Pollard's Rho 算法提取非平凡因子。

```python
from math import gcd
from random import randint

def pollard_rho(n):
    if n % 2 == 0:
        return 2
    if pow(2, n-1, n) != 1:
        return n
    x = randint(2, n-1)
    y = x
    c = randint(1, n-1)
    d = 1
    f = lambda x: (x*x + c) % n
    while d == 1:
        x = f(x)
        y = f(f(y))
        d = gcd(abs(x-y), n)
    return d if d != n else None
```

## 最大公因数与扩展欧几里得算法

上一章介绍了欧几里得算法求 gcd，这一章看它的扩展——**扩展欧几里得算法**。

该算法不仅能求 $\gcd(a, b)$，还能找到整数 $x, y$ 使得：

$$ax + by = \gcd(a, b)$$

这就是贝祖等式（Bézout's identity）。在密码学中，这个算法最大用途是**求模逆元**。

```
function extended_gcd(a, b):
    if b == 0:
        return (a, 1, 0)  # gcd, x, y
    g, x1, y1 = extended_gcd(b, a % b)
    x = y1
    y = x1 - (a // b) * y1
    return (g, x, y)
```

**求模逆元**：要求 $a^{-1} \pmod n$，即找 $x$ 使 $ax \equiv 1 \pmod n$，等价于求解 $ax + ny = 1$。

```python
def mod_inverse(a, n):
    g, x, _ = extended_gcd(a, n)
    if g != 1:
        return None  # no inverse
    return x % n
```

**我的见解**：扩展欧几里得是密码学中被调用最频繁的算法之一——RSA 密钥生成、CRT 加速、ElGamal 解密处处用到。掌握它的递归推导比死记代码重要得多：每次递归实际上是在做 $ax + by = \gcd(a, b) \to bx_1 + (a \bmod b)y_1 = \gcd$ 的递推。

## 整数唯一分解性质在密码学中的意义

整数的许多性质看似简单，但正是这些基础的"积木"决定了密码算法的安全性。

| 性质 | 在密码学中的影响 |
|------|----------------|
| 素数无平凡因子 | RSA 依赖大整数分解困难性 |
| gcd 可高效计算 | 密钥生成、共模攻击都可快速检测 |
| 唯一分解定理 | TLS/ECDH 的参数标准化基础 |
| 欧几里得算法高效 | 模逆元可快速计算，RSA 解密才可能实时 |

**计算练习**：给定 $n = pq$，若 $p, q$ 相差很小（如 $|p - q| < n^{1/4}$），可用 Fermat 分解快速求解 $p, q$。

```python
def fermat_factor(n):
    a = isqrt(n)
    if a * a < n:
        a += 1
    b2 = a * a - n
    while b2 >= 0:
        b = isqrt(b2)
        if b * b == b2:
            return a - b, a + b
        a += 1
        b2 = a * a - n
    return None
```
