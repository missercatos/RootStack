# 原根与整数阶

原根理论回答了"模 $p$ 乘法群是什么结构"这个问题——它是循环群。离散对数问题的困难性则正是 Diffie-Hellman 密钥交换和 ElGamal 加密的安全基石。

---

## 整数阶

### 定义

设 $\gcd(a, n) = 1$。使

$$a^k \equiv 1 \pmod n$$

成立的最小正整数 $k$ 称为 $a$ 模 $n$ 的**阶**，记作 $\operatorname{ord}_n(a)$。

由欧拉定理得：

$$\operatorname{ord}_n(a) \mid \varphi(n)$$

### 阶的性质

对任意 $k \ge 1$：

1. $\operatorname{ord}(a^k) = \dfrac{\operatorname{ord}(a)}{\gcd(\operatorname{ord}(a), k)}$
2. $a^m \equiv 1 \iff \operatorname{ord}(a) \mid m$
3. $a^i \equiv a^j \iff i \equiv j \pmod{\operatorname{ord}(a)}$

**性质 1 证明**：设 $d = \operatorname{ord}(a)$，$g = \gcd(d, k)$。则 $(a^k)^{d/g} = a^{d(k/g)} = (a^d)^{k/g} \equiv 1$。若 $a^k$ 的阶为 $r$，则 $r \mid d/g$。另一方面，$a^{kr} \equiv 1$ 故 $d \mid kr$，即 $d/g \mid r$。得 $r = d/g$。

### 效率计算

```python
def order(a, n, phi=None):
    if gcd(a, n) != 1:
        return None
    if phi is None:
        phi = euler_phi(n)
    for d in divisors(phi):
        if pow(a, d, n) == 1:
            return d
    return phi
```

只需枚举 $\varphi(n)$ 的因子（而非 $1$ 到 $\varphi(n)$ 全部），即可找到阶。

## 原根

### 定义

若 $\operatorname{ord}_n(a) = \varphi(n)$，则称 $a$ 为模 $n$ 的**原根**（Primitive Root）。

有原根的模数仅有 $n = 2, 4, p^k, 2p^k$（$p$ 为奇素数）。这是 Gauss 证明的。

### $\mathbb{Z}_p^*$ 是循环群

若 $g$ 为模 $p$ 的原根，则：

$$\{g^0, g^1, g^2, \dots, g^{p-2}\} = \mathbb{Z}_p^*$$

即 $\mathbb{Z}_p^*$ 是由 $g$ 生成的循环群。这是离散对数问题定义的前提。

### 原根计数

模 $p$ 的原根个数为 $\varphi(p-1)$。

**推理**：若 $g$ 是原根，则所有原根恰为 $g^t$（$\gcd(t, p-1) = 1$），共有 $\varphi(p-1)$ 个。

### 原根检验

$g$ 为原根当且仅当：对 $\varphi(p)$ 的每个素因子 $q$，

$$g^{\varphi(p)/q} \not\equiv 1 \pmod p$$

**证明**：若存在 $r < \varphi(p)$ 使 $g^r \equiv 1$，则 $r$ 整除 $\varphi(p)$。由算术基本定理，存在素因子 $q \mid \varphi(p)$ 使 $r \mid \varphi(p)/q$，从而 $g^{\varphi(p)/q} \equiv 1$。

```
def find_primitive_root(p):
    phi = p - 1
    factors = distinct_prime_factors(phi)
    for g in range(2, p):
        ok = True
        for q in factors:
            if pow(g, phi // q, p) == 1:
                ok = False
                break
        if ok:
            return g
    return None
```

**我的见解**：常见的初学误区是枚举 $\varphi(p)$ 的所有因子。检验各素因子即可——若对每个素因子 $q$ 都有 $g^{\varphi(p)/q} \not\equiv 1$，则 $\operatorname{ord}(g) = \varphi(p)$。

## 离散对数问题（DLP）

### 定义

给定模 $p$、原根 $g$ 和 $y$，求整数 $x$（$0 \le x < p-1$）使：

$$g^x \equiv y \pmod p$$

记 $x = \log_g y$，称为**离散对数**。

### 计算 Diffie-Hellman（CDH）假设

给定 $g, g^a, g^b$，计算 $g^{ab}$ 是困难的。

### 判定 Diffie-Hellman（DDH）假设

区分 $(g^a, g^b, g^{ab})$ 和 $(g^a, g^b, g^c)$（$c$ 随机）是困难的。

**关系**：DLP 容易 $\implies$ CDH 容易 $\implies$ DDH 容易。反之均不成立（一般认为）。

---

## DLP 求解算法

### Baby-step Giant-step（BSGS）

中间相遇攻击，时间 $O(\sqrt{p})$，空间 $O(\sqrt{p})$。

设 $m = \lceil \sqrt{p} \rceil$，将 $x$ 写为 $x = im + j$（$0 \le i, j < m$）：

$$g^{im+j} \equiv y \iff g^j \equiv y \cdot (g^{-m})^i$$

```
function bsgs(g, y, p):
    m = ceil(sqrt(p))
    # baby step: 预存 g^j
    table = {}
    cur = 1
    for j in range(m):
        table[cur] = j
        cur = cur * g % p
    # giant step: 寻找碰撞
    factor = pow(g, -m, p)
    cur = y
    for i in range(m):
        if cur in table:
            return i * m + table[cur]
        cur = cur * factor % p
    return None
```

### Pohlig-Hellman 算法

当 $p-1$ 是**光滑数**（所有素因子较小）时高效。

核心思想：对 $p-1 = \prod p_i^{e_i}$ 的每个因子，在子群 $\mathbb{Z}_{p_i^{e_i}}$ 中解 DLP，再用 CRT 合并。

```
function pohlig_hellman(g, y, p):
    factors = factorize(p - 1)
    congruences = []
    for qi, ei in factors:
        # 在阶为 qi^ei 的子群中求解
        gi = pow(g, (p-1) // (qi**ei), p)
        yi = pow(y, (p-1) // (qi**ei), p)
        xi = bsgs(gi, yi, p)
        congruences.append((xi, qi**ei))
    return crt(congruences)
```

**我的见解**：Pohlig-Hellman 是 DLP 求解的"杀手锏"——若 $p-1$ 光滑，BSGS 用不上也能靠这个快速求解。要避免此类攻击，须选安全素数 $p = 2q+1$（$q$ 也为素数），确保 $p-1$ 有大素因子。

### Index Calculus

对 $\mathbb{F}_p^*$ 子指数级算法。核心思路：

1. 选因子基 $B = \{p_1, \dots, p_t\}$（小素数集）
2. 搜集形如 $g^r$ 且 $B$-光滑的方程，线性组合得每个 $p_j$ 的离散对数
3. 对目标 $y$，求 $r$ 使 $y \cdot g^r$ $B$-光滑，间接算出 $\log_g y$

## DLP 在密码学中的应用

### Diffie-Hellman 密钥交换

```
Alice ←→ Bob
选素数 p 和原根 g（公开）
a ← random     b ← random
A = g^a mod p  →   B ← g^b mod p  ←
K = B^a = g^{ab} mod p = A^b mod p
```

### ElGamal 加密

- 密钥：私钥 $x$，公钥 $y = g^x \bmod p$
- 加密 $m$：选随 $k$，输出 $(g^k, m \cdot y^k)$
- 解密：$m = c_2 \cdot (c_1^x)^{-1}$
