# 原根与整数阶

## 阶的定义

给定模 $n$ 和与 $n$ 互素的整数 $a$，使 $a^k \equiv 1 \pmod n$ 成立的最小正整数 $k$ 称为 $a$ 模 $n$ 的**阶**，记作 $\operatorname{ord}_n(a)$。

由欧拉定理得 $\operatorname{ord}_n(a) \mid \varphi(n)$。

```
def order(a, n, phi=None):
    if gcd(a, n) != 1:
        return None
    if phi is None:
        phi = euler_phi(n)
    for d in divisors(phi):
        if pow(a, d, n) == 1:
            return d
    return phi  # 理论上不会走到这
```

**效率优化**：枚举 $\varphi(n)$ 的所有因子检查即可，无需枚举 $1$ 到 $\varphi(n)$。

---

## 原根

若 $a$ 模 $n$ 的阶恰好等于 $\varphi(n)$，称 $a$ 为模 $n$ 的**原根**（Primitive Root）。

有原根的 $n$ 只能是：$2, 4, p^k, 2p^k$（$p$ 为奇素数）。这是高斯证明的。

### 原根的存在性意味着什么

若 $g$ 是模 $p$ 的原根，则集合 $\{g^0, g^1, g^2, \dots, g^{p-2}\}$ 恰好遍历模 $p$ 的全体非零元素。换句话说，模 $p$ 的乘法群 $\mathbb{Z}_p^*$ 是**循环群**。

```
def find_primitive_root(p):
    # 找模 p 的最小原根
    phi = p - 1
    factors = distinct_prime_factors(phi)  # φ(n) 的不同素因子
    for g in range(2, p):
        ok = True
        for q in factors:
            if pow(g, phi // q, p) == 1:
                ok = False
                break
        if ok:
            return g
    return None
```

检查原根的方法：对 $\varphi(p)$ 的每个素因子 $q$，验证 $g^{\varphi(p)/q} \not\equiv 1 \pmod p$。不需要验证所有因子，只需验证素因子。

**我的见解**：原根检验的常见初学误区是全部枚举 $\varphi(p)$ 的因子。实际上只需检验素因子——因为若 $g$ 对每个素因子 $q$ 都不满足 $g^{\varphi(p)/q} \equiv 1$，则 $\operatorname{ord}(g) = \varphi(p)$。这比完整枚举快得多。

## 离散对数问题

给定模 $p$、原根 $g$ 和 $y$，找 $x$ 使 $g^x \equiv y \pmod p$。这个 $x$ 称为 $y$ 以 $g$ 为底的离散对数，记作 $\log_g y$。

离散对数问题的困难性是 Diffie-Hellman 密钥交换和 ElGamal 加密的安全基础。

### Baby-step Giant-step (BSGS)

时间 $O(\sqrt{p})$，空间 $O(\sqrt{p})$，是中间相遇攻击的典例。

思路：设 $x = im + j$，其中 $m = \lceil \sqrt{p} \rceil$。
$$g^{im+j} \equiv y \Rightarrow g^j \equiv y \cdot (g^{-m})^i$$

预计算所有 $g^j$（baby steps），然后遍历 $i$ 寻找碰撞（giant steps）。

```
function bsgs(g, y, p):
    m = ceil(sqrt(p))
    # baby step: 计算 g^j 并存入哈希表
    table = {}
    cur = 1
    for j in range(m):
        table[cur] = j
        cur = cur * g % p

    # giant step: 计算 y * (g^{-m})^i
    factor = pow(g, -m, p)  # g^{-m} mod p
    cur = y
    for i in range(m):
        if cur in table:
            return i * m + table[cur]
        cur = cur * factor % p
    return None  # 无解
```

默认可解 $p$ 在 $2^{40}$ 以下的离散对数。更大需要 Pollard's Rho 或 Index Calculus。

### Pohlig-Hellman 算法

当 $p-1$ 是光滑数（只有小素因子）时，可以分别对每个素因子求解离散对数再用 CRT 合并。

```
function pohlig_hellman(g, y, p):
    factors = factorize(p - 1)  # [(p1, e1), (p2, e2), ...]
    congruences = []
    for pi, ei in factors:
        # 在阶为 pi^ei 的子群中求解
        gi = pow(g, (p-1) // (pi**ei), p)
        yi = pow(y, (p-1) // (pi**ei), p)
        xi = bsgs(gi, yi, p)  # 或更精细的逐位求解
        congruences.append((xi, pi**ei))
    return crt(congruences)
```

**我的见解**：Pohlig-Hellman 是离散对数求解中的"杀手锏"——如果 $p-1$ 是光滑的，BSGS 用不上也能靠这个快速求解。反过来，要避免这种攻击，就得选取安全素数 $p = 2q+1$（$q$ 也为素数），确保 $p-1$ 含大素因子。

## 离散对数在密码学中的应用

### Diffie-Hellman 密钥交换

```
Alice                                      Bob
  a ← random                              b ← random
  A = g^a mod p  ————————————————→  B
                ←————————————————  B = g^b mod p
  K = B^a mod p                          K = A^b mod p
  (K = g^{ab} mod p)
```

### ElGamal 加密

```
密钥生成: 选 g, x, 公钥 y = g^x mod p, 私钥 x
加密(m): 选随机 k, 输出 (g^k, m · y^k)
解密(c1, c2): m = c2 · c1^{-x}
```

### 编程求解示例

```python
# 已知 p, g, y，求解 x 满足 g^x ≡ y (mod p)
# 方法 1: p-1 光滑时用 Pohlig-Hellman
x = pohlig_hellman(g, y, p)

# 方法 2: 直接 SageMath
R = IntegerModRing(p)
x = discrete_log(R(y), R(g))
```

SageMath 内置了高效的离散对数求解（结合了多种算法，自动选择最优策略），对 $2^{80}$ 量级的模数也能在合理时间内求解。
