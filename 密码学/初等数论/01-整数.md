# 整数

整数是数论最基本的对象，"整"就是无"零头"。在深入研究整数性质前，先梳理最基础但最容易被忽略的基本概念。

## 整除

若存在整数 $k$ 使得 $b = a k$，则称 $a$ 整除 $b$，记作 $a \mid b$。否则记 $a \nmid b$。

基本性质：
- 若 $a \mid b$ 且 $b \mid c$，则 $a \mid c$（传递性）
- 若 $a \mid b$ 且 $a \mid c$，则 $a \mid (b \pm c)$
- 若 $a \mid b$，则 $|a| \le |b|$（$b \neq 0$ 时）

## 带余除法

这是整个数论的核心起点。任意整数 $a$ 除以正整数 $n$，存在唯一的一对整数 $q$（商）和 $r$（余数），满足：

$$a = q n + r,\quad 0 \le r < n$$

这个式子是所有同余运算的基石。

```
function div_mod(a, n):
    # 要求 n > 0
    q = floor(a / n)   # Python 中 // 操作符
    r = a - q * n       # Python 中 % 操作符
    return q, r
```

**注意**：Python 中的 `%` 对负数处理与数学定义不同。数学上余数要求非负，Python 中 `-5 % 3 = 1`，而 C/C++/Java 中 `-5 % 3 = -2`。写算法时务必注意语言差异。

## 最大公因数与欧几里得算法

两个整数 $a, b$ 的最大公因数记作 $\gcd(a, b)$。若 $\gcd(a, b) = 1$，称 $a, b$ 互素。

欧几里得算法（辗转相除法）的数学原理：

$$\gcd(a, b) = \gcd(b, a \bmod b)$$

```
function gcd(a, b):
    while b != 0:
        a, b = b, a % b
    return abs(a)
```

**递归写法更贴近数学定义**：

```
function gcd_recursive(a, b):
    if b == 0:
        return a
    return gcd_recursive(b, a % b)
```

时间复杂度 $O(\log \min(a, b))$，这是数论中最快的算法之一。

### 编程应用

扩展欧几里得算法（下章）的前置技能，常用于 RSA 中检查 $e$ 与 $\phi(n)$ 是否互素。

**计算练习**：给定两个大数 $a = 12345678901234567890$，$b = 98765432109876543210$，用编程计算 $\gcd(a, b)$：

```python
from math import gcd
print(gcd(12345678901234567890, 98765432109876543210))
# 输出: 90000000090
```

## 算术基本定理

每个大于 1 的整数都可以唯一分解为素数的乘积（不计顺序）：

$$n = p_1^{e_1} p_2^{e_2} \cdots p_k^{e_k}$$

这就是"基本定理"之所以"基本"的原因——整数可以唯一地拆成素数积木。

由此可得：

$$\gcd(a, b) = \prod p_i^{\min(e_i, f_i)}, \quad \operatorname{lcm}(a, b) = \prod p_i^{\max(e_i, f_i)}$$

且 $\gcd(a, b) \times \operatorname{lcm}(a, b) = a \times b$。

**我的见解**：大部分初学密码学的人容易忽略这个定理在证明中的威力。很多恒等式只需把两边的数写成素因子幂乘积就能一眼看出结论。

## 数的进制表示

计算机领域最常用的是二进制和十六进制。

一个整数 $n$ 在 $b$ 进制下的表示：

$$n = a_k b^k + a_{k-1} b^{k-1} + \cdots + a_1 b + a_0,\quad 0 \le a_i < b$$

```
function to_base(n, b):
    if n == 0:
        return "0"
    digits = []
    while n > 0:
        digits.append(digit_char(n % b))
        n = n // b
    return reverse(digits)
```

**编程提示**：密文常以十六进制字符串形式给出，最优先的操作就是 `bytes.fromhex()` 或 `int(hex_str, 16)` 转整数处理。
