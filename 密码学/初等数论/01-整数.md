# 整数

整数是数论最基本的研究对象。本章从有理数起步，严格建立整数的定义与基本性质，为后续所有数论运算奠定基础。

---

## 从有理数到整数

设 $a, b \in \mathbb{Z}$ 且 $b \neq 0$，有理数 $\frac{a}{b}$ 满足：

$$\frac{a}{b} = q \in \mathbb{Z} \iff a = bq, \quad q \in \mathbb{Z}$$

当 $|a| \ge |b|$ 且 $a$ 是 $b$ 的整数倍时，$\frac{a}{b}$ 为整数；否则为**真分数**（$|a| < |b|$）或**假分数**（$|a| \ge |b|$ 但 $b \nmid a$）。

> 整数集 $\mathbb{Z} = \{\dots, -2, -1, 0, 1, 2, \dots\}$ 是有理数 $\mathbb{Q}$ 的子集，也是所有分子能被分母整除的有理数。

---

## 整除

### 定义

若存在整数 $k \in \mathbb{Z}$ 使得 $b = a k$，则称 $a$ **整除** $b$。此时 $\dfrac{b}{a} = k$ 为整数。记作：

$$a \mid b \quad\iff\quad \frac{b}{a} \in \mathbb{Z}$$

$a$ 是 $b$ 的**因数**（约数），$b$ 是 $a$ 的**倍数**。若不存在这样的 $k$，记 $a \nmid b$，即 $\dfrac{b}{a} \notin \mathbb{Z}$。

符号 `|` 表示"整除关系"，$a \mid b$ 读作"$a$ 整除 $b$"，等价于 $b/a$ 是整数。

### 基本性质

对任意整数 $a, b, c$：

1. **自反性**：$a \mid a$，即 $\dfrac{a}{a} = 1 \in \mathbb{Z}$

2. **传递性**：若 $a \mid b$ 且 $b \mid c$，则 $a \mid c$
 $$\frac{b}{a} \in \mathbb{Z}\ \land\ \frac{c}{b} \in \mathbb{Z}\ \implies\ \frac{c}{a} = \frac{b}{a} \cdot \frac{c}{b} \in \mathbb{Z}$$

3. **线性性**：若 $a \mid b$ 且 $a \mid c$，则 $a \mid (b \pm c)$
 $$\frac{b}{a} = k_1,\ \frac{c}{a} = k_2\ \implies\ \frac{b \pm c}{a} = k_1 \pm k_2 \in \mathbb{Z}$$

4. **大小关系**：若 $a \mid b$ 且 $b \neq 0$，则 $|a| \le |b|$
 $$b = a k,\ |k| \ge 1\ \implies\ |b| = |a| \cdot |k| \ge |a|$$

5. **符号无关**：$a \mid b \iff -a \mid b \iff a \mid -b \iff |a| \mid |b|$

**与除法的对应**：上述性质中传递性对应 $(c/b) \cdot (b/a) = c/a$，线性性对应 $(b \pm c)/a = b/a \pm c/a$，都是分数运算的自然推论。

## 取整函数

两个在计算机数论中不可或缺的函数。

### 定义

对任意实数 $x \in \mathbb{R}$：

$$
\begin{aligned}
\lfloor x \rfloor &= \max\{m \in \mathbb{Z} \mid m \le x\} \quad &\text{（向下取整）} \\
\lceil x \rceil &= \min\{m \in \mathbb{Z} \mid m \ge x\} \quad &\text{（向上取整）}
\end{aligned}
$$

### 基本不等式

$$
x - 1 < \lfloor x \rfloor \le x \le \lceil x \rceil < x + 1
$$

### 与整除的关系

带余除法中的商 $q$ 可写为 $q = \left\lfloor \frac{a}{n} \right\rfloor$（当 $a \ge 0, n > 0$）。

### 常用恒等式

$$
\left\lfloor \frac{a}{b} \right\rfloor + \left\lfloor \frac{-a}{b} \right\rfloor = \begin{cases}
0 & \text{若 } b \mid a \\
-1 & \text{若 } b \nmid a
\end{cases}, \quad b > 0
$$

## 带余除法

这是整个初等数论的**核心算子**。没有带余除法，同余、gcd、CRT 全部无从谈起。

### 定理

对任意整数 $a \in \mathbb{Z}$ 和正整数 $n \in \mathbb{Z}^+$，存在**唯一**的一对整数 $q, r$ 满足：

$$a = q n + r, \quad 0 \le r < n$$

其中 $q$ 称为**商**，$r$ 称为**余数**。$q$ 和 $r$ 的存在性和唯一性由良序原理保证。

**存在性**：考虑集合 $S = \{a - kn \mid k \in \mathbb{Z}\}$ 中的非负元素，由良序原理取最小者即为 $r$，对应 $k$ 即为 $q$。

**唯一性**：若有两组 $(q_1, r_1)$ 和 $(q_2, r_2)$，则 $r_1 - r_2 = (q_2 - q_1)n$，且 $|r_1 - r_2| < n$，故 $r_1 = r_2$，$q_1 = q_2$。

```
function div_mod(a, n):
 # 要求 n > 0
 q = floor(a / n) # Python 中 // 操作符
 r = a - q * n # Python 中 % 操作符
 return q, r
```

**语言差异**：数学上要求 $0 \le r < n$。Python 的 `%` 行为满足 $r \ge 0$（`-5 % 3 = 1`），而 C/C++/Java 的 `%` 允许 $r$ 为负（`-5 % 3 = -2$`）。编写跨平台算法时必须显式处理。

## 最大公因数与欧几里得算法

### 定义

设 $a, b \in \mathbb{Z}$ 不全为零。$d = \gcd(a, b)$ 是满足以下条件的正整数：

1. $d \mid a$ 且 $d \mid b$（公因数）
2. 对任意公因数 $c$，$c \mid d$（最大）

### 欧几里得算法

算法基于如下定理：

$$\gcd(a, b) = \gcd(b, a \bmod b), \quad b \neq 0$$

**证明**：设 $a = qb + r$，则任何同时整除 $a$ 和 $b$ 的数必整除 $r = a - qb$，反之任何整除 $b$ 和 $r$ 的数也整除 $a$。故 $\gcd(a, b) = \gcd(b, r)$。

```
function gcd(a, b):
 while b != 0:
 a, b = b, a % b
 return abs(a)
```

**Lamé 定理**：欧几里得算法最多执行 $5 \log_{10}(\min(a, b))$ 步（$O(\log n)$）。最坏情况发生在相邻 Fibonacci 数上，如 $\gcd(F_{k+1}, F_k) = 1$ 需要 $k$ 步。

```
function gcd_fib_worst_case(n):
 # 验证 Lamé 定理：gcd(F_{n+1}, F_n) 需要 n 步
 a, b = 1, 1
 for i in range(n):
 a, b = a + b, a
 return gcd(a, b)
```

### 互素

若 $\gcd(a, b) = 1$，称 $a$ 与 $b$ **互素**（互质）。

## 算术基本定理

### 定理

每个大于 1 的整数 $n$ 可以**唯一**地（不计因子顺序）分解为素数的乘积：

$$n = p_1^{e_1} p_2^{e_2} \cdots p_k^{e_k}, \quad p_1 < p_2 < \dots < p_k, \quad e_i \ge 1$$

**证明概要**：存在性由强归纳法保证；唯一性由素数性质（$p \mid ab \implies p \mid a \lor p \mid b$）保证。

### 推论

记 $a = \prod p_i^{e_i}$，$b = \prod p_i^{f_i}$，则：

$$
\gcd(a, b) = \prod p_i^{\min(e_i, f_i)}, \quad
\operatorname{lcm}(a, b) = \prod p_i^{\max(e_i, f_i)}
$$

且成立恒等式：

$$\gcd(a, b) \times \operatorname{lcm}(a, b) = a \times b$$

**我的见解**：许多数论恒等式只需将两边写成素因子幂积即可一眼看出。例如 $\gcd(a, b) \mid a$、$\operatorname{lcm}(a, b)$ 整除任何公倍数，都可由指数 $(\min, \max)$ 的性质直接导出。

## 数的进制表示

### 定义

设 $b > 1$ 为进制基。任意正整数 $n$ 有**唯一**的 $b$ 进制表示：

$$n = a_k b^k + a_{k-1} b^{k-1} + \cdots + a_1 b + a_0, \quad 0 \le a_i < b, \quad a_k \neq 0$$

其中各项系数 $a_i$ 满足：

$$a_i = \left\lfloor \frac{n}{b^i} \right\rfloor \bmod b$$

```
function to_base(n, b):
 if n == 0:
 return "0"
 digits = []
 while n > 0:
 digits.append(digit_char(n % b))
 n = n // b
 return reverse(digits)
```

计算机领域最常用的是二进制（$b=2$）和十六进制（$b=16$）。

**编程提示**：密文常以十六进制字符串形式给出，最优先的操作就是 `bytes.fromhex()` 或 `int(hex_str, 16)` 转整数处理。
