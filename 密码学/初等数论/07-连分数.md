# 连分数

连分数通过有理数的最佳逼近，架起了数论与密码分析之间的桥梁。最著名的应用是 Wiener 攻击——当 RSA 私钥指数 $d$ 太小时，用连分数恢复 $d$ 只需毫秒级计算。

---

## 定义

### 有限连分数

形如：

$$a_0 + \cfrac{1}{a_1 + \cfrac{1}{a_2 + \cfrac{1}{\ddots + \cfrac{1}{a_n}}}}$$

简记为 $[a_0; a_1, a_2, \dots, a_n]$。其中 $a_0 \in \mathbb{Z}$，$a_1, \dots, a_n \in \mathbb{Z}^+$。

### 无限连分数

$\alpha$ 为无理数时，其连分数展开无限：$\alpha = [a_0; a_1, a_2, \dots]$。

$$\sqrt{2} = [1; 2, 2, 2, \dots], \quad
\frac{1 + \sqrt{5}}{2} = [1; 1, 1, 1, \dots], \quad
\pi = [3; 7, 15, 1, 292, 1, 1, 1, 2, \dots]$$

### 展开算法

任意实数 $\alpha$ 的连分数展开由反复取整和取倒数得到：

```
def continued_fraction(alpha, n=20):
    terms = []
    for _ in range(n):
        a = int(alpha)
        terms.append(a)
        frac = alpha - a
        if frac == 0:
            break
        alpha = 1 / frac
    return terms
```

**数学过程**：$a_0 = \lfloor \alpha \rfloor$，$\alpha_1 = \frac{1}{\alpha - a_0}$，$a_1 = \lfloor \alpha_1 \rfloor$，依此类推。

## 渐近分数（Convergents）

### 定义

截取连分数前 $k$ 项得到的分数 $\frac{p_k}{q_k}$ 称为第 $k$ 个**渐近分数**。

### 递推公式

$$
\begin{aligned}
p_{-2} &= 0, & p_{-1} &= 1, & p_k &= a_k p_{k-1} + p_{k-2} \\
q_{-2} &= 1, & q_{-1} &= 0, & q_k &= a_k q_{k-1} + q_{k-2}
\end{aligned}
$$

```
def convergents(cf):
    p_prev2, p_prev1 = 0, 1
    q_prev2, q_prev1 = 1, 0
    convs = []
    for a in cf:
        p = a * p_prev1 + p_prev2
        q = a * q_prev1 + q_prev2
        convs.append((p, q))
        p_prev2, p_prev1 = p_prev1, p
        q_prev2, q_prev1 = q_prev1, q
    return convs
```

递推公式形式上与 Fibonacci 数列相同——实际上 Fibonacci 数是 $[1; 1, 1, 1, \dots]$ 的渐近分数。

---

## 逼近性质

### 基本不等式

对渐近分数 $\frac{p_n}{q_n}$ 和实数 $\alpha$：

$$\left|\alpha - \frac{p_n}{q_n}\right| < \frac{1}{q_n^2}$$

### 最佳逼近定理

若 $\frac{p}{q}$ 是有理数且 $0 < q < q_{n+1}$，则 $|q\alpha - p| \ge |q_n\alpha - p_n|$。即**渐近分数是所有分母不超过它的有理数中最精确的逼近**。

### Legendre 定理

若 $\left|\alpha - \frac{p}{q}\right| < \frac{1}{2q^2}$，则 $\frac{p}{q}$ 是 $\alpha$ 的一个渐近分数。

这一条是 Wiener 攻击的理论基础。

---

## Wiener 攻击

### 适用条件

RSA 中，若私钥指数 $d < \frac{1}{3} N^{1/4}$，可由 $e, N$ 恢复 $d$。

### 数学推导

由 $ed \equiv 1 \pmod{\varphi(N)}$ 得 $ed = 1 + k\varphi(N)$，即：

$$\frac{e}{\varphi(N)} - \frac{k}{d} = \frac{1}{d\varphi(N)}$$

用 $N$ 近似 $\varphi(N)$（$\varphi(N) = N - p - q + 1 \approx N$）：

$$\left|\frac{e}{N} - \frac{k}{d}\right| < \frac{1}{2d^2}$$

由 Legendre 定理，$\frac{k}{d}$ 是 $\frac{e}{N}$ 的渐近分数。

### 算法

```
def wiener_attack(e, n):
    cf = continued_fraction(Fraction(e, n))
    for k, d in convergents(cf):
        if k == 0:
            continue
        if (e * d - 1) % k != 0:
            continue
        phi = (e * d - 1) // k
        # p + q = n - phi + 1
        s = n - phi + 1
        discriminant = s * s - 4 * n
        if discriminant < 0:
            continue
        p = (s + isqrt(discriminant)) // 2
        q = (s - isqrt(discriminant)) // 2
        if p * q == n:
            return d
    return None
```

**我的见解**：Wiener 攻击的条件很苛刻（$d < \frac{1}{3} N^{1/4}$），但一满足即秒破。实践中 $e$ 非常大（接近 $n$）时是 Wiener 攻击的典型特征。Boneh-Durfee 攻击将条件放宽至 $d < N^{0.292}$，但需格 LLL，已超出连分数范畴。

## Pell 方程

### 定义

$$x^2 - D y^2 = 1, \quad D \in \mathbb{Z}^+ \text{ 非完全平方}$$

### 解的结构

Pell 方程有无限组解，均来源于最小解 $(x_1, y_1)$，由 $\sqrt{D}$ 的连分数展开给出：最小解来自 $\sqrt{D}$ 的某个渐近分数。

$$\sqrt{D} = [a_0; \overline{a_1, a_2, \dots, a_h}]$$

```
def solve_pell(D):
    cf = continued_fraction(sqrt(D), 100)
    for x, y in convergents(cf):
        if x * x - D * y * y == 1:
            return x, y
    return None
```

**延伸应用**：某些椭圆曲线同构计算可归约到 Pell 方程。
