# 初等数论 导读

本目录收录初等数论（Elementary Number Theory）在密码学中应用的笔记与总结。
另外这里收录的部分仅与计算机相关，或感觉可能与计算机相关。若要学习完整数论知识还需要自行阅读书籍学习。

## 参考书籍

- 《A Course in Number Theory and Cryptography》— Neal Koblitz, Springer
- 《An Introduction to the Theory of Numbers》— G.H. Hardy, E.M. Wright, Oxford University Press
- 《A Computational Introduction to Number Theory and Algebra》— Victor Shoup（免费在线版）
- 《Number Theory: Step by Step》— Kuldeep Singh, Oxford University Press

## GitHub 仓库 & 在线资源

- [SymPy Number Theory](https://docs.sympy.org/latest/modules/ntheory.html) — Python 数论函数库
- [FactorDB](http://factordb.com/) — 在线大整数分解查询
- [CryptoHack - Number Theory](https://cryptohack.org/challenges/number-theory/) — 数论方向在线练习
