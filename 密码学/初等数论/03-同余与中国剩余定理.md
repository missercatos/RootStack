# 同余与中国剩余定理

## 同余

若 $n \mid (a - b)$，称 $a$ 与 $b$ 模 $n$ 同余，记作 $a \equiv b \pmod n$。

同余式可以像等式一样加减乘，但除法需要额外条件——除数与模数互素。

**同余类与完全剩余系**：模 $n$ 将所有整数划分为 $n$ 个等价类，每个类取一个代表元组成完全剩余系。最常用的是 $\{0, 1, \dots, n-1\}$。

**简化剩余系**：与 $n$ 互素的同余类组成的集合，大小为 $\varphi(n)$。

## 模运算性质

### 加减乘

$$a \pm b \equiv c \pm d \pmod n \quad \text{若 } a \equiv c,\ b \equiv d$$

$$a \cdot b \equiv c \cdot d \pmod n \quad \text{若 } a \equiv c,\ b \equiv d$$

### 除法（乘逆元）

$a \div b \pmod n$ 定义为 $a \times b^{-1} \pmod n$，其中 $b^{-1}$ 是 $b$ 模 $n$ 的逆元，存在当且仅当 $\gcd(b, n) = 1$。

逆元的求法就是上一章的扩展欧几里得算法。

### 幂运算

幂运算使用快速幂，这是密码学中使用最频繁的算法。

```
function mod_pow(base, exp, mod):
    result = 1
    base = base % mod
    while exp > 0:
        if exp & 1:             # 当前二进制位为 1
            result = (result * base) % mod
        base = (base * base) % mod  # 平方
        exp >>= 1               # 右移
    return result
```

时间复杂度 $O(\log \text{exp})$，RSA 加密解密全部依赖此算法。

```python
# Python 内置 pow 已经是快速幂
c = pow(m, e, n)  # m^e mod n
m = pow(c, d, n)  # c^d mod n
```

**最佳实践**：永远不要用 `(m ** e) % n`——中间结果会爆炸。总是用三参数 `pow(m, e, n)`。

## 线性同余方程

形如 $ax \equiv b \pmod n$ 的方程。

- 若 $\gcd(a, n) \mid b$，有解
- 解的个数为 $\gcd(a, n)$
- 解为 $x \equiv x_0 + \frac{n}{\gcd(a,n)} \cdot t,\ t = 0, 1, \dots, \gcd(a,n)-1$

```
function solve_congruence(a, b, n):
    g = gcd(a, n)
    if b % g != 0:
        return []  # no solution
    a1, b1, n1 = a // g, b // g, n // g
    x0 = mod_inverse(a1, n1) * b1 % n1
    return [x0 + n1 * t for t in range(g)]
```

**我的见解**：线性同余方程本身很少作为独立考点，但它是一大类攻击的底层逻辑。Coppersmith 攻击的本质就是在模意义下解高次方程。

## 中国剩余定理（CRT）

中国剩余定理解决这样的问题：已知 $x$ 模一组两两互素的模数的余数，求 $x$ 模它们乘积的值。

定理表述：设 $n_1, n_2, \dots, n_k$ 两两互素，$N = \prod n_i$，则方程组

$$\begin{cases}
x \equiv a_1 \pmod{n_1} \\
x \equiv a_2 \pmod{n_2} \\
\quad \vdots \\
x \equiv a_k \pmod{n_k}
\end{cases}$$

在模 $N$ 下有唯一解。

解法：

1. 计算 $N = \prod n_i$
2. 对每个 $i$，计算 $N_i = N / n_i$
3. 计算 $y_i = N_i^{-1} \pmod{n_i}$
4. $x \equiv \sum a_i N_i y_i \pmod N$

```
function crt(remainders, moduli):
    # remainders = [a1, a2, ..., ak]
    # moduli = [n1, n2, ..., nk]
    N = product(moduli)
    result = 0
    for a_i, n_i in zip(remainders, moduli):
        N_i = N // n_i
        y_i = mod_inverse(N_i, n_i)  # N_i mod n_i 的逆元
        result = (result + a_i * N_i * y_i) % N
    return result
```

### CRT 在密码学中的应用

**1. RSA-CRT 加速解密**：RSA 解密时 $m = c^d \bmod n$ 直接算很慢。利用 CRT 分解为模 $p$ 和模 $q$ 的两个小指数运算再合并，速度提升约 4 倍。

```python
# RSA-CRT 解密
def rsa_crt_decrypt(c, p, q, d):
    dp = d % (p - 1)
    dq = d % (q - 1)
    qinv = mod_inverse(q, p)
    m1 = pow(c, dp, p)
    m2 = pow(c, dq, q)
    h = (qinv * (m1 - m2)) % p
    return m2 + h * q
```

**2. Hastad 广播攻击**：同一明文 $m$ 用三个不同的公钥 $(e=3, n_i)$ 加密得 $c_i \equiv m^3 \pmod{n_i}$。用 CRT 恢复 $m^3$ 再开立方即可。

```python
# e=3 广播攻击
def hastad_broadcast(c1, n1, c2, n2, c3, n3):
    m3 = crt([c1, c2, c3], [n1, n2, n3])
    m = iroot(m3, 3)  # 整数开立方
    return m
```

**3. 共模攻击**：同一 $n$ 不同 $e$ 加密同一明文，扩展欧几里得结合 CRT 的思路可恢复明文（不直接使用 CRT 公式，但思想一致）。

**计算练习**：CRT 故障恢复因子。假设用 CRT 加速计算 $m = c^d \bmod n$，其中 $n = pq$。若模 $p$ 的运算中发生错误，得到错误结果 $\tilde{m}$，而模 $q$ 的部分正确；已知 $m = 42$，$\tilde{m} = 10$，$n = 77$，求 $p, q$。

提示：正确结果 $m$ 与错误结果 $\tilde{m}$ 在模 $q$ 下相等，$m - \tilde{m}$ 是 $p$ 的倍数，$\gcd(m - \tilde{m}, n) = p$。

```python
def fault_recover(m, m_tilde, n):
    p = gcd(m - m_tilde, n)
    q = n // p
    return p, q
```

**我的见解**：CRT 不仅是 RSA 加速工具，它更是一种"分治"思维——把一个大的模数问题拆解成多个小模数问题。在密码分析中，看到多重同余条件就应该想到 CRT。

## 快速幂的编程应用

直接使用 Python 内置 `pow(base, exp, mod)` 即可，但有时题目会考察快速幂的实现细节。一个常见变体是逐次平方法（square-and-multiply）在侧信道场景下的泄漏。

```python
# 不安全的实现——指数位泄漏
def pow_leaky(base, exp, mod):
    result = 1
    while exp > 0:
        if exp & 1:           # 此处若被测量功耗，敌手可判断当前位为 1
            result = result * base % mod
        base = base * base % mod
        exp >>= 1
    return result
```

若 CPU 的功耗/时间随 `exp & 1` 分支而变化，侧信道攻击可以逐比特恢复指数。
