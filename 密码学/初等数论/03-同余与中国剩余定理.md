# 同余与中国剩余定理

同余关系是数论进入"计算机代数学"的门槛。它将无穷整数集划分为有限个等价类，使得模运算得以用编程高效实现。

---

## 同余的定义与基本性质

### 定义

设 $n$ 为正整数。若 $n \mid (a - b)$，则称 $a$ **同余于** $b$ 模 $n$，记作：

$$a \equiv b \pmod n$$

### 等价关系

同余是整数集 $\mathbb{Z}$ 上的等价关系：

$$
\begin{aligned}
a &\equiv a \pmod n \quad &\text{（自反性）} \\
a \equiv b \pmod n &\implies b \equiv a \pmod n \quad &\text{（对称性）} \\
(a \equiv b \pmod n) \land (b \equiv c \pmod n) &\implies a \equiv c \pmod n \quad &\text{（传递性）}
\end{aligned}
$$

### 同余类与剩余系

模 $n$ 将 $\mathbb{Z}$ 划分为 $n$ 个等价类，每个类称为一个**同余类**：

$$[a]_n = \{a + kn \mid k \in \mathbb{Z}\}$$

每个类选取一个代表元，构成**完全剩余系**。最常用的是 $\{0, 1, \dots, n-1\}$。

**简化剩余系**（既约剩余系）：与 $n$ 互素的同余类组成的集合：

$$\mathbb{Z}_n^* = \{a \in \{1, \dots, n-1\} \mid \gcd(a, n) = 1\}$$

其基数定义为欧拉函数：$|\mathbb{Z}_n^*| = \varphi(n)$。

## 模运算

### 加减乘

若 $a \equiv c \pmod n$ 且 $b \equiv d \pmod n$，则：

$$
\begin{aligned}
a \pm b &\equiv c \pm d \pmod n \\
a \cdot b &\equiv c \cdot d \pmod n
\end{aligned}
$$

**证明**：$(a \pm b) - (c \pm d) = (a-c) \pm (b-d)$ 均为 $n$ 的倍数。

### 除法（乘逆元）

模 $n$ 下的除法定义为乘以乘法逆元：

$$a \div b \equiv a \cdot b^{-1} \pmod n$$

**存在性定理**：

$$b^{-1} \pmod n \text{ 存在} \iff \gcd(b, n) = 1$$

**证明**：$\gcd(b, n) = 1$ 时存在 $x, y$ 使 $bx + ny = 1$，则 $bx \equiv 1 \pmod n$，故 $x = b^{-1}$。

$$b^{-1} \equiv b^{\varphi(n)-1} \pmod n \quad (\text{当 } n \text{ 为素数时用费马小定理})$$

或直接用扩展欧几里得算法。

### 幂运算与快速幂

计算 $a^e \bmod n$ 用平方-乘算法（快速幂）：

```
function mod_pow(base, exp, mod):
    result = 1
    base = base % mod
    while exp > 0:
        if exp & 1:
            result = (result * base) % mod
        base = (base * base) % mod
        exp >>= 1
    return result
```

**正确性**：将 $e$ 写为二进制 $e = \sum e_i 2^i$，则：

$$a^e \equiv a^{\sum e_i 2^i} \equiv \prod_{e_i = 1} a^{2^i} \pmod n$$

每个 $a^{2^i}$ 通过反复平方得到，共 $O(\log e)$ 次乘法，而非 $O(e)$。

```python
# Python 内置 pow 已经是快速幂实现
c = pow(m, e, n)   # 等价于 m^e mod n
m = pow(c, d, n)   # 等价于 c^d mod n
```

**最佳实践**：永远不要用 `(m ** e) % n`——中间结果会爆炸。始终使用三参数 `pow()`。

## 线性同余方程

### 标准形式

$$ax \equiv b \pmod n$$

### 解的存在性与结构

**定理**：方程有解当且仅当 $\gcd(a, n) \mid b$。若 $g = \gcd(a, n)$ 且 $g \mid b$，则方程在模 $n$ 下有 $g$ 个解：

$$x \equiv x_0 + \frac{n}{g} \cdot t \pmod n, \quad t = 0, 1, \dots, g-1$$

其中 $x_0$ 是 $a_1 x \equiv b_1 \pmod{n_1}$ 的解（$a_1 = a/g$，$b_1 = b/g$，$n_1 = n/g$）。

```
function solve_congruence(a, b, n):
    g = gcd(a, n)
    if b % g != 0:
        return []
    a1, b1, n1 = a // g, b // g, n // g
    x0 = mod_inverse(a1, n1) * b1 % n1
    return [x0 + n1 * t for t in range(g)]
```

**我的见解**：线性同余方程本身看似简单，但 Coppersmith 攻击的本质正是在模意义下解**高次**方程，核心工具是格基约简。

## 中国剩余定理（CRT）

### 定理

设 $n_1, n_2, \dots, n_k$ 两两互素，令 $N = \prod_{i=1}^k n_i$。则线性同余方程组：

$$
\begin{cases}
x \equiv a_1 \pmod{n_1} \\
x \equiv a_2 \pmod{n_2} \\
\quad \vdots \\
x \equiv a_k \pmod{n_k}
\end{cases}
$$

在模 $N$ 下有**唯一**解。

### 存在性证明

对每个 $i$，令 $N_i = N / n_i$。由于 $\gcd(N_i, n_i) = 1$，存在 $y_i$ 使 $N_i y_i \equiv 1 \pmod{n_i}$。构造：

$$x \equiv \sum_{i=1}^k a_i N_i y_i \pmod N$$

验证：$x \equiv a_i N_i y_i \equiv a_i \cdot 1 \equiv a_i \pmod{n_i}$。

### 唯一性证明

若 $x_1, x_2$ 都是解，则 $x_1 - x_2 \equiv 0 \pmod{n_i}$ 对所有 $i$ 成立。由于 $n_i$ 两两互素，$N \mid (x_1 - x_2)$，故 $x_1 \equiv x_2 \pmod N$。

```
function crt(remainders, moduli):
    N = product(moduli)
    result = 0
    for a_i, n_i in zip(remainders, moduli):
        N_i = N // n_i
        y_i = mod_inverse(N_i, n_i)
        result = (result + a_i * N_i * y_i) % N
    return result
```

### Garner 算法（免大整数）

当模数乘积 $N$ 超出字长时，Garner 算法避免了大整数运算，逐位合并：

```
function garner(remainders, moduli):
    # 预处理：预计算所有 n_i^{-1} mod n_j (i < j)
    # 递推：x = x_{k-1} + t * (n_1 * ... * n_{k-1})
    x = remainders[0]
    prod = 1
    for i in range(1, len(moduli)):
        prod = prod * moduli[i-1] % M  # M 为最终模数
        # 求解 t 使 x + t*prod ≡ a_i (mod n_i)
        t = ((remainders[i] - x) * mod_inverse(prod, moduli[i])) % moduli[i]
        x = x + t * prod
    return x
```

## CRT 在密码学中的应用

### 1. RSA-CRT 加速解密

直接计算 $m = c^d \bmod n$ 的指数 $d$ 与 $n$ 同量级（约 2048 位）。CRT 将其拆为两个约 1024 位的指数运算：

$$
\begin{aligned}
m_p &= c^{d \bmod (p-1)} \bmod p \\
m_q &= c^{d \bmod (q-1)} \bmod q \\
m &= m_q + q \cdot (q^{-1} \bmod p) \cdot (m_p - m_q) \bmod n
\end{aligned}
$$

速度约提升 4 倍。

```python
def rsa_crt_decrypt(c, p, q, d):
    dp = d % (p - 1)
    dq = d % (q - 1)
    qinv = mod_inverse(q, p)
    m1 = pow(c, dp, p)
    m2 = pow(c, dq, q)
    h = (qinv * (m1 - m2)) % p
    return m2 + h * q
```

### 2. Hastad 广播攻击

同一明文 $m$ 用 $e = 3$ 和三个不同模数 $n_1, n_2, n_3$ 加密：

$$c_i \equiv m^3 \pmod{n_i}, \quad i = 1,2,3$$

由 CRT 恢复 $m^3 \pmod{n_1 n_2 n_3}$。若 $m^3 < n_1 n_2 n_3$（即 $m$ 不太大），直接整数开立方即可。

```python
def hastad_broadcast(c1, n1, c2, n2, c3, n3):
    m3 = crt([c1, c2, c3], [n1, n2, n3])
    m = iroot(m3, 3)  # 整数开立方
    return m
```

### 3. CRT 故障攻击

RSA-CRT 解密时，若模 $p$ 的子运算发生错误（硬件故障）而模 $q$ 正确，得到错误结果 $\tilde{m}$，则有：

$$\tilde{m} \not\equiv m \pmod p, \quad \tilde{m} \equiv m \pmod q$$

于是 $\gcd(m - \tilde{m}, n) = p$。

```python
def fault_recover(m, m_tilde, n):
    p = gcd(m - m_tilde, n)
    q = n // p
    return p, q
```

**计算练习**：已知 $n = 77 = 7 \times 11$，正确值 $m = 42$，错误值 $\tilde{m} = 10$，求 $p, q$。
