## RSA

### 密钥生成

1. 随机选两个大素数 $p, q$
2. 计算 $n = pq$，$\varphi(n) = (p-1)(q-1)$
3. 选加密指数 $e$ 使 $\gcd(e, \varphi(n)) = 1$
4. 计算 $d \equiv e^{-1} \pmod{\varphi(n)}$

公钥 $(n, e)$，私钥 $(n, d)$，销毁 $p, q$。

```
def rsa_keygen(bits=2048):
    p = random_prime(bits // 2)
    q = random_prime(bits // 2)
    n = p * q
    phi = (p - 1) * (q - 1)
    e = 65537  # 常见选择
    d = mod_inverse(e, phi)
    return (n, e, d, p, q)
```

### 加密与解密

$$c = m^e \bmod n$$
$$m = c^d \bmod n$$

### 正确性

$$c^d \equiv m^{ed} \equiv m^{1 + k\varphi(n)} \equiv m \cdot (m^{\varphi(n)})^k \equiv m \cdot 1^k \equiv m \pmod n$$

其中关键步骤用到了欧拉定理 $m^{\varphi(n)} \equiv 1 \pmod n$（前提 $\gcd(m, n) = 1$，但即使不互素也成立，可用中国剩余定理逐素数证明）。

## RSA 常见攻击

### 1. 分解 $n$

若 $n$ 可分解，$p, q$ 到手则私钥全破。

**我的见解**：这不是"一种攻击"，而是所有 RSA 攻击的底层假设——如果分解容易，什么都白搭。现代 RSA 要求 $n$ 至少 2048 位（约 617 位十进制数）。

### 2. 小 $e$ 攻击

当 $e = 3$ 且 $m^3 < n$ 时，直接计算 $\sqrt[3]{c}$ 即可恢复 $m$。

防御：对明文进行 OAEP 填充，确保 $m$ 够大。

### 3. 共模攻击

同一 $m$ 用相同 $n$ 但不同 $e_1, e_2$ 加密得到 $c_1, c_2$。若 $\gcd(e_1, e_2) = 1$，可用扩展欧几里得找到 $s, t$ 使 $e_1 s + e_2 t = 1$，则 $m \equiv c_1^s c_2^t \pmod n$。

```
def common_modulus_attack(c1, e1, c2, e2, n):
    g, s, t = extended_gcd(e1, e2)
    if g != 1:
        return None
    # 注意 s 可能为负，需要模逆元
    if s < 0:
        c1 = mod_inverse(c1, n)
        s = -s
    if t < 0:
        c2 = mod_inverse(c2, n)
        t = -t
    return (pow(c1, s, n) * pow(c2, t, n)) % n
```

### 4. 低解密指数攻击

$d$ 太小时 Wiener 攻击或 Boneh-Durfee 攻击可恢复 $d$。

### 5. 选择密文攻击（CCA）

RSA 本身不具备 IND-CCA 安全性。若攻击者能解密任意密文（除目标外），可以：

1. 截获 $c = m^e \bmod n$
2. 选随机 $r$，计算 $c' = r^e \cdot c \bmod n$
3. 请求解密 $c'$ 得 $m' = r \cdot m \bmod n$
4. 计算 $m = m' \cdot r^{-1} \bmod n$

防御：使用 OAEP 填充，使密文不可延展，或禁用解密预言机。

### 6. $p$ 和 $q$ 相差太小

Fermat 分解：
$$\left(\frac{p+q}{2}\right)^2 - n = \left(\frac{p-q}{2}\right)^2$$

检查 $a = \lceil \sqrt{n} \rceil$ 附近 $a^2 - n$ 是否为完全平方数。

## 数字签名

### RSA 签名

$$\sigma = m^d \bmod n \quad \text{（签名）}$$
$$m \equiv \sigma^e \pmod n \quad \text{（验证）}$$

注意是"私钥签名，公钥验证"，与加密相反。

### ElGamal 签名

密钥：$y = g^x \bmod p$，私钥 $x$。

签名：选随机 $k$，计算 $r = g^k \bmod p$，$s = (H(m) - xr)k^{-1} \pmod{p-1}$。

验证：$g^{H(m)} \equiv y^r r^s \pmod p$。

```
拿到公钥 (n, e) 和密文 c

│
├─ 检查 p, q 是否接近 → Fermat 分解
│
└─ 尝试 Pollard's Rho / Pollard p-1
```

## 好的密码学实践

### 不要做的事
- 使用相同 $n$ 给多个用户
- 使用过小 $e$ 且不填充
- 使用过小 $d$
- 选择过于接近的 $p, q$
- 选择 $p-1$ 或 $q-1$ 光滑的素数
- 使用 PKCS#1 v1.5（已发现多种攻击，Bleichenbacher 攻击）
- 自己"魔改"密码算法

### 推荐做法
- 使用标准库（PyCryptodome, libsodium, OpenSSL）
- 始终使用 OAEP 或至少 PSS 填充
- $e = 65537$（安全性好且效率高）
- $p, q$ 相差几位（bit-length 差不能太大，约 5-10 位）
- $p, q$ 选择安全素数 $p = 2p' + 1$（$p'$ 也为素数）
