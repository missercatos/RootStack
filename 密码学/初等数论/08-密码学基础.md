## 古典密码

古典密码是现代密码的前身，其设计思路（替换、换位、代换）贯穿整个密码学历史。虽然它们大多已被破解，但理解古典密码对掌握密码分析的基本思维（频率分析、模式识别、已知明文攻击）至关重要。

### 单表替换密码

#### 凯撒密码 (Caesar Cipher)

最古老的加密方法之一。将字母在字母表上平移固定位数 $k$：

$$E_k(m) = (m + k) \bmod 26, \quad D_k(c) = (c - k) \bmod 26$$

其中字母映射为 $a=0, b=1, \dots, z=25$。

```python
def caesar_encrypt(plain, k):
 return ''.join(chr((ord(c) - 97 + k) % 26 + 97) if c.islower()
 else chr((ord(c) - 65 + k) % 26 + 65) if c.isupper()
 else c for c in plain)
```

破解只需穷举 26 种位移，或通过字母频率分布确定 $k$。

#### 仿射密码 (Affine Cipher)

推广的凯撒密码，加密为线性变换：

$$E(m) = (a m + b) \bmod 26$$

要求 $\gcd(a, 26) = 1$ 以保证可逆。解密：

$$D(c) = a^{-1}(c - b) \bmod 26$$

仿射密码的密钥空间小于 $26 \times \varphi(26) = 26 \times 12 = 312$，可穷举破解。

```python
def affine_encrypt(plain, a, b):
 return ''.join(chr((a * (ord(c) - 97) + b) % 26 + 97) if c.islower()
 else chr((a * (ord(c) - 65) + b) % 26 + 65) if c.isupper()
 else c for c in plain)
```

### 多表替换密码

#### 维吉尼亚密码 (Vigenère Cipher)

使用密钥词 $K = k_0 k_1 \dots k_{L-1}$，对明文的第 $i$ 个字符：

$$c_i = (m_i + k_{i \bmod L}) \bmod 26$$

这不是一个映射，而是 $L$ 个凯撒密码的轮换，因此字母频率分布被"抹平"。

**破解方法**：
1. **Kasiski 测试**：查找密文中重复片段，计算间隔的最大公因数，推测密钥长度 $L$
2. **重合指数法**：对每个候选 $L$，将密文按 $i \bmod L$ 分组，计算各组的重合指数（Index of Coincidence, IC），$L$ 正确时 IC 约为 $0.065$（英语），否则约为 $0.038$
3. **频率分析**：对每组分别进行凯撒破解

```python
# 重合指数计算
def index_of_coincidence(text):
 freq = [text.count(chr(97+i)) for i in range(26)]
 n = len(text)
 return sum(f * (f-1) for f in freq) / (n * (n-1)) if n > 1 else 0
```

### 希尔密码 (Hill Cipher)

将明文分组视为向量，用可逆矩阵加密：

$$\mathbf{c} = \mathbf{K} \cdot \mathbf{m} \bmod 26, \quad \mathbf{m} = \mathbf{K}^{-1} \cdot \mathbf{c} \bmod 26$$

其中 $\mathbf{K}$ 为 $n \times n$ 矩阵，$\det(\mathbf{K})$ 模 26 可逆。

```python
import numpy as np

def hill_encrypt(plain, K):
 n = K.shape[0]
 nums = [ord(c) - 97 for c in plain.lower() if c.isalpha()]
 nums += [0] * ((-len(nums)) % n) # padding
 groups = [nums[i:i+n] for i in range(0, len(nums), n)]
 result = []
 for g in groups:
 c = K @ np.array(g) % 26
 result.extend(chr(int(x) + 97) for x in c)
 return ''.join(result)
```

希尔密码对已知明文攻击是脆弱的——已知 $n$ 对明密文对即可恢复 $\mathbf{K}$。

### 换位密码

#### 栅栏密码 (Rail Fence Cipher)

将明文按"之"字形写在多行轨道上，按行读取得到密文。

```
plain: HELLO WORLD
rails: H . . O . . R . .
 . E . L . W . L D
 . . L . . . O . .
cipher: HOR ELW LDLO (去除空格)
```

#### 列换位密码 (Columnar Transposition)

将明文按行写入矩阵，按列读取（列顺序由密钥词决定）：

```
密钥: SECRET (排序: 2,5,1,4,3,6)
矩阵: T H I S I S
 A S E C R E
 T C I P H E
输出: IET HST ... (按列 1→2→3→4→5→6 读取)
```

换位密码不改变字符本身，只改变顺序。破解主要依靠猜测换位模式或寻找字典单词片段。

### 其他常见古典密码

| 名称 | 描述 | 特点 |
|------|------|------|
| Atbash | $a \leftrightarrow z$, $b \leftrightarrow y$ 对称替换 | 相当于仿射 $(a,b)=(-1,25)$ |
| Rot13 | 凯撒密码 $k=13$ | 加密=解密，常用于简单的文本混淆 |
| 培根密码 | 5 位二进制编码 (A/B) 表示字母 | 可隐写在正常文本的字体差异中 |
| 波利比乌斯方阵 | 5×5 网格坐标替换 | 可配合键盘布局变体 |

```python
# Atbash
def atbash(text):
 return ''.join(chr(25 - (ord(c) - 97) + 97) if c.islower()
 else chr(25 - (ord(c) - 65) + 65) if c.isupper()
 else c for c in text)
```

**我的见解**：CTF 中有时会出现"类古典密码"或"少见古典密码变体"，例如仿射密码的模数改为 $256$（适用于字节级加密而非字母）、希尔密码的矩阵阶数不为标准值（如 3×3 改为 4×4 或使用模 $p$）、或几种古典密码的复合使用（先换位再替换）。识别这类题目的关键不是死记算法，而是观察密文的统计特征——字母频率分布、IC 值、周期模式——来判断底层变换类型，然后针对性地还原。

## RSA 公钥加密

### 密钥生成

1. 随机选两个大素数 $p, q$
2. $n = pq$，$\varphi(n) = (p-1)(q-1)$
3. 选 $e$ 使 $1 < e < \varphi(n)$ 且 $\gcd(e, \varphi(n)) = 1$
4. $d \equiv e^{-1} \pmod{\varphi(n)}$（或 $\pmod{\lambda(n)}$）

公钥：$(n, e)$；私钥：$(n, d)$。销毁 $p, q$。

```python
def rsa_keygen(bits=2048):
 p = random_prime(bits // 2)
 q = random_prime(bits // 2)
 n = p * q
 phi = (p - 1) * (q - 1)
 e = 65537
 d = mod_inverse(e, phi)
 return (n, e, d, p, q)
```

### 加密与解密

$$c = m^e \bmod n, \quad m = c^d \bmod n$$

**正确性**：详见第四章。核心是 $m^{ed} \equiv m \pmod n$，由欧拉定理或 CRT 保证。

## RSA 常见攻击

### 1. 分解 $n$

若 $n$ 可分解，则 $\varphi(n)$ 和 $d$ 均可计算。现代 RSA 要求 $n \ge 2048$ 位。

### 2. 小 $e$ 攻击

当 $e = 3$ 且 $m^3 < n$ 时：

$$c = m^3 \implies m = \sqrt[3]{c}$$

**防御**：OAEP 填充使 $m$ 足够大。

### 3. 共模攻击

同一 $m$ 用相同 $n$、不同 $e_1, e_2$ 加密得 $c_1, c_2$。若 $\gcd(e_1, e_2) = 1$，存在 $s, t$ 使 $e_1 s + e_2 t = 1$，则：

$$m \equiv c_1^s c_2^t \pmod n$$

```
def common_modulus_attack(c1, e1, c2, e2, n):
 g, s, t = extended_gcd(e1, e2)
 if g != 1:
 return None
 if s < 0:
 c1 = mod_inverse(c1, n)
 s = -s
 if t < 0:
 c2 = mod_inverse(c2, n)
 t = -t
 return (pow(c1, s, n) * pow(c2, t, n)) % n
```

### 4. 低解密指数攻击

$d$ 太小时 Wiener 攻击（第七章）或 Boneh-Durfee 攻击可恢复 $d$。

### 5. 选择密文攻击（CCA）

RSA 不具备 IND-CCA 安全性：

1. 截获 $c = m^e \bmod n$
2. 选随机 $r$，令 $c' = r^e c \bmod n$
3. 解密得 $m' = r m \bmod n$
4. $m = m' \cdot r^{-1} \bmod n$

**防御**：OAEP 填充（RSA-OAEP 已被证明 IND-CCA 安全）。

### 6. Fermat 分解

$p, q$ 接近时（$|p-q| < n^{1/4}$）：

$$\left(\frac{p+q}{2}\right)^2 - n = \left(\frac{p-q}{2}\right)^2$$

迭代检查 $a = \lceil \sqrt{n} \rceil, a+1, \dots$ 直到 $a^2 - n$ 为完全平方。

## Diffie-Hellman 密钥交换

依赖 CDH 假设（给定 $g, g^a, g^b$ 求 $g^{ab}$ 困难）。

```
Alice Bob
 a ← random b ← random
 A = g^a mod p B
 ————————————————————————→
 ←———————————————————————— B = g^b mod p
 K = B^a = g^{ab} K = A^b = g^{ab}
```

## ElGamal 加密

基于 DDH 假设。

- 密钥：私钥 $x$，公钥 $y = g^x \bmod p$
- 加密 $m$：选随机 $k$，输出 $(c_1, c_2) = (g^k, m \cdot y^k)$
- 解密：$m = c_2 \cdot c_1^{-x}$

## 数字签名

### RSA 签名

$$\sigma = m^d \bmod n \quad \text{（签名）}, \quad m \equiv \sigma^e \pmod n \quad \text{（验证）}$$

注意"私钥签名，公钥验证"与加密相反。

### ElGamal 签名

密钥：$y = g^x \bmod p$，私钥 $x$。

签名：选随机 $k$（$\gcd(k, p-1) = 1$），计算：

$$r = g^k \bmod p, \quad s = (H(m) - xr)k^{-1} \pmod{p-1}$$

验证：$g^{H(m)} \equiv y^r r^s \pmod p$。

## RSA 攻击实战路线

```
输入: (n, e, c) 或 (n, e) + 密文
│
├─ n 已有因子？ → factordb.com / 多公钥 gcd
├─ e = 3 ? → 直接开立方 / Hastad 广播
├─ e 很大（≈ n）？ → Wiener 攻击
├─ 相同 n 不同 e ？ → 共模攻击
├─ n 完全平方附近？ → Fermat 分解
├─ p-1 光滑？ → Pollard p-1
├─ 其余 → Pollard Rho / 已知高位 Coppersmith
```

## 好的密码学实践

### 避免
- 相同 $n$ 分给多个用户
- 过小 $e$ 且不填充
- 过小 $d$
- $p, q$ 过于接近 / $p-1$ 光滑
- 自己"魔改"密码算法

### 推荐
- 使用标准库（PyCryptodome, libsodium, OpenSSL）
- OAEP 或 PSS 填充
- $e = 65537$
- $p, q$ 为安全素数（$p = 2p'+1$）
