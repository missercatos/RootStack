## RSA 公钥加密

### 密钥生成

1. 随机选两个大素数 $p, q$
2. $n = pq$，$\varphi(n) = (p-1)(q-1)$
3. 选 $e$ 使 $1 < e < \varphi(n)$ 且 $\gcd(e, \varphi(n)) = 1$
4. $d \equiv e^{-1} \pmod{\varphi(n)}$（或 $\pmod{\lambda(n)}$）

公钥：$(n, e)$；私钥：$(n, d)$。销毁 $p, q$。

```python
def rsa_keygen(bits=2048):
    p = random_prime(bits // 2)
    q = random_prime(bits // 2)
    n = p * q
    phi = (p - 1) * (q - 1)
    e = 65537
    d = mod_inverse(e, phi)
    return (n, e, d, p, q)
```

### 加密与解密

$$c = m^e \bmod n, \quad m = c^d \bmod n$$

**正确性**：详见第四章。核心是 $m^{ed} \equiv m \pmod n$，由欧拉定理或 CRT 保证。

## RSA 常见攻击

### 1. 分解 $n$

若 $n$ 可分解，则 $\varphi(n)$ 和 $d$ 均可计算。现代 RSA 要求 $n \ge 2048$ 位。

### 2. 小 $e$ 攻击

当 $e = 3$ 且 $m^3 < n$ 时：

$$c = m^3 \implies m = \sqrt[3]{c}$$

**防御**：OAEP 填充使 $m$ 足够大。

### 3. 共模攻击

同一 $m$ 用相同 $n$、不同 $e_1, e_2$ 加密得 $c_1, c_2$。若 $\gcd(e_1, e_2) = 1$，存在 $s, t$ 使 $e_1 s + e_2 t = 1$，则：

$$m \equiv c_1^s c_2^t \pmod n$$

```
def common_modulus_attack(c1, e1, c2, e2, n):
    g, s, t = extended_gcd(e1, e2)
    if g != 1:
        return None
    if s < 0:
        c1 = mod_inverse(c1, n)
        s = -s
    if t < 0:
        c2 = mod_inverse(c2, n)
        t = -t
    return (pow(c1, s, n) * pow(c2, t, n)) % n
```

### 4. 低解密指数攻击

$d$ 太小时 Wiener 攻击（第七章）或 Boneh-Durfee 攻击可恢复 $d$。

### 5. 选择密文攻击（CCA）

RSA 不具备 IND-CCA 安全性：

1. 截获 $c = m^e \bmod n$
2. 选随机 $r$，令 $c' = r^e c \bmod n$
3. 解密得 $m' = r m \bmod n$
4. $m = m' \cdot r^{-1} \bmod n$

**防御**：OAEP 填充（RSA-OAEP 已被证明 IND-CCA 安全）。

### 6. Fermat 分解

$p, q$ 接近时（$|p-q| < n^{1/4}$）：

$$\left(\frac{p+q}{2}\right)^2 - n = \left(\frac{p-q}{2}\right)^2$$

迭代检查 $a = \lceil \sqrt{n} \rceil, a+1, \dots$ 直到 $a^2 - n$ 为完全平方。

## Diffie-Hellman 密钥交换

依赖 CDH 假设（给定 $g, g^a, g^b$ 求 $g^{ab}$ 困难）。

```
Alice                          Bob
  a ← random                    b ← random
  A = g^a mod p             B
  ————————————————————————→
  ←————————————————————————  B = g^b mod p
  K = B^a = g^{ab}             K = A^b = g^{ab}
```

## ElGamal 加密

基于 DDH 假设。

- 密钥：私钥 $x$，公钥 $y = g^x \bmod p$
- 加密 $m$：选随机 $k$，输出 $(c_1, c_2) = (g^k, m \cdot y^k)$
- 解密：$m = c_2 \cdot c_1^{-x}$

## 数字签名

### RSA 签名

$$\sigma = m^d \bmod n \quad \text{（签名）}, \quad m \equiv \sigma^e \pmod n \quad \text{（验证）}$$

注意"私钥签名，公钥验证"与加密相反。

### ElGamal 签名

密钥：$y = g^x \bmod p$，私钥 $x$。

签名：选随机 $k$（$\gcd(k, p-1) = 1$），计算：

$$r = g^k \bmod p, \quad s = (H(m) - xr)k^{-1} \pmod{p-1}$$

验证：$g^{H(m)} \equiv y^r r^s \pmod p$。

## RSA 攻击实战路线

```
输入: (n, e, c) 或 (n, e) + 密文
│
├─ n 已有因子？       → factordb.com / 多公钥 gcd
├─ e = 3 ?            → 直接开立方 / Hastad 广播
├─ e 很大（≈ n）？     → Wiener 攻击
├─ 相同 n 不同 e ？    → 共模攻击
├─ n 完全平方附近？     → Fermat 分解
├─ p-1 光滑？          → Pollard p-1
├─ 其余               → Pollard Rho / 已知高位 Coppersmith
```

## 好的密码学实践

### 避免
- 相同 $n$ 分给多个用户
- 过小 $e$ 且不填充
- 过小 $d$
- $p, q$ 过于接近 / $p-1$ 光滑
- 自己"魔改"密码算法

### 推荐
- 使用标准库（PyCryptodome, libsodium, OpenSSL）
- OAEP 或 PSS 填充
- $e = 65537$
- $p, q$ 为安全素数（$p = 2p'+1$）
