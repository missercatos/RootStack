# 椭圆曲线密码 导读

本目录收录椭圆曲线密码（Elliptic Curve Cryptography）的笔记与总结。

## 参考书籍

- 《Guide to Elliptic Curve Cryptography》— Darrel Hankerson, Alfred Menezes, Scott Vanstone, Springer
- 《An Introduction to Mathematical Cryptography》— Jeffrey Hoffstein, Jill Pipher, Joseph H. Silverman, Springer
- 《The Arithmetic of Elliptic Curves》— Joseph H. Silverman, Springer（GTM 106）
- 《Rational Points on Elliptic Curves》— Joseph H. Silverman, John T. Tate, Springer

## GitHub 仓库 & 在线资源

- [python-ecdsa](https://github.com/warner/python-ecdsa) — Python ECDSA 实现
- [ecdsa](https://github.com/tls-attacker/TLS-Attacker) — ECDSA 签名验证
- [SageMath](https://github.com/sagemath/sage) — ECC 点运算与攻击
- [CryptoHack - Elliptic Curves](https://cryptohack.org/challenges/elliptic-curves/) — ECC 练习
- [Awesome ECC Papers](https://github.com/Anon-Exploiter/awesome-ecc) — ECC 资源合集

## 覆盖内容

椭圆曲线群运算、ECDLP、Pohlig-Hellman、Smart攻击、MOV攻击、ECDSA/EdDSA、双线性对
