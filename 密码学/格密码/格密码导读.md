# 格密码 导读

本目录收录格密码（Lattice-Based Cryptography）的笔记与总结。

## 参考书籍

- 《An Introduction to Mathematical Cryptography》— Hoffstein, Pipher, Silverman, Springer（格相关章节）
- 《Lattice-Based Cryptography: From Theory to Practice》— Máire O'Neill et al., Springer
- 《Modern Cryptography Volume 2: Post-Quantum Cryptography》— Zhiyong Zheng et al., Springer（开放获取）
- 《The LLL Algorithm: Survey and Applications》— Phong Q. Nguyen, Brigitte Vallée, Springer

## GitHub 仓库 & 在线资源

- [fpylll](https://github.com/malb/fpylll) — Python LLL 格约简库
- [flintlib](https://github.com/wbhart/flint2) — 数论与格运算库
- [SageMath LLL](https://doc.sagemath.org/html/en/reference/matrices/sage/matrix/matrix_integer_dense.html) — SageMath 格攻击实现
- [CryptoHack - Lattices](https://cryptohack.org/challenges/lattices/) — 格密码练习

## 覆盖内容

LLL 算法、背包密码攻击、近似 GCD (AGCD)、Hidden Number Problem (HNP)、LWE/RLWE、SVP/CVP 问题
