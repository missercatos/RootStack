# 侧信道分析 导读

本目录收录侧信道分析（Side-Channel Analysis）的笔记与总结。

## 参考书籍

- 《The Hardware Hacking Handbook: Breaking Embedded Security with Hardware Attacks》— Jasper van Woudenberg, Colin O'Flynn, No Starch Press
- 《Security Engineering: A Guide to Building Dependable Distributed Systems》— Ross Anderson, Wiley（密码实现章节）
- 《Embedded Cryptography 1》— Prouff, Renault et al., Wiley（2025）
- 《Cryptography and Embedded Systems Security》— Springer

## GitHub 仓库 & 在线资源

- [ChipWhisperer](https://github.com/newaetech/chipwhisperer) — 开源侧信道分析工具/硬件平台
- [dudect](https://github.com/oreparaz/dudect) — 常量时间实现检测工具
- [SCAFFARI](https://github.com/AES-SCA/SCAFFARI) — 侧信道分析框架
- [SideChannelMarvels](https://github.com/SideChannelMarvels) — 侧信道攻击工具合集

## 覆盖内容

时序攻击、功耗分析 (SPA/DPA)、电磁侧信道、缓存侧信道 (Flush+Reload)、故障注入、RSA-CRT 故障攻击
